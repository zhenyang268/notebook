## 一、定位与边界

本项目是一套配套工程，用于实现从零到可训练的前向、反向流程，覆盖 CMU 11-785 课程主线。它解决的问题有三个：梯度到底从哪来，即用 NumPy 手写 MLP 并把每个偏导写成可检验的代码；自动微分如何把手工推导变成通用机制；变长序列如何与标签对齐并解码，即从 RNN 到 CTC 再到注意力。它不解决分布式训练、推理部署与量化、大规模预训练、CUDA 算子编写。与相邻项目的分工是：机器学习基础项目负责优化理论与泛化分析，本项目负责网络结构与梯度实现，语音与自然语言应用项目负责数据采集与产品级流水线。

## 二、整体架构

模块划分与职责：

- `config/`：YAML 配置解析与实验快照，保证可复现；
- `data/`：特征提取、变长批处理、padding 与长度记录；
- `numpy_layers/`：Linear、ReLU、SoftmaxCrossEntropy、Conv2D、Pool、BatchNorm、Dropout 的前向与手写反向；
- `autograd/`：微型反向模式引擎，含 `Tensor`、`Function`、拓扑排序与广播梯度归约；
- `models/`：MLP、CNN、RNN/LSTM、Transformer 的组网代码；
- `ctc/`：前向-后向格子计算、log-sum-exp、贪心与 beam 解码；
- `train/`：训练循环、优化器、学习率调度、检查点与日志；
- `eval/`：编辑距离、PER/WER、混淆对分析。

调用方向是单向的：`config → data → models → ctc/loss → train → eval`；`numpy_layers` 与 `autograd` 是被 `models` 依赖的叶子模块，`tests/` 横切所有模块做数值校验。

## 三、技术选型与理由

Python 3.10：类型注解与 `match` 便于写清晰的张量形状契约，替代方案 C++ 会让手写反向的调试成本不可接受。

NumPy：手写阶段只允许它，因为显式写出 `dW = X.T @ dout` 才能暴露形状错误；纯 Python 循环慢两个数量级，无法完成梯度检验。

PyTorch：自动微分与 GPU 阶段使用。选它而非 TensorFlow，是因为动态图让断点与 `print` 直接落在真实计算上，便于和手写版本逐行对照；选它而非 JAX，是因为课程生态与预训练权重都在 PyTorch 侧。

torchaudio：fbank 特征与课程提供的特征口径一致，避免自己写 STFT 引入窗函数与归一化偏差。

pytest：参数化 fixture 适合批量跑形状与数值用例，替代 unittest 可少写一半样板。

TensorBoard：曲线与直方图足以定位不收敛，替代 W&B 可离线运行。

## 四、数据流

以 16 kHz 语音、25 ms 窗、10 ms 帧移为例。输入 `waveform: (N=32, T_samples≈40000)`；特征阶段得到 `fbank: (32, 400, 40)`，经 3 帧拼接或下采样成 `(32, 200, 120)`；模型编码器输出 `logits: (32, 200, V+1)`，`V+1` 含 CTC blank；`log_probs = log_softmax(logits, dim=-1)`；损失为标量 `ctc_loss`；反向传播得到各参数梯度；解码输出 `List[str]`，每样本一条音素串；与标签比对经编辑距离得 PER。批内所有张量附带 `input_lengths: (N,)` 与 `target_lengths: (N,)`，它们是 CTC 格子的边界条件，缺失即报错。

## 六、验收判据

- 梯度检验：float64 下对 MLP 全部参数随机抽 50 个分量，中心差分相对误差 `< 1e-6`。
- 与 PyTorch 对照：同初始化同数据，10 步后参数最大绝对偏差 `< 1e-5`。
- 微型 autograd 引擎：16/16 单元测试通过，覆盖广播归约、同一变量被多次使用、对不可求导张量调用 `backward` 时报错。
- CTC 正确性：`T≤8, L≤4` 的全部枚举样本上，前向算法与暴力边缘化的相对误差 `< 1e-6`；与 `torch.nn.CTCLoss` 偏差 `< 1e-5`。
- CNN 任务：验证集准确率 `≥ 0.85`，训练与验证差距 `< 5` 个百分点。
- 端到端语音：贪心解码 PER `≤ 0.30`，beam=10 相对贪心至少降低 2 个绝对百分点。
- 吞吐：GPU 单卡 batch=32 每 epoch `< 6 min`；同结构 NumPy 与 PyTorch 单 epoch 加速比 `≥ 20x`。
- 稳定性：3 个随机种子下 PER 标准差 `< 0.02`。

## 七、风险与已知坑

CTC 全程必须用 log 域，`T=200` 时概率连乘必然下溢；不可能路径初始化为 `-inf` 而非 0。padding 位置的 logits 若参与损失会让 blank 主导梯度，mask 形状 `(N,T,1)` 与 `(N,1,V)` 的广播极易写错。PyTorch 的 `grad` 默认累加，忘记清零时前十几步看起来完全正常。BatchNorm 的 `train/eval` 模式与 running stats 必须显式切换。卷积反向经 im2col 后要用 scatter-add 还原，用赋值会静默丢梯度。帧移与模型下采样因子不一致会让特征长度与标签长度对不上，CTC 直接报错或学不到对齐。BPTT 需裁剪梯度范数到 5 附近。
