## 一、它解决什么问题

这项能力要拦住两类问题：真实工程里“能跑但规模一大就崩”的实现，以及面试里“会写但讲不清为什么对”的答题。

场景一：日志去重或区间合并，常见输入规模 $n=10^5\sim10^6$，秒级时限。若用双重循环判重，$O(n^2)$ 在 $n=10^5$ 时约 $10^{10}$ 次比较，基本不可接受；排序后双指针可到 $O(n\log n)$，哈希可到期望 $O(n)$，但哈希最坏会退化，必须能说明。场景二：任务依赖图或链表式队列，节点量 $10^4\sim10^5$，没有环检测、哑结点或访问状态，线上表现为死循环、断链、重复入队；面试里对应“判断环”“合并链表”“拓扑排序”，考的是指针不变量和访问状态，不是背模板。

它解决的不是“多刷几题”，而是把题型、复杂度、边界和证明口径对齐。

**入口（本文的读法）**：在 algorithm-interview 的 $n=10^5\sim10^6$、秒级时限、面试官追问 `while` 循环次数、递归栈深度、哈希冲突链的约束下，解决日志去重、区间合并、任务依赖图、链表队列中能跑但规模一大就崩的问题，换成可验证的数据结构选择：排序双指针、哈希桶、邻接表/入度数组、`next` 指针与 `visited` 状态。换的是题型识别、比较指令次数/缓存行访问估算、边界枚举和循环不变量/

**不换的是什么**：全程不变的是输入规模 $n$ 与时限/内存预算对应的比较指令次数、缓存行访问、栈帧深度，数据结构访问路径（数组下标、哈希桶、链表 `next`、图邻接表与入度），边界状态（空输入、重复值、环、断链、重复入队）和证明口径（循环不变量、状态转移覆盖、递归终止条件），所以看到差异先问：$n$、秒级时限、内存页/缓存行预算是否变，哈希桶冲突链是否最坏退化，`next` 指针不变量是否仍成立，`visited`/入度数组是否覆盖所有入队出队路径。

## 二、为什么这样做（方法论设计）

关键取舍是：**只把可复现、可证伪的结果算数**。

有口径才算数的做法包括：代码能编译运行；给出时间/空间上界并说明推导；写出循环不变量或 DP 状态定义；覆盖空、单元素、重复、有序、极值、溢出、环、非连通等边界；用小规模暴力解随机对拍。看起来专业但无法证伪的包括：“刷了 N 百题”“这题有手感”“复杂度大概是线性的”“模板我熟”。题量不是指标，盲写通过率、对拍零反例、讲解完整率才是。

指标按题型记：一次盲写通过率、边界用例通过率、暴力对拍通过率、复杂度推导正确率、口述时能否在 3 分钟内说清“状态/不变量—转移/步骤—终止—复杂度”。边界要按题目约束划：数据范围决定算法档位，$n\le 20$ 可考虑指数级，$n\le 10^5$ 通常要求 $O(n\log n)$ 或更优；但常数、语言、内存限制会改变结论，按实现而定。

这套方法会失效的情形：题目约束缺失或隐藏；最优解依赖强常数优化；面试官只考沟通不考代码；题库答案本身有争议。

常见错误做法及代价：只背模板，遇到变体无法迁移，调试时间翻倍；不写暴力对拍，边界错一个就全错；先写“最优解”再补证明，往往状态定义错、转移漏项，返工成本最高；用大 O 掩盖实际循环，$O(n)$ 代码里套了排序仍宣称线性，面试追问即暴露。

## 三、章节大纲

### 数组与双指针
讲下标语义、区间开闭、原地修改、相向/同向双指针、滑动窗口、前缀和。学完能回答：为什么双指针不会漏解？窗口收缩条件怎么定？$O(n)$ 的摊还依据是什么？

### 字符串
讲字符编码边界、子串/子序列区别、哈希与冲突、KMP/字典树的选择、回文与分词。学完能回答：字符串比较为什么不能默认 $O(1)$？哈希冲突如何处理？子序列题为何常用 DP 而非滑窗？

### 链表
讲哑结点、快慢指针、断链与合并、环检测、反转区间。学完能回答：怎样证明快慢指针一定相遇？删除节点时边界条件是什么？为什么链表题先画指针图？

### 栈队列与堆
讲单调栈/队列、括号与表达式、BFS 队列、堆的 top-k 与延迟删除。学完能回答：何时用单调栈而不是暴力？堆的 $O(\log n)$ 操作对应哪一步？优先队列如何保证答案正确？

### 树与图
讲遍历序、递归/迭代、二叉搜索树性质、拓扑排序、最短路与连通性。学完能回答：DFS 与 BFS 的适用边界？有环图为什么不能直接拓扑排序？访问标记放在入队还是出队？

### 二分与排序
讲二分答案、边界收缩、排序稳定性、比较器、归并/快排/堆排取舍。学完能回答：二分循环条件怎么写才不漏？答案单调性如何证明？排序题何时必须稳定？

### 动态规划
讲状态定义、转移、初始化、遍历顺序、空间压缩、区间/背包/序列 DP。学完能回答：状态为什么无后效性？转移漏了哪类情况？一维压缩后为何要倒序？

### 回溯与贪心
讲搜索树、剪枝、去重、排列组合、贪心选择与交换论证。学完能回答：回溯复杂度怎么估？剪枝是否改变正确性？贪心为什么局部最优能到全局？

## 四、不做什么 · 必要性 · 失效点

### 必要性：删掉会怎样

| 机制 | 删掉会怎样 | 判定 |
|---|---|---|
| 排序后双指针 | 删掉排序数组与双指针扫描，区间合并的 $O(n\log n)$ 承诺破，$n=10^5\sim10^6$ 时在 1s 时限内无法输出合并区间。 | 选择 |
| 哈希 | 删掉哈希桶判重，日志去重的期望 $O(n)$ 承诺破，退化为双重循环判重 $O(n^2)$ 或排序后双指针 $O(n\log n)$。 | 选择 |
| 环检测 | 删掉访问状态数组或快慢指针环检测，任务依赖图拓扑排序与链表式队列承诺破，`while(next)` 或 DFS 递归进入死循环。 | 必需 |
| 哑结点 | 删掉合并链表中的哑结点，头节点替换/删除边界承诺破，`head` 指针更新遗漏导致返回旧头或断链。 | 选择 |
| 暴力解随机对拍 | 删掉小规模暴力解随机对拍，边界用例通过率承诺破，空、单元素、重复、有序、极值、溢出、环、非连通等错误无法被证伪。 | 必需 |

### 失效点：哪条前提一破，结论就变

- 1s 时限、$n=10^5$、哈希桶负载因子 0.75 且冲突链长度超过阈值 → 哈希期望 $O(n)$ 结论变双重循环判重 $O(n^2)$，必须切换排序后双指针或平衡树扫描。
- 8MB 线程栈、任务依赖图深度 $>10^4$ → 环检测 DFS 递归帧溢出，必须切换显式栈或拓扑排序入度数组。
- 64MB 内存限制、输入对象含 `next` 指针 + 访问状态数组 + 哈希桶 → 哈希 $O(n)$ 空间承诺破，必须切换排序数组双指针。
- 随机对拍种子固定、暴力解枚举范围仅 $n\le20$ → 边界用例通过率不能证明 $n=10^5$ 区间合并，必须扩展重复、有序、极值、溢出、非连通用例。

### 不做什么（范围）

不把 408 考点（组成原理、操作系统、网络等）混进来；不教具体语言语法和 STL/集合 API 细节；不承诺覆盖所有竞赛高级算法（如后缀自动机、Link-Cut Tree）；不做完整在线判题系统；不替系统设计、项目经历和简历包装。题库只收按题型可复用的核心解法与证明口径；偏题、依赖特定评测机常数、答案有争议的题不纳入主路径。语言相关只保留与复杂度/边界有关的必要说明，其余交给对应语言层。

## 五、面试怎么讲

**30 秒版本**：我按题型整理算法面试题，重点不是背答案，而是把每道题落到四件事：状态或不变量、复杂度上界、边界清单、暴力对拍。现场拿到题，我先确认约束和数据范围，再给可证明的解法；如果只能写模板，我会说明适用条件和失效场景。证明方式是讲清推导、跑边界用例，并用小规模随机对拍检查，不靠“刷题量”自证。

**可能被追问的 6–8 个点**

1. 问法：“这题你凭什么说 $O(n)$？”→ 考点：复杂度推导。答：指出每个下标最多进/出窗口一次，摊还 $O(n)$；若中间有排序，改为 $O(n\log n)$，并说明排序位置。用主定理或摊还分析，不口头保证。
2. 问法：“双指针为什么不会漏解？”→ 考点：不变量。答：写出窗口不变量，说明移动哪端由单调性决定；用 $n\le 8$ 的暴力脚本随机对拍，判据是零反例。
3. 问法：“链表环检测怎么证？”→ 考点：快慢指针。答：slow 一步、fast 两步，有环必相遇；再推导入口位置。边界测空/单节点，用 AddressSanitizer/UBSan 查越界。
4. 问法：“二分边界怎么写？”→ 考点：循环不变量。答：统一区间语义为 $[lo,hi)$ 或闭区间，更新必须缩小区间；判据是循环结束 $lo=hi$ 且答案在候选集，用 `lower_bound` 对照。
5. 问法：“DP 状态怎么定？”→ 考点：无后效性。答：先定义 `dp[i]` 语义，再写转移、初始化、依赖顺序；用暴力递归加 memo 对小数据对拍。
6. 问法：“图 BFS 标记时机？”→ 考点：重复入队。答：入队时标记，避免同一节点多次入队；非连通图外层遍历；复杂度 $O(V+E)$。
7. 问法：“贪心为什么对？”→ 考点：交换论证。答：给出交换步骤，说明不劣于最优解；同时举反例检验，不能只举例。
8. 问法：“回溯剪枝会不会剪错？”→ 考点：搜索树。答：剪枝只能删不可能产生解的枝；去重先排序再同层跳过；复杂度按搜索树节点数估，不保证多项式。

**别说什么**

- “这题我背过模板”——暴露不能迁移；改说适用条件与失效场景。
- “复杂度肯定是 $O(n)$”——没有摊还或主定理推导，追问即崩。
- “我全部刷完了 / 实测提升 N 倍”——未经证实；改说口径、判据和可复现检查方式。
- “贪心/DP 凭感觉”——没有状态定义或交换论证，等于没答。
