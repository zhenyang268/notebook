# algorithm-interview · 分章详细

## 第 1 章 题型：数组与双指针

**识别特征**：题目给一个数组（往往附加「有序」「原地」「连续子数组」三个词之一），要求找一对或一组元素、调整元素位置、或维护某段区间的极值。答案与下标区间强相关，暴力做法通常是 $O(n^2)$ 或 $O(nk)$，而这类题几乎都能把区间收缩成线性扫描。

**通用套路**：先问数组是否有序——有序就走左右夹逼；无序且要配对，就用哈希表换时间。原地修改用「读写指针」，写指针之前的区间永远是已经处理好的结果。连续区间用滑动窗口，右指针扩张、左指针收缩，收缩条件的单调性决定它是否正确。求区间极值用单调队列或单调栈，保证每个元素只进出一次。二分题先统一区间定义（闭区间还是半开区间），再写循环，边界自然就对了。

---

**1. 两数之和（LC 1）**
- **题意**：无序数组里找两个下标，使其和等于 target。
- **关键一步**：边遍历边建哈希表 `{值: 下标}`，对当前 `x` 先查 `target - x`，查不到再把 `x` 存进去。
- **复杂度**：时间 $O(n)$，空间 $O(n)$。
- **常见错法**：先存后查——`[3,2,4], target=6` 时 $i=0$ 会查到自己，返回 `[0,0]`。

**2. 两数之和 II（LC 167，有序数组）**
- **题意**：非递减数组，找两个数（1-based 下标）之和为目标值。
- **关键一步**：`l=0, r=n-1`，和偏小移 `l`，偏大移 `r`，相等即返回。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：循环条件写成 `l <= r`，多算一轮；或返回下标忘加 1。

**3. 三数之和（LC 15）**
- **题意**：找出所有不重复的三元组，和为 0。
- **关键一步**：排序后固定 `nums[i]`，在 `i+1..n-1` 上跑两数之和双指针；固定时若 `nums[i] == nums[i-1]` 则跳过。
- **复杂度**：时间 $O(n^2)$，空间 $O(1)$（不计排序与输出）。
- **常见错法**：去重条件写成 `nums[i] == nums[i+1]`，把 `[-1,-1,2]` 这类解跳掉；或双指针命中后只移一边，忘记跳过重复值。

**4. 移动零（LC 283）**
- **题意**：把所有 0 移到末尾，非零元素相对顺序不变，原地完成。
- **关键一步**：`slow` 指向下一个待写位置，遍历 `fast`，遇非零就 `nums[slow++] = nums[fast]`，最后把 `slow..n-1` 补 0。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：覆盖写法忘记补零；交换写法里 `slow == fast` 时仍 swap，虽然结果对但多写一次，面试官会追问能否只写一次。

**5. 盛最多水的容器（LC 11）**
- **题意**：两条竖线加 x 轴围成的最大面积。
- **关键一步**：左右指针从两端夹，每步算 `(r-l) * min(h[l], h[r])`，然后移动较矮的一侧。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：移动较高一侧——高度不可能变高而宽度一定变小，答案必被跳过。

**6. 接雨水（LC 42）**
- **题意**：每根柱子宽度 1，求总共能接多少雨水。
- **关键一步**：双指针维护 `maxL, maxR`；每步先更新两侧最大高度，再比较 `maxL < maxR`：成立则结算 `maxL - h[l]` 后 `l++`，否则结算 `maxR - h[r]` 后 `r--`。
- **复杂度**：时间 $O(n)$，空间 $O(1)$（双指针法）。
- **常见错法**：先结算再更新最大值，或先移动指针再结算，边界柱会算出负数。

**7. 二分边界（LC 704 变体）**
- **题意**：有序数组里找第一个 $\ge target$ 的位置，不存在返回 $n$。
- **关键一步**：半开区间 `[lo, hi)`，`while lo < hi`，`mid = lo + (hi - lo) / 2`；`nums[mid] < target` 则 `lo = mid + 1`，否则 `hi = mid`；返回 `lo`。
- **复杂度**：时间 $O(\log n)$，空间 $O(1)$。
- **常见错法**：循环条件用 `lo <= hi` 配半开区间，导致死循环；`mid` 写成 `(lo + hi) / 2` 在大下标下溢出（按语言而定）；返回值在 `lo` 与 `hi` 之间犹豫——循环结束时两者相等。

**8. 滑动窗口最大值（LC 239）**
- **题意**：长度 $k$ 的窗口从左滑到右，返回每个窗口内的最大值。
- **关键一步**：单调递减队列存下标；入队前从队尾弹掉所有 $\le nums[i]$ 的下标，队头下标 $\le i-k$ 时弹出队头。
- **复杂度**：时间 $O(n)$，空间 $O(k)$。
- **常见错法**：队列只存值不存下标，无法判断队头是否已滑出窗口；或先取答案再入队，窗口还没凑满 $k$ 就输出。

**9. 长度最小的子数组（LC 209）**
- **题意**：正整数数组，求和 $\ge target$ 的最短连续子数组长度。
- **关键一步**：右指针累加 `sum`，当 `sum >= target` 时用 `while` 持续更新答案并 `sum -= nums[l++]`。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：收缩用 `if` 而不是 `while`，一个右端点只缩一次会漏掉更短解；或返回时漏写 `ans == INF ? 0 : ans`。

**10. 删除有序数组中的重复项（LC 26）**
- **题意**：原地去重，返回新长度，前 $k$ 个元素为去重结果。
- **关键一步**：`slow = 0`，`fast` 从 1 开始，当 `nums[fast] != nums[slow]` 时执行 `nums[++slow] = nums[fast]`。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：返回 `slow` 而不是 `slow + 1`，长度少 1；把 `nums[++slow]` 写成 `nums[slow++]`，先写后移会覆盖当前元素。

## 第 2 章 题型：字符串

**要解决的问题**：把散落在字符串里的题归成有限几类可复用的处理模式，让人看到「回文」「子串」「匹配」「翻转」能立刻定位到对应模板。不解决这一章，字符串题就会变成一题一背，面试时写出的代码边界全靠运气。

**识别特征与通用套路**

识别特征通常是三句话：题目给的是 `char` 序列而不是数字；答案要求「子串 / 子序列 / 匹配位置 / 重排」；约束里出现「长度 10^5」意味着必须接近 $O(n)$ 或 $O(n\log n)$。

字符串题只有五个基本要素：**字符集大小**、**是否连续**、**是否有序**、**是否可原地修改**、**是否有通配/失配**。根据这五个要素选择模板：求「连续子串」优先考虑滑动窗口（无重复最长子串、最小覆盖子串）；求「回文」分为中心扩展（连续）和区间 DP（不连续）两条路线；求「模式匹配」用 KMP（单模式、无通配）或 DP（带 `*`、`.` 这类通配）；求「重排 / 翻转」用双指针或三次反转；求「按规则展开」用栈。

工程实现层面非常实用的三条：字符集固定（小写字母、ASCII）时用 `int[26]` / `int[128]` 计数，比哈希表快且好写；字符串不可变时（Java、Python、Go）所谓的「原地」其实做不到，必须先转成字符数组；所有双指针都可能出现 `left <= right` 还是 `left < right` 的判断分歧，先把区间定义写死（左闭右开还是左闭右闭），再写代码。

**KMP 的 next 数组**（`next[i]` 定义为 `p[0..i]` 的**最长相等真前缀=真后缀长度**）：

```python
def build_next(p):
    nxt = [0] * len(p)
    k = 0
    for i in range(1, len(p)):
        while k > 0 and p[i] != p[k]:
            k = nxt[k - 1]        # 失配：退到次长 border，不回到 0
        if p[i] == p[k]:
            k += 1
        nxt[i] = k
    return nxt
```

**最小例子**：`p = "ababaca"` 建成 `nxt = [0,0,1,2,3,0,1]`。用 `s = "abababaca"` 匹配：前 5 个字符一路匹配到 `j = 5`（已匹配 `"ababa"`），此时 `s[5]='b'` 对 `p[5]='c'` 失配，执行 `j = nxt[4] = 3`，直接拿 `s[5]` 去比 `p[3]='b'`，命中，继续推进，最终在 `s[2..8]` 处得到 `"ababaca"`。关键是 `j` 从 5 退到 3 而不是退到 0，省掉了 3 次必然成立的比较；这就是 KMP 能做到 $O(n+m)$ 的全部原因。

---

1. **实现 strStr()（KMP）**
   - **题意**：返回模式串 `p` 在文本串 `s` 中第一次出现的下标，没有则 `-1`。
   - **关键一步**：先花 $O(m)$ 建 `nxt`，主循环里只对 `s` 前进、对 `j` 用 `while` 回退，绝不回退 `i`。
   - **复杂度**：时间 $O(n+m)$，空间 $O(m)$。
   - **常见错法**：回退写 `j = nxt[j]`（应为 `nxt[j-1]`，差一位就死循环或漏解）；`p` 为空串没特判。

2. **最长回文子串（中心扩展）**
   - **题意**：求最长的连续回文子串。
   - **关键一步**：枚举 $2n-1$ 个中心（奇数中心 $i,i$；偶数中心 $i,i+1$），向两侧扩到不相等为止。
   - **复杂度**：时间 $O(n^2)$，空间 $O(1)$。
   - **常见错法**：只枚举了 $n$ 个单字符中心，漏掉偶数长度的回文（如 `"abba"`）；记录结果时用长度算区间端点，`start = i - (len-1)//2` 写反。

3. **最长回文子序列**
   - **题意**：求最长的不要求连续的回文子序列长度。
   - **关键一步**：区间 DP，`dp[i][j]` 在 `s[i]==s[j]` 时等于 `dp[i+1][j-1]+2`，否则取 `max(dp[i+1][j], dp[i][j-1])`。
   - **复杂度**：时间 $O(n^2)$，空间 $O(n^2)$。
   - **常见错法**：把遍历顺序写成 `i` 从小到大、`j` 从小到大，导致 `dp[i+1][j-1]` 还没算；初始化只填了对角线而忘了 `dp[i][i-1] = 0` 这个空区间。

4. **字符串解码（394）**
   - **题意**：把 `"3[a2[c]]"` 展开成 `"accaccacc"`。
   - **关键一步**：遇到数字累积 `multi`，遇 `[` 把 `(当前串, multi)` 压栈并把两者清空，遇 `]` 弹栈并拼接 `prev + cur * multi`。
   - **复杂度**：时间 $O(\text{输出长度})$，空间 $O(\text{嵌套深度} + \text{输出长度})$。
   - **常见错法**：把 `multi` 当单字符处理（`"12[a]"` 会错）；遇 `[` 压栈后没把 `multi` 归零，导致后面的 `2[c]` 用错倍数。

5. **翻转字符串里的单词（151）**
   - **题意**：`"  hello world  "` → `"world hello"`，词序反转、多余空格压缩成一个。
   - **关键一步**：若可原地，整体反转再逐词反转；若不可原地，从右往左扫描、跳过空格、截出单词追加。
   - **复杂度**：时间 $O(n)$，空间 $O(n)$（不可原地）/ $O(1)$ 额外（可原地）。
   - **常见错法**：只处理了词间单空格，首尾空格和连续空格没跳；原地实现里单词反转的右端点写成 `r` 而不是 `r-1`。

6. **正则表达式匹配（10）**
   - **题意**：实现支持 `.`（任意单字符）和 `*`（前一个字符出现零次或多次）的完全匹配。
   - **关键一步**：`dp[i][j]` 表示 `s` 前 `i` 个和 `p` 前 `j` 个是否匹配；`p[j-1]=='*'` 时拆成「`*` 取零次」`dp[i][j-2]` 与「取一次」`match(s[i-1], p[j-2]) and dp[i-1][j]`。
   - **复杂度**：时间 $O(mn)$，空间 $O(mn)$（可滚到 $O(n)$）。
   - **常见错法**：`*` 只写了「零次/一次」的其中一支；`dp[0][j]` 的初始化没处理 `a*b*c*` 能匹配空串；索引上把 `p[j]` 和 `p[j-1]` 混用。

7. **无重复字符的最长子串（3）**
   - **题意**：求不含重复字符的最长连续子串长度。
   - **关键一步**：右指针扩、用计数表判重，一旦冲突就左指针收缩到冲突字符退出窗口。
   - **复杂度**：时间 $O(n)$，空间 $O(\Sigma)$，$\Sigma$ 为字符集大小。
   - **常见错法**：左指针写成 `left = i`（应跳到冲突字符上次出现的下一位）；用哈希表存「出现次数」但 `while` 条件写成 `if`，遇到连续冲突收不干净。

8. **最小覆盖子串（76）**
   - **题意**：在 `s` 中找覆盖 `t` 全部字符（含重复次数）的最短子串。
   - **关键一步**：`need` 计数 + `valid` 记录「已达标的字符种类数」，`valid == len(need)` 时才尝试收缩左边界更新答案。
   - **复杂度**：时间 $O(n)$，空间 $O(\Sigma)$。
   - **常见错法**：把 `valid` 当「已匹配字符总数」用（重复字符会重复计数）；收缩时先更新答案再减计数，导致 `[left, right]` 区间与答案差一位。

9. **字符串相加（415）**
   - **题意**：不用大整数库，求两个十进制字符串的和。
   - **关键一步**：双指针从两个串尾部走，`sum = a + b + carry`，当前位 `sum % 10`、新进位 `sum // 10`，循环条件带上 `carry`。
   - **复杂度**：时间 $O(\max(m,n))$，空间 $O(1)$ 额外（不计返回值）。
   - **常见错法**：循环条件只写两个指针都非负，最高位进位丢掉（`"9"+"1"` 返回 `"0"`）；字符转数字用了 `ord(c) - ord('a')`。

10. **最长公共前缀（14）**
    - **题意**：求字符串数组的最长公共前缀。
    - **关键一步**：以 `strs[0]` 为基准做纵向扫描，第 `i` 位只要有任意串越界或不等就返回 `strs[0][:i]`。
    - **复杂度**：时间 $O(S)$（$S$ 为所有串总字符数，最坏情形），空间 $O(1)$ 额外。
    - **常见错法**：只跟相邻串两两取前缀，走进「两两合并顺序」的坑；空数组没返回 `""`。

**面试高频问法**

- 「KMP 的 next 数组表示什么，为什么失配时跳到 `nxt[j-1]` 而不是回到 0？」→ 考点是 border（相等真前后缀）的性质与复杂度证明 → 答法：`nxt[j-1]` 是已匹配部分的最长 border，跳到它既保证前缀仍然对齐，又跳过了所有不可能匹配的位置；因为每次失配 `j` 严格减小、而 `j` 的总增量不超过 $n$，总比较次数是 $O(n)$。
- 「最长回文子串中心扩展是 $O(n^2)$，Manacher 优化在哪？」→ 考点是回文的对称性复用 → 答法：Manacher 用已求出的回文半径，对当前中心在一个已知回文区间内的部分直接取对称点的半径作初值，只在超出右边界时才真正扩展，从而把总扩展次数摊还到 $O(n)$；实现上要先插入分隔符把奇偶统一。
- 「正则匹配为什么用 DP 而不是贪心？」→ 考点是 `*` 的分支不确定性 → 答法：`a*` 匹配多少个 `a` 是真正的分支，贪心在后继字符需要这些 `a` 时会错（如 `s="aaa", p="a*a"`），DP 把「取零次」和「再吃一个」两个分支都枚举，状态数 $O(mn)$，天然覆盖全部情况。
- 「翻转单词怎么做到 $O(1)$ 额外空间？」→ 考点是字符串可变性这个语言差异 → 答法：在 C 里字符串是 `char*`，整体反转 + 逐词反转可以原地做；Java、Python、Go 的字符串不可变，必须先转字符数组，额外空间是 $O(n)$ 而不是 $O(1)$，面试时要主动说明这一点。
- 「字符串题该用什么哈希结构？」→ 考点是字符集意识 → 答法：字符集封闭且小（小写字母、ASCII）时用定长数组，访问 $O(1)$ 且无哈希开销；只有字符集开放（Unicode、任意 token）时才用 `dict`，此时要额外考虑哈希碰撞与最坏 $O(n)$ 退化。

## 第 3 章 题型：链表

**要解决的问题**：链表是唯一一类「算法本身很简单，但面试时手写准确率最低」的题型。这一章解决两件事：一是把指针改写拆成可复用的固定套路（哨兵、快慢指针、头插、哈希映射），二是在白板上不借助调试器也能一次写对。

**识别特征与通用套路**：题目给出 `ListNode`（`val` + `next`，可能多一个 `random`），要求原地重排或 $O(1)$ 额外空间，基本就是链表题。看到「不能改值只能改指针」「$O(1)$ 空间」几乎必然指向指针改写；看到「$O(1)$ 时间 + 淘汰策略」指向双向链表加哈希；看到「随机指针」指向哈希映射两遍扫描。四条通用套路：① **改头、删头、合并一律先挂 `dummy`**，返回 `dummy.next`，消掉 `head == null` 特判；② **快慢指针**负责定位（中点、环、倒数第 k）；③ **先存后改再移动**是改写指针的唯一安全顺序；④ 写完后必须能在脑内从新头走回 `null`，并且旧尾 `next` 为 `null`。

**机制**：以反转为主线，三个指针的循环不变式是「`prev` 之前已反转完毕，`cur` 及之后是原链」。

```python
prev, cur = None, head
while cur:
    nxt = cur.next      # 1. 先存：不然改完就找不到后面
    cur.next = prev     # 2. 再改：指向已反转段的头
    prev = cur          # 3. 后移动：prev 吃掉 cur
    cur = nxt           #    cur 前进到原链下一个
return prev             # 循环结束时 cur 为 None，prev 才是新头
```

环检测的数学也在这里定下：设头到入口距离 $a$、入口到相遇点距离 $b$、环长 $L$，慢走 $a+b$、快走 $2(a+b)$，差值 $a+b$ 必是 $L$ 的整数倍，所以从头和相遇点同速各走一步，第一次重逢就是入口（等价于 $a \equiv L-b \pmod L$）。LRU 的 $O(1)$ 来自两个结构的分工：哈希表负责「按 key 定位节点」，双向链表负责「$O(1)$ 摘挂」，缺任一个都会退化。深拷贝的关键是**先建完整映射再连边**，否则 `random` 指回前面节点时会重复创建甚至递归死循环。

**最小例子**：`head = 1→2→3→null`。初始 `prev=null, cur=1`；轮 1：`nxt=2`，`1.next=null`，`prev=1, cur=2`；轮 2：`nxt=3`，`2.next=1`，`prev=2, cur=3`；轮 3：`nxt=null`，`3.next=2`，`prev=3, cur=null`；返回 `prev=3`，结果 `3→2→1→null`。

**环入口例子**：`1→2→3→4→5`，`5.next = 2`（入口 2，$L=4$）。快慢从 1 出发，慢 1→2→3→4，快 1→3→5→3→5，相遇于 5；`head=1` 与 `meet=5` 同速走一步得 2 与 2，返回 2。

**1. 反转链表（206）**
- **题意**：把单链表整体反向，返回新头。
- **关键一步**：`prev=None, cur=head` 三指针循环，每轮先存 `cur.next`。
- **复杂度**：时间 $O(n)$，空间 $O(1)$；递归版时间 $O(n)$、栈空间 $O(n)$。
- **常见错法**：循环结束返回 `cur`（此时是 `null`）而不是 `prev`；忘了原头节点的 `next` 已被置空导致成环。

**2. 反转链表 II（92）**
- **题意**：只反转第 $m$ 到第 $n$ 个节点，一趟扫描。
- **关键一步**：`dummy` 挂在 `head` 前，走 $m-1$ 步拿到区间前驱 `pre`，之后在 `pre` 后面做 $n-m$ 次头插。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：头插时跟着改 `pre.next`，把已经接好的段打断；$m=1$ 时不挂 `dummy`，新头直接丢失。

**3. K 个一组翻转链表（25）**
- **题意**：每 $k$ 个节点翻一次，末尾不足 $k$ 个保持原序。
- **关键一步**：先走 $k$ 步确认本组够长并记下 `groupNext`，不够就直接返回，够了再翻转本组并接回前后。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：翻转后忘了把本组新尾接 `groupNext`；`pre` 更新成原组头而不是翻转后的新尾。

**4. 环形链表（141）**
- **题意**：判断链表中是否存在环。
- **关键一步**：快慢指针同头出发，慢一步、快两步，相遇即有环。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：`while` 只判 `fast.next != null` 漏判 `fast != null`，偶数长度链在尾后访问空指针。

**5. 环形链表 II（142）**
- **题意**：返回入环的第一个节点，无环返回 `null`。
- **关键一步**：先用快慢指针找相遇点，再让一个指针回到 `head`，两指针同速前进，重逢处即入口。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：直接返回相遇点（那是环内任意点不是入口）；相遇后新开循环忘了同步只走一步。

**6. 合并两个有序链表（21）**
- **题意**：把两条升序链表合成一条升序链表。
- **关键一步**：`dummy` + `tail`，比较两头谁小就把谁接到 `tail` 后，`tail` 后移。
- **复杂度**：时间 $O(m+n)$，额外空间 $O(1)$。
- **常见错法**：循环退出后只接了一条，忘了把剩下那条整段挂上；返回 `head` 而不是 `dummy.next`。

**7. 合并 K 个有序链表（23）**
- **题意**：$k$ 条有序链表合成一条。
- **关键一步**：容量为 $k$ 的小顶堆（或分治两两合并），先把所有非空头节点入堆，每弹一个就把它的 `next` 入堆。
- **复杂度**：堆法时间 $O(N\log k)$、空间 $O(k)$；分治法时间同为 $O(N\log k)$、递归栈 $O(\log k)$，$N$ 为总节点数。
- **常见错法**：弹出节点后忘了把 `node.next` 入堆，结果只合出前 $k$ 个；把 `null` 头也塞进堆导致比较空指针。

**8. 重排链表（143）**
- **题意**：重排成 $L_0\to L_n\to L_1\to L_{n-1}\to\cdots$。
- **关键一步**：快慢指针找中点 → 断开并反转后半 → 前后两半交替合并。
- **复杂度**：时间 $O(n)$，空间 $O(1)$。
- **常见错法**：快慢初值取错导致两半长度差一，合并时越界；反转后没把中点 `next` 置空，合并时成环。

**9. LRU 缓存（146）**
- **题意**：`get`/`put` 均 $O(1)$，容量满时淘汰最久未使用的 key。
- **关键一步**：哈希表 `key → node`，配合带 `head`/`tail` 哨兵的双向链表，节点同时存 `key` 和 `value`；命中就摘下来挂到头部。
- **复杂度**：时间 $O(1)$，空间 $O(\text{capacity})$。
- **常见错法**：节点只存 `value`，淘汰尾节点时拿不到 `key` 去删哈希表；`get` 命中后忘了把节点移到头部，访问序失效。

**10. 随机链表深拷贝（138）**
- **题意**：复制一条带 `next` 和 `random` 的链表，返回全新结构。
- **关键一步**：第一遍遍历只建「原节点 → 新节点」的映射，第二遍再统一连 `next` 和 `random`。
- **复杂度**：时间 $O(n)$，空间 $O(n)$。
- **常见错法**：边遍历边递归创建新节点，`random` 指回前面节点时重复创建甚至递归死循环；第二遍取 `next` 时忘了也从映射里查，接回了原节点。

---

**面试高频问法**

1. **「反转链表的递归版怎么理解？返回值到底是什么？」→ 考点在递归语义 → 答法**：递归函数返回的是「子链表反转后的新头」，每层只做两件事——把 `head.next.next` 指回 `head`、把 `head.next` 置空，最后逐层把新头往上抛。
2. **「快慢指针为什么一定相遇？入口点为什么是那个位置？」→ 考点在数学推导 → 答法**：快比慢每轮多走一步，进环后两者距离每轮缩小 1，必然追平；设头到入口 $a$、入口到相遇点 $b$，由 $2(a+b)-(a+b)=kL$ 得 $a \equiv L-b$，所以从头和相遇点同速走必在入口重合。
3. **「LRU 为什么非要用双向链表，单向链表不行吗？」→ 考点在 $O(1)$ 的代价来源 → 答法**：淘汰和提升都要删除一个已知节点，单向链表删它得先 $O(n)$ 找前驱，双向链表有 `prev` 可以原地改指针，才能保证 $O(1)$。
4. **「LRU 的节点为什么要额外存 key？」→ 考点在数据结构联动 → 答法**：淘汰尾节点时必须用它的 key 去哈希表里 `erase`，只存 value 就找不到要删的条目。
5. **「深拷贝能不能一遍扫描搞定？」→ 考点在环与随机指针 → 答法**：不能，`random` 可能指向尚未创建的节点；必须先把整条链的映射建全，第二遍连边，本质是用 $O(n)$ 空间换掉「节点是否已创建」的判断。

## 第 4 章 题型：栈、队列与堆

**识别特征**：题干里出现「最近/上一个/下一个更大（更小）」「括号匹配」「嵌套」「撤销」「后缀表达式」，先考虑栈；出现「滑动窗口最值」「窗口内的单调性」「先进先出」，先考虑队列（多数是单调队列）；出现「第 K 大 / 前 K 个 / 中位数 / 数据流 / 动态最值」，先考虑堆。数据规模 $n \le 10^5$ 又要求优于 $O(n^2)$ 时，基本可以排除「每个位置重新排序」这种写法。

**通用套路**：栈题第一个决定是栈里存下标还是存值——要算距离、宽度就必须存下标。单调栈的弹栈条件是「新元素破坏了栈的单调性」，弹栈那一刻就是结算答案的时刻，所以先写清「弹出时算什么」，再写循环。堆题先定三件事：堆里存什么、堆的大小上限是多少、堆顶代表什么。求 TopK 用小顶堆（堆顶是候选集里最差的那个，方便被淘汰）；求中位数用两个堆对顶，让两堆大小差不超过 1。所有「每个元素最多进一次、出一次」的结构，复杂度都是 $O(n)$，不要在循环里再套扫描。

---

- **有效括号（20）**
  - **题意**：只含 `()[]{}` 的字符串，判断括号是否按正确顺序闭合。
  - **关键一步**：遇左括号压栈；遇右括号时先判栈空，再比对栈顶是否为对应左括号并弹出；遍历结束后栈必须为空。
  - **复杂度**：时间 $O(n)$，空间 $O(n)$。
  - **常见错法**：右括号分支里先 `pop` 再判空，空栈直接抛异常；或者结尾漏写 `stack.isEmpty()`，把 `"("` 判成合法。

- **最小栈（155）**
  - **题意**：设计栈，支持 push/pop/top，并在 $O(1)$ 内取当前最小值。
  - **关键一步**：开一个辅助栈同步记录「压入该元素后栈内的最小值」，push 时压 `min(x, minStack.top())`，pop 时两个栈一起弹。
  - **复杂度**：四个操作均摊 $O(1)$，空间 $O(n)$。
  - **常见错法**：只在「新元素更小」时才压辅助栈，pop 却无条件弹辅助栈，两栈长度错位；正确做法是让两栈始终等长（允许重复压最小值）。

- **用栈实现队列（232）**
  - **题意**：只用两个栈实现队列的 push/pop/peek/empty。
  - **关键一步**：入队压入 in 栈；出队时若 out 栈为空，把 in 栈整体倒入 out 栈，再从 out 弹出；out 非空时绝不倒栈。
  - **复杂度**：push $O(1)$；pop/peek 摊还 $O(1)$、单次最坏 $O(n)$；空间 $O(n)$。
  - **常见错法**：每次 pop 都无条件倒栈，把摊还 $O(1)$ 写成 $O(n)$；或者倒栈时机搞反，在 out 非空时又倒一次，元素顺序被打乱。

- **每日温度（739）**
  - **题意**：给温度数组，对每天求「还要等几天才会出现更高温度」，没有则为 0。
  - **关键一步**：维护一个存下标的单调递减栈，新元素大于栈顶温度就循环弹栈，并令 `ans[idx] = i - idx`。
  - **复杂度**：时间 $O(n)$（每个下标进出栈各一次），空间 $O(n)$。
  - **常见错法**：栈里存温度值而不是下标，结算时算不出天数差；或者用 `while` 换成 `if`，只弹一个，遇到连续递增序列就错。

- **柱状图中最大的矩形（84）**
  - **题意**：给柱高数组，求能勾勒出的最大矩形面积。
  - **关键一步**：单调递增栈存下标，弹出时以「被弹元素为高」，左右第一个更矮的位置为边界，宽度为 `i - stack.top() - 1`；首尾各补一个 0 哨兵，省掉遍历结束后的清栈。
  - **复杂度**：时间 $O(n)$，空间 $O(n)$。
  - **常见错法**：宽度写成 `i - stack.top()` 漏减 1；或不补哨兵，遍历结束后栈里剩余元素没被结算，答案偏小。

- **接雨水（42）**
  - **题意**：给每根柱子的高度，求这些柱子之间总共能接多少雨水。
  - **关键一步**：单调递减栈存下标，遇到比栈顶高的柱子就弹出低洼底部，取 `min(左壁, 右壁) - 底高` 乘上宽度累加；左壁是弹出一个后的新栈顶。
  - **复杂度**：单调栈 $O(n)$ 时间 / $O(n)$ 空间；双指针法可做到 $O(n)$ 时间 / $O(1)$ 空间。
  - **常见错法**：弹出底部后忘了再取一次栈顶当左壁；高度差用当前柱高而非 `min(左右壁)`，把斜坡当成蓄水区多算。

- **滑动窗口最大值（239）**
  - **题意**：长度 $k$ 的窗口在数组上从左滑到右，返回每个窗口内的最大值。
  - **关键一步**：用双端队列存下标、维护递减序；入队前从队尾弹掉所有比它小的，队头下标 `<= i - k` 时弹出，队头即当前窗口最大值。
  - **复杂度**：时间 $O(n)$，空间 $O(k)$。
  - **常见错法**：队头越界判断写成 `<= i` 而不是 `< i - k + 1`，窗口长度多算一个；或者先取答案再入队，漏掉刚进窗口的新元素。

- **数据流的中位数（295）**
  - **题意**：不断 `addNum`，随时返回当前所有数的中位数。
  - **关键一步**：大顶堆存较小的一半、小顶堆存较大的一半，始终保持 `big.size() == small.size()` 或 `big.size() == small.size() + 1`，中位数从堆顶取。
  - **复杂度**：addNum $O(\log n)$，findMedian $O(1)$，空间 $O(n)$。
  - **常见错法**：插入后不调整两堆大小差，堆顶不再是中位数；或者比较对象搞错——应先跟大顶堆堆顶比决定进哪个堆，直接跟小顶堆比会把顺序弄反。

- **数组中的第 K 个最大元素（215）**
  - **题意**：无序数组里找第 $K$ 大的元素（按位置算，不是第 $K$ 个不同值）。
  - **关键一步**：维护大小为 $K$ 的小顶堆，超过 $K$ 就弹堆顶，遍历完堆顶即答案；或快速选择，划分后只递归包含目标下标的一侧。
  - **复杂度**：堆 $O(n\log k)$ 时间 / $O(k)$ 空间；快速选择平均 $O(n)$、最坏 $O(n^2)$ / $O(1)$ 空间（迭代写法）。
  - **常见错法**：把「第 K 大」当成「第 K 小」用了大顶堆；快速选择里把「第 K 大」换算成升序下标 `n - k` 时算错，或划分边界写错导致死循环。

- **前 K 个高频元素（347）**
  - **题意**：给数组，返回出现频率最高的 $K$ 个元素，顺序不限。
  - **关键一步**：哈希表统计频次，再用大小为 $K$ 的小顶堆按频次筛（堆存 `(频次, 元素)`）；频次上界不超过 $n$ 时改用桶排序，桶下标就是频次。
  - **复杂度**：堆 $O(n\log k)$ 时间 / $O(n)$ 空间；桶排序 $O(n)$ 时间 / $O(n)$ 空间。
  - **常见错法**：堆里只存元素不存频次，比较时查表导致同一元素反复进出；桶数组只开到 $n-1$，而某元素频次恰好等于 $n$ 时下标越界。

## 第 5 章 题型：树与图

**要解决的问题**：把“这题看着像树或图”的直觉，转化为四套可复用的代码骨架：递归语义、层序队列、拓扑入度、最短路松弛。否则每道题都要重新设计一次遍历，并且在边界条件上重复出错。

**机制**：

- **树的识别特征**：输入是一棵二叉树或多叉树，问题围绕“路径、祖先、按层、子树聚合”。解法是递归函数 `dfs(node)`：先确定它**返回什么**（给父节点用的贡献值），再确定**在哪一步结算答案**（跨左右子树的答案不能通过返回值传出）。
- **图的识别特征**：输入是边集、邻接表或网格，问题围绕“顺序、连通性、最短距离”。解法只看三个问题：有向还是无向、有没有环、边权是 1 还是任意正数。
- **三种数据结构分别对应三类题**：入度数组对应拓扑排序，`parent[]` 数组对应并查集求连通性，`dist[]` 加堆对应 Dijkstra。
- **递归模板**（先定义语义，再写状态转移）：

```python
def dfs(node):
    if not node: return BASE                  # 空节点的返回值必须和语义自洽
    l, r = dfs(node.left), dfs(node.right)
    ans = max(ans, combine(l, r, node.val))   # 跨子树的答案在这里结算
    return contribute(l, r, node.val)         # 只把能给父节点用的部分返回上去
```

- **图的统一注意事项**：访问标记必须在**入队或首次访问时**置位，不能在出队时置位，否则同一个点会被重复入队。

### 题目清单

**1. 二叉树的中序遍历（迭代）**
- **题意**：不用递归，返回中序序列。
- **关键一步**：栈模拟“一路向左压栈”，弹出节点时访问，再让 `cur = cur.right` 转向右子树。
- **复杂度**：时间 $O(n)$，空间 $O(h)$，$h$ 为树高。
- **常见错法**：外层写成 `while cur:` 而不是 `while cur or stack:`，栈非空但指针为空时提前退出。

**2. 二叉树的层序遍历**
- **题意**：按层输出二维数组。
- **关键一步**：每轮先记下 `size = len(q)`，这一轮只弹出这 size 个节点。
- **复杂度**：时间 $O(n)$，空间 $O(w)$，$w$ 为最大层宽。
- **常见错法**：边弹边用 `len(q)` 当循环上界，下一层节点被混进本层。

**3. 路径总和 II（根到叶）**
- **题意**：找出所有根到叶路径和等于 target 的路径。
- **关键一步**：回溯时 `path.append(v)` 且 `target -= v`，只有**叶子且 target 恰为 0** 时才收集。
- **复杂度**：时间最坏 $O(n^2)$（每条路径都要复制），空间 $O(h)$。
- **常见错法**：收集时 `res.append(path)` 存了引用，必须写 `list(path)`；把“节点为空”误当终止条件，导致非叶节点被当路径终点。

**4. 二叉树的最大路径和**
- **题意**：任意节点到任意节点的一条路径，求最大和。
- **关键一步**：递归返回“以当前节点为端点向下延伸的最大贡献”（负数取 0 截断），同时用 `left + node.val + right` 更新全局答案。
- **复杂度**：时间 $O(n)$，空间 $O(h)$。
- **常见错法**：返回值漏写 `node.val + max(0, l) + max(0, r)` 中的 `max(0, ·)`，负数子树把贡献拉低；或把“跨两边”的值也返上去，路径分叉了。

**5. 二叉树的最近公共祖先**
- **题意**：给两个节点，求最深的公共祖先。
- **关键一步**：后序递归，遇到 p 或 q 直接返回自身；左右返回值都非空，当前节点就是答案。
- **复杂度**：时间 $O(n)$，空间 $O(h)$。
- **常见错法**：改成“求两条根到节点的路径再找最后一个公共点”，但忘了处理 p 本身是 q 祖先的情况。

**6. 课程表 II（拓扑排序）**
- **题意**：给定先修关系，返回一个合法学习顺序，有环则返回空。
- **关键一步**：建邻接表和入度数组，入度为 0 的节点入队；出队时把邻居入度减 1，减到 0 才入队。
- **复杂度**：时间 $O(V+E)$，空间 $O(V+E)$。
- **常见错法**：最后不检查 `len(order) == numCourses`，有环时返回了残缺序列；把 `[a, b]`（b 是 a 的先修）建成 a→b，方向反了。

**7. 冗余连接（并查集）**
- **题意**：一棵树多了一条边形成环，找出这条多余边。
- **关键一步**：按输入顺序逐条 union，第一次 `find(u) == find(v)` 的那条边即为答案。
- **复杂度**：时间 $O(n\,\alpha(n))$，空间 $O(n)$。
- **常见错法**：union 时忘了先对两个参数各做一次 find，直接 `parent[a] = b`，把整棵子树挂错根。

**8. 网络延迟时间（Dijkstra）**
- **题意**：有向带权图，从 k 出发，求所有节点都收到信号的最短时间。
- **关键一步**：邻接表加小顶堆，弹出元素时若 `d > dist[u]` 就跳过（惰性删除），用 `dist[u] + w` 松弛邻居。
- **复杂度**：时间 $O((V+E)\log V)$，空间 $O(V+E)$。
- **常见错法**：有节点不可达时返回堆里最后一个值而不是 -1；题目是有向边却建成无向。

**9. 岛屿数量（网格 DFS）**
- **题意**：`'1'` 为陆地、四连通，数连通块个数。
- **关键一步**：扫描到 `'1'` 就答案加 1，然后 DFS 把整块连通陆地标记为 `'0'`。
- **复杂度**：时间 $O(mn)$，空间最坏 $O(mn)$（递归深度或队列）。
- **常见错法**：先递归再判越界导致下标越界；只改标记不判边界，或把四方向写成八方向。

**最小例子**：课程表 II，`numCourses = 4`，`prerequisites = [[1,0],[2,0],[3,1],[3,2]]`。建边 $0\to1, 0\to2, 1\to3, 2\to3$，入度 `indeg = [0,1,1,2]`。初始队列 `[0]`；弹出 0 → 1、2 入度归零入队；弹出 1 → 3 入度变 1；弹出 2 → 3 入度归零入队；弹出 3。输出 `[0,1,2,3]`，长度 4 等于 n，无环。

**面试高频问法**：

1. “树题什么时候用递归、什么时候用 BFS？” → 考点：问题要的是“自底向上汇总”还是“按距离分层” → 答：需要子树信息往上传（高度、路径和、祖先）就用后序递归；问最短步数、按层输出就用 BFS，因为树上边权为 1，BFS 首次到达即最短。
2. “拓扑排序两种写法怎么判环？” → 考点：入度法 vs 三色标记 → 答：BFS 版看输出顶点数是否等于总顶点数；DFS 版看是否碰到“正在访问”的灰色节点。
3. “Dijkstra 为什么不能有负权边？” → 考点：贪心正确性的前提 → 答：它假设出堆即最终最短路，负权边可能让已出堆的点被更短路径更新，前提失效；负权改 Bellman-Ford。
4. “并查集的两个优化分别解决什么？” → 考点：路径压缩与按秩合并 → 答：路径压缩压平树高，按秩/按大小合并避免退化，两者合用均摊 $O(\alpha(n))$，实际近似常数。
5. “LCA 只有递归这一种做法吗？” → 考点：知识广度 → 答：还有倍增（$O(n\log n)$ 预处理、$O(\log n)$ 查询）、树链剖分和离线 Tarjan；面试手写通常要递归版，但要能说出倍增的思路。

## 第 6 章 题型：二分与排序

**要解决的问题**：把「只要数组有序（或局部有序、或答案单调）就能把 $O(n)$ 降到 $O(\log n)$」这件事变成可复用的模板，同时把排序从「调库」升级成「排序的中间状态本身是解题工具」（归并数逆序对、partition 定位第 k 个、堆维护 Top-K）。不解决这一章，遇到「旋转数组」「第 K 大」「逆序对」就只能写暴力，面试第一轮就被复杂度卡掉。

**识别特征与通用套路**：

- 题面出现「有序」「旋转」「找第一个/最后一个」「最少/最大是多少」且答案对参数单调 → 二分。二分分两类：**索引二分**（在数组下标上找）和**答案二分**（在值域上找，`check(x)` 单调）。
- 题面出现「第 K 大/小」「前 K 个」「中位数」且不要求有序 → 快速选择或堆，不要全排序。
- 题面出现「逆序对」「右侧小于它的个数」「大于它的个数」→ 归并排序的合并阶段顺手结算。
- 题面出现「值域有界/均匀分布」「要求线性时间排序」→ 桶排序、计数排序、基数排序。

**机制**：

二分写错的根源永远是「区间语义」和「循环条件」不匹配。统一成**左闭右开**，只记一个 `lower_bound`，其余全是它的变体：

```python
def lower_bound(nums, target):     # 第一个 >= target 的下标
    lo, hi = 0, len(nums)          # 区间 [lo, hi)，hi 取不到
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < target:
            lo = mid + 1           # mid 不满足，排除
        else:
            hi = mid               # mid 满足，保留为候选
    return lo                      # lo == hi，可能等于 len(nums)
```

三个变体只需改谓词：找最后一个 `<= target` 就是 `lower_bound(target+1) - 1`；找旋转数组最小值就是把谓词换成 `nums[mid] > nums[hi]`；答案二分就是把 `nums[mid] < target` 换成 `check(mid)` 为假。

排序侧的关键不变量：**归并合并时，左右两半各自有序且左半原下标全部小于右半**——这条不变量是逆序对和「右侧小于当前元素」能 $O(n\log n)$ 结算的唯一依据。快速选择的 `partition` 返回 pivot 最终落点 `p`，`p` 左边全小、右边全大，因此只需递归/迭代一侧，期望规模每次减半。

**题目清单与逐个要点**

1. **搜索旋转排序数组**（LC 33，无重复）
- **题意**：升序数组在某点旋转，$O(\log n)$ 找 target 的下标。
- **关键一步**：先比较 `nums[lo]` 与 `nums[mid]` 判断哪半边有序，再看 target 是否落在有序半边的值域内，落在里面就去那半边，否则去另一半。
- **复杂度**：$O(\log n)$ / $O(1)$。
- **常见错法**：判有序时写 `nums[lo] < nums[mid]`，当 `lo == mid`（区间只剩一个元素）时判成「右半有序」，走到错误分支。

2. **搜索旋转排序数组 II**（LC 81，含重复）
- **题意**：同上，但元素可重复，返回是否存在。
- **关键一步**：当 `nums[lo] == nums[mid] == nums[hi]` 时无法判序，`lo += 1; hi -= 1` 同时收缩两端。
- **复杂度**：平均 $O(\log n)$，最坏 $O(n)$（全等值）/ $O(1)$。
- **常见错法**：只收缩 `lo` 不收缩 `hi`，另一半的候选被永久跳过，答案是「不存在」但实际存在。

3. **寻找旋转排序数组中的最小值**（LC 153）
- **题意**：无重复旋转数组里找最小元素。
- **关键一步**：与**右端点**比较——`nums[mid] > nums[hi]` 说明最小值在 `mid` 右侧，`lo = mid + 1`；否则 `hi = mid`（mid 自己可能就是最小值，不能 `mid - 1`）。
- **复杂度**：$O(\log n)$ / $O(1)$。
- **常见错法**：拿 `nums[lo]` 做比较基准，旋转量为 0（数组本来就升序）时判据恒假，一路把 `hi` 压到 0，答案错。

4. **在排序数组中查找元素的第一个和最后一个位置**（LC 34）
- **题意**：返回 target 出现的区间 `[first, last]`，不存在返回 `[-1, -1]`。
- **关键一步**：跑两次 `lower_bound`：`first = lower_bound(target)`，`last = lower_bound(target+1) - 1`；再判 `first == n or nums[first] != target`。
- **复杂度**：$O(\log n)$ / $O(1)$。
- **常见错法**：找到 target 后向左右线性扫边界，数组全是 target 时退化成 $O(n)$；以及 `lower_bound(target+1) - 1` 忘了减 1。

5. **二分答案：分割数组的最大值 / 爱吃香蕉的狒狒**（LC 410 / 875）
- **题意**：求一个最小的容量 $x$，使得按 $x$ 分组/按 $x$ 吃香蕉能在约束内完成。
- **关键一步**：确定答案区间为 `[max(nums), sum(nums)]`，写 `check(x)` 做一遍贪心扫描（累加超限就开新组、计数 +1），二分找**第一个** `check(x)` 为真的 $x$。
- **复杂度**：$O(n \log(\sum \text{nums}))$ / $O(1)$。
- **常见错法**：下界写 0 或 1，单元素大于下界时 `check` 直接死循环或返回错解；`check` 里分组计数从 0 开始，最后少算一组。

6. **数组中的第 K 个最大元素**（LC 215，快速选择）
- **题意**：无序数组里找第 $k$ 大，要求平均 $O(n)$。
- **关键一步**：目标下标转成升序的 `n - k`，`partition` 后比较 `p` 与目标下标，只对包含目标的那一侧继续，另一侧直接丢弃。
- **复杂度**：平均 $O(n)$，最坏 $O(n^2)$；空间 $O(1)$（迭代写法）。
- **常见错法**：直接拿 `k` 和 `p` 比而没转成 `n - k`；pivot 固定取端点，遇到已排序输入每轮只砍掉一个元素，退化成冒泡级。

7. **数组中的逆序对**（剑指 Offer 51 / LCR 170）
- **题意**：统计满足 `i < j` 且 `nums[i] > nums[j]` 的数对个数。
- **关键一步**：归并合并时，若 `nums[i] > nums[j]`，一次性结算 `mid - i + 1` 个逆序对（左半 `[i, mid]` 有序，全部大于 `nums[j]`）。
- **复杂度**：$O(n \log n)$ / $O(n)$ 辅助数组。
- **常见错法**：写成 `count += 1`，只算了当前这一对；递归返回后忘记把辅助数组拷回原数组，上一层合并读到的是脏数据。

8. **计算右侧小于当前元素的个数**（LC 315）
- **题意**：对每个 `nums[i]`，返回它右边比它小的元素个数。
- **关键一步**：对**下标**归并；合并时若从左半取出元素，则右侧已出队的元素个数 `j - (mid + 1)` 就是它的答案，累加到 `ans[idx[i]]`。
- **复杂度**：$O(n \log n)$ / $O(n)$。
- **常见错法**：直接对值归并，排序后下标丢失、答案写不回原位置；或者在「从右半出队」时累加，方向正好反了。

9. **前 K 个高频元素 / 堆排序**（LC 347）
- **题意**：统计频次后取频次最高的 $k$ 个；底层是建堆 + 反复取堆顶。
- **关键一步**：哈希计数后用**大小为 k 的小顶堆**（按频次比较）维护候选，超过 $k$ 就弹堆顶；堆排序本身从 `n // 2 - 1` 起自底向上 `sift-down` 建堆（$O(n)$），再交换堆顶与末尾、堆长减一、对新堆顶下沉。
- **复杂度**：堆排 $O(n \log n)$ / $O(1)$；Top-K 用堆 $O(n \log k)$ / $O(n)$。
- **常见错法**：建堆从 `n // 2` 开始（漏掉下标 0 的子树根，且 `2*i+1` 越界）；`sift-down` 里只跟左孩子比，没先选出较大的那个孩子。

10. **最大间距 / 桶排序**（LC 164）
- **题意**：无序数组，要求线性时间求排序后相邻元素的最大差值。
- **关键一步**：$n$ 个数放进 $n+1$ 个桶，桶宽 `(max - min) // n + 1` 或按值域等分，每个桶只维护 `max` 和 `min`；最大间距必然出现在「相邻非空桶」之间，即 `本桶 min - 上一非空桶 max`，桶内元素无需排序。
- **复杂度**：$O(n)$ / $O(n)$。
- **常见错法**：桶数取 $n$ 而非 $n+1$，最大值恰好落到第 $n$ 个桶时下标越界；不特判 `max == min`（所有元素相同），除零或直接返回错值。

**最小例子**：`nums = [4,5,6,7,0,1,2]`，`target = 0`（题 1）。`lo=0, hi=6, mid=3`，`nums[3]=7`，`nums[0]=4 <= 7` 故左半 `[4,5,6,7]` 有序，`0` 不在 `[4,7]` 内 → `lo = 4`。`lo=4, hi=6, mid=5`，`nums[5]=1`，`nums[4]=0 <= 1` 故左半 `[0,1]` 有序，`0` 落在内 → `hi = 5`。`lo=4, hi=5, mid=4`，`nums[4] == 0`，命中，返回下标 4。共 3 次比较，$O(\log n)$。

再看快速选择的落点：`nums = [3,2,1,5,6,4]`，找第 2 大即升序下标 `6-2 = 4`。设某轮 `partition` 返回 `p = 3`（左侧 3 个元素都更小），`3 < 4` 故只递归右段 `[4,5]`，左段不再触碰——这正是平均 $O(n)$ 而非 $O(n\log n)$ 的来源。

**面试高频问法**

1. 「二分的循环条件什么时候写 `lo < hi`，什么时候写 `lo <= hi`？」
   → 考点：区间语义与循环条件必须自洽。
   → 一句话答法：先定区间再写循环——我用左闭右开 `[lo, hi)`，条件就是 `lo < hi`，退出时 `lo == hi` 恰好是第一个不满足谓词的位置，全程不用特判；如果用闭区间 `[lo, hi]`，条件才是 `lo <= hi`，且 `hi` 更新必须写 `mid - 1`。

2. 「旋转数组为什么不能直接拿 `nums[mid]` 和 target 比？」
   → 考点：全局单调性被破坏，但局部单调性仍在。
   → 一句话答法：`mid` 把数组切成两半，其中至少一半是有序的，所以先用端点比较找出哪半有序，再用 target 是否落在该半的值域内决定走向，每步仍然砍掉一半。

3. 「快速选择平均 $O(n)$ 怎么推？最坏什么时候退化？」
   → 考点：期望分析和随机化的动机。
   → 一句话答法：每轮期望把问题规模乘 $1/2$，总代价是 $n + n/2 + n/4 + \cdots = O(n)$；如果 pivot 每轮都取到极值（固定取端点 + 输入已排序），递推变成 $T(n) = T(n-1) + O(n)$，就是 $O(n^2)$，所以要随机化或三数取中。

4. 「归并求逆序对为什么一次能加 `mid - i + 1`？」
   → 考点：合并阶段的不变量。
   → 一句话答法：左半 `[i, mid]` 已经有序，`nums[i] > nums[j]` 意味着从 `i` 到 `mid` 全都大于 `nums[j]`，所以是整批结算，不是一对。

5. 「桶排序凭什么 $O(n)$？什么情况下不成立？」
   → 考点：非比较排序的适用前提。
   → 一句话答法：它把排序换成「按值域定位 + 桶内处理」，前提是知道值域或分布；桶数取 $n$ 时平均每桶 $O(1)$ 个元素，但数据全挤进一个桶就退化成桶内排序的复杂度——最大间距那题用 $n+1$ 个桶并只保留每桶 max/min，就是为了从设计上保证桶内永远不用排。

## 第 7 章 题型：动态规划

**识别特征**：问“最优值、方案数、可行性”，且当前决策只依赖更小规模的子问题；暴力搜索的递归树里出现大量重复状态。看到“最大/最小/最多/多少种/能否”和“选择若干元素、切分序列、两串对齐”，优先想 DP。

**通用套路**：先定义状态（下标集合 + 附加维度）→ 写转移方程（枚举“最后一步的选择”）→ 确定边界与遍历顺序（保证依赖项先算出来）→ 考虑空间压缩与溢出。状态定义错了，后面全错；所以面试时先说“我定义 $f[i][j]$ 表示……”，让面试官先纠状态，比写完代码再改便宜得多。

### 1. 01 背包

- **题意**：$n$ 件物品，每件有体积 $w_i$、价值 $v_i$，每件最多取一次，容量 $W$ 下求最大价值。
- **关键一步**：定义 $f[j]$ 为容量不超过 $j$ 的最大价值，外层枚举物品、内层**倒序**枚举容量 $j$ 从 $W$ 到 $w_i$，`f[j] = max(f[j], f[j-w[i]] + v[i])`。
- **复杂度**：$O(nW)$ 时间，$O(W)$ 空间（滚动数组）。
- **常见错法**：内层写成正序，等于把 01 背包写成完全背包，同一件物品被重复取；以及 `f[j-w[i]]` 的下标越界——循环下界必须是 $w_i$。

### 2. 完全背包

- **题意**：同 01 背包，但每件物品可以取无限次。
- **关键一步**：与 01 背包唯一差别是内层容量**正序**枚举，因为正序时 `f[j-w[i]]` 已经包含了“再取一件 $i$”的最优解。
- **复杂度**：$O(nW)$ 时间，$O(W)$ 空间。
- **常见错法**：记住“正序是完全背包”却说不清为什么；另一种错法是把“恰好装满”和“不超过容量”混用——前者初始化 `f[0]=0`、其余为 $-\infty$，后者全部初始化为 0。

### 3. 最长递增子序列（LIS）

- **题意**：给数组 $a$，求最长严格递增子序列的长度，子序列不要求连续。
- **关键一步**：$O(n^2)$ 版定义 $f[i]$ 为以 $a_i$ 结尾的 LIS 长度，转移 `f[i] = 1 + max(f[j]) for j<i and a[j]<a[i]`；$O(n\log n)$ 版维护数组 `tails`，`tails[k]` 表示长度 $k+1$ 的递增子序列的最小结尾，对每个 $a_i$ 二分找第一个 $\ge a_i$ 的位置替换。
- **复杂度**：$O(n^2)$ 或 $O(n\log n)$ 时间，$O(n)$ 空间。
- **常见错法**：在 $O(n\log n)$ 版里用 `lower_bound` 还是 `upper_bound` 取决于“严格递增”还是“非递减”，严格递增用 `lower_bound`（找第一个 $\ge a_i$）；另一个高频错误是把 `tails` 的长度当成“某个具体的子序列”——`tails` 不是 LIS 本身，要还原路径得额外记录前驱。

### 4. 编辑距离

- **题意**：把字符串 $a$ 变成 $b$，允许插入、删除、替换，求最少操作数。
- **关键一步**：$f[i][j]$ 表示 $a$ 前 $i$ 个字符变成 $b$ 前 $j$ 个字符的最小代价；$a_i = b_j$ 时 $f[i][j] = f[i-1][j-1]$，否则 $1 + \min(f[i-1][j],\ f[i][j-1],\ f[i-1][j-1])$。
- **复杂度**：$O(nm)$ 时间，$O(\min(n,m))$ 空间（滚动一维）。
- **常见错法**：三个候选取错对应关系——$f[i-1][j]$ 是删、$f[i][j-1]$ 是插，写成 `f[i-1][j-1]` 加一就漏了情况；以及初始化的方向：`f[i][0]=i`、`f[0][j]=j`，这是空串的代价，不写就全是 0。

### 5. 最长公共子序列（LCS）

- **题意**：两个串的最长公共子序列长度，子序列不要求连续。
- **关键一步**：$a_i = b_j$ 时 $f[i][j] = f[i-1][j-1]+1$，否则 $f[i][j] = \max(f[i-1][j], f[i][j-1])$。
- **复杂度**：$O(nm)$ 时间，空间可压到一维但需保留左上角旧值。
- **常见错法**：不等时写成 `max(f[i-1][j-1]+1, ...)` 或忘记取两种来源的最大值；一维压缩时正序覆盖了 `f[j-1]`（新值）却当成左上角旧值用，需用一个临时变量存旧 `f[j]`。

### 6. 区间 DP：最长回文子序列 / 戳气球

- **题意**：给定序列，求在区间上合并或消除操作的最优值，典型如“戳气球”求最大得分、“最长回文子序列”求长度。
- **关键一步**：定义 $f[l][r]$ 为区间 $[l,r]$ 的答案，**按区间长度从小到大**枚举，转移枚举分割点 $k$：$f[l][r] = \max_{k}(f[l][k] + f[k+1][r] + \text{cost})$；回文类则用 $f[l][r] = f[l+1][r-1] + 2$（两端相等时）。
- **复杂度**：$O(n^3)$ 时间（分割点枚举），$O(n^2)$ 空间，可用长度递增的遍历天然保证依赖已算。
- **常见错法**：外层循环写成 `for l in 0..n` / 内层 `for r in l..n`，导致 `f[l+1][r-1]` 还没算；正确写法是外层枚举**长度** `len`，内层枚举起点 `l`。戳气球还要补虚拟边界（左右各加一个 1），漏了边界会漏掉最后一枪的价值。

### 7. 股票买卖（状态机 DP）

- **题意**：价格数组，允许有限次交易（如至多 $k$ 次、含冷冻期），求最大收益。
- **关键一步**：定义每天结束时的持股状态 `hold` 与空仓状态 `cash`，转移 `hold = max(hold, cash - price)`、`cash = max(cash, hold + price)`，限定交易次数就再加一维 `k`。
- **复杂度**：$O(nk)$ 时间，$O(k)$ 或 $O(1)$ 空间。
- **常见错法**：同一天先更新 `cash` 再更新 `hold`，用了同一天的买入卖出信息造成“当天既买又卖”；正确做法是先用上一轮旧值算两个新值，或用临时变量。冷冻期则要在状态里多留一天。

### 8. 状压 DP：旅行商（TSP）/ 集合划分

- **题意**：$n$ 较小（约 $n \le 20$）时，用二进制位表示“哪些元素已被选”，求最优排列或划分。
- **关键一步**：$f[mask][i]$ 表示已访问集合 `mask`、当前停在 $i$ 的最小代价，转移枚举下一个未访问点 $j$：`f[mask | (1<<j)][j] = min(..., f[mask][i] + d[i][j])`。
- **复杂度**：$O(2^n \cdot n^2)$ 时间，$O(2^n \cdot n)$ 空间。
- **常见错法**：外层枚举 `mask` 时没有保证子集先算——因为 `mask | (1<<j)` 严格大于 `mask`，按 `mask` 从小到大枚举是安全的，但若写成从大到小就错；另外 `(mask >> i) & 1` 判位与 `mask & (1<<i)` 混用时优先级出错。

### 9. 数位 DP / 计数类 DP（方案数）

- **题意**：统计满足某种数字或序列约束的方案数，如“不超过 $N$ 且不含某模式的数有多少个”。
- **关键一步**：把“是否贴着上界”作为状态一维 `tight`，从高位向低位递归或迭代，`tight` 为真时下一位只能枚举到原数该位，否则枚举到 9；配合记忆化 `f[pos][state][tight]`。
- **复杂度**：$O(\text{位数} \times \text{状态数} \times 10)$。
- **常见错法**：记忆化时把 `tight` 也存进缓存并在 `tight=true` 分支复用，导致答案偏小；正确做法是 `tight=true` 的分支不记忆化（或单独处理），只有 `tight=false` 才写入缓存。

### 10. 打家劫舍 / 线性相邻约束

- **题意**：一排带权元素，不能选相邻的，求最大权值和（环形版本首尾也相邻）。
- **关键一步**：$f[i] = \max(f[i-1], f[i-2] + a_i)$，只保留前两项即可 $O(1)$ 空间；环形拆成“不选第一个”和“不选最后一个”两个线性问题取最大。
- **复杂度**：$O(n)$ 时间，$O(1)$ 空间。
- **常见错法**：环形版本直接对整圈套线性转移，忽略了首尾冲突；以及 `f[i-2]` 在 $i=1$ 时越界，需要把 `f[0]=a[0]`、`f[1]=max(a[0],a[1])` 的边界单独写。

**面试收尾话术**：说清“状态是什么、为什么这个状态足够、转移枚举了什么、复杂度怎么来的”四件事即可；被追问优化时，一维滚动和“决策单调性/二分”是常见加分点，但不要主动报没验证过的复杂度。

## 第 8 章 题型：回溯与贪心

**识别特征与通用套路**

回溯：题目要求返回「所有方案」，或问「方案总数 / 是否存在一条路径」，且 $n$ 很小（通常 $\le 20$），而答案本身具有指数级规模。既然必须枚举，复杂度就没有优化余地；能优化之处只有**剪枝**与**去重**。贪心：题目问「最少 / 最多」，并且能构造出「每一步取当前最优、不回头」的交换论证；如果举得出反例，就不能用贪心，而应退回动态规划。

回溯的骨架固定由三部分组成：`path`（已经做出的选择）、`choices`（当前还能选择什么）、`终止条件`（把 path 复制进答案）。两个高频补充手段：**先排序，再同层去重**（处理重复元素）、**先排序，再提前 break**（和超过 target 就停）。

贪心的骨架同样固定：先选排序键，再线性扫描一遍并维护一个状态量，最后输出。区间类问题的排序键几乎总是**右端点**，因为「越早结束，给后面留的余地越大」，这一点可以用交换论证写出来。

**1. 全排列（46）**
- **题意**：给一个无重复数组，返回它的所有排列。
- **关键一步**：开一个 `used[n]` 数组，递归的每一层遍历所有 `!used[i]` 的下标；选中后把 `used[i]` 置为 true，递归，再回溯置为 false。当 `path.size() == n` 时收集答案。
- **复杂度**：时间 $O(n \cdot n!)$（$n!$ 个叶子，每个叶子复制一次长度为 $n$ 的路径），空间 $O(n)$ 递归栈加 used，不计结果。
- **常见错法**：回溯时忘记写 `used[i] = false`，导致后面层再也选不到该元素；或者用 `res.add(path)` 传入引用，最后所有结果都是同一个被清空的列表。

**2. 全排列 II（47）**
- **题意**：数组含重复元素，返回所有**不重复**的排列。
- **关键一步**：先排序，再在循环开头加一行同层去重：`if (i > 0 && nums[i] == nums[i-1] && !used[i-1]) continue;`
- **复杂度**：上界 $O(n \cdot n!)$，实际输出数远小于 $n!$，按实现而定。
- **常见错法**：把条件写成 `used[i-1]`（树枝去重）而不是 `!used[i-1]`，会把 `[1,1,2]` 这类合法的重复元素排列一并砍掉，答案变少。记法：带 `!` 是树层，不带是树枝；排列题要的是树层。

**3. 组合总和（39）**
- **题意**：candidates 无重复且**可无限次取用**，找出和为 target 的所有组合。
- **关键一步**：递归参数带 `start` 以控制不回头，下一层传 `i` 而不是 `i+1`（允许重复选自己）；排序后，在循环里用 `if (sum + candidates[i] > target) break;` 剪掉后面。
- **复杂度**：指数级，与解的个数和 target 相关，按实现而定；空间为递归深度 $O(\text{target}/\min)$。
- **常见错法**：下一层传了 `i+1`，退化成「每个数只能用一次」（那是 40 题）；或者用 `continue` 代替 `break`，剪枝失效还多跑。

**4. 组合总和 II（40）**
- **题意**：candidates 有重复且每个元素只能用一次，找出不重复的组合。
- **关键一步**：排序；递归传 `i+1`；同层去重 `if (i > start && candidates[i] == candidates[i-1]) continue;`，此处的去重条件不需要 `used` 数组，因为 `i > start` 这个条件本身已经限定了「本层第二个及以后」。
- **复杂度**：指数级，按实现而定；空间为递归深度 $O(n)$。
- **常见错法**：写成 `i > 0` 而不是 `i > start`，把同一树枝上不同层的相同元素误判为同层重复，导致漏解。

**5. N 皇后（51）**
- **题意**：$n \times n$ 棋盘上放 $n$ 个皇后，互不同行、列、对角线，求所有摆法。
- **关键一步**：按行递归（一行只放一个，行约束自动满足），用三个集合 `cols`、`r-c`、`r+c` 做 $O(1)$ 冲突检测；落子前查三处，递归返回后逐个删除。
- **复杂度**：时间上界 $O(n!)$（剪枝后远小于），空间 $O(n)$。
- **常见错法**：用双重循环逐格判断冲突，判定退化成 $O(n)$；对角线键写错或不做偏移——主对角线 `r-c` 可能为负，用数组实现时要加 $n$ 的偏移，副对角线是 `r+c`。

**6. 无重叠区间 / 区间调度（435）**
- **题意**：给若干区间，问最少删掉几个才让剩下的互不重叠。
- **关键一步**：按**右端点**升序排序，维护 `lastEnd = -inf`；遇到 `start >= lastEnd` 就收下并更新 `lastEnd = end`，返回 `n - 收下的个数`。
- **复杂度**：$O(n \log n)$ 排序 + $O(n)$ 扫描；空间 $O(1)$ 额外（排序栈 $O(\log n)$）。
- **常见错法**：按左端点排序——反例 `[1,10],[2,3],[4,5]` 按左端点会先选 `[1,10]`，只留得下一个；端点相接时该用 `>=` 还是 `>` 没看清题意。

**7. 跳跃游戏（55）**
- **题意**：`nums[i]` 是从 i 出发最远能跳的步数，问能否从 0 到 n-1。
- **关键一步**：维护 `maxReach = 0`，遍历到 i 时**先判** `if (i > maxReach) return false;`，**再更新** `maxReach = max(maxReach, i + nums[i])`。
- **复杂度**：$O(n)$ 时间、$O(1)$ 空间。
- **常见错法**：先更新后判断（或根本不判断），把跳不到的断点也计入可达范围，把 false 判成 true。

**8. 跳跃游戏 II（45）**
- **题意**：求跳到末尾的**最少步数**（保证可达）。
- **关键一步**：分层贪心，维护 `end`（当前这一步的覆盖右边界）与 `farthest`；当 `i == end` 时说明本层走完，`step++`、`end = farthest`；循环上界写 `n-1`。
- **复杂度**：$O(n)$ 时间、$O(1)$ 空间。
- **常见错法**：循环写成 `i < n` 而不是 `i < n-1`，最后一格又触发一次 `i == end`，答案凭空多 1；或 `farthest` 在判断 `i == end` 之前没更新。

**9. 用最少数量的箭引爆气球（452）**
- **题意**：气球是区间 $[start, end]$，箭沿 x 轴垂直射出，问最少几支箭打穿全部。
- **关键一步**：按右端点排序；第一支箭放在第一个气球的右端点，之后若某气球 `start > 箭位置` 就新射一支并把箭位置更新为该气球的右端点。
- **复杂度**：$O(n \log n)$ 排序 + $O(n)$ 扫描、$O(1)$ 空间。
- **常见错法**：新箭条件写成 `start >= 箭位置`——端点相接（`start == 箭位置`）时气球已被射穿，应是严格 `>`，写反会多射一支。

**面试高频问法**

1. **「回溯和 DFS 什么关系？」** → 考点：概念边界，以及状态恢复。→ 答法：DFS 是遍历方式，回溯是 DFS 的一种用法，区别在于有没有「撤销选择」这个动作：求连通块时状态在参数里、天然不共享，不需要撤销；求排列组合时状态是共享的 `path` 与 `used`，递归返回必须手动还原。
2. **「全排列去重为什么是 `!used[i-1]`？画个树说明。」** → 考点：树层与树枝的区别。→ 答法：`used[i-1] == true` 说明前一个相同元素在**当前路径上**，那是同一树枝的延续，必须保留；为 `false` 说明它在本层已经被选过又撤回了，再选和上一条分支完全同构，剪掉。
3. **「区间调度为什么按右端点排，不按左端点？」** → 考点：能否写出交换论证。→ 答法：设最优解的第一个区间是 A，右端点最小的区间是 B，B 的右端点 $\le$ A 的右端点，把 A 换成 B 不会与后面任何区间冲突，所以「选右端点最小」不劣，归纳即可。
4. **「跳跃游戏为什么贪心成立，不用 DP？」** → 考点：单调性与无后效性。→ 答法：可达性是单调的——i 可达则 $0..i$ 全可达，所以布尔 DP 数组被压成一个标量 `maxReach`；只要扫描时保证 `i <= maxReach`，就不会用到无效状态。
5. **「N 皇后凭什么用 `r-c` 和 `r+c` 判对角线？」** → 考点：坐标变换降维。→ 答法：左上到右下的主对角线所有格子 `r-c` 相等，右上到左下的副对角线所有格子 `r+c` 相等，二维的冲突检测就变成两次集合查重。
