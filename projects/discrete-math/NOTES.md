# discrete-math · 分章详细

## 第 1 章 逻辑与证明：命题逻辑、量词、直接/反证/归纳

**要解决的问题**：把自然语言断言翻译成有真值的公式，再给出一条「为什么必须相信它」的合法推理链。如果不解决这个问题，后续所有定理（鸽巢、容斥、主定理的复杂度界）都会变成只能背的结论，代码里的循环不变式与递归终止性也无法论证。

**机制**

- 语义是递归定义的函数：给定赋值 $v:P\to\{0,1\}$，$\llbracket A\to B\rrbracket=\max(1-\llbracket A\rrbracket,\llbracket B\rrbracket)$，于是 $A\to B\equiv\neg A\vee B$。所以「前件假则蕴含真」是等值变形的必然结果，并非保留的特殊规定。
- 任意公式都能化成 CNF（用德摩根律加分配律），所以 SAT 是 NP 完全性的标准载体；归结法在 CNF 上完备：子句集不可满足 $\iff$ 反复归结能导出空子句。这是「自动定理证明器」的全部原理。
- 量词要求论域非空，否则 $\forall xP(x)\to\exists xP(x)$ 不成立；否定会穿过量词改变量词类型，即 $\neg\forall xP\equiv\exists x\neg P$。量词顺序不可交换：$\forall x\exists y$ 允许 $y$ 依赖 $x$，$\exists y\forall x$ 要求一个常值见证。
- 证明骨架分四类：直接法（假设 $p$ 推出 $q$）；逆否法（证 $\neg q\to\neg p$）；反证法（假设 $p\wedge\neg q$ 导出矛盾，或对无前提命题只假设 $\neg q$）；分情况。存在性证明区分构造性（给出 $x$）与非构造性（只证不可能不存在）。
- 归纳的合法性来自自然数的良序原理（任意非空子集有最小元），而非「看起来对」。弱归纳：基例 $P(b)$，归纳步 $\forall k\ge b,\,P(k)\to P(k+1)$，结论 $\forall n\ge b,\,P(n)$。强归纳假设 $P(b)\wedge\cdots\wedge P(k)$，与弱归纳可互推，差别只在假设强度，适合需要把对象拆小的场景。
- 结构归纳是归纳在递归定义集合上的版本：命题对原子成立（基例），对每个构造子封闭（归纳步）。这正是递归函数正确性的标准证明形状。

```python
def merge_sort(a):
    if len(a) <= 1: return a           # 基例：长度 0/1 天然有序且是原排列
    m = len(a)//2
    L, R = merge_sort(a[:m]), merge_sort(a[m:])
    return merge(L, R)                 # 归纳步：两个有序序列归并仍有序且不丢元素

# 命题 P(n)：对任意长度 n 的数组，merge_sort 返回有序且元素多重集不变的数组
# 结构归纳：基例 n<=1 直接成立；归纳步假设 P(<n)，merge 的有序性与守恒性给出 P(n)
```

对循环版本，对应的是循环不变式的三段，分别对齐基例、归纳步、终止：初始化时不变式成立；每一轮保持；退出时把「不变式」和「取反的循环条件」合起来就是后置条件。

**最小例子**：强归纳证明「每个 $n\ge 2$ 都能写成素数之积」。
基例 $n=2$ 本身是素数。归纳步取 $n>2$：若 $n$ 是素数则完成；否则 $n=ab$，其中 $a,b$ 都是真因子，故 $2\le a,b<n$。由强归纳假设，$P(a)$ 与 $P(b)$ 都成立，把它们分解出的素数相乘即得 $n$ 的分解。注意这里用到的是 $a,b<n$ 而非 $n-1$，弱归纳的假设 $P(n-1)$ 对 $a$ 完全无效，所以这一步必须换成强归纳。

**面试高频问法**

1. 「$p\to q$ 前件为假时整体为真，凭什么？」→ 考点是蕴含的定义与等值替换的自洽性。→ 因为 $p\to q$ 定义为 $\neg p\vee q$，这是唯一让演绎定理与等值变形同时成立的取法；在工程上，`if (p) assert(q)` 对 `p` 为假的情况本来就不作要求。
2. 「弱归纳和强归纳等价吗，什么时候必须用强归纳？」→ 考点是良序原理与假设强度。→ 二者等价、都能由良序原理导出；强归纳在需要把对象分解成更小两块（素因子分解、Fib 递推、分治递归）时更顺手。
3. 「反证法和逆否证明的区别？」→ 考点是假设集合与适用范围。→ 逆否法只证 $\neg q\to\neg p$，前提仍是 $p$；反证法可以只假设 $\neg q$ 去证无前提命题（如 $\sqrt2$ 无理），代价是结论依赖排中律。
4. 「$\forall x\exists y$ 和 $\exists y\forall x$ 差在哪？」→ 考点是见证的依赖性。→ 在 $\mathbb{R}$ 上 $\forall x\exists y(y>x)$ 为真（$y$ 可随 $x$ 变），$\exists y\forall x(y>x)$ 为假（要求常值上界）；顺序换来的是量词的依赖结构。
5. 「归纳法怎么用到代码上？」→ 考点是不变式与递归的对应。→ 递归对应结构归纳（基例对基例、构造子对归纳步），循环对应不变式的初始化、保持、终止三步，终止时不变式与退出条件合起来给出后置条件。

## 第 2 章 集合、关系与函数：等价关系与划分、偏序与格、闭包

**要解决的问题**：给「相同」「不超过」「属于同一类」这三种日常判断建立精确模型。计数一章的等价类、图论的邻接关系、抽象代数的商群、数据库的函数依赖，全都建立在这一章的对象上。

**机制**

- 集合侧只需要记住几件事：$|2^A|=2^{|A|}$；$\varnothing\ne\{\varnothing\}$；$A\times B$ 的元素是有序对。$A$ 上的二元关系就是 $A\times A$ 的子集，共 $2^{|A|^2}$ 个，所以对关系的性质做分类是有意义的。
- 等价关系 $=$ 自反 $+$ 对称 $+$ 传递。核心定理：$A$ 上的等价关系与 $A$ 的划分一一对应。证明骨架双向：给定 $R$，令 $[a]=\{x:xRa\}$；自反给 $a\in[a]$ 故覆盖，对称与传递给「$[a]\cap[b]\ne\varnothing\Rightarrow[a]=[b]$」故互斥，于是 $\{[a]\}$ 是划分。反向给定划分 $\{A_i\}$，定义 $aRb\iff\exists i,\,a,b\in A_i$，三条性质逐条验证。商集 $A/R$ 的元素个数就是划分块数。
- 偏序 $=$ 自反 $+$ 反对称 $+$ 传递。注意极大元不需要与所有元素可比，最大元需要；上确界是最小上界且可以不在 $A$ 内。拓扑排序就是偏序的线性扩展：把偏序补成全序且不违反原序，图里有环则原关系连传递都不是，所以无解。
- 格是任意两元素都有唯一最小上界 $a\vee b$ 与最大下界 $a\wedge b$ 的偏序集。$(2^S,\subseteq)$ 是布尔格（有补分配格），$(\mathbb{N},\mid)$ 是分配格但非有补，全序集都是格。格的运算与代码里的求交、求并同构，所以能用分配律做优化。
- 闭包：$R$ 关于性质 $P$ 的闭包是「包含 $R$ 的最小 $P$ 关系」。存在唯一的前提是 $P$ 对任意交封闭，否则可能没有最小元。自反闭包 $R\cup I_A$、对称闭包 $R\cup R^{-1}$、传递闭包 $R^+=\bigcup_{k\ge1}R^k$，且 $R^*=R^+\cup I_A$。传递关系之交仍传递，所以 $R^+$ 存在。

```python
# Warshall：原地求传递闭包，O(n^3)，位运算可压到 O(n^3/word)
for k in range(n):
    for i in range(n):
        if d[i][k]:                 # 剪枝：i 到不了 k 就不用扫
            for j in range(n):
                d[i][j] |= d[k][j]  # R^(k) = R^(k-1) ∪ R^(k-1)∘R^(k-1)
# 同一份三重循环把 max/min 换成 or/and 就是传递闭包，换成 +/min 就是 Floyd
```

**最小例子**：用并查集维护 $A=\{1,2,3,4,5,6\}$ 上的等价关系，依次合并 $\{1,2\}$、$\{2,3\}$、$\{4,5\}$。结果等价类为 $\{1,2,3\},\{4,5\},\{6\}$ —— 三个块，商集大小 3。这里只需验证：合并是等价类的并（若 $a\sim b$，则 $[a]\cup[b]$ 仍是等价类），而「分裂」不对应任何关系运算，所以并查集天然只能合并、不能分裂；带删除的等价关系必须换成可持久化结构或离线倒序处理。

再手算一次传递闭包：$A=\{1,2,3\}$，$R=\{(1,2),(2,3)\}$。$R^2=\{(1,3)\}$，$R^3=\varnothing$，故 $R^+=\{(1,2),(2,3),(1,3)\}$；$R^*$ 再加 $(1,1),(2,2),(3,3)$。矩阵上就是 3 步之内把「一步可达」传播完，这也解释了 Warshall 为什么外层必须是中间点 $k$。

**面试高频问法**

1. 「等价关系和划分为什么一一对应？」→ 考点是等价类的互斥加覆盖。→ 自反保证覆盖，对称与传递保证任两块要么相同要么不交，于是等价类构成划分；反过来划分定义的关系显然满足三条。
2. 「并查集维护的是哪种结构，为什么不能分裂？」→ 考点是等价关系与关系运算的封闭性。→ 它维护等价类，合并就是取等价类的并仍然合法，分裂不保持最小性，也无法在近似 $O(\alpha(n))$ 的路径压缩结构上回退。
3. 「极大元和最大元、上界和上确界的区别？」→ 考点是可比性。→ 最大元属于 $A$ 且与所有元素可比，极大元只要求没有比它大的元素；上确界是最小上界，通常不在 $A$ 里，$(\mathbb{Q},\le)$ 中 $\{x:x^2<2\}$ 就没有上确界。
4. 「传递闭包怎么算，复杂度是多少？」→ 考点是 $R^+=\bigcup_k R^k$ 与 Warshall 的不变式。→ 三重循环 $O(n^3)$，位集可到 $O(n^3/64)$，与 Floyd 是同一份代码换半环；$R^*$ 只是再多加自反对角线。
5. 「Python 里重写 `__eq__` 为什么必须重写 `__hash__`？」→ 考点是等价关系对哈希的一致性要求。→ 等价关系要求 $a\sim b$ 时二者行为不可区分，否则同一个等价类会被哈希桶拆成多份，字典查找和去重直接失效。

## 第 3 章 计数：排列组合、容斥原理、鸽巢原理

**要解决的问题**：把“有多少种”从模糊直觉变成可复现的计算。它决定暴力枚举是否可行、概率的分母取什么、组合恒等式能不能落地；数不清，后面的概率与复杂度分析就都没有依据。

**机制**：一切从两条规则出发——加法原理（互斥分类相加）、乘法原理（分步相乘）。由此推出：排列 $P(n,r)=\frac{n!}{(n-r)!}$、组合 $\binom{n}{r}=\frac{n!}{r!(n-r)!}$；$r$ 个相同球放入 $n$ 个不同盒（可重组合）为 $\binom{n+r-1}{r}$，即隔板法；多重集排列 $\frac{n!}{n_1!\cdots n_k!}$；圆排列 $(n-1)!$。不要单独背结论，记住推导路径：先选位置，再排元素。

容斥原理对有限集 $A_1,\dots,A_m$ 成立：
$$\Bigl|\bigcup_{i=1}^{m}A_i\Bigr|=\sum_{\varnothing\ne S\subseteq[m]}(-1)^{|S|+1}\Bigl|\bigcap_{i\in S}A_i\Bigr|.$$
证明骨架：取元素 $x$，设它属于其中 $t$ 个集合。它在右式被计入 $\sum_{k=1}^{t}(-1)^{k+1}\binom{t}{k}=1-(1-1)^t=1$（$t\ge1$），$t=0$ 时计入 $0$。逐元素对齐，恒等式成立。求“都不满足”时用补集形式：$|\overline{A_1}\cap\cdots\cap\overline{A_m}|=|U|-\sum|A_i|+\sum|A_i\cap A_j|-\cdots$。经典应用是错排：$D_n=\sum_{k=0}^{n}(-1)^k\binom{n}{k}(n-k)!=n!\sum_{k=0}^{n}\frac{(-1)^k}{k!}$。注意 $D_n$ 等于 $n!/e$ 四舍五入，是近似，不是恒等式。

鸽巢原理：$n$ 个物品落入 $k$ 个盒，必有盒内至少 $\lceil n/k\rceil$ 个。条件是物品与盒子有限、对应关系是函数。它只给存在性——正确用法是证明“必有”，错误用法是“所以能快速找到”。

代码层面的容斥，就是枚举非空子集、按 $|S|$ 定符号、对整除问题取 lcm：

```python
from math import gcd
def count_coprime(n, primes):        # 1..n 中不被 primes 中任何质数整除的个数
    total, m = n, len(primes)
    for s in range(1, 1 << m):
        l, bits = 1, 0
        for i in range(m):
            if s >> i & 1:
                l = l // gcd(l, primes[i]) * primes[i]
                bits += 1
        total += (-1) ** bits * (n // l)   # n - |并集| = n + Σ(-1)^{|S|}(n/lcm)
    return total
```

复杂度 $O(2^m\log n)$，$m$ 为不同质因子数。这段 `for s in range(1<<m)` 也是状压 DP 的同一动作。

**最小例子**：$1..100$ 中不能被 $2,3,5$ 整除的个数。被 $2$ 整除 50 个、$3$ 整除 33 个、$5$ 整除 20 个；两两为 $6$ 的 16 个、$10$ 的 10 个、$15$ 的 6 个；三者交集是 $30$ 的 3 个。答案 $=100-(50+33+20)+(16+10+6)-3=26$。用另一条路校验：与 $30$ 互质的剩余类有 $\varphi(30)=8$ 个，$1..90$ 是三组共 24 个，$91..100$ 中再取 $91,97$ 两个，仍为 26，说明没有漏项。

**面试高频问法**：
1. “容斥的符号怎么记？” → 考点：按交集大小奇加偶减，以及求补集时整体取反。答：并集按 $|S|$ 奇加偶减；求“都不满足”时以 $|U|$ 打头，后面各项符号翻转。
2. “错排的 $n!/e$ 是精确值吗？” → 考点：区分近似与恒等式。答：不是，$D_n$ 是整数而 $n!/e$ 一般不是；严格式是 $n!\sum(-1)^k/k!$，$n!/e$ 只是取最近的整数。
3. “鸽巢原理能用来设计算法吗？” → 考点：存在性与构造性。答：只能保证解存在，例如哈希冲突必然发生、前缀和模 $n$ 必有两个同余；要定位还得靠查表或计数。
4. “$\binom{n}{r}\bmod p$ 怎么算？” → 考点：阶乘加逆元，以及 $n\ge p$ 的推广。答：$n<p$ 时预处理阶乘与阶乘逆元，$O(n)$ 预处理、$O(1)$ 查询；$n\ge p$ 用 Lucas 按 $p$ 进制拆位递归。

## 第 4 章 递推与生成函数：线性递推求解、主定理与分治复杂度

**要解决的问题**：递推只给相邻项之间的关系，但工程与面试要的是量级或通项——分治算法多快、第 $n$ 项能否 $O(\log n)$ 求出、增长是指数还是多项式。不会解递推，复杂度分析就只能背结论。

**机制**：常系数线性齐次递推 $a_n=c_1a_{n-1}+\cdots+c_ka_{n-k}$ 对应特征方程
$$x^k=c_1x^{k-1}+\cdots+c_{k-1}x+c_k.$$
根 $r_1..r_k$ 互异时 $a_n=\sum A_ir_i^n$，系数由 $k$ 个初值解线性方程组定出；若 $r$ 是 $m$ 重根，对应项为 $(A_0+A_1n+\cdots+A_{m-1}n^{m-1})r^n$。成立条件是常系数、线性、齐次、初值个数等于阶数。非齐次时通解 = 齐次通解 + 一个特解，特解形式按右端项猜（多项式、指数、$r^n$ 乘多项式）。

生成函数是同一件事的另一面：$A(x)=\sum a_nx^n$，代入递推得 $A(x)=P(x)/Q(x)$，其中 $Q$ 就是特征多项式；部分分式拆开后每项 $\frac{1}{(1-rx)^m}$ 展开成 $\binom{n+m-1}{m-1}r^n$，就是通项。它更容易推广，卷积型递推靠它：Catalan 数 $C_n=\sum_{i=0}^{n-1}C_iC_{n-1}$ 给出 $C(x)=1+xC(x)^2$，解得 $C_n=\frac{1}{n+1}\binom{2n}{n}$。

主定理：$T(n)=aT(n/b)+f(n)$，$a\ge1,b>1$，令临界指数 $c=\log_ba$，比较 $f(n)$ 与 $n^c$：
- $f(n)=O(n^{c-\varepsilon})$ → $T(n)=\Theta(n^c)$；
- $f(n)=\Theta(n^c)$ → $T(n)=\Theta(n^c\log n)$；
- $f(n)=\Omega(n^{c+\varepsilon})$ 且满足正则性 $af(n/b)\le cf(n)$ → $T(n)=\Theta(f(n))$。

条件必须说清：恰好 $a$ 个规模 $n/b$ 的子问题、$f$ 非负。落在两种情况之间的间隙（如 $f=n^c\log n$）主定理不适用，要改用递归树或 Akra–Bazzi。递归树视角：第 $i$ 层有 $a^i$ 个规模 $n/b^i$ 的结点，叶子层共 $\Theta(n^{c})$，总代价是各层之和，取决于 $a$ 与 $b$ 谁增长更快。

```python
def merge_sort(a):
    if len(a) <= 1: return a
    m = len(a) // 2
    return merge(merge_sort(a[:m]), merge_sort(a[m:]))
# T(n)=2T(n/2)+Θ(n)：a=2,b=2,c=1,f=Θ(n^c) → Θ(n log n)
```

二分查找 $T(n)=T(n/2)+\Theta(1)$：$c=0$，$f=\Theta(1)=\Theta(n^c)$ → $\Theta(\log n)$。朴素分块矩阵乘 $8T(n/2)+\Theta(n^2)$：$c=\log_28=3$ → $\Theta(n^3)$；Strassen 把子乘法降到 7 次，$c=\log_27\approx2.81$，优于 $n^3$——减少乘法次数的好处就在这个指数里。

**最小例子**：$F_0=0,F_1=1,F_n=F_{n-1}+F_{n-2}$。特征方程 $x^2=x+1$，根 $\phi=\frac{1+\sqrt5}{2}$、$\psi=\frac{1-\sqrt5}{2}$，代入初值得 $F_n=(\phi^n-\psi^n)/\sqrt5$，$F_{10}=55$。工程上不真算浮点幂（溢出且失真），而用矩阵快速幂 $\begin{pmatrix}1&1\\1&0\end{pmatrix}^n$ 做到 $O(\log n)$。

**面试高频问法**：
1. “主定理三种情况怎么快速判断？” → 考点：先算 $c=\log_ba$ 再与 $f$ 比阶。答：先算临界指数 $c$；$f$ 低一阶取 $n^c$，同阶乘 $\log n$，高一阶且满足正则性取 $f(n)$。
2. “为什么归并排序 $n\log n$，快排最坏 $n^2$？” → 考点：子问题规模是否均衡。答：归并恒定二分，递推是 $2T(n/2)+n$，落在主定理第二种；快排最坏划分成 $1$ 与 $n-1$，退化为 $T(n)=T(n-1)+n$，解为 $n^2$。
3. “特征根有重根为什么多乘 $n$？” → 考点：重根对应生成函数的高阶极点。答：$m$ 重根使部分分式出现 $\frac{1}{(1-rx)^m}$，展开是 $\binom{n+m-1}{m-1}r^n$，即 $n$ 的 $m-1$ 次多项式乘 $r^n$。
4. “生成函数和特征方程是什么关系？” → 考点：是否理解二者同一。答：生成函数把递推变成有理函数，分母即特征多项式，部分分式展开等价于按特征根分解；生成函数还能处理卷积型递推，如 Catalan 数。

## 第 5 章 图论基础：连通性、欧拉与哈密顿、树与生成树、平面图

**要解决的问题**：图是离散数学里唯一能直接建模「关系网络」的结构。这一章把「连通」这个直觉变成可判定、可计算的性质（等价类），再给出三类经典判定——欧拉（边遍历）、哈密顿（点遍历）、平面性（可嵌入）——并说明树为什么是「最省的连通图」。不解决它，后面匹配、网络流、着色全都无从下嘴，工程上的并查集、拓扑序、最小生成树也失去正确性依据。

**机制**

**基本量**　图 $G=(V,E)$，$n=|V|$、$m=|E|$，简单图指无重边无自环，$\deg(v)$ 为度。**握手定理**：$\sum_{v\in V}\deg v=2m$（每条边在两端各计一次）。推论：奇度顶点个数必为偶数——这是欧拉判定的全部来源。

**连通性**　$u,v$ 之间存在通路即连通。「连通」是 $V$ 上的**等价关系**（自反、对称、传递），等价类即连通分量。所以「判连通」= 「求等价类」= BFS/DFS 或并查集。$u,v$ 间所有通路上都要经过的点叫割点，对应的边叫桥；树里每条边都是桥。求割点用 Tarjan 的 $\mathrm{dfn}/\mathrm{low}$（具体写法按实现而定），判据是 $\mathrm{low}(v)\ge \mathrm{dfn}(u)$。

**欧拉**　经过每条边**恰好一次**。
- 欧拉回路（闭迹）存在 $\iff$ 忽略孤立点后连通，且**所有顶点度为偶数**。
- 欧拉通路存在 $\iff$ 忽略孤立点后连通，且奇度顶点恰有 $0$ 个或 $2$ 个（$2$ 个时它们必为起点与终点）。

必要性骨架：闭迹每进入一个顶点必离开一次，对度的贡献是 $2$，故必为偶。充分性骨架：从任一点不断走未用边（每点偶度保证「进得去也出得来」），必回到起点得到一条回路；若还有未用边，由连通性该回路必与剩余边相接，把剩余边上的回路「拼接」进原回路，归纳至用完。

有向版：弱连通 + 每点入度 = 出度（回路）；或恰有一点出度 = 入度 $+1$（起点）、一点入度 = 出度 $+1$（终点）。

**哈密顿**　经过每个顶点恰好一次。判定是 **NP-完全**的，没有已知好用的充要条件，只有充分条件：
- **Dirac**：$n\ge3$ 且最小度 $\delta(G)\ge n/2$ $\Rightarrow$ 哈密顿。
- **Ore**：$n\ge3$ 且任意两个不相邻顶点满足 $\deg u+\deg v\ge n$ $\Rightarrow$ 哈密顿。

Ore 的证明骨架：取一条最长路 $v_1\cdots v_k$，它的两个端点邻居必全在路上（否则路可延长）。用 $\deg v_1+\deg v_k\ge n\ge k$ 配合鸽巢，可找到下标 $i$ 使 $v_1v_{i+1}$、$v_iv_k$ 同时是边，于是把路首尾接成圈；再把圈外顶点用「$n$ 足够大 + 度数条件」逐个塞进圈。

工程含义：只要看到「遍历所有顶点一次」的判定/构造题，先想 NP-完全，再想状态压缩 DP（$O(2^nn^2)$）或近似。

**树与生成树**　树 = 连通无圈。对 $n$ 个顶点的简单图，以下三条**两两等价**：① 连通且无圈；② 连通且 $m=n-1$；③ 无圈且 $m=n-1$。

骨架：连通无圈 $\Rightarrow$ 每条边都是桥 $\Rightarrow$ 逐条删桥得单点，恰删 $n-1$ 条，故 $m=n-1$；反之若 $m=n-1$ 且含圈，删去圈上一边仍连通但只剩 $n-2$ 条边，不可能连通 $n$ 个点，矛盾。

连通图必有生成树（BFS/DFS 树，或反复删圈上的边）。最小生成树的正确性来自两条性质：**割性质**（跨任一割的最小权边必属于某棵 MST）与**环性质**（任一环上的最大权边必不属于某棵 MST），Kruskal 与 Prim 分别对应后者与前者的贪心实现。Cayley 公式：$n$ 个标号顶点的生成树共 $n^{\,n-2}$ 棵。

**平面图**　能画在平面上使边只在公共顶点处相交。**欧拉公式**：连通平面图满足
$$n-m+f=2,\qquad f\ \text{含外部面}$$
证明骨架：对边数归纳；树时 $f=1$ 且 $m=n-1$，成立；每加一条非桥边，$m$ 与 $f$ 各增 $1$，等式保持。

两个推论（$n\ge3$、简单连通）：由「每个面至少由 $3$ 条边围成」得 $2m\ge3f$，代入得
$$m\le 3n-6$$
若还是二部图（无三角形，每面至少 $4$ 条边），则 $2m\ge4f$，得 $m\le 2n-4$。

于是 $K_5$：$m=10>3\cdot5-6=9$，非平面；$K_{3,3}$：$m=9>2\cdot6-4=8$，非平面。Kuratowski 定理给出充要条件：非平面 $\iff$ 含有 $K_5$ 或 $K_{3,3}$ 的细分。

代码里长什么样——连通性与生成树就是一个并查集：

```python
par = list(range(n))
def find(x):
    while par[x] != x:
        par[x] = par[par[x]]; x = par[x]   # 路径压缩
    return x
# Kruskal：排序后按 (u,v,w) 贪心
for u, v, w in sorted(edges, key=lambda e: e[2]):
    ru, rv = find(u), find(v)
    if ru != rv:                            # 不在同一连通分量 -> 不成环
        par[ru] = rv; total += w; cnt += 1
```

**最小例子**

取 $V=\{0,1,2,3,4,5\}$，边与权：$0\text{-}1{:}4,\ 0\text{-}2{:}1,\ 1\text{-}2{:}2,\ 1\text{-}3{:}5,\ 2\text{-}4{:}3,\ 3\text{-}4{:}6,\ 3\text{-}5{:}7,\ 4\text{-}5{:}8$，共 $m=8$ 条。

- 握手定理校验：度序列 $(2,3,3,3,3,2)$，和为 $16=2\times8$ ✓。
- 欧拉：奇度顶点是 $1,2,3,4$ 共 $4$ 个，既非 $0$ 也非 $2$，故**无欧拉回路也无欧拉通路**。
- Kruskal 按权升序：$0\text{-}2(1)$ 收，$1\text{-}2(2)$ 收，$2\text{-}4(3)$ 收，$0\text{-}1(4)$ 成环弃，$1\text{-}3(5)$ 收，$3\text{-}4(6)$ 成环弃，$3\text{-}5(7)$ 收。共 $5=n-1$ 条边，$W=1+2+3+5+7=18$。
- 平面性：$m=8\le 3n-6=12$ 满足必要条件，**不能**据此判定平面（必要条件不逆向）。

**面试高频问法**

1. 问法：「怎么判断一个图有没有欧拉回路？为什么？」→ 考点：握手定理 + 必要性充分性两条方向 → 答法：「忽略孤立点后连通，且所有顶点度为偶。必要是因为闭迹每进必出、贡献度为 2；充分是从任一点一直走未用边必然回到起点成圈，再把剩下的圈拼上去。」
2. 问法：「哈密顿回路能用欧拉那套判吗？」→ 考点：边的遍历 vs 点的遍历本质不同，NP-完全 → 答法：「不能，哈密顿判定是 NP-完全的，只知道充分条件：Dirac 的 $\delta\ge n/2$、Ore 的不相邻点度数和 $\ge n$，工程上要么状态压缩 DP 要么启发式。」
3. 问法：「Kruskal 为什么正确？并查集在里面起什么作用？」→ 考点：割/环性质与贪心正确性 → 答法：「依据环性质，环上最大权边不必选，所以按权升序加边、成环就弃是正确的；并查集就是判『加这条边会不会成环』，即两端是否已同属一个连通分量，均摊近 $O(1)$，总复杂度 $O(m\log m)$ 来自排序。」
4. 问法：「$K_5$ 和 $K_{3,3}$ 为什么非平面？」→ 考点：欧拉公式推出的边数上界 → 答法：「$n\ge3$ 的简单平面图有 $m\le 3n-6$，$K_5$ 是 $10>9$；二部平面图 $m\le 2n-4$，$K_{3,3}$ 是 $9>8$。反过来 Kuratowski 定理说非平面就等价于含这两者的细分。」
5. 问法：「判断连通性你会用 BFS 还是并查集？」→ 考点：静态查询 vs 动态增量 → 答法：「一次性判连通用 BFS/DFS，$O(n+m)$；边是流式加入、要边加边查的（比如 Kruskal）用并查集，因为它支持增量合并且均摊近常数。」

## 第 6 章 图论进阶：二分图匹配、网络流与最大流最小割、着色

**要解决的问题**：把「分配」「运输」「冲突最少化」三类组合优化统一到两张图上：二分图匹配与网络流（前者是后者的单位容量特例，两者被 max-flow-min-cut 与 König 定理串起来），着色则刻画「冲突图最少需要多少资源」。不解决它，就无法回答「这个调度/分配为什么有解、下界在哪、算法复杂度多少」。

**机制**

**二分图**　$V$ 可划分为 $L,R$ 且所有边跨越两部分。等价刻画：**不含奇圈**。判定就是一个 BFS 二着色，染色冲突处即找到一个奇圈。

**匹配**　边集两两不共端点。$M$ 最大 $\iff$ 不存在 $M$-增广路（两端均为未匹配点的交替路），这是 Berge 定理。于是算法只有一件事：反复找增广路，沿路取对称差，匹配大小 $+1$；匈牙利算法对每个左点 DFS 找增广路，$O(VE)$。

**Hall 定理**　二分图 $G=(L,R,E)$ 存在饱和 $L$ 的匹配
$$\iff\ \forall S\subseteq L,\ |N(S)|\ge|S|$$
必要性一行：$S$ 的点必须匹配到 $N(S)$ 里互不相同的点上。充分性骨架：取最大匹配，从左侧未匹配点出发走交替路，把可达左点集记为 $Z_L$，可证 $|N(Z_L)|<|Z_L|$，与条件矛盾。

**König 定理**　二分图中
$$\text{最大匹配}=\text{最小顶点覆盖}$$
骨架：取最大匹配 $M$，从左侧未匹配点出发走交替路（未匹配边左$\to$右、匹配边右$\to$左），令 $Z$ 为可达点集，取 $K=(L\setminus Z_L)\cup Z_R$，可验证 $K$ 覆盖所有边且 $|K|=|M|$，再由「覆盖 $\ge$ 匹配」得等号。这条定理是「最大 = 最小」型对偶的第一个样本，网络流里会再见到它。

**网络流**　容量 $c(u,v)$，流 $f$ 满足 $0\le f(u,v)\le c(u,v)$ 与流量守恒（源汇除外），值 $|f|$ 为源的净流出。核心装置是**残量网络**：正向余量 $c_f(u,v)=c(u,v)-f(u,v)$，**反向边** $c_f(v,u)=f(u,v)$——反向边是「撤销」机制，没有它算法会卡死在贪心错误上。

**最大流最小割定理**：
$$\max_f |f|=\min_{S}\ c(S,T)$$
- 弱对偶：$|f|=f(S,T)\le c(S,T)$，因为净流量不超过正向流量和，而后者不超过割容量。
- 取等：若残量网络无 $s\to t$ 路，令 $S$ 为残量网络中 $s$ 可达点集，则 $t\notin S$，且所有跨割边满流、反向边为零，于是 $|f|=c(S,T)$。三句话合成完整证明，面试要求能口述这一段。
- **整数性定理**：容量全为整数时存在整数最大流（Ford–Fulkerson 每次增广至少 $+1$，必终止）。但增广次数依赖容量数值，不是多项式；Edmonds–Karp 改用 BFS 取最短增广路，$O(VE^2)$；Dinic 用分层图 + 阻塞流，一般图 $O(V^2E)$，单位容量网络（含二分图匹配）可到 $O(E\sqrt V)$。

## 第 7 章 数论基础：整除与同余、欧拉定理、模逆、RSA 的骨架

**要解决的问题**：把“整数除法余数”变成可计算的代数系统 $\mathbb{Z}_n$，并说明公钥加密为什么能在公开模数下完成可逆变换。不解决它，RSA、哈希取模、扩展欧几里得都只是背代码。

**机制**：

整除定义为 $a\mid b \iff \exists k\in\mathbb{Z},\,b=ak$。带余除法给出唯一 $a=bq+r,\ 0\le r<b$。$\gcd(a,b)$ 可用欧几里得算法求，并满足贝祖等式：存在 $x,y$ 使 $ax+by=\gcd(a,b)$。

同余定义为 $a\equiv b\pmod n \iff n\mid(a-b)$。模 $n$ 的剩余类构成 $\mathbb{Z}_n$。其中与 $n$ 互素的类组成乘法群 $\mathbb{Z}_n^*$，其元素个数为欧拉函数 $\varphi(n)$；若 $n=pq$ 且 $p,q$ 为不同素数，则 $\varphi(n)=(p-1)(q-1)$。

欧拉定理：若 $\gcd(a,n)=1$，则 $a^{\varphi(n)}\equiv1\pmod n$。条件“互素”不可去。证明骨架：$\mathbb{Z}_n^*$ 有 $\varphi(n)$ 个元素；乘以 $a$ 是单位集合上的置换，故 $\prod_{u\in \mathbb{Z}_n^*}u\equiv\prod_{u}au=a^{\varphi(n)}\prod u$，两边约去可逆的乘积即得。费马小定理是 $n=p$ 的特例：$a^{p-1}\equiv1\pmod p$。

模逆：$ax\equiv1\pmod n$ 有解当且仅当 $\gcd(a,n)=1$。此时可用扩展欧几里得求 $x$，或由欧拉定理取 $x\equiv a^{\varphi(n)-1}$。实现上扩展欧几里得更通用：

```python
def egcd(a, b):
    if b == 0:
        return a, 1, 0
    g, x1, y1 = egcd(b, a % b)
    return g, y1, x1 - (a // b) * y1
# egcd(a,n) 返回 g,x,y 使 ax+ny=g；g=1 时 x%n 就是逆
```

RSA 骨架：选不同素数 $p,q$，令 $n=pq$，$\varphi=(p-1)(q-1)$；选 $e$ 使 $\gcd(e,\varphi)=1$；求 $d\equiv e^{-1}\pmod\varphi$。公钥 $(n,e)$，私钥 $d$。加密 $c\equiv m^e\pmod n$，解密 $c^d\equiv m\pmod n$。正确性：$ed=1+k\varphi$，对 $\gcd(m,n)=1$ 用欧拉定理直接得 $m^{ed}\equiv m$；对 $m$ 与 $n$ 不互素的情形，用中国剩余定理分别模 $p,q$ 验证同样成立。注意教科书 RSA 是确定性的，实际必须加随机填充。

**最小例子**：取 $p=5,q=11$，$n=55$，$\varphi=40$。选 $e=3$，则 $d=27$，因为 $3\cdot27=81\equiv1\pmod{40}$。明文 $m=7$：$c=7^3=343\equiv13\pmod{55}$。解密 $13^{27}\bmod55$：$13^2\equiv4$，$13^4\equiv16$，$13^8\equiv36$，$13^{16}\equiv31$，而 $27=16+8+2+1$，故 $31\cdot36\cdot4\cdot13\equiv7\pmod{55}$。代码只需 `pow(7,3,55)=13`、`pow(13,27,55)=7`。

**面试高频问法**：

- 问“模逆什么时候存在” → 考点是 $\mathbb{Z}_n$ 中可逆元刻画 → 答：当且仅当 $\gcd(a,n)=1$，因为贝祖等式给出 $ax+ny=1$，反之若公因子大于 1 则同余式左边必被该因子整除。
- 问“欧拉定理和费马小定理什么关系” → 考点是群阶与特殊化 → 答：费马小定理是欧拉定理在模素数时的特例，统一说法是单位群中元素阶整除群阶。
- 问“RSA 为什么解密能还原” → 考点是 $ed\equiv1\pmod\varphi$ 与欧拉定理 → 答：$ed=1+k\varphi$，互素时 $m^{ed}=m(m^{\varphi})^k\equiv m$，非互素时用 CRT 分到两个素数验证。
- 问“知道公钥能不能直接求 $d$” → 考点是 $\varphi(n)$ 与分解难度的关系 → 答：知道 $p,q$ 就能算 $\varphi$ 和 $d$；一般相信由 $(n,e)$ 求 $d$ 与分解 $n$ 同难，但没有无条件证明。
- 问“为什么要填充” → 考点是确定性加密的语义安全 → 答：裸 RSA 对相同明文产生相同密文且乘法同态，必须用随机化填充破坏可预测性。

## 第 8 章 代数结构：群、环、域与同态，为什么密码学与编码要用群

**要解决的问题**：把“可逆运算”“指数运算”“线性代数”抽象成统一结构，解释为什么密码学总在群上做幂运算、编码总在有限域上做线性运算。不解决它，椭圆曲线、AES 的 $GF(2^8)$、Reed–Solomon 都只能死记。

**机制**：

群是集合 $G$ 与二元运算 $*$，满足封闭性、结合律、存在单位元 $e$、每个元素有逆元。若还交换则称阿贝尔群。有限群元素个数叫阶 $|G|$。若存在 $g$ 使 $G=\{g^k\}$，称循环群，$g$ 为生成元。

拉格朗日定理：有限群 $G$ 的子群 $H$，其阶整除 $|G|$。证明骨架：左陪集 $aH$ 两两不交或相同，且每个 $aH$ 与 $H$ 等势，因此 $G$ 被分成 $|G|/|H|$ 个等大块。推论：$a^{|G|}=e$。取 $G=\mathbb{Z}_n^*$ 就得到欧拉定理，取 $G=\mathbb{Z}_p^*$ 就得到费马小定理。

环是 $(R,+,\cdot)$：$(R,+)$ 为阿贝尔群，$\cdot$ 结合，且乘法对加法分配。域是交换环，$1\ne0$，且每个非零元都有乘法逆元。$\mathbb{Z}_n$ 是域当且仅当 $n$ 为素数；$GF(p)$ 是素域；$GF(2^8)$ 不是 $\mathbb{Z}_{256}$，而是 $\mathbb{F}_2[x]/(x^8+x^4+x^3+x+1)$，因为 $\mathbb{Z}_{256}$ 有零因子，无法让所有非零元可逆。

同态是保持运算的映射：$\varphi(a*b)=\varphi(a)*\varphi(b)$。核 $\ker\varphi=\{g:\varphi(g)=e_H\}$，像 $\operatorname{im}\varphi$ 是子群；群同态第一同构定理：$G/\ker\varphi\cong\operatorname{im}\varphi$。证明骨架：定义 $gK\mapsto\varphi(g)$，用核刻画“映到单位元”来证良定义与单射，像的定义给满射。

密码学用群，是因为需要可逆变换和可高效计算的幂：解密要求逆元存在，密钥交换要求循环群中的离散对数难，RSA 的 $x\mapsto x^e$ 是 $\mathbb{Z}_n^*$ 上的乘法同态。编码用有限域，是因为线性码、校验矩阵、插值都要做域上加减乘除；Reed–Solomon 在 $GF(2^m)$ 上插值，AES 在 $GF(2^8)$ 上做字节运算。代码里“群”常表现为可替换的乘法函数：

```python
def xtime(a):          # GF(2^8) 中乘 x，模 0x11B
    a <<= 1
    if a & 0x100:
        a ^= 0x11B
    return a & 0xFF
```

任意 $GF(2^8)$ 乘法都可由“移位 + 条件异或 + 累加”实现，这正是域结构落到字节操作的样子。

**最小例子**：$\mathbb{Z}_7^*=\{1,2,3,4,5,6\}$，阶为 6。取 $g=3$，幂为 $3,2,6,4,5,1$，故 $3$ 是生成元。$5$ 的逆是 $3$，因为 $5\cdot3=15\equiv1\pmod7$。子群 $\langle2\rangle=\{1,2,4\}$ 阶为 3，整除 6。映射 $f:\mathbb{Z}_6\to\mathbb{Z}_3,\ f(x)=x\bmod3$ 是同态，核为 $\{0,3\}$，像是整个 $\mathbb{Z}_3$。

**面试高频问法**：

- 问“群、环、域的区别” → 考点是运算与逆元层级 → 答：群只要求一个运算可逆，环有两个运算且加法成阿贝尔群、乘法只需结合与分配，域再要求非零元全可逆。
- 问“拉格朗日定理有什么用” → 考点是子群阶与元素阶 → 答：子群阶整除群阶，所以元素阶也整除群阶，直接推出 $a^{|G|}=e$，欧拉定理和费马小定理都是它。
- 问“为什么密码学偏爱群” → 考点是可逆性与困难问题 → 答：群保证逆运算存在，幂运算可用快速幂高效计算，而循环群上的离散对数可被假设为困难。
- 问“同态的核为什么重要” → 考点是结构保持与信息损失 → 答：核衡量同态丢失了多少信息，第一同构定理说商掉核后与像同构。
- 问“AES 为什么用 $GF(2^8)$ 而不是 $\mathbb{Z}_{256}$” → 考点是域与零因子 → 答：$256$ 非素数，$\mathbb{Z}_{256}$ 有零因子，很多非零元不可逆；用不可约多项式构造的 $GF(2^8)$ 才是所有非零元可逆的域。

## 第 9 章 布尔代数与组合电路

**要解决的问题**：把“真值表描述的功能”变成门数、深度可接受的电路，并能说明化简为什么不改变功能。不解决这件事，综合出的电路可能正确但面积和延迟失控，也看不懂 HDL 里组合逻辑被综合成什么。

**机制**：

布尔代数取载体 $B=\{0,1\}$，运算 $\lor,\land,\neg$，满足交换律、分配律、同一律、补元律：
$$a\lor(b\land c)=(a\lor b)\land(a\lor c),\quad a\lor\neg a=1,\quad a\land\neg a=0.$$
布尔函数是 $f:B^n\to B$。**最小项** $m_x=\bigwedge_{i=1}^n (x_i\text{ 或 }\neg x_i)$ 只在输入 $x$ 处为 1；于是任何 $f$ 都有最小项之和（SOP）：
$$f=\bigvee_{x:f(x)=1}m_x.$$
这就是“SOP 一定存在”的构造性证明：逐行把真值表翻译成与项再或起来。对偶地有 POS。

**卡诺图**把真值表按格雷码排成二维，相邻格只差一个变量。圈 $2^k$ 个 1，对应一个蕴含项；圈越大，被消去的变量越多，依据是 $x\lor\neg x=1$。化简目标是：覆盖所有 1、圈数尽量少、圈尽量大；无关项可当 0 或 1 用来扩大圈，但不得覆盖必须为 0 的格。卡诺图只适合手算小变量；变量多时工具用 Quine–McCluskey 或 Espresso 一类启发式，具体按实现而定。

逻辑门中 NAND 是**功能完备**的：
$$\neg a=a\uparrow a,\quad a\land b=(a\uparrow b)\uparrow(a\uparrow b),\quad a\lor b=(a\uparrow a)\uparrow(b\uparrow b).$$
所以只用 NAND 就能搭出任意组合电路。组合电路是**无反馈**的门网络；含反馈和时钟的才是时序电路。不同路径延迟不同会在输出上产生毛刺（静态冒险），工程上用寄存器打拍、加冗余项或握手来消除，具体按工艺与时序约束而定。

代码里最直接的落地是 **LUT**：$k$ 输入查找表就是 $2^k$ 位存储，把布尔函数存成位掩码，求值即查表。FPGA 的基本单元就是这种结构。

```python
def eval_lut(table, x):
    # table 的第 m 位是 f(m)，m 是 minterm 编号
    return (table >> x) & 1

def nand(a, b):
    return 0 if (a and b) else 1

def not_(a):    return nand(a, a)
def and_(a, b): return not_(nand(a, b))
def or_(a, b):  return nand(not_(a), not_(b))
```

**最小例子**：$f(a,b,c)=\sum m(0,1,2,3,5,7)$。卡诺图按 $ab$ 格雷码为行、$c$ 为列：

| $ab\backslash c$ | 0 | 1 |
|---|---|---|
| 00 | 1 | 1 |
| 01 | 1 | 1 |
| 11 | 0 | 1 |
| 10 | 0 | 1 |

左上 $2\times2$ 四格覆盖 $a=0$ 的全部输入，得 $\neg a$；右侧 $c=1$ 且 $a=1$ 的两格得 $ac$。合并：
$$f=\neg a\lor ac=\neg a\lor c.$$
按两级 SOP 实现，最小项写法要 6 个三输入与项再加一个大或门；化简后只要一个 NOT 加一个 OR。功能等价可由 $x\lor\neg x y=x\lor y$ 直接验证。

**面试高频问法**：

1. **问**：为什么 NAND 门叫通用门？→ **考点**：功能完备性。→ **答**：因为 NOT、AND、OR 都能只用 NAND 表示，所以任意 SOP 都能落成 NAND 网络。
2. **问**：卡诺图为什么只能圈 $2^k$ 个格？→ **考点**：格雷码相邻只差一个变量。→ **答**：圈内每对相邻格只变一个变量，成对合并正好用 $x\lor\neg x=1$ 消掉它，所以圈大小必须是 2 的幂。
3. **问**：卡诺图圈出来的结果一定是最简吗？→ **考点**：两级 SOP 与多级综合的区别。→ **答**：手算卡诺图只保证对两级 SOP 做了素蕴含项覆盖，不保证全局门数最少；多级综合和工艺映射是另一层优化。
4. **问**：无关项怎么处理？→ **考点**：规范与实现的分离。→ **答**：无关项在规范里取值任意，化简时可当 0 或 1 来扩大圈，但不能覆盖必须为 0 的格。
5. **问**：组合逻辑的毛刺怎么来的？→ **考点**：路径延迟与冒险。→ **答**：同一信号经不同路径到达或门的时间不同，瞬时出现错误输出；用寄存器同步、加冗余项或握手消除，具体按工艺而定。

## 第 10 章 离散概率与随机算法

**要解决的问题**：在算法里用随机性换时间、空间或确定性，必须能算出“错概率多大”“期望代价多少”。不解决这件事，就只会背“随机快排平均 $O(n\log n)$”，说不出对什么分布、最坏多坏、错概率能否重复放大。

**机制**：

概率空间是 $(\Omega,P)$，事件 $A\subseteq\Omega$。条件概率
$$P(A\mid B)=\frac{P(A\cap B)}{P(B)},\quad P(B)>0.$$
全概率公式把 $P(A)$ 按划分拆开；贝叶斯公式由条件概率定义直接变形。独立是 $P(A\cap B)=P(A)P(B)$，注意两两独立不蕴含相互独立。

随机变量 $X$ 的期望 $E[X]=\sum_x xP(X=x)$。**期望线性性**：
$$E\left[\sum_i X_i\right]=\sum_i E[X_i]$$
对任意随机变量成立，**不要求独立**，这是随机算法分析最常用的工具。方差才需要独立或不相关才有可加性。

**马尔可夫不等式**：若 $X\ge0$，$t>0$，则
$$P(X\ge t)\le \frac{E[X]}{t}.$$
证明骨架：$E[X]=\sum_x xP(X=x)\ge\sum_{x\ge t}xP(X=x)\ge tP(X\ge t)$。它只用一阶矩，所以松；要更紧就用方差和切比雪夫。

随机算法分两类：**拉斯维加斯**总是正确、运行时间随机；**蒙特卡洛**时间确定、以某概率出错。单边错概率为 $p$ 时，独立重复 $k$ 次可降到 $p^k$。

哈希是这套分析的标准应用。均匀哈希假设下，$n$ 个元素散到 $m$ 个桶，负载因子 $\alpha=n/m$，链地址法不成功查找的期望探测数为 $1+\alpha$；成功查找在元素等概率被查的常见模型下约为 $1+\alpha/2$。通用哈希族只要求对 $x\ne y$ 有 $\Pr_{h\in H}[h(x)=h(y)]\le1/m$，就足以得到同样的期望界。生日悖论给出碰撞门槛：$m$ 个桶投 $n$ 个球，碰撞概率约
$$1-\prod_{i=0}^{n-1}\left(1-\frac{i}{m}\right)\approx 1-e^{-n(n-1)/(2m)},$$
所以 $n\sim\sqrt{m}$ 就开始碰撞；64 位哈希在 $2^{32}$ 条记录量级要防碰撞。

随机快排的期望比较次数：对 $i<j$，令 $X_{ij}=1$ 当且仅当第 $i$ 小和第 $j$ 小元素被比较。它们被比较，当且仅当区间 $[i,j]$ 中 $i$ 或 $j$ 最先被选为 pivot，概率 $2/(j-i+1)$。于是
$$E[C]=\sum_{i<j}\frac{2}{j-i+1}<2nH_n=O(n\log n).$$
骨架就是：指示变量 + 线性性 + 调和级数，不需要分析递归树。

```python
import random

def birthday(n=23, m=365, trials=10000):
    hit = 0
    for _ in range(trials):
        seen = set()
        for _ in range(n):
            x = random.randrange(m)
            if x in seen:
                hit += 1
                break
            seen.add(x)
    return hit / trials   # 约 0.507
```

**最小例子**：$n=3$ 的随机快排。三对元素的比较概率分别为 $2/2=1$、$1$、$2/3$，所以
$$E[C]=1+1+\frac23=\frac83\approx2.67.$$
直接枚举 6 种 pivot 排列也能得到同一均值。生日模拟取 $n=23,m=365$，重复一万次，命中率约 $0.507$，与近似 $1-e^{-23\cdot22/(2\cdot365)}\approx0.5$ 吻合。

**面试高频问法**：

1. **问**：期望线性性需要随机变量独立吗？→ **考点**：和的期望与方差的可加条件不同。→ **答**：不需要，$E[X+Y]=E[X]+E[Y]$ 对任意随机变量成立；方差相加才要独立或不相关。
2. **问**：马尔可夫不等式什么时候能用？→ **考点**：非负、$t>0$。→ **答**：只要求 $X\ge0$ 且 $t>0$，它把期望转成尾概率上界，适合重复放大错概率，但通常偏松。
3. **问**：随机快排为什么期望 $O(n\log n)$？→ **考点**：指示变量与调和级数。→ **答**：第 $i$、$j$ 小元素被比较的概率是 $2/(j-i+1)$，求和得 $2nH_n$，所以期望 $O(n\log n)$，最坏仍是 $O(n^2)$。
4. **问**：哈希表查询为什么平均 $O(1)$？→ **考点**：均匀哈希或通用哈希 + 常数负载因子。→ **答**：链地址法期望链长是 $1+\alpha$，只要 $\alpha=O(1)$ 就是常数；通用哈希族只要求碰撞概率 $\le1/m$ 就够。
5. **问**：生日悖论对工程有什么实际影响？→ **考点**：碰撞门槛是 $\sqrt{m}$ 量级。→ **答**：$m$ 个桶投到约 $\sqrt{m}$ 个元素就大概率碰撞，所以 64 位哈希在 $2^{32}$ 条记录量级要防碰撞，不能把哈希当唯一标识。
