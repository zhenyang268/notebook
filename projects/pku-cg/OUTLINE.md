# 北大图形学 · 渲染与游戏 — 项目大纲

> **性质**：工程兴趣线，**无考纲对位**。价值在"把光栅化、光线追踪、几何处理从原理写到能出图"。
> **总时长**：40–60 小时 ｜ **详细**：`NOTES.md`

---

## 0 一句话

**自己写一个能渲染出带阴影和反射的场景的最小渲染器（光栅化 + 光追各一遍）。**

## 1 目标：做完之后必须能回答

1. **透视投影**的 $w$ 除为什么必须发生在裁剪之后？
2. **深度测试**用 $z$ 还是 $1/z$？为什么？
3. **Blinn-Phong** 和 **Cook-Torrance** 的差别在哪，什么时候必须用后者？
4. **光线追踪**的求交：球、平面、三角形各是什么形式？为什么要用重心坐标？
5. **BVH** 把复杂度从 $O(n)$ 降到 $O(\log n)$，靠的是什么性质？

## 2 里程碑

| 里程碑 | 内容 | 验收 | 估时 |
|---|---|---|---|
| **M1 变换** | MVP 矩阵、视图变换、投影 | 画出一个旋转的立方体（线框） | 6h |
| **M2 光栅化** | 三角形填充、深度测试、抗锯齿 | 立方体正确遮挡，边缘无明显锯齿 | 10h |
| **M3 着色** | Blinn-Phong + 纹理映射 | 带高光的球体，纹理不畸变 | 8h |
| **M4 阴影** | Shadow map | 物体在地面投下正确阴影 | 6h |
| **M5 光追** | 光线求交 + 递归反射 | 两个球互相反射的场景 | 12h |
| **M6 加速** | BVH | 10 万三角形场景**渲染时间降 10 倍** | 8h |

**M1–M3 是光栅化主线**，M5 是另一条线（光追）。**两条线选一条走通即可**。

## 3 验收标准

- M1：MVP 矩阵相乘顺序正确，**立方体绕自身中心转**（不是绕世界原点）。
- M2：**深度测试用 $1/z$ 插值**，否则远处出现 z-fighting。
- M3：法线要**变换到世界空间**再算光照（用逆转置矩阵）。
- M5：**反射深度限制 3–5 层**，否则指数爆炸。
- M6：BVH 构建用**表面积启发式（SAH）**，否则加速有限。

## 4 时间预算与取舍

```
最小闭环：M1 + M2 + M3（24h），能出"带纹理和光照的旋转立方体"。
```
**明确不做**：全局光照（路径追踪）、PBR 完整实现、实时软阴影。

## 5 前置

- 线性代数（矩阵乘法、齐次坐标、叉积）。
- C++ 或 Python + 一个图形库（OpenGL / Taichi / 甚至纯 CPU 写 PPM）。
