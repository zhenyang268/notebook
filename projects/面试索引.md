# 面试索引 — 36 份 OUTLINE 的「面试怎么讲」抽成一页

> **用途**：面试前一晚只看这一页；要展开再进对应 `OUTLINE.md` §五。
> **生成方式**：脚本抽取 §五 的「30 秒版本」首句与追问问法，**文字未改写**（原句照录）。
> **不是简历替代品**：简历只摆 3–5 个项目，这一页是全库检索表。

## 怎么用（三步）

1. 按岗位挑一条线（`PLAN.md` §3 的三条支线），只背那条线上 3 个项目的 30 秒版本。
2. 每个项目挑 3 个追问：念一遍问法，30 秒内答得完才算过。
3. 答不出的回对应 `OUTLINE.md` §五 第 N 条，那里有「考点 / 答法 / 边界」三段。

### langs/cpp-basics
1. “虚函数怎么实现的？一个类几个 vptr？” → 考点：分不分得清“标准规定”和“ABI 实现”。**
2. “构造过程中抛异常会发生什么？你的 RAII 类怎么保证异常安全？” → 考点：资源归属、异常保证级别。**
3. “`std::move` 做了什么？vector 扩容什么时候拷贝、什么时候移动？” → 考点：move 只是 cast；`move_if_noexcept`。**
4. “`shared_ptr` 线程安全吗？`make_shared` 和 `shared_ptr(new T)` 差在哪？” → 考点：线程安全的边界在控制块，不在对象。**
5. “模板里 `typename` 什么时候必须写？” → 考点：两阶段名字查找、依赖名。**
6. “`vector::push_back` 什么复杂度？`unordered_map` 查找最坏多少？” → 考点：摊还 vs 最坏；失效规则。**
7. “两个线程同时读写一个 `int`，用 `atomic` relaxed 够不够？`volatile` 行不行？” → 考点：data race 是 UB；happens-before。**
8. “你怎么确认代码里没有未定义行为？” → 考点：知不知道工具的能力边界。**
