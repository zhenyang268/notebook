# CS231N · 视觉识别 — 项目大纲

> **性质**：工程兴趣线，**无考纲对位**。价值在"把反向传播、卷积、批量归一化从公式变成张量形状"。

## 0 一句话

**手写一遍反向传播和卷积，之后看任何深度学习代码都不再是黑箱。**

## 1 目标：做完之后必须能回答

1. **softmax + 交叉熵**的梯度为什么是 $\hat y - y$？（推导 + 代码验证）
2. **卷积**的反向传播要对什么做翻转？`im2col` 在这里起什么作用？
3. **BatchNorm** 在训练和推理时的行为差别在哪？为什么推理要用滑动平均？
4. 为什么**残差连接**能缓解梯度消失？（从雅可比连乘看）

## 2 里程碑

| 里程碑 | 内容 | 验收 | 估时 |
|---|---|---|---|
| **A1 kNN + SVM + Softmax** | 向量化实现 + 解析梯度 | 与数值梯度**相对误差 < 1e-8** | 8h |
| **A1 两层网络** | 手写前向 + 反向 | 过拟合 50 个样本到 100% 准确率 | 4h |
| **A2 卷积与池化** | `im2col` + 反向 | 与朴素实现逐元素一致 | 6h |
| **A2 BatchNorm / Dropout** | 训练/推理双模式 | 梯度检查通过 + 推理用滑动统计 | 4h |
| **A3 检测/分割/风格迁移** | 任选其一 | 能在小数据上出可视化结果 | 8h |

**A1 是全部地基**。A2 的卷积反向是第二个坎。

## 3 验收标准

- **梯度检查**：所有手写层必须与 `numerical_gradient` 对比，**相对误差 < 1e-7**（不达标不许往下走）。
- **过拟合测试**：小数据（50 张）必须能到 **100% 训练准确率**（到不了说明实现有 bug）。
- **形状断言**：每个函数的输入输出形状写成注释，与代码一致。
