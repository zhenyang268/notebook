## 一、它在做什么

这个项目做一件事：用 NumPy 把图像分类这条流水线从头到尾手写一遍，中间不借助任何自动微分。**输入**是 CIFAR-10 的彩色图像张量，形状 $(N,3,32,32)$，像素为 0–255 的整数，配一个 0–9 的类别标签。**输出**是两样东西：一套可自由组合的层（线性层、ReLU、SVM 与 Softmax 损失、卷积、最大池化、批归一化、Dropout），每层都带手写的前向与反向；以及一个用这些层训练出来的分类器，连同它的训练曲线、混淆矩阵和错例可视化。起点是 kNN 这种没有参数的基线，终点是一个测试准确率在 55%–65% 区间的小型卷积网络——不冲纪录，只求每一步都说得清为什么。

**验收**有三条硬线。其一，每个手写的反向传播必须和中心差分数值梯度对上，相对误差在 $10^{-7}$ 以下，任何一层不过关就不往下走。其二，把训练集缩到 50 张，模型必须能过拟合到 100% 训练准确率——做不到说明实现有 bug，而不是模型容量不够。其三，在全量数据上，卷积网络要明显超过线性 softmax 基线，并且这个提升能被拆开归因：卷积贡献多少、批归一化贡献多少、数据增强贡献多少。

## 二、为什么这样做（功能设计）

**把 autograd 换成 cache 约定。** 整个项目替换掉的现成组件就是自动微分。接口定在层这一级：`forward(x, params)` 返回输出和一个 `cache`，`backward(dout, cache)` 返回对输入的梯度与对参数的梯度。`cache` 是唯一的信息通道——这一条把链式法则从数学命题变成工程约束：前向时忘了存某个中间量，反向就根本写不出来。自动微分顺手替你做的事现在全要自己实现：参数初始化、训练/推理双模式开关、滑动统计量的累积、正则项的梯度、优化器的状态。代价是，写错的梯度不会报错，只会让训练变慢或者收敛到更差的点，所以必须有一个独立的裁判。

**数值梯度是唯一裁判。** 用中心差分 $(f(x+h)-f(x-h))/2h$，$h$ 取 $10^{-5}$ 量级，全程 float64；相对误差用 $|a-n|/\max(|a|+|n|,10^{-8})$。不能用前向差分（截断误差是 $O(h)$，精度不够），也不能在 float32 下检查（舍入误差直接淹没信号）。要预先知道两类假警报：ReLU 在折点附近左右导数不等，BatchNorm 里方差接近零时分母放大误差——遇到这些先换输入样本或加大 $h$，别急着改代码。

**数据形态与三类不可靠性。** 图像是 $(N,C,H,W)$ 四维张量，标签是一维整数。不可靠性来自三处。数值层面：softmax 里直接算 $\exp$ 会溢出，必须先减最大值（log-sum-exp 稳定化）；交叉熵会碰到 $\log 0$；批归一化的方差可能为零。形状层面：`reshape` 和 `transpose` 写反了不报错，只是悄悄变慢或变差，$(N,C,H,W)$ 与 $(N,H,W,C)$ 混用是最常见的 bug——对策是每个函数在注释里写死输入输出形状，测试里显式断言。随机性层面：初始化尺度、shuffle、Dropout 掩码、batch 采样都会让两次实验的结论对不上，对策是固定种子、单一配置文件、A/B 对比时只改一个变量。

**卷积为什么必须走 im2col。** 朴素六重循环在 Python 里一步训练要几十秒，做不了超参对比，等于放弃了后面所有训练技巧的实验。`im2col` 把每个感受野展平成一行，得到 $(N H_{out}W_{out},\,C k_h k_w)$ 的矩阵，与权重 $(F,\,C k_h k_w)$ 做一次矩阵乘就直接调进 BLAS。它的代价是显存放大 $k_h k_w$ 倍（3×3 就是九倍），用分块 batch 控制。反向的坑在 `col2im`：相邻窗口在输入上重叠，梯度必须累加而不是覆盖，用 `np.add.at` 或者 reshape 后按维求和，写错的表现是梯度检查差一点点——刚好卡在阈值边缘。

**训练与推理的行为分裂。** 这是训练技巧这一章真正的核心，也是自动微分不会提醒你的地方。批归一化在训练时用当前 batch 的均值和方差，推理时用滑动平均，且这对统计量是缓冲区不是参数——不进梯度、不被优化器更新，只在前向里按动量累积。Dropout 同理：只有 inverted 版本是对的，训练时除以 $(1-p)$、推理时什么都不做；若按"训练乘 $p$、推理不乘"来写，准确率掉几个点，但不报错，极难查。

**训练技巧是另一半工作量。** 同样的网络结构，学习率差十倍，结果差二十个点。所以优化器（SGD、Momentum、Adam）、学习率衰减、He 初始化（对应 ReLU 的 $2/\text{fan\_in}$）、正则强度扫描，都要作为独立变量被实验过，而不是抄一组默认值。

**为什么不用更简单的做法。** 直接用 PyTorch，一行 autograd 就完事，但你不会知道 `cache` 里该存什么，遇到自定义算子或梯度不流动时无从下手；代价是我们主动放弃了自动微分和 GPU，训练时间以小时计而不是分钟。只用 kNN 和线性分类器，看不到批归一化和 Dropout 的收益——线性模型在 CIFAR-10 上四十个点就饱和了。改用 MNIST，99% 的准确率会掩盖所有实现细节。跳过梯度检查、靠"损失在降"判断对错，是最贵的省事：错位的梯度常常仍能让损失缓慢下降，只是收敛到更差的点。

## 三、章节大纲

**第 1 章 · 数据与 kNN 基线。** 载入 CIFAR-10、划分训练验证、可视化样本。kNN 的三种距离实现三连跳：双重循环、单层循环、完全向量化（利用 $\|a-b\|^2=\|a\|^2+\|b\|^2-2a\cdot b$ 把距离矩阵变成一次矩阵乘）。知识点：广播、内存布局、向量化思维。做完能验证：三个版本输出逐元素一致，而耗时差两个数量级。

**第 2 章 · 线性分类器。** SVM 的 hinge 损失与 softmax 交叉熵，两者的打分函数相同、损失不同；手推两者的梯度，看清为什么都会出现 $\hat y - y$ 这个结构（一个对错误类稀疏、一个对错误类稠密）。知识点：多类 SVM、交叉熵、log-sum-exp 稳定化、正则项。做完能验证：解析梯度与数值梯度一致；两个模型在验证集上的准确率与错误类型可对比。

**第 3 章 · 反向传播与梯度检查。** 计算图视角下的链式法则，局部梯度与上游梯度的相乘；写一个通用的 `grad_check`，参数化地接受任意函数与输入。知识点：雅可比、向量化反向、中心差分、相对误差。做完能验证：一段手推的矩阵表达式与程序输出的梯度完全对得上。

**第 4 章 · 层化与两层网络。** 把"一坨 forward"拆成 Linear + ReLU + Softmax 的层组合，写出 Solver 训练循环、参数更新与学习率衰减。知识点：模块化接口、参数与超参分离、过拟合小样本的判据。做完能验证：50 张样本训练到 100% 准确率。

**第 5 章 · 优化器与超参扫描。** SGD、Momentum、RMSProp、Adam 的更新式与状态变量；学习率、正则强度、初始化尺度的网格扫描；从训练/验证曲线判读欠拟合与过拟合。知识点：动量、自适应步长、权重初始化、早停。做完能验证：同一模型下不同优化器的收敛速度对比表，以及一张能读懂的超参热图。

**第 6 章 · 卷积与池化。** 输出尺寸公式、感受野、权值共享带来的参数效率；朴素实现先跑通，再用 im2col/col2im 重写，两版对拍；最大池化的反向是把梯度路由给前向取到最大值的位置（cache 存 argmax）。知识点：互相关与卷积的区别、重叠区域梯度累加。做完能验证：加速版与朴素版前向、反向逐元素一致。

**第 7 章 · 归一化与正则化。** 批归一化的前向（batch 统计、滑动平均）与反向（梯度要穿过统计量，因此 $dx$ 里有与批均值、批方差相关的修正项）；LayerNorm 作对照；Dropout 的 inverted 约定与掩码生成。知识点：缓冲区与参数的区别、内部协变量偏移的经验证据、正则的等价集成解释。做完能验证：切换到推理模式后输出分布正确；加上批归一化，更深的网络才训得动。

**第 8 章 · 综合实验与解读。** 完整 CNN 训练、数据增强、混淆矩阵、卷积核可视化、错例分析；把准确率提升拆解归因到各组件。可选外延：检测（IoU/NMS）或分割（像素交叉熵/IoU）的最小闭环。知识点：消融实验的设计、结果的可复现写法。做完能验证：一份带对照组的实验报告，结论不是"感觉更好了"。

## 四、不做什么

**不追 SOTA。** CIFAR-10 上不冲 95%，不做模型集成、不抄排行榜结构。目标是机制跑通并解释清楚，准确率只是"实现没写错"的旁证。

**不做大规模训练。** ImageNet、多卡、分布式、混合精度、梯度累积，全部不在范围内。本地算力撑不住，而且这些属于工程化议题，和"理解反向传播"没有关系。

**不实现自动微分框架。** 不做计算图引擎、不做算子融合、不做图编译。`cache` 手工传递是刻意的笨拙。

**不让框架接管主实现。** PyTorch 只作为对照手段——同一层用 autograd 再算一遍梯度，看两边是否一致；不作为主要实现路径。反过来也不拒绝框架：如果课程后半段涉及 Transformer、自监督、扩散模型这类内容，只读论文和代码、只做推理级调用，不手写训练。

**不做部署与推理优化。** 量化、剪枝、ONNX 导出、TensorRT、移动端，都不碰。

**不深挖理论。** 泛化界、优化景观、双下降这些属于理论线，这里只在实验现象层面提一句，不做推导。

**常见跑偏。** 一是顺序颠倒：一上来就搭大网络，梯度写错了查不出来——必须按 kNN → 线性分类器 → 两层网络 → 卷积的顺序推进，每一步都有独立可验证的判据。二是拿训练准确率当验收，正确的判据是梯度检查加小样本过拟合。三是边调超参边换随机种子，结论不可复现。四是把批归一化的滑动统计量当参数交给优化器更新，训练看起来正常但推理崩掉。五是为了"跑得快"直接抄一份现成实现，跳过推导——那这个项目就等于没做。
