# ai · 分章详细

## 第 1 章 最小数学集：向量与矩阵、内积与投影、范数、随机变量与期望

**要解决的问题**：后面每一章都在描述「一个形状为 X 的张量经过某个算子变成形状为 Y 的张量」，而算子只有两类——线性的（矩阵乘、卷积、注意力里的加权和）和非线性的（激活、归一化）。没有这套最小记号，形状推导和参数量估算就只能靠背。如果这里缺一块，读到 Transformer 的 $QK^\top/\sqrt{d_k}$ 时就不知道那个 $\sqrt{d_k}$ 在对什么做补偿。

**机制**：

- **向量与矩阵**。向量是 $\mathbb{R}^n$ 里的列，形状 $(n,)$；矩阵 $W\in\mathbb{R}^{m\times n}$ 就是一个线性映射 $\mathbb{R}^n\to\mathbb{R}^m$。$y=Wx$ 的第 $i$ 个分量是 $W$ 的第 $i$ 行与 $x$ 的内积：$y_i=\sum_j W_{ij}x_j$。所以「一层」的本质是：对每个输出位置，取输入的一个加权和，权重就是那一行。行数 $m$ 决定输出宽度，列数 $n$ 必须等于输入宽度。
- **内积与投影**。$a\cdot b=\sum_i a_i b_i=\|a\|_2\|b\|_2\cos\theta$，它同时编码了方向和长度。$b$ 在 $a$ 方向上的分量是 $\frac{a\cdot b}{a\cdot a}a$，剩下的是与 $a$ 正交的残差。这一条直接对应注意力的语义：Query 与 Key 的内积越大，说明两者方向越一致；注意力输出就是把 Value 按这个相似度加权后拼起来，等价于一次「沿 Query 方向的投影 + 残差」。
- **范数**。$\|x\|_2=\sqrt{\sum_i x_i^2}$，$\|x\|_1=\sum_i|x_i|$，$\|x\|_\infty=\max_i|x_i|$。几何上 L2 的等值面是球、L1 是菱形、L∞ 是立方体。形状差异决定了两件事：L2 对大分量惩罚更重（平方增长），倾向于把分量摊匀；L1 在坐标轴上有尖角，最优点容易落在某些分量为 0 的位置。归一化层则是用 L2 范数的思路，把一层的输出尺度拉回固定量级。
- **随机变量与期望**。把不确定的量写成 $X$，期望 $\mathbb{E}[X]=\sum_x x\,p(x)$（连续时换成积分），方差 $\mathrm{Var}(X)=\mathbb{E}[(X-\mathbb{E}X)^2]=\mathbb{E}[X^2]-(\mathbb{E}X)^2$。期望的线性性 $\mathbb{E}[aX+bY]=a\mathbb{E}X+b\mathbb{E}Y$ 无条件成立；方差可加 $\mathrm{Var}(X+Y)=\mathrm{Var}X+\mathrm{Var}Y$ 才要求不相关。模型里最常见的用法是把输出当成分布参数：softmax 把任意实数 logits 变成 $p_i=e^{z_i}/\sum_j e^{z_j}$，于是可以谈「模型预测的期望类别」。

**最小例子**：

取 $W=\begin{pmatrix}1&0&-1\\2&1&0\end{pmatrix}$（形状 $(2,3)$）、$x=(3,1,2)^\top$（形状 $(3,)$）。逐行做内积：$y_1=1\cdot3+0\cdot1+(-1)\cdot2=1$，$y_2=2\cdot3+1\cdot1+0\cdot2=7$，得 $y=(1,7)$，形状 $(2,)$。参数量是 $2\times3=6$。

投影：$a=(1,0)$、$b=(3,4)$，系数 $\frac{a\cdot b}{a\cdot a}=\frac{3}{1}=3$，投影向量 $(3,0)$，残差 $(0,4)$ 与 $a$ 正交——这正是「注意力只沿 Query 方向取分量、其余信息靠残差连接保留」的几何图像。

范数：$x=(3,4)$ 时 $\|x\|_2=5$、$\|x\|_1=7$、$\|x\|_\infty=4$。

期望：softmax 输出 $p=(0.1,0.6,0.3)$，类别取值为 $(0,1,2)$ 时 $\mathbb{E}=0\cdot0.1+1\cdot0.6+2\cdot0.3=1.2$，$\mathbb{E}[X^2]=0+0.6+1.2=1.8$，$\mathrm{Var}=1.8-1.44=0.36$。

**面试高频问法**：

1. 「内积为什么能表示相似度？为什么注意力里要除以 $\sqrt{d_k}$？」
   → 考点：几何解释 + 尺度随维度增长。
   → 一句话答法：$a\cdot b=\|a\|\|b\|\cos\theta$，夹角越小内积越大，但内积同时被模长放大；$d_k$ 维独立同分布、各分量量级为 1 时，内积的尺度约按 $\sqrt{d_k}$ 增长，不除掉它，softmax 就会进入梯度极平的饱和区。
2. 「L1 和 L2 的区别，为什么一个稀疏一个不稀疏？」
   → 考点：等值面形状，而不是公式。
   → 一句话答法：L2 的等值面是球、惩罚随平方增长，会把大分量压下去而不偏向任何坐标；L1 的等值面是菱形、在坐标轴上有尖角，最优点更容易落在某些分量恰好为 0 的位置，所以出现稀疏。
3. 「期望的线性性需要独立吗？」
   → 考点：独立与不相关的混淆。
   → 一句话答法：不需要，$\mathbb{E}[X+Y]=\mathbb{E}X+\mathbb{E}Y$ 恒成立；需要不相关（独立是更强条件）的是方差可加。
4. 「为什么网络里到处是矩阵乘，而不是逐元素乘？」
   → 考点：线性映射与并行度。
   → 一句话答法：$(m,n)$ 矩阵就是可学习的 $\mathbb{R}^n\to\mathbb{R}^m$ 线性映射，它把每个输出元素写成输入的一个内积，能一次算完整个 batch，并且天然落成 GPU 上的 GEMM。
5. 「softmax 的输出为什么能当概率用？」
   → 考点：随机变量建模。
   → 一句话答法：它把任意实数 logits 映射成每项为正、总和为 1 的向量，正好是类别分布的参数化形式，于是交叉熵这类量才有概率含义。

## 第 2 章 张量与形状：广播规则、batch 维、reshape 与 transpose 的代价

**要解决的问题**：形状错了模型根本跑不起来，但形状对了也可能出问题——广播悄悄把不该对齐的维度对上、transpose 之后接 reshape 触发一次全量拷贝、或者把 batch 维和数据维搞混导致样本之间互相串。这一章解决的是「张量的逻辑形状和物理内存布局是两件事」，后面 CNN 的 NCHW 与 NHWC、Transformer 的多头切分都以此为前置。

**机制**：

一个张量由三件东西确定：`data`（一段一维连续内存）、`shape`（每一维多长）、`stride`（沿每一维走一步，要在内存里跨过多少元素）。行主序连续时，stride 从最右往左累乘：形状 $(B,T,C)=(8,512,64)$ 对应 strides $(512\cdot64,\;64,\;1)=(32768,64,1)$。

- **广播规则**：从尾部对齐，逐维比较；两维相等、或其中一个是 1，则兼容，结果取较大的那个；缺失的维按 1 补齐。长度为 1 的维通过「stride 设为 0」实现逻辑复制，不真正分配内存。
- **batch 维**：约定第 0 维是 batch。这样每个算子的签名只需要描述「单样本形状」，kernel 按前导维展开并行；同时归一化层的统计范围完全由形状决定——在最后一维（特征维）上统计，就是每个 token 各自归一化；在 $(N,H,W)$ 上统计，就是把每个通道跨样本聚合。
- **reshape 与 transpose 的代价**：`transpose`/`permute` 只交换 stride，是 $O(1)$，但结果通常不再连续；`reshape` 在 stride 兼容时也只改 shape，是 $O(1)$，一旦不兼容就必须先拷贝成连续内存，变成 $O(n)$。`view` 是「不兼容就直接报错」的严格版本。这条规则解释了为什么「先 permute 再 reshape」的写法在形状上正确、在性能上却可能是一次隐藏的全量拷贝。

```python
from itertools import zip_longest

def broadcast_shape(a, b):
    out = []
    for x, y in zip_longest(reversed(a), reversed(b), fillvalue=1):
        if x != y and 1 not in (x, y):
            raise ValueError(f"{a} 与 {b} 不可广播")
        out.append(max(x, y))
    return tuple(reversed(out))

broadcast_shape((2, 1, 4), (3, 4))   # (2, 3, 4)
broadcast_shape((8, 512, 64), (512, 64))  # (8, 512, 64)
```

**最小例子**：

1）广播：$A$ 形状 $(2,1,4)$，$B$ 形状 $(3,4)$。尾部对齐后：$4$ vs $4$ 相等；$1$ vs $3$ 中 $1$ 可广播成 $3$；$2$ vs 缺失（补 $1$）得 $2$。结果 $(2,3,4)$，共 $24$ 个元素，而实际参与运算的只有 $8+12=20$ 个存储元素，多出来的 4 份靠 stride 0 复用。

2）批维与卷积形状：输入 $(32,3,224,224)$ 过一个 $k=7,s=2,p=3$、输出通道 $64$ 的卷积。输出边长 $=\lfloor(224+2\cdot3-7)/2\rfloor+1=\lfloor 223/2\rfloor+1=112$，输出形状 $(32,64,112,112)$。参数量 $64\times(3\cdot7\cdot7+1)=64\times148=9472$——**跟 batch 大小和输入分辨率无关**，这是「形状只影响计算量、不影响参数量」的最典型例子。

3）transpose 的代价：$(8,512,64)$ 经 `permute(0,2,1)` 得 $(8,64,512)$，strides 从 $(32768,64,1)$ 变为 $(32768,1,64)$，操作本身 $O(1)$。但此时内存布局是「同一位置跨 64 个通道、步长为 1」，若再 `reshape(8, 64*512)`，由于第 1、2 维的 stride 不是连续期望的 $(512,1)$，必须先把 $8\times512\times64=262144$ 个元素按新顺序拷一遍。改成先 `contiguous()` 再 `reshape`，语义相同，但拷贝点变得显式可控。

**面试高频问法**：

1. 「广播规则说一遍，什么情况下会报错？」
   → 考点：尾部对齐，而不是从头对齐。
   → 一句话答法：从最后一维往前逐维比，相等或有一个是 1 就兼容、取较大值，缺失的维补 1；只要有某一维既不相等又没有 1，就报错。
2. 「为什么 batch 维固定放第 0 维？」
   → 考点：算子签名统一与访存局部性。
   → 一句话答法：同一 batch 内每个样本形状完全一致、走完全相同的算子，放第 0 维后每个算子只需描述单样本形状，kernel 按前导维展开并行；同时行主序下 batch 维在最外层，切片一个样本仍是一段连续内存。
3. 「transpose 是免费的吗？」
   → 考点：shape 与 stride 分离。
   → 一句话答法：transpose 只交换 stride，本身 $O(1)$，但它让张量不再连续；后续接 reshape 或矩阵乘时可能触发一次 $O(n)$ 的隐式拷贝，所以要么保证转置的是相邻维、要么显式 `contiguous()`。
4. 「`view` 和 `reshape` 有什么区别？」
   → 考点：连续性与 stride 兼容。
   → 一句话答法：`view` 只在原张量 stride 兼容时才能改形状，否则直接报错；`reshape` 遇到不兼容会先拷一份连续内存再改，所以能用 `view` 的地方说明你没走隐式拷贝。
5. 「归一化层到底在哪些维上做统计，由什么决定？」
   → 考点：共享统计量的范围就是张量的维度划分。
   → 一句话答法：由形状决定共享范围——在最后一维（特征维）统计，就是每个位置各自归一化；在 $(N,H,W)$ 上统计，就是每个通道跨样本聚合。改一批维度顺序，语义就变了，不只是快慢问题。

## 第 3 章 从线性回归到感知机：模型就是一个参数化的函数

**要解决的问题**：把“模型”从一句“输入到输出”落实到可计算的对象：给定输入 $x$ 和参数 $\theta$，前向算出 $f_\theta(x)$。不解决，后面看 MLP、CNN、Transformer 都只是黑箱，也说不清参数量和决策边界从哪来。

**机制**：

线性模型是 $f(x)=w^\top x+b$，其中 $x\in\mathbb R^d$，$w\in\mathbb R^d$，$b\in\mathbb R$，参数共 $d+1$ 个。输出实数时叫线性回归；把输出过阈值得到类别时叫感知机：

$$
\hat y=\operatorname{sign}(w^\top x+b)
$$

符号函数只改输出解释，不改几何：决策边界始终是超平面 $w^\top x+b=0$。因此单层感知机的假设空间只包含线性可分函数；XOR 的正负样本不能被一条直线分开，单层感知机无解。不是参数没调好，而是模型族里没有这个函数。

批量输入时 $X\in\mathbb R^{B\times d}$，前向写成 $Xw+b$，输出形状 $B$；$b$ 广播到每个样本。参数仍是 $d+1$，batch 维不增加参数，只增加计算量。

```python
def linear(X, w, b):        # X: (B, d), w: (d,), b: scalar
    return X @ w + b        # (B,)

def perceptron(X, w, b):
    z = linear(X, w, b)
    return (z >= 0).astype(int)
```

关键取舍：线性模型参数少、可解释、外推行为受控，但假设强；感知机把输出二值化，不提升几何表达能力。参数如何得到不在本章范围，本章只关心“这个函数长什么样、有多少参数、算什么”。

**最小例子**：

取 $x=(2,1)$，$w=(0.5,-1)$，$b=0.3$，则

$$
z=0.5\times2+(-1)\times1+0.3=0.3
$$

感知机输出 $+1$。决策边界 $0.5x_1-x_2+0.3=0$，即 $x_2=0.5x_1+0.3$。点 $(0,0)$ 得 $0.3>0$，判为正；点 $(0,1)$ 得 $-0.7<0$，判为负。参数量 $d+1=3$。若输入是 $784$ 维，单层就有 $785$ 个参数；batch 取 $32$，矩阵乘法是 $32\times784$ 乘 $784$，得到 $32$ 个输出。

**面试高频问法**：

- **问**：线性回归和感知机有什么区别？→ **考点**：输出形式与模型族是否改变 → **答**：两者都是 $w^\top x+b$；线性回归输出实数，感知机把实数过符号函数变成类别，决策边界仍是同一个超平面。
- **问**：感知机为什么不能解 XOR？→ **考点**：线性可分性与假设空间 → **答**：XOR 的正负样本不被任何一条直线分开，而单层感知机的决策边界就是 $w^\top x+b=0$，所以模型族里没有解。
- **问**：$w$ 的维度和参数量由什么决定？→ **考点**：形状与参数计数

## 第 5 章 卷积网络

**要解决的问题**：全连接层把图像展平成一个向量，相当于假设「第 3 个像素和第 5000 个像素的关系」与「相邻两个像素的关系」同等重要；参数量随分辨率平方增长，且整幅图平移一个像素输出就全变。卷积层要在保留二维邻域结构的前提下，把参数量从「与分辨率挂钩」变成「只与核大小、通道数挂钩」。

**机制**：卷积核是权重张量 $K\in\mathbb{R}^{k_h\times k_w\times C_{in}\times C_{out}}$。输出每个位置是输入一个 $k_h\times k_w$ 窗口与该核的加权和（框架里实际算的是互相关，不翻转核；核是学出来的，翻不翻转无差别）。

两个归纳偏置撑起整个结构：**局部连接**——每个输出只看 $k\times k$ 邻域，把「远处像素不该直接影响我」写进结构；**权重共享**——同一组核在所有空间位置复用，把「同一个图案出现在哪都该被同样识别」写进结构，带来平移等变性（输入平移 $s$，输出也平移 $s$）。

形状与代价三件套（单边）：

$$O=\left\lfloor\frac{I+2P-D(K-1)-1}{S}\right\rfloor+1$$

$$\#\text{params}=K_hK_wC_{in}C_{out}+C_{out}\qquad \text{MACs}=O_hO_wC_{out}K_hK_wC_{in}$$

参数量与 $H,W$ 无关，计算量与分辨率成正比——这是 CNN 能上高分辨率图像的根本原因。感受野递推：$r_l=r_{l-1}+(k_l-1)\prod_{i<l}s_i$，$r_0=1$。

三个旋钮各有明确职责：**padding** 控制输出尺寸、避免边缘像素被少算；**stride** 下采样；**dilation** 在核元素间插空洞，感受野按 $D$ 线性放大而参数不变。**池化**对每通道局部窗口取 max/mean，无可学习参数，作用是降分辨率、放大后续层的有效感受野；max 池化额外给一点局部平移不变性，代价是丢掉精确位置。

```python
def conv_out(i, k, p=0, s=1, d=1):
    return (i + 2*p - d*(k-1) - 1)//s + 1

def receptive_field(ks, ss):          # 各层 kernel / stride
    r, jump = 1, 1
    for k, s in zip(ks, ss):
        r += (k-1)*jump
        jump *= s
    return r
```

**最小例子**：单通道 $3\times3$ 输入、$3\times3$ 核、$S=1,P=0,D=1$：

输入
```
1 2 3
4 5 6
7 8 9
```
核取单位阵（对角为 1，其余 0）。$O=(3+0-3)/1+1=1$，唯一元素 $=1\cdot1+5\cdot1+9\cdot1=15$，输出 `[[15]]`——这个核就是「取对角线之和」。

尺寸与参数量：输入 $224\times224\times3$ 接 `Conv2d(3, 64, k=3, s=1, p=1)` → 输出 $224\times224\times64$，参数 $3\cdot3\cdot3\cdot64+64=1792$，乘加约 $224\cdot224\cdot64\cdot9\cdot3\approx8.7\times10^7$。同输入接一个 1000 维全连接层是 $224\cdot224\cdot3\cdot1000\approx1.5\times10^8$ 参数，差五个数量级。

感受野：`ks=[3,3,3], ss=[1,1,1]` → $r=1\to3\to5\to7$，三层 3×3 抵一个 7×7；$C$ 通道下参数 $3\cdot9C^2=27C^2$ 对 $49C^2$，中间还多两次非线性。

stride 减半：$k=3,s=2,p=1,I=224$ → $\lfloor(224+2-3-1)/2\rfloor+1=112$，正好减半。

**面试高频问法**：

1. 「卷积层和全连接层的本质差别？」→ 考点是那两个归纳偏置。答法：卷积只让每个输出看 $k\times k$ 邻域，且同一组核在所有位置复用，所以参数量与分辨率解耦、天然平移等变；全连接给每个位置学独立权重，把空间结构当成了无结构的向量。
2. 「给定 $k,s,p$ 算输出尺寸；想让 stride=2 时正好减半怎么配？」→ 考点是公式。答法：$O=\lfloor(I+2P-D(K-1)-1)/S\rfloor+1$；$k=3,s=2,p=1$ 时 $O=\lfloor(I-1)/2\rfloor+1$，$I$ 为偶数正好是 $I/2$。
3. 「3 个 3×3 和 1 个 7×7 感受野一样，选哪个？」→ 考点是参数与非线性。答法：选堆叠，参数 $27C^2$ 对 $49C^2$，且中间多两层激活、表达力更强；代价是更深的串行链路和更多内存访问。
4. 「1×1 卷积在干什么？」→ 考点是通道维线性组合。答法：它在每个像素位置对 $C_{in}$ 个通道做一次加权和，空间上不聚合，参数 $C_{in}C_{out}$；用于升降通道、跨通道融合，后面还能接非线性。
5. 「池化和 dilation 都是为了扩大感受野，怎么选？」→ 考点是任务约束。答法：池化是硬下采样，降分辨率、max 池化带一点平移不变性，适合分类主干；dilation 不下采样就放大感受野，适合分割检测这类要保分辨率的下游。代价是核采样点稀疏会出现网格盲区，常用混合 dilation 率的堆叠。

## 第 6 章 序列模型

**要解决的问题**：前几章的模型都吃定长、同构、无序的输入。但语言、语音、传感器读数的长度可变，且顺序本身携带信息（"dog bites man" 和 "man bites dog" 词袋相同）。需要一个参数量不随长度增长、又能把「到目前为止看过什么」编码下来的结构。

**机制**：RNN 的核心是一个在时间上共享的递推单元：

$$h_t=\tanh(W_{xh}x_t+W_{hh}h_{t-1}+b_h),\qquad y_t=W_{hy}h_t+b_y$$

1. **参数共享**：$W_{xh},W_{hh},W_{hy}$ 每步复用，参数量与序列长度 $T$ 无关，任意长度都能跑。
2. **链式依赖**：$h_t$ 依赖 $h_{t-1}$，时间步之间不能并行，跑完 $T$ 步必须串行 $T$ 次。
3. **定长瓶颈**：整段历史被压进一个 $d_h$ 维向量，每来一个新 token 就整体重写一次，没有「原地保留」的通道。

## 第 7 章 注意力与 Transformer：QKV、多头、位置编码、残差与归一化的位置

**要解决的问题**：RNN 靠链式依赖传递信息，任意两个位置之间的路径长度随距离增长，且时间步不能并行。注意力让每个位置直接读取序列中任意位置的信息，Transformer 则把“注意力 + 前馈网络”堆成可并行的块。不解决这个问题，长程依赖和长序列并行都受限于递归结构。

**机制**：输入序列 $X\in\mathbb{R}^{n\times d}$，$n$ 是 token 数，$d$ 是模型维度。每个位置产生三组向量：查询 $Q$、键 $K$、值 $V$，由可学习矩阵投影得到：

$$
Q=XW_Q,\quad K=XW_K,\quad V=XW_V,\quad W_Q,W_K,W_V\in\mathbb{R}^{d\times d_k}
$$

注意力分数是查询和键的内积，除以 $\sqrt{d_k}$ 后 softmax，再对值加权：

```text
Q, K, V = X @ Wq, X @ Wk, X @ Wv      # [n,d] -> [n,d_k]
S = Q @ K.T / sqrt(d_k)                # [n,n]
S[mask] = -inf                         # 因果或 padding 屏蔽
A = softmax(S, dim=-1)                 # 每行和为 1
Y = A @ V                              # [n,d_k]
```

$QK^\top$ 的每个元素衡量“位置 $i$ 的查询”和“位置 $j$ 的键”有多匹配；softmax 把匹配度变成权重；$A V$ 就是按权重对值做加权和。除以 $\sqrt{d_k}$ 是因为点积的方差随 $d_k$ 增大而增大，不缩放会让 softmax 进入饱和区，权重接近 one-hot。因果掩码把 $j>i$ 的位置置为 $-\infty$，保证自回归模型只能看左侧。

多头注意力把 $d$ 维切成 $h$ 个头，每头维度 $d_k=d/h$，各自做一次注意力，拼接后再乘输出矩阵 $W_O$：

$$
\text{head}_i=\text{Attention}(XW_Q^i,XW_K^i,XW_V^i),\quad
Y=\text{Concat}(\text{head}_1,\dots,\text{head}_h)W_O
$$

若每头 $d_k=d/h$，QKV 加输出的总参数量约为 $4d^2$，和单头 $d_k=d$ 同量级；多头不是简单堆参数，而是让不同头在不同子空间里建立关系。

自注意力对位置置换是等变的：把 token 顺序打乱，输出也跟着打乱，模型本身不知道谁在前谁在后。因此要加位置编码。正弦位置编码为：

$$
PE(pos,2i)=\sin\left(\frac{pos}{10000^{2i/d}}\right),\quad
PE(pos,2i+1)=\cos\left(\frac{pos}{10000^{2i/d}}\right)
$$

不同维度对应不同频率，每个位置得到一个唯一模式；它也可以被学习成位置嵌入。相对位置编码、RoPE 等变体按实现而定。

每个 Transformer 块由两个子层组成：多头注意力和前馈网络（通常是两层线性加激活，$d_{ff}$ 常取 $4d$）。残差连接让子层只学习“增量”：

$$
x\leftarrow x+\text{Sublayer}(x)
$$

归一化的位置有两种常见写法。Post-LN 是“先残差相加，再归一化”：$x\leftarrow \text{Norm}(x+\text{Sublayer}(x))$，原始 Transformer 采用这种结构。Pre-LN 是“先归一化，再进子层”：$x\leftarrow x+\text{Sublayer}(\text{Norm}(x))$，残差主干不被归一化打断，常见大模型实现采用这种写法。两者差别不在参数量，而在信号沿主干的传播路径。

**最小例子**：取 $n=2$、$d_k=2$，单头，令

$$
Q=K=\begin{bmatrix}1&0\\0&1\end{bmatrix},\quad V=\begin{bmatrix}1&0\\0&1\end{bmatrix}
$$

则 $QK^\top=I$，除以 $\sqrt{2}$ 后分数矩阵为

$$
S=\begin{bmatrix}0.707&0\\0&0.707\end{bmatrix}
$$

对每行 softmax：第一行 $e^{0.707}\approx2.028$、$e^0=1$，权重为 $[0.670,0.330]$；第二行为 $[0.330,0.670]$。于是

$$
A=\begin{bmatrix}0.670&0.330\\0.330&0.670\end{bmatrix},\quad
Y=AV=A
$$

第一个 token 的输出是 $[0.670,0.330]$，它混入了第二个 token 的值。若把两个 token 交换，输出也交换，说明没有位置编码时模型分不清顺序；把位置向量加到输入 $X$ 上，才会打破这种置换等变。

**面试高频问法**：

- 为什么注意力要除以 $\sqrt{d_k}$？ → 考点是缩放点积的数值性质。答法：点积方差随 $d_k$ 线性增长，不缩放会让 softmax 饱和、权重近似 one-hot；除以 $\sqrt{d_k}$ 把方差拉回 1 量级。
- 多头注意力和单头比，参数量增加了吗？ → 考点是头拆分与参数共享。答法：若每头 $d_k=d/h$，QKV 加输出约 $4d^2$，与单头 $d_k=d$ 同量级；多头是划分子空间，不是靠堆参数。
- 位置编码为什么必要？正弦编码怎么表达位置？ → 考点是自注意力的置换等变性。答法：自注意力本身对 token 顺序等变，没有位置信息；正弦编码用不同频率的 sin/cos 给每个位置唯一模式，相对位移可由线性变换表达。
- Pre-LN 和 Post-LN 的区别是什么？ → 考点是残差与归一化的连接顺序。答法：Pre-LN 先归一化再进子层，残差主干直通；Post-LN 在残差相加后归一化。原论文用 Post-LN，常见大模型实现用 Pre-LN。
- 自注意力的计算复杂度是多少？ → 考点是 $n^2$ 项来源。答法：$QK^\top$ 和 $AV$ 都是 $n\times n$ 矩阵，复杂度 $O(n^2d)$；长序列时这是主要瓶颈。

## 第 8 章 架构选型：参数量与计算量估算、归纳偏置、什么时候不该用 Transformer

**要解决的问题**：同一个任务可以用 MLP、CNN、RNN 或 Transformer，参数量、计算量、延迟和样本效率差别很大。选型要能先用公式估算“存得下吗、算得动吗”，再判断结构先验是否匹配数据。不解决这个问题，就会把 Transformer 当成默认答案，忽略长序列二次成本和弱归纳偏置的代价。

**机制**：先算参数量。线性层 $d_{in}\to d_{out}$ 的参数量是 $d_{in}d_{out}+d_{out}$；卷积层 $K\times K$、输入通道 $C_{in}$、输出通道 $C_{out}$ 的参数量是 $K^2C_{in}C_{out}+C_{out}$，与输入空间尺寸无关，这是权重共享的直接结果。Transformer 每层忽略 bias 和 LayerNorm，注意力投影约 $4d^2$，前馈网络约 $2dd_{ff}$；取 $d_{ff}=4d$，每层约

$$
4d^2+2d\cdot 4d=12d^2
$$

$L$ 层约 $12Ld^2$，词嵌入表约 $Vd$，$V$ 是词表大小。

再算计算量。矩阵乘 $[m,k]\times[k,n]$ 的乘加次数是 $mkn$，按 FLOPs 常粗略算 $2mkn$。卷积的输出乘加次数是

$$
H_{out}W_{out}C_{out}K^2C_{in}
$$

自注意力每层约 $4n^2d$ 次乘加（$QK^\top$ 和 $AV$ 各 $2n^2d$），投影和前馈约 $24nd^2$。所以每层计算量大致是

$$
24nd^2+4n^2d
$$

$n$ 较小时前馈占主导，$n$ 增大后 $n^2$ 项迅速变成瓶颈。稠密模型前向常粗略按“每 token FLOPs 约 $2\times$ 参数量”估，但注意力部分随序列长度增长，必须单独加。

归纳偏置决定样本效率。MLP 对输入维度一视同仁，没有空间或顺序先验；CNN 有局部连接、权重共享和平移等变，适合图像中局部模式反复出现的结构；RNN 有顺序递归和状态传递，适合流式、因果序列；Transformer 除位置编码外近似置换等变，先验弱、表达灵活，因此更依赖数据量和位置信息设计。结构先验与任务匹配时，小数据也能学好；先验不匹配时，模型容量再大也可能样本效率很低。

什么时候不该用 Transformer：序列很长时，$O(n^2)$ 注意力在计算和显存上都昂贵；数据规模小、任务有强局部性时，CNN 往往更省参数；边缘设备要求低延迟、低内存时，深层 Transformer 的参数量和访存成本可能不划算；严格流式、逐 token 到达的因果任务，RNN 或状态空间模型可能更自然；低维表格特征上，线性模型或树模型常常比深层网络更合适。选型顺序可以是：先看输入结构（网格、序列、集合、表格），再看约束（参数量、FLOPs、延迟、序列长度），最后看数据规模是否支撑弱先验模型。

**最小例子**：一个 $d=512$、$d_{ff}=2048$ 的 Transformer 块，注意力投影约 $4\times512^2=1{,}048{,}576$，前馈约 $2\times512\times2048=2{,}097{,}152$，合计约 $3.15$M 参数（不含 bias/LN）。堆 $12$ 层约 $37.7$M；若词表 $V=32000$，嵌入表约 $32000\times512=16.38$M，总计约 $54$M。计算量方面，取 $n=1024$，每层前馈与投影约 $24nd^2\approx6.44$G FLOPs，注意力约 $4n^2d\approx2.15$G FLOPs；序列再长，后一项会按平方增长。

对比一个卷积层：输入 $32\times32\times3$，卷积核 $3\times3$，输出 $64$ 通道，padding 保持尺寸，参数量为 $3^2\times3\times64+64=1{,}792$；输出乘加次数为 $32\times32\times64\times3^2\times3=1{,}769{,}472$。参数量很小，但计算量与空间尺寸成正比，这正是 CNN 权重共享和局部性的体现。

**面试高频问法**：

- 怎么快速估算 Transformer 的参数量？ → 考点是每层 $12d^2$ 的来源。答法：注意力 QKV 加输出约 $4d^2$，前馈取 $d_{ff}=4d$ 约 $8d^2$，每层约 $12d^2$；总参数约 $12Ld^2+Vd$，不含 bias 和 LayerNorm。
- 参数量和计算量是一回事吗？ → 考点是存储与运算的区分。答法：不是；参数量决定存储，计算量还取决于序列长度和输入尺寸；注意力参数不随 $n$ 变，但计算量含 $n^2$ 项。
- CNN 的归纳偏置是什么？ → 考点是局部性、权重共享、平移等变。答法：卷积只连接局部邻域，同一组核在空间上共享，因此对平移等变；匹配图像局部模式时样本效率高。
- 什么时候不该用 Transformer？ → 考点是二次复杂度和弱先验的代价。答法：长序列、小数据、边缘低延迟、强局部或严格流式任务，应优先考虑 CNN、RNN、状态空间模型或更简单的模型。
- 为什么 Transformer 在视觉里也能用？ → 考点是 patch 化与先验取舍。答法：把图像切 patch 当 token，位置编码补空间信息；它先验弱、容量大，数据充足时可与 CNN 竞争，小数据上 CNN 仍常更省。

## 第 4 章 全连接网络：层的堆叠、激活函数、为什么必须有非线性

**要解决的问题**：把单个线性打分器扩展成能表达特征之间非线性组合的函数。否则无论堆多少层，整个模型仍然只是一个仿射变换，“深度”不带来任何表达能力。

**机制**：全连接层（dense/linear 层）做的是仿射映射：

$$
y = Wx + b,\quad W\in\mathbb{R}^{d_{\text{out}}\times d_{\text{in}}},\ b\in\mathbb{R}^{d_{\text{out}}}
$$

输入是 batch 时，$X\in\mathbb{R}^{B\times d_{\text{in}}}$，输出为

$$
Y = XW^\top + b
$$

其中 $b$ 沿 batch 维广播。第 $l$ 层参数量是

$$
P_l = d_{l-1}d_l + d_l = (d_{l-1}+1)d_l
$$

前向乘加次数约为 $B d_{l-1}d_l$，batch 只放大计算量，不改变参数量。全连接层没有权重共享：输入的每个坐标和输出的每个坐标之间都有独立权重，所以参数量随输入、输出维度相乘增长。

层堆叠的基本形式是“线性混合 → 逐元素激活 → 线性混合 → …”。激活函数按元素作用，不在特征维上混合；混合只发生在全连接层里。常见隐藏层激活包括：

- ReLU：$\max(0,z)$，分段线性、正半轴无上界、负半轴恒零，计算便宜。
- GELU：平滑的 ReLU 变体，常用于 Transformer。
- sigmoid/tanh：有界、两端饱和，早期网络常用，也常出现在门控或概率输出里。

输出层按任务决定：回归通常直接输出；二分类可用 sigmoid；多分类常用 softmax 把 logits 变成概率分布。softmax 会跨类别归一化，不是逐元素激活。

一个三层全连接网络可以写成：

```python
# X: (B, d_in)
H1 = relu(X @ W1.T + b1)   # W1: (h1, d_in) -> H1: (B, h1)
H2 = gelu(H1 @ W2.T + b2)  # W2: (h2, h1) -> H2: (B, h2)
logits = H2 @ W3.T + b3    # W3: (d_out, h2) -> (B, d_out)
```

**为什么必须有非线性**：如果两层之间不加激活，设

$$
h = W_1x+b_1,\quad y = W_2h+b_2
$$

则

$$
y = W_2(W_1x+b_1)+b_2 = (W_2W_1)x + (W_2b_1+b_2)
$$

仍然是单个仿射层。更深也只是把多个矩阵乘成一个矩阵，秩不超过各层矩阵秩的最小值，深度没有增加新的函数族。加入 ReLU 后，网络变成分段线性函数；堆叠层数会增加线性区域的数量，使模型能逼近更复杂的输入输出关系。单隐层足够宽时可以逼近连续函数，但这是存在性结论，不等于一定容易学或泛化好。

**最小例子**：取输入 $x=(1,2)$，第一层两个隐藏单元：

$$
W_1=\begin{bmatrix}1&-1\\0.5&0.5\end{bmatrix},\quad b_1=(0,0)
$$

则 $z_1=W_1x=(-1,1.5)$，经过 ReLU 得 $h=(0,1.5)$。第二层取 $W_2=(2,-1)$，$b_2=0.5$：

$$
y = 2\cdot0 + (-1)\cdot1.5 + 0.5 = -1.0
$$

如果去掉 ReLU，则 $y=(2,-1)\cdot(-1,1.5)+0.5=-3.0$。同一个输入、同一组权重，仅因为中间多了非线性，输出就不同。参数量为第一层 $2\times2+2=6$，第二层 $1\times2+1=3$，共 9 个。若 batch 大小 $B=2$，输入形状是 $(2,2)$，隐藏层是 $(2,2)$，输出是 $(2,1)$，参数形状不变。

宽度决定每层能形成多少个线性组合，深度决定组合的层数。全连接网络对输入坐标没有空间或时间上的权重共享，因此适合特征已经是定长向量的场景；对图像、长序列这类有局部结构的数据，全连接不是最省参数的归纳偏置，这也是后续卷积网络和序列模型要解决的问题。

**面试高频问法**：

1. 问：两层全连接中间不加激活，和一层有什么区别？  
   考点：仿射复合的封闭性。  
   答：没有区别，$W_2(W_1x+b_1)+b_2=(W_2W_1)x+(W_2b_1+b_2)$，仍是一个仿射层，深度白加。

2. 问：全连接层参数量和计算量怎么估？  
   考点：形状与 batch 维。  
   答：第 $l$ 层参数是 $(d_{l-1}+1)d_l$，前向乘加约 $B d_{l-1}d_l$，batch 只放大计算不放大参数。

3. 问：ReLU 为什么常作默认隐藏层激活？  
   考点：设计取舍。  
   答：$\max(0,z)$ 分段线性、正半轴不饱和、计算便宜；代价是负半轴输出恒零，信息被截断。

4. 问：sigmoid/tanh 和 ReLU 的差别在哪？  
   考点：饱和性与输出范围。  
   答：sigmoid/tanh 有界且两端饱和，适合门控或概率输出；ReLU 无上界、负半轴稀疏，适合宽隐藏层。

5. 问：输出层要不要加激活？  
   考点：logits 与概率的区别。  
   答：回归通常直接输出；二分类用 sigmoid；多分类用 softmax 把 logits 变成概率分布，但 softmax 不改变类别排序。
