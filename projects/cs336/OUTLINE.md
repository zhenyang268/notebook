## 0 一句话

**不用 `transformers` 库，从 tokenizer 开始把 GPT 搭出来并训到能说人话。**

## 1 目标：做完之后必须能回答

1. **BPE** 的合并规则是怎么从语料里学出来的？为什么它比按词切分好？
2. **注意力**的 $QK^T/\sqrt{d}$ 里那个 $\sqrt{d}$ 为什么必须除？
3. **RMSNorm vs LayerNorm** 差在哪？为什么现在多用前者？
4. **学习率 warmup + cosine 衰减**解决什么问题？不做会怎样？

## 2 里程碑

| 里程碑 | 内容 | 验收 | 估时 |
|---|---|---|---|
| **M1 Tokenizer** | BPE 训练 + 编解码 | 与参考实现的 token 序列**完全一致** | 8h |
| **M2 Transformer** | 注意力、FFN、残差、位置编码 | 前向输出形状正确 + 小模型能过拟合 | 12h |
| **M3 训练循环** | AdamW、warmup+cosine、梯度裁剪 | loss 单调下降，不 NaN | 8h |
| **M4 小规模训练** | 在 TinyStories 级数据上训练 | 能生成通顺短句 | 12h |
| **M5 推理优化** | KV cache、采样策略 | 生成速度 ≥ 3× 无 cache | 6h |

**M1 + M2 是地基**，M4 是"真的训出来"的标志。

## 3 验收标准

- M1：给同一段文本，**你的 token id 序列与 `tiktoken` 完全一致**（逐 id 比对）。
- M2：**形状断言全部通过**；用 100 条样本过拟合到 loss < 0.1。
- M3：训练 1000 步**不出现 NaN**；loss 曲线无剧烈震荡。
- M4：生成的句子**语法通顺率 > 70%**（人工抽 20 条判断）。

## 4 时间预算与取舍

```
最小闭环：M1 + M2 + M3（28h），能训出"能过拟合"的模型。
```
**明确不做**：分布式训练、FlashAttention 手写、RLHF。
