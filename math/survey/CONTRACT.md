# survey/ 契约 —— 主仓数学面的镜像清单

> 定于 2026-11-03。**本文件是 `survey/` 的唯一规约，改规约只能改这里。**
> 真源在代码仓，不在这里；本目录只是镜像。

## 0. 一句话

`survey/` **不是教程，是镜像**：库里有的数学对象，这里必须有且必须标对状态；库里没有的，这里只能以「缺位」或「缺口」的形式出现，不许自造。

## 1. 定位（唯一职责）

只回答三个问题，多一个都不答：

1. 这个数学对象在库里**哪个位置**（文件 / 函数 / 常量）；
2. 它的结论**在什么条件下成立**；
3. 它**失败时长什么样**（阈值、异常、症状）。

不回答：为什么美妙、直觉怎么说、怎么推导。前者归 `../bridges/`，后者归 `math/` 主篇 A–R。

## 2. 边界（五条硬线）

1. **单真源**。事实只来自三处：
   - `learning/graphics/src/**/*.hpp` 末尾的「③ 数学公式与符号表」；
   - `learning/docs/standard/01-numerics.md`（D7 / D12 / D19 / D20）；
   - 同一头文件 ① 段的接口契约（形状、容差、异常类型）。

   教科书只用于读懂，**不许用来补「原文未给」**。原文没给就写「原文未给」，并进 `p11-audit.tex` 的缺口节。
2. **无位置不立条**。每个 `know` 条目必须能落到一处位置：某个 `.hpp`，或 `NOW.md` 的某个条目号，或显式的「缺位」（见 §4）。
3. **不写代码**。不给字节布局、循环写法、指针技巧。库怎么实现归代码仓，这里只到「功能与设计」。
4. **编号只增不改**。十一组 `A L N C H P D G F T M` 是冻结的编号空间。删条目只标记不重排；**新增组必须先改 `p1-overview.tex` 的分支表**，否则全库交叉引用失效。
5. **不引入第二个坐标系**。文件→条目的映射表（`p11-audit.tex` 第一张表）是**唯一**的「哪个文件贡献哪几条」的真源，别处只许引用，不许复制第二份。

## 3. 条目格式（冻结）

```latex
\begin{know}{编号}{名称}{状态：真源位置}
\field{是什么}     …
\field{为什么需要} …
\field{关键结论}   …（必须带成立条件）
\field{判据}       …（必须落到数字，或写「原文未给」）
\field{前置}       …（必须给编号，或写「无」）
\field{常见误解}   …
\end{know}
```

六个字段、这个顺序，**一个都不能少**。缺字段不算风格问题，算没写完：

| 字段 | 硬要求 |
|---|---|
| 关键结论 | 必须跟一句「成立条件：…」；没有条件就是错 |
| 判据 | 必须是数字 / 容差 / 异常类型，或「原文未给」四字 |
| 前置 | 必须是已有编号，或「无」；不许写「见上文」 |
| 常见误解 | 必须是否定式（「以为……其实……」），不是补充说明 |

## 4. 状态词（白名单 5 值，机器可判）

| 状态 | 判据（怎么核） |
|---|---|
| 已实现 | 函数体有真实算法 |
| 框架 | 签名与注释已定、函数体全 `throw`；注释即规格 |
| 骨架 | 源码自述「骨架」 |
| 未建 | 只在 `NOW.md` 规划，文件还不存在 |
| 缺位 | 库里既没位置、也没规划 —— **必须同时在 `p11-audit.tex` 缺口节登记一行** |

状态词后可带括号限定（`已实现（部分）`），冒号后写真源位置。**不许出现第六种说法。**

> 2026-11-03 的两处改写：A4「部分已实现」→`已实现（部分）`；L9「库无 det 入口」→`缺位`。
> 原因是这两种写法无法归类，会让计数对不上；改写后 97 条 = 49 + 28 + 3 + 16 + 1。

## 5. 更新触发（T1–T5）——「我说更新」到底等于什么

触发是**事件**，不是心情。五件事任一发生，`survey/` 必须在同一次提交内跟完；一件都没发生就不动。

| 触发 | 怎么发现 | 必须改的位置 |
|---|---|---|
| **T1** 新头文件 / 文件删除 | `graphics/src` 下出现或消失 `.hpp` | `p11` 表加/删一行；至少一条 `know` 条目 |
| **T2** 状态迁移（未建→框架→已实现） | 函数体出现 / `throw` 消失 | 该条目状态词 + 判据段；`p11` 状态列；`p1` 计数 |
| **T3** 契约变更（D7 / D12 / D19 / D20、`01-numerics.md`） | 父仓文档 diff | 受影响条目的「关键结论」与「判据」 |
| **T4** 判据变更（阈值、容差、异常类型） | `demo/**/*.cpp` 或 `04-test-writing.md` | 该条目「判据」段 |
| **T5** `NOW.md` 整篇重写（版本头变了） | `NOW.md` 第 11 行日期 | F / M 组（未建条目）重排 + `p1` 计数 + `p11` 末四行 |

## 6. 同步动作（固定四步，顺序不能换）

1. 改条目：状态词 → 判据段 → 常见误解（若失败模式变了）；
2. 改 `p11-audit.tex` 的文件映射表与缺口节；
3. 改 `p1-overview.tex` 的总数与分类数；
4. 跑 `python3 math/survey/verify.py`，**必须 CRIT=0**。

> 计数是**校验和**：手写的 97 / 49 / 28 / 3 / 16 / 1 必须能被重新数出来。改完不跑脚本 = 没同步。

## 8. 不做清单

- 不写跨篇直觉与 ≅（→ `../bridges/`）
- 不写推导与证明（→ `math/` 主篇）
- 不写进度、排期、谁在做（→ `NOW.md`）
- 不复制 `NOW.md` 条目正文，只引用条目号
- 不因「教科书上更完整」而扩条目；该扩的是 `p11` 的**缺口清单**，不是 `know` 条目

## 9. 与 bridges 的分工

| | `survey/` | `bridges/` |
|---|---|---|
| 分篇依据 | 代码结构（十个分支） | 结构动作（S1–S6） |
| 方向 | **横向**：库里有什么数学 | **纵向**：这些数学是同一个动作的不同实例 |
| 真源 | 头文件 ③ 段 | 骨架节点 + `NOW.md` 工程出口 |
| 共同点 | 同一套状态词、同一套「缺口必须登记」的手法 | 同左 |

两个目录**不许互相抄正文**，只能互相引用编号。
