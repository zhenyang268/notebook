## 第一阶段：分析学的计算基础

### 1.1 勒贝格积分与收敛定理

**必须完成的计算：**

1. 证明 $f_n(x) = n \cdot \mathbf{1}_{(0, 1/n)}(x)$ 逐点收敛到 0，但 $\int f_n = 1$ 不收敛到 0。说明为什么 DCT 不适用（找不到控制函数）。

2. 计算 $\lim_{n\to\infty} \int_0^1 \frac{n x}{1 + n^2 x^2}\,dx$。先猜答案，再用 DCT 或 MCT 严格证明。

3. 证明 $\int_0^\infty e^{-x^2}\,dx = \frac{\sqrt{\pi}}{2}$（用极坐标换元，涉及勒贝格积分的 Fubini 定理）。

4. 构造一个黎曼不可积但勒贝格可积的函数（狄利克雷函数），计算其勒贝格积分。

**经典问题：**

- **Vitali 集合**：构造一个不可测集。理解为什么需要选择公理，以及为什么不是所有集合都可测。
- **Cantor 集与 Cantor 函数（魔鬼阶梯）**：一个测度为零的集合上定义的连续函数，导数几乎处处为零但函数不是常数。理解"奇异"的含义。

### 1.2 $L^p$ 空间与泛函分析

**必须完成的计算：**

1. 证明 $L^2[0,1]$ 中 $\{1, \sqrt{2}\cos 2\pi nx, \sqrt{2}\sin 2\pi nx\}_{n=1}^\infty$ 是正交基。计算 $f(x) = x$ 的傅里叶系数，验证 Parseval 定理：$\int_0^1 x^2\,dx = \sum |c_n|^2$。

2. 在 $L^2[-1,1]$ 中，将 $f(x) = x^3$ 展开为 Legendre 多项式。验证正交性。

3. 证明柯西-施瓦茨不等式 $|\langle f, g\rangle| \leq \|f\|\|g\|$，并找出等号成立条件。

4. 计算积分算子 $(Tf)(x) = \int_0^1 K(x,y)f(y)\,dy$（$K$ 给定）的特征值和特征函数。具体取 $K(x,y) = \min(x,y)$（这是布朗运动的协方差核！）。

**经典问题：**

- **Hilbert 矩阵**：$H_{ij} = \frac{1}{i+j-1}$。证明它是 $L^2[0,1]$ 上某个积分算子的矩阵表示。计算其条件数（无穷大！），理解为什么是病态的。
- **Sturm-Liouville 问题的完备性**：对 $-y'' = \lambda y$，$y(0) = y(\pi) = 0$，证明特征函数 $\{\sin nx\}$ 构成 $L^2[0,\pi]$ 的完备正交基。

### 1.3 分布与格林函数

**必须完成的计算：**

1. 验证 $\delta'(x)$ 的作用：$\langle \delta', \varphi \rangle = -\varphi'(0)$。

2. 计算 $\mathcal{F}[\delta] = 1$，$\mathcal{F}[1] = 2\pi\delta$（傅里叶变换的分布意义）。

3. 求 $-u'' = \delta(x - \xi)$，$u(0) = u(1) = 0$ 的解（即格林函数），验证 $G$ 在 $x = \xi$ 处连续但导数跳跃。

4. 求三维拉普拉斯方程的基本解：证明 $\nabla^2 \frac{1}{4\pi r} = -\delta(\mathbf{x})$（用散度定理）。

**经典问题：**

- **Dirac 的 $\delta$ 函数**：历史上 Dirac 在量子力学中引入 $\delta$ 函数，但当时没有严格数学基础。直到 Schwartz 在 1940 年代建立分布理论才严格化。尝试用"测试函数"的语言重新表述量子力学中的 $\langle x | x' \rangle = \delta(x - x')$。

## 第二阶段：线性代数与矩阵分析

### 2.1 矩阵分解

**必须完成的计算：**

1. 对矩阵 $A = \begin{pmatrix} 1 & 2 \\ 3 & 4 \end{pmatrix}$ 做 LU、QR、SVD、特征分解。验证每种分解的正确性。

2. 对协方差矩阵 $C = \frac{1}{n}\sum \mathbf{x}_i \mathbf{x}_i^T$ 做特征分解，理解 PCA。用具体数据（如 2D 高斯分布的采样点）验证主成分方向。

3. 证明：$A$ 是正定矩阵 $\iff$ 所有特征值 > 0 $\iff$ 存在 Cholesky 分解 $A = LL^T$ $\iff$ 所有顺序主子式 > 0。

4. 计算矩阵指数 $e^{At}$，其中 $A = \begin{pmatrix} 0 & 1 \\ -1 & 0 \end{pmatrix}$。验证 $e^{At}$ 是旋转矩阵。

**经典问题：**

- **Google 的 PageRank**：本质是求一个随机矩阵的主特征向量（Perron-Frobenius 定理）。构造一个 5 个网页的小例子，计算 PageRank。
- **振动模式分析**：$M\ddot{x} + Kx = 0$（$M$ 质量矩阵，$K$ 刚度矩阵）。化为广义特征值问题 $K\phi = \omega^2 M\phi$。对 3 个质点-弹簧系统计算所有振动频率和模式。

### 2.2 无穷维矩阵与算子

**必须完成的计算：**

1. 在基 $\{1, x, x^2, x^3, \ldots\}$ 下，写出微分算子 $D = d/dx$ 的矩阵表示（无穷维）。计算 $D^2$ 的矩阵。验证 $e^{tD}$ 的矩阵给出 Taylor 公式。

2. 在基 $\{\sin nx\}_{n=1}^\infty$ 下，写出 $-d^2/dx^2$（$[0,\pi]$，Dirichlet 边界）的矩阵。验证它是对角的，特征值为 $n^2$。

3. 在基 $\{e^{inx}\}_{n\in\mathbb{Z}}$ 下，写出 $-d^2/dx^2$（$[0,2\pi]$，周期边界）的矩阵。

4. 取 $V(x) = \cos x$，在傅里叶基下写出 $-d^2/dx^2 + \cos x$ 的矩阵（Mathieu 方程的算子）。截断为 $5\times 5$，数值计算特征值。

**经典问题：**

- **Mathieu 方程**：$y'' + (a - 2q\cos 2x)y = 0$。这是椭圆鼓膜的振动方程，也是周期势中量子力学（能带理论）的模型。特征值 $a(q)$ 形成"能带"结构。
- **氢原子的矩阵力学**：Heisenberg 1925 年用无穷维矩阵（而非波函数）表述量子力学。尝试在 $|n\rangle$ 基下写出氢原子哈密顿量的矩阵。

## 第三阶段：常微分方程与特殊函数

### 3.1 经典 ODE 的完整求解

**必须完成的计算：**

1. **Airy 方程** $y'' - xy = 0$：用幂级数法求两个线性无关解。确定收敛半径（无穷大）。画出 $Ai(x)$ 和 $Bi(x)$ 的大致形状。

2. **Bessel 方程** $x^2y'' + xy' + (x^2 - \nu^2)y = 0$：用 Frobenius 方法求 $J_\nu(x)$。验证 $J_0(x)$ 满足方程。计算 $\int_0^1 x J_0(\alpha x)^2\,dx$（$\alpha$ 是 $J_0$ 的零点）。

3. **Hermite 方程** $y'' - 2xy' + 2ny = 0$：用幂级数法求解，验证 $H_0 = 1$，$H_1 = 2x$，$H_2 = 4x^2 - 2$。验证正交性 $\int_{-\infty}^\infty H_m H_n e^{-x^2}\,dx = 0$（$m \neq n$）。

4. **Legendre 方程**：验证 $P_0 = 1$，$P_1 = x$，$P_2 = \frac{1}{2}(3x^2 - 1)$。用 Rodrigues 公式推导。验证 $\int_{-1}^1 P_m P_n\,dx = \frac{2}{2n+1}\delta_{mn}$。

**经典问题：**

- **三体问题与混沌**：限制性三体问题的运动方程是耦合的非线性 ODE。证明不存在一般的解析解（Poincaré）。理解为什么需要数值方法和定性理论。
- **Van der Pol 振荡器**：$\ddot{x} - \mu(1-x^2)\dot{x} + x = 0$。对 $\mu = 0$ 是简谐振动；$\mu > 0$ 有极限环。用相平面分析定性行为。

### 3.2 格林函数与边值问题

**必须完成的计算：**

1. 求 $-y'' = f(x)$，$y(0) = y(1) = 0$ 的格林函数。用 $f(x) = x(1-x)$ 验证。

2. 求 $-y'' + y = f(x)$，$y(0) = y(1) = 0$ 的格林函数（与上题比较，多了 $+y$ 项）。

3. 用特征函数展开法重新求格林函数。**注意归一化因子**：$L^2[0,1]$ 上真正正交归一的基是 $\{\sqrt{2}\sin n\pi x\}$，
   所以正确结果是
   $$G(x,\xi) = \sum_{n=1}^{\infty} \frac{2\,\sin n\pi x\,\sin n\pi \xi}{n^2\pi^2}$$
   （**漏掉这个因子 2 是最常见的错误**。）验证与直接法结果一致。

4. 求二维拉普拉斯方程在圆盘 $r < 1$ 上的格林函数（用镜像法或分离变量）。

**经典问题：**

- **Dirichlet 问题**：给定圆盘边界上的温度分布，求内部温度。这就是拉普拉斯方程的边值问题。Poisson 积分公式给出解析解。
- **Sturm 的比较定理**：若 $q_1(x) \leq q_2(x)$，则 $-y'' + q_2 y = \lambda y$ 的特征值 $\geq$ $-y'' + q_1 y = \lambda y$ 的特征值。物理意义：势阱越深，能级越低。

## 第四阶段：变分法与经典力学

### 4.1 变分法的核心计算

**必须完成的计算：**

1. **最速降线问题（Brachistochrone）**：从 $(0,0)$ 到 $(a,b)$，在重力下最快到达的曲线。
   - 写出泛函 $T = \int_0^a \sqrt{\frac{1+y'^2}{2gy}}\,dx$
   - 用欧拉-拉格朗日方程推导
   - 验证解是摆线（旋轮线）

2. **测地线问题**：在球面上，两点之间的最短路径是大圆。
   - 写出球面上的弧长泛函
   - 用欧拉-拉格朗日方程推导
   - 验证大圆满足方程

3. **悬链线问题（Catenary）**：两端固定的链条在重力下的形状。
   - 泛函：$\int y\sqrt{1+y'^2}\,dx$（势能最小）
   - 解：$y = a\cosh(x/a)$

4. **等周问题**：给定周长，面积最大的封闭曲线是圆。
   - 用拉格朗日乘子处理约束
   - 验证圆满足欧拉-拉格朗日方程

**经典问题：**

- **Fermat 原理与折射定律**：光走时间最短的路径。从变分法推导 Snell 定律 $n_1\sin\theta_1 = n_2\sin\theta_2$。
- **最小曲面**：肥皂膜的形状。泛函 $\int\int \sqrt{1 + u_x^2 + u_y^2}\,dx\,dy$。欧拉-拉格朗日方程是非线性 PDE（最小曲面方程）。

### 4.2 拉格朗日力学的完整练习

**必须完成的计算：**

1. **单摆**：$L = \frac{1}{2}ml^2\dot{\theta}^2 - mgl(1-\cos\theta)$
   - 推导运动方程：$\ddot{\theta} + \frac{g}{l}\sin\theta = 0$
   - 小角度近似：$\ddot{\theta} + \frac{g}{l}\theta = 0$
   - 求周期（精确解用椭圆积分）

2. **双摆**：两个质点，两根杆。
   - 写出拉格朗日量（2 个自由度）
   - 推导耦合的运动方程
   - 分析小振动模式（特征值问题！）

3. **中心力问题**：$L = \frac{1}{2}m(\dot{r}^2 + r^2\dot{\theta}^2) - V(r)$
   - 由 $\theta$ 的循环坐标性 → 角动量守恒
   - 约化为有效势问题：$V_{\text{eff}}(r) = V(r) + \frac{l^2}{2mr^2}$
   - 对 $V = -k/r$（引力），推导轨道方程 $r = \frac{p}{1+e\cos\theta}$（圆锥曲线）

4. **Noether 定理的验证**：
   - 自由粒子 $L = \frac{1}{2}m\dot{x}^2$：平移不变 → 动量守恒
   - 中心力：旋转不变 → 角动量守恒
   - 不含时：时间平移不变 → 能量守恒

### 4.3 哈密顿力学

**必须完成的计算：**

1. **谐振子的相空间**：$H = \frac{p^2}{2m} + \frac{1}{2}m\omega^2 q^2$
   - 哈密顿方程：$\dot{q} = p/m$，$\dot{p} = -m\omega^2 q$
   - 相轨迹是椭圆
   - 验证泊松括号 $\{q, H\} = \dot{q}$，$\{p, H\} = \dot{p}$
   - 验证 $\{q, p\} = 1$

2. **正则变换**：找生成函数 $F_2(q, P)$ 使得谐振子变为 $H' = P$（即 $P$ 是守恒量）。
   - 这就是作用量-角变量 $(J, \theta)$ 变换

3. **Hamilton-Jacobi 方程**：对自由粒子 $H = p^2/2m$，解 $S(q, t)$。
   - $\frac{\partial S}{\partial t} + \frac{1}{2m}\left(\frac{\partial S}{\partial q}\right)^2 = 0$
   - 验证 $S = \frac{m(q-q_0)^2}{2t}$ 是解

4. **泊松括号与量子对易子**：验证经典泊松括号 $\{q, p\} = 1$ 对应量子对易子 $[\hat{q}, \hat{p}] = i\hbar$。对 $\{q^2, p\}$ 和 $[\hat{q}^2, \hat{p}]$ 做同样的验证。

**经典问题：**

- **KAM 定理**：近可积哈密顿系统的不变环面在微扰下大部分存活。这是经典力学中"混沌"与"规则"共存的原因。
- **辛积分器的验证**：对谐振子，分别用 Euler 法、RK4、Verlet 积分 1000 步，画出能量随时间的变化。观察 Euler 能量漂移、RK4 缓慢漂移、Verlet 有界振荡。

## 第五阶段：电磁学与对称性

### 5.1 Maxwell 方程的对称性

**必须完成的计算：**

1. **从库仑定律推导高斯定律**：$\oint \mathbf{E}\cdot d\mathbf{A} = Q/\varepsilon_0$。用散度定理得到 $\nabla\cdot\mathbf{E} = \rho/\varepsilon_0$。

2. **从 Biot-Savart 定律推导安培定律**：$\oint \mathbf{B}\cdot d\mathbf{l} = \mu_0 I$。

3. **验证电磁波的波动方程**：从 Maxwell 方程推导 $\nabla^2 \mathbf{E} - \frac{1}{c^2}\frac{\partial^2 \mathbf{E}}{\partial t^2} = 0$，确认 $c = 1/\sqrt{\mu_0\varepsilon_0}$。

4. **规范不变性验证**：$A_\mu \to A_\mu + \partial_\mu \lambda$，验证 $F_{\mu\nu} = \partial_\mu A_\nu - \partial_\nu A_\mu$ 不变。

5. **Lorentz 协变性**：将 Maxwell 方程写成 $\partial_\nu F^{\mu\nu} = \mu_0 J^\mu$ 和 $\partial_{[\lambda} F_{\mu\nu]} = 0$。验证在 Lorentz 变换下形式不变。

**经典问题：**

- **Aharonov-Bohm 效应**：在 $\mathbf{B} = 0$ 的区域，矢势 $\mathbf{A} \neq 0$ 仍然影响量子相位。这说明 $\mathbf{A}$（而非 $\mathbf{B}$）是基本的物理量。拓扑上，这对应 $U(1)$ 丛的非平凡性（$\pi_1(U(1)) = \mathbb{Z}$）。
- **磁单极与拓扑**：如果存在磁单极，则 $\nabla\cdot\mathbf{B} \neq 0$，矢势不能全局定义（需要两个 patch）。Dirac 量子化条件 $\dfrac{eg}{\hbar c} = \dfrac{n}{2}$（$n \in \mathbb{Z}$） 来自 $U(1)$ 丛的拓扑（第一 Chern 类）。

### 5.2 电磁学中的变分原理

**必须完成的计算：**

1. 从作用量 $S = \int \left(-\frac{1}{4}F_{\mu\nu}F^{\mu\nu} - J^\mu A_\mu\right)d^4x$ 推导 Maxwell 方程。

2. 验证能量守恒（Poynting 定理）：$\frac{\partial u}{\partial t} + \nabla\cdot\mathbf{S} = -\mathbf{J}\cdot\mathbf{E}$，其中 $u = \frac{1}{2}(\varepsilon_0 E^2 + B^2/\mu_0)$，$\mathbf{S} = \mathbf{E}\times\mathbf{B}/\mu_0$。

3. 验证动量守恒（Maxwell 应力张量）。

### 5.3 对称性与守恒量的完整对应

**必须完成的计算：**

| 对称性 | 变换 | 守恒量 | 验证 |
|--------|------|--------|------|
| 时间平移 | $t \to t + \epsilon$ | 能量 | 对谐振子验证 |
| 空间平移 | $\mathbf{x} \to \mathbf{x} + \boldsymbol{\epsilon}$ | 动量 | 对自由粒子验证 |
| 空间旋转 | $\mathbf{x} \to R\mathbf{x}$ | 角动量 | 对中心力验证 |
| 规范变换 | $A_\mu \to A_\mu + \partial_\mu\lambda$ | 电荷 | 验证 $\partial_\mu J^\mu = 0$ |
| Lorentz boost | $x^\mu \to \Lambda^\mu_\nu x^\nu$ | 质心运动 | 验证 |

## 第六阶段：量子力学的计算

### 6.1 基本量子系统

**必须完成的计算：**

1. **无限深势阱**：$V = 0$（$0 < x < L$），$V = \infty$（其他）
   - 解薛定谔方程，得 $E_n = \frac{n^2\pi^2\hbar^2}{2mL^2}$，$\psi_n = \sqrt{2/L}\sin(n\pi x/L)$
   - 验证正交性和完备性
   - 计算 $\langle x \rangle$，$\langle p \rangle$，$\Delta x$，$\Delta p$，验证不确定性原理

2. **谐振子**：$H = \frac{p^2}{2m} + \frac{1}{2}m\omega^2 x^2$
   - 用升降算子 $a^\dagger, a$ 求解
   - $[a, a^\dagger] = 1$，$H = \hbar\omega(a^\dagger a + 1/2)$
   - $E_n = \hbar\omega(n + 1/2)$
   - 验证基态 $\psi_0 \propto e^{-m\omega x^2/2\hbar}$ 满足不确定性原理的等号

3. **氢原子**：
   - 分离变量（球坐标）：$R(r)Y_l^m(\theta,\phi)$
   - 角度部分 → 球谐函数
   - 径向部分 → 关联 Laguerre 多项式
   - $E_n = -\frac{13.6\text{ eV}}{n^2}$
   - 验证 $SO(4)$ 隐藏对称性（Runge-Lenz 向量）

4. **自旋 1/2**：
   - Pauli 矩阵 $\sigma_x, \sigma_y, \sigma_z$
   - 验证 $[\sigma_i, \sigma_j] = 2i\varepsilon_{ijk}\sigma_k$
   - Stern-Gerlach 实验的矩阵计算
   - 自旋在 $z$ 方向测量后，再在 $x$ 方向测量的概率

### 6.2 路径积分的计算

**必须完成的计算：**

1. **自由粒子传播子**：直接计算高斯路径积分，验证：
$$K_{\text{free}}(x_f,T;x_i,0) = \sqrt{\frac{m}{2\pi i\hbar T}}\;\exp\left(\frac{i\,m\,(x_f-x_i)^2}{2\hbar T}\right)$$
   （**括号不能省**：写成 `e^{im(x_f-x_i)^2/2\hbar T}` 会被解析成 `(...)/2` 再乘 $\hbar T$，量纲与结果都错。）

2. **谐振子传播子**：验证经典作用量代入后给出正确结果。

3. **稳相近似**：对 $K = \int \mathcal{D}x\, e^{iS[x]/\hbar}$，在 $\hbar \to 0$ 极限下，证明主导贡献来自 $\delta S = 0$ 的路径（经典路径）。

4. **Wick 转动**：$t \to -i\tau$，将 $e^{iS/\hbar}$ 变为 $e^{-S_E/\hbar}$。验证谐振子的欧几里得传播子与统计力学的配分函数一致。

**经典问题：**

- **双缝干涉的路径积分解释**：粒子通过两条缝的振幅相加（而非概率相加），产生干涉。
- **瞬子（Instanton）**：双势阱中的隧穿效应。在欧几里得路径积分中，瞬子是连接两个势阱底的经典解。

### 6.3 角动量与表示论

**必须完成的计算：**

1. 验证 $[L_x, L_y] = i\hbar L_z$（用 $L_i = \varepsilon_{ijk}x_j p_k$ 和 $[x_i, p_j] = i\hbar\delta_{ij}$）。

2. 用升降算子 $L_\pm = L_x \pm iL_y$ 推导 $l$ 和 $m$ 的取值范围。

3. 计算 $Y_1^0 = \sqrt{3/4\pi}\cos\theta$，$Y_1^{\pm 1} = \mp\sqrt{3/8\pi}\sin\theta\, e^{\pm i\phi}$。验证它们是 $L^2$ 和 $L_z$ 的本征函数。

4. **Clebsch-Gordan 系数**：两个自旋 $1/2$ 粒子的耦合。$|1,1\rangle = |\uparrow\uparrow\rangle$，$|1,0\rangle = \frac{1}{\sqrt{2}}(|\uparrow\downarrow\rangle + |\downarrow\uparrow\rangle)$，$|0,0\rangle = \frac{1}{\sqrt{2}}(|\uparrow\downarrow\rangle - |\downarrow\uparrow\rangle)$。

## 第七阶段：PDE 与数学物理

### 7.1 三大方程的完整求解

**必须完成的计算：**

1. **一维波动方程**：$u_{tt} = c^2 u_{xx}$，$u(0,t) = u(L,t) = 0$，$u(x,0) = f(x)$，$u_t(x,0) = g(x)$
   - 分离变量 → 傅里叶正弦级数
   - d'Alembert 公式
   - 验证能量守恒：$E = \frac{1}{2}\int_0^L (u_t^2 + c^2 u_x^2)\,dx$ 不随时间变化

2. **一维热方程**：$u_t = ku_{xx}$，$u(0,t) = u(L,t) = 0$，$u(x,0) = f(x)$
   - 分离变量 → 傅里叶正弦级数，系数含 $e^{-k(n\pi/L)^2 t}$
   - 验证：$t \to \infty$ 时 $u \to 0$（热平衡）
   - 验证极值原理

3. **圆盘上的拉普拉斯方程**：$\nabla^2 u = 0$，$r < 1$，$u(1,\theta) = f(\theta)$
   - 极坐标分离变量
   - 解：$u(r,\theta) = \frac{a_0}{2} + \sum_{n=1}^\infty r^n(a_n\cos n\theta + b_n\sin n\theta)$
   - Poisson 积分公式：$u(r,\theta) = \frac{1}{2\pi}\int_0^{2\pi} \frac{1-r^2}{1-2r\cos(\theta-\phi)+r^2}f(\phi)\,d\phi$

4. **三维波动方程的 Kirchhoff 公式**：验证 Huygens 原理（三维波有锐利波前）。

### 7.2 积分变换的应用

**必须完成的计算：**

1. 用 Fourier 变换解 $\mathbb{R}$ 上的热方程，验证解是热核与初始数据的卷积。

2. 用 Laplace 变换解 $y'' + 2y' + 5y = e^{-t}\sin t$，$y(0) = 0$，$y'(0) = 0$。

3. 用 Laplace 变换解半直线上的热方程：$u_t = ku_{xx}$，$x > 0$，$u(0,t) = 1$，$u(x,0) = 0$。解涉及误差函数 $\text{erf}$。

4. 验证卷积定理：$\mathcal{L}\{f * g\} = \mathcal{L}\{f\}\cdot\mathcal{L}\{g\}$。

### 7.3 变分法与 PDE

> **交叉引用（同一个一维 $-u''=1$ 算例在本文件出现三次，分工如下，不要重复推导）**
> - **本节**：讲清「变分 → 弱形式 → 离散」的完整推导（概念侧）
> - **§10.2 第 3 题**：要求把它**写成代码**（实现侧）
> - **§11.3**：综合题，要求做到 4 单元并**验证收敛阶 $O(h^2)$**（量化侧）

**必须完成的计算：**

1. 证明 $-\nabla^2 u = f$（$u|_{\partial\Omega} = 0$）等价于最小化 $J[u] = \int_\Omega \frac{1}{2}|\nabla u|^2 - fu\,d\Omega$。

2. 推导弱形式，验证对称性：$a(u,v) = a(v,u)$。

3. 对一维情况 $-u'' = 1$，$u(0) = u(1) = 0$：
   - 精确解：$u = x(1-x)/2$
   - 用线性有限元（2 个单元）求近似解
   - 比较误差

**经典问题：**

- **Plateau 问题**：给定空间中的闭合曲线，找以它为边界的最小面积曲面。这是变分法的经典问题，解是最小曲面。
- **特征值问题的变分刻画**：$\lambda_1 = \min_{u \neq 0} \frac{\int|\nabla u|^2}{\int u^2}$（Rayleigh 商）。用这个公式估计圆形鼓膜的第一振动频率。

## 第八阶段：李群与对称性的计算

### 8.1 具体的李群计算

**必须完成的计算：**

1. **$SO(3)$ 的指数映射**：给定 $\omega = (0, 0, \theta)$，计算 $e^{[\omega]_\times}$，验证是绕 $z$ 轴旋转 $\theta$ 的矩阵。

2. **BCH 公式验证**：取 $X = \epsilon J_1$，$Y = \epsilon J_2$（$\mathfrak{so}(3)$ 的基），计算 $e^X e^Y$ 和 $e^{X+Y+\frac{1}{2}[X,Y]}$，比较到 $O(\epsilon^2)$。

3. **$SU(2) \to SO(3)$ 的覆盖映射**：给定四元数 $q = \cos\frac{\theta}{2} + \sin\frac{\theta}{2}\hat{n}$，计算对应的旋转矩阵 $R$。验证 $q$ 和 $-q$ 给出同一个 $R$。

4. **$\mathfrak{so}(3)$ 的伴随表示**：计算 $\text{ad}_{J_3}$ 的矩阵（在基 $\{J_1, J_2, J_3\}$ 下），验证它是 $3\times 3$ 反对称矩阵。

### 8.2 对称性解 ODE

**必须完成的计算：**

1. 对 $y' = y/x + x^2/y$（齐次方程），找对称性 $\mathbf{v} = x\partial_x + y\partial_y$，用不变量 $r = y/x$ 降阶。

2. 对 $y'' = f(y)$（缺 $x$），用平移对称性 $\partial_x$ 降阶。

3. 对 Euler 方程 $x^2y'' + axy' + by = 0$，用尺度对称性 $x\partial_x$ 化为常系数。

### 8.3 对称性解 PDE

**必须完成的计算：**

1. 热方程 $u_t = u_{xx}$ 的尺度对称性：$(x, t, u) \to (\lambda x, \lambda^2 t, u)$。用不变量 $\xi = x/\sqrt{t}$ 化为 ODE，得到自相似解（热核）。

2. 波动方程 $u_{tt} = c^2 u_{xx}$ 的平移对称性：$(x, t) \to (x - ct, t)$。用不变量 $\xi = x - ct$ 得到行波解。

## 第十一阶段：跨领域综合问题

### 11.1 量子力学 ↔ 渲染

**问题：** 路径追踪与费曼路径积分的数学结构对比。

**具体任务：**
1. 写出渲染方程的 Neumann 级数：$L = \sum_{k=0}^\infty \mathcal{T}^k L_e$
2. 写出费曼路径积分的微扰展开：$K = \sum_{k=0}^\infty K^{(k)}$
3. 对比：
   - 渲染的"弹射次数" ↔ 量子的"相互作用阶数"
   - 渲染的"几何衰减 $1/r^2$" ↔ 量子的"传播子"
   - 渲染的"BRDF" ↔ 量子的"顶点因子"
4. 关键区别：渲染是正实数（概率/能量），量子是复数（振幅，有干涉）

### 11.2 谱理论 ↔ 几何处理

**问题：** 网格上的拉普拉斯算子的谱。

**具体任务：**
1. 构造一个简单网格（如正四面体或正方形网格）
2. 组装余切拉普拉斯矩阵 $L$
3. 计算特征值和特征向量
4. 验证：
   - $\lambda_0 = 0$（常数函数）
   - $\lambda_1 > 0$（第一个非平凡模式）
   - 特征向量的零点个数随特征值增大而增加（类似 Sturm 定理）
5. 用前几个特征向量做"形状分割"

### 11.3 变分法 ↔ 有限元

> **已知重复**：本题的 1–3 步与 §7.3 同题，第 4 步与 §10.2 第 3 题同题。
> 本题的**新增要求只有第 5–6 步**（4 单元 + 收敛阶验证），所以做这一题时不必重复推前面的部分。

**问题：** 从连续变分到离散有限元。

**具体任务：**
1. 连续问题：最小化 $\int_0^1 \frac{1}{2}(u')^2 - u\,dx$，$u(0) = u(1) = 0$
2. 推导欧拉-拉格朗日方程：$-u'' = 1$
3. 精确解：$u = x(1-x)/2$
4. 用 2 个线性有限元离散，组装 $2\times 2$ 系统，求解
5. 用 4 个线性有限元离散，组装 $4\times 4$ 系统，求解
6. 比较误差，验证收敛阶 $O(h^2)$

### 11.4 李群 ↔ 微分方程 ↔ 物理

**问题：** 从对称性到守恒量到量子化。

**具体任务：**
1. 经典谐振子有 $U(1)$ 对称性（相空间旋转）→ 能量守恒
2. 量子化后，$U(1)$ 的不可约表示是 $e^{in\theta}$（$n \in \mathbb{Z}$）→ 能量量子化 $E_n = \hbar\omega(n+1/2)$
3. 三维各向同性谐振子有 $SU(3)$ 对称性 → 能级简并度 $\frac{(n+1)(n+2)}{2}$
4. 氢原子有 $SO(4)$ 对称性 → 能级简并度 $n^2$

### 11.5 拓扑 ↔ 物理 ↔ CG

**问题：** 拓扑不变量在各领域的体现。

**具体任务：**
1. 计算球面 $S^2$ 的欧拉示性数 $\chi = 2$（用三角剖分：$V - E + F = 2$）
2. 计算环面 $T^2$ 的 $\chi = 0$
3. 验证 Gauss-Bonnet：$\int_{S^2} K\,dA = 4\pi = 2\pi\chi$
4. 在网格上验证离散 Gauss-Bonnet：$\sum_i \left(2\pi - \sum_j \theta_{ij}\right) = 2\pi\chi$
5. 讨论：为什么球面上的向量场必有零点（Hairy Ball），而环面上可以没有
