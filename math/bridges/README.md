# bridges/ —— 结构串讲（专题三）

> 2026-11-03 改版。**本文件是 `bridges/` 的唯一规约。**
> 旧口径（「四篇贯通性讲义的索引」）作废：四篇仍在，但**分篇依据从「话题」换成了「结构动作」**。

## 0. 为什么要换分篇依据

旧做法是「我理解到哪，就写哪篇」。它有两个必然后果：

1. **散**：每来一个新领域就要加一篇，篇与篇之间没有咬合，读者拿不到「一张网」；
2. **对不了**：选题依赖当下理解，理解一变，篇目的对错就无法判定 —— 没有判据。

换成**结构动作**分篇后，这两个问题都有解：篇数有上限（六个，见 §2），任何新领域只能落进已有节点，或者证明节点不够 —— 后者是需要显式决定的大版本，不许悄悄加一篇绕过。

**判据**：新增一篇的正当理由是「某个真问题（含 `NOW.md` 条目）归不进六个节点」，不是「这个话题有意思」。

## 1. 一条硬规则：只收 ≅

每篇正文的每一段，必须能写成 **A ≅ B**（同一机制的两种写法：换基/投影/求极限）。
写不成 ≅ 的是知识点，退回主篇 A–R 或 `../survey/`，不进本目录。

每篇必须给两样东西，缺一不进 `main.tex`：

- **主语清单**：正文开头一行一个 ≅，最多 8 条；
- **落点**：至少 1 个主仓可算对象 —— `NOW.md` 条目号，或 `capability-coverage.md` 的 `IF/W/E/S` 主键。

> 没有落点的篇目 = 无法验收的散文。降为草稿，不 `\input`。

## 2. 六个结构动作（骨架，先定后填）

| 节点 | 一句话 | 可算判据（这条判不出就不是结构，是装饰） |
|---|---|---|
| **S1 表示** | 换基、换坐标：对象不变，数组变 | 换基后不变量（谱、迹、内积、体积元）逐项相等 |
| **S2 线性化** | 在一点假装线性：曲面 → 切空间，非线性 → 矩阵 | 残差随 $\varepsilon$ 减半降 4 倍（$O(\varepsilon^2)$） |
| **S3 谱** | 选一个让算子不耦合的基，就是对角化 | 截断 $N$ 项的残差按 $\lvert\lambda_N\rvert$ 衰减 |
| **S4 流** | 沿向量场走：走一步与走到底之差就是群律 | $\Phi_{t+s}=\Phi_t\circ\Phi_s$ 数值成立；$h$ 减半误差降 $2^p$ |
| **S5 约束与投影** | 允许集合不是子空间时，先投影再走；最近点 = 正交投影 | 残差与允许方向的内积为 0（机器精度） |
| **S6 离散与极限** | 连续 → 有限自由度 → 让自由度趋于无穷，问何时回去 | $h$ 减半误差降 $2^p$，且 $p$ = 所用子空间的多项式次数 |

**自否证条件**（骨架错了怎么发现）：

- 任一节点凑不出上面那列判据 → 该节点是装饰，删；
- 某个真问题无法归入六节点 → 缺第七个，先登记再决定（走 §5 的 `B4`）；
- 两个节点合并后 ≅ 清单不变 → 说明二者本来是一个动作，合并。

## 6. 占位节规则（「基础必须先出现」的机制）

规划已出现、正文还没写的节点，**必须**在 `br0_skeleton.tex` 里留占位节，占位节至少三行：

1. 要串的 ≅（一句话）；
2. 依据（主篇哪节 / 哪本书哪章，没有就写「待定真源」）；
3. 验收（一句话，可算）。

占位节是**契约**，不是 TODO 备注：正文写成什么样，以这三行为准。
**不许出现「待补」两个字而下面没有这三行** —— 那样等于没登记。

## 7. 维护规则

1. **只写连接，不重推**。公式在主篇已有推导，串讲只引用。
2. **编号 `BR<n>-`**，`n=0` 为骨架篇；序号在文件内连续，不跨文件。
3. **对照表随主键变**：`capability-coverage.md` 或 `NOW.md` 变了，§4 必须同步 —— 这是本文件唯一会腐化的地方。
4. **不写进度与排期**（本文件属契约类）。
5. **每篇正文开头必须列「本篇 ≅」清单**（§1），否则视为未完成。
   紧随其后要有「**这里默认你已经会** / **不要求会**」两行（2026-11-04 加）：
   写给非数学系读者，只列前置概念，**不写其它册子的节名当指针** —— 本册自足，不靠交叉引用成立。
6. **篇目顺序 = 归位顺序**（`br0` → `br1`(S4) → `br2`(S3) → `br3`(跨 S1–S6) → `br4`(S5)），不是写作顺序。
   注意 S1、S2 **没有独立篇**：正文寄在 `br3` §BR3.3（张量）与 `br1` §BR1.5（切空间），
   所以不要按「S1 在前」去重排 `main.tex`——重排会打乱已收敛的交叉引用。
