# bridges/ — 跨篇串讲（专题三）

四篇**贯通性**讲义，不是新知识点，是**篇与篇之间的连接**。

- **读法**：回头贯通，不是逐篇学。建议在学过对应主篇之后读，用来把散点连成线。
- **格式**：LaTeX，**独立册**（2026-11-02 从 `math/main.tex` 拆出）。
  入口 `bridges/main.tex`，产物 `bridges/main.pdf`；`math/main.pdf` **不再包含**本专题。
  编译（在本目录下）：`latexmk -pdfxe -interaction=nonstopmode main.tex`。
- **公式编号**：`(BR1-n)` … `(BR4-n)`，与主篇的 `(Q1)`/`(MA1)`/`(SO1)`/`(C1)` 不冲突。

## 四篇索引

| 文件 | 一篇话 | 主要拉通的篇 |
|---|---|---|
| `br1_slerp_geodesic.tex` | slerp 不是插值技巧，是 $S^3$ 上的等速测地线；由此推出大圆、指数映射、单参数子群、对极奇点 | H（CG）、li（李群）、R（复分析） |
| `br2_fourier_gauss.tex` | 一切变换 = 选基 + 对角化；复指数是微分的本征函数，所以高斯是傅里叶不动点，所以正态特征函数还是高斯 | A（分析）、G（数值）、部分 R |
| `br3_ode_pde_tensor_lie.tex` | 对称 → 李代数 → 指数映射 → 张量 → PDE，五层一条链；球谐是群作用给的正交基 | C（偏微分）、E（场论）、li、H |
| `br4_probability_map.tex` | 概率论的原创概念只有三根经线：独立性、条件化、鞅；其余全是测度论 + 时间轴 + 信息轴 | A（测度）、G（数值）、I（流体） |

1. **只写连接，不重写知识点**。某个公式在主篇已有推导，串讲只引用不重推。
2. **公式编号前缀 `BR<n>-`**，序号在文件内连续，不跨文件。
3. **对照表随主键变**：`capability-coverage.md` 增删 `IF`/`W`/`E`/`S` 时，本表要同步（这是本表唯一会腐化的地方）。
4. **不写进度与排期**（本文件属"契约/参考"类）。
