### E1–E3 · exam · 分章详细讲解（辅导书正文）

**结构变了**：不再是"一个考点一个文件"，而是**一章一个文件**。

| 任务 | 输出 | 章数 |
|---|---|---|
| E1 | `exam/408/{ds,co,os,net}/NN-章名.md` | 7 / 7 / 5 / 6 |
| E2 | `exam/math1/{hs,la,ps}/NN-章名.md` | 8 / 6 / 8 |
| E3 | `exam/english1/`、`exam/politics/` | 按题型 / 按模块 |

**每章固定四段**：

1. **本章考点与档位**（从 K0 抄，别重写）
2. **正文**：概念 → 推导 → 例题（带完整计算过程）
3. **真题落点**：本章哪些考点考过、以什么形式考（不冒充原题）
4. **易错清单**：3–8 条，每条"错在哪一步"

篇幅：每章 2000–4000 字。

### N1–N3 · note · 考点 × 真题复合版（多考点合并，去重）

> **口径以 `prompts/N-note.md` 为准**（该文件自述「口径修正三次」）。本层不是"分章配题册"：
> 它是**一个考点一个文件**，把已收真题按「考法」聚类去重，只写思路不写答案。

- 文件：`note/408/<子科>/<KP>-<名>.md`（112 个）、`note/math1/<子科>/<KP>-<名>.md`（72 个）。
- 单文件结构：`## 考法 1 …` 下每道题 **思路** + **坑**；`思路` 与 `坑` 数量必须相等；**不写答案**。
- 真题来源：只用 `exam/真题/` 里实际存在的 2016–2024 及其题号，校验有年份白名单。
- 数学一：真题库只收 408，单文件头标注「近四年真题未收录，按常见考法组织」，篇幅 800–1200 字，不注水。
- 生成方式：**每块 8–10 个考点**（输出约 2000–2500 字），拼装时按 `syllabus` 顺序切成单文件。

**硬性**：**绝不编造真题原文或年份题号**。

### W1 · 单词书（5500+）

**分组**：25–30 组，每组约 200 词 + **一段短文**。

**顺序**（按考场用法，不按字母）：

| 组 | 内容 | 词数 |
|---|---|---|
| 1–4 | 考研核心动词 / 论证名词 / 逻辑连接与态度词 | 800 |
| 5–13 | 按主题：经济、科技、环境、生物医学、心理、社会政治、法律、教育、文化 | 1800 |
| 14–15 | 高频形容词、副词与介词短语 | 400 |
| 16–17 | 熟词僻义、易混词辨析 | 400 |
| 18–19 | 词根词缀 | 400 |
| 20–22 | **初高中衔接基础**（明确标注"复习用，不要喧宾夺主"） | 600 |
| 23–26 | 考研大纲补充与超纲词 | 800 |

**每组两块内容**：
1. 词表：`word 词性. 释义`，**不加例句**
2. 短文：120–150 词英文 + 中译 + 5 条语法点

**风险**：单块 250 词时约 20% 会失败，**降到 150–200 词/块**，短文单独成任务。

## 二、projects

### P1 / P2 · 每项目两件套（**干掉 QUICK**）

| 文件 | 回答什么 | 篇幅 |
|---|---|---|
| `OUTLINE.md` | **这个项目到底在做什么、想说什么** + 目标功能设计 + 章节大纲 | 2000–3500 字 |
| `NOTES.md` | 分章详细（原文件保留，只补不删） | 已有 1–8 万字 |

**`OUTLINE.md` 的四段**（这是与旧版最大的不同）：

1. **它在做什么**：一句话说清项目的目标，不用术语堆。
2. **为什么这样做（功能设计）**：这是用户特别强调的——
   - 例：`cs144` 不能只写"模拟 TCP"，要写清**怎么做到替换真实协议栈**（socket API 怎么接、UDP 怎么承载、内核栈怎么绕过）。
   - 例：`6824` 不能只写"实现 Raft"，要写清**多副本怎么在不可靠网络上收敛**、线性一致性怎么保证。
3. **章节大纲**：每章讲什么、涉及哪些知识点、与考纲哪个 KP 对应。
4. **不做什么**：明确边界，避免范围膨胀。

**硬性**：**不写代码仓状态**（用户明确说"你同步的也不对"）。项目笔记讲项目本身，不讲"我写到哪个 commit 了"。
