# 任务 W1 · 单词书（5500+，分组 + 每组短文）

## 背景与目标

用户原话：「从**初高中到考研的所有词汇**，你也要根据你自己的理解给出这套必背的单词书
**顺序、释义**等等，中间**不要给单词加例句**，但是可以以帮我**复习语法**的方式，
每几百个单词加上**一段短文**，目的是复习语法和培养语感。」

三个要点，缺一不可：
1. **总量 5500+**（上一版只做到 2152，不及格）
2. **不加例句**（词表必须极简，一行一词）
3. **每几百词一段短文**（复习语法 + 语感，不是背词任务）

## 分组顺序（按考场用法，不按字母）

| 组 | 内容 | 词数 | 为什么排在这 |
|---|---|---|---|
| 1–4 | 核心动词 / 论证名词 / 逻辑连接与态度词 | 800 | 写作必须先能写出，性价比最高 |
| 5–13 | 经济、科技、环境、生物医学、心理、社会政治、法律、教育、文化 | 1800 | 阅读 A 的主题面 |
| 14–15 | 高频形容词、副词与介词短语 | 400 | 写作提分最快 |
| 16–17 | 熟词僻义、易混词辨析 | 400 | 阅读拦路词 |
| 18–19 | 词根词缀 | 400 | 减少记忆量 |
| 20–22 | **初高中衔接基础**（标注"复习用"） | 600 | 用户允许，但要明确标注 |
| 23–26 | 考研大纲补充与超纲词 | 800 | 兜底 |

**关键约束**：初高中词**不要喧宾夺主**——放在第 20–22 组，且文件名带"复习"字样，
不要混进前 19 组。

## 每组两块产出

### 1. 词表（`NN-主题.md` 前半）

```
word 词性. 释义；释义
abandon v. 放弃；抛弃；中止
```

规则：
- **不要例句**、不要记忆法、不要考频、不要音标
- 一词一行，释义最多三个义项，用「；」分隔
- 按"由易到难、由具体到抽象"排，不按字母
- 词性用 `n./v./adj./adv./prep./conj.`

### 2. 短文（同文件后半，或独立文件）

- 120–150 词英文短文，主题与本组相关
- 尽量用本组词，但不强求逐个覆盖
- 附：`**译文**`（逐句对应）+ `**语法点**`（5 条：原句片段 → 结构名 → 作用）
- 语法点必须覆盖：一个从句、一个非谓语、一个倒装或强调、一个被动或虚拟

## 生成方式（这里最容易失败）

**实测数据**：
- 250 词/块 → 约 20% 的块输出 1 字节（失败）
- 降到 150 词/块 → 失败率接近 0
- 短文和词表**放同一块会写不下**（250 词已占满输出预算）

所以：
1. **词表每块 150 词**，单独任务
2. **短文单独任务**，每段一个
3. 词表任务和短文任务**分开编号**（`w01` / `p01`），拼接时配对

## 交付

```
kaoyan/words/
├── README.md            目录 + 排序理由 + 使用方法
├── 01-核心动词上.md     词表
├── 01-短文.md           （或合并进上一份）
…
```

`README.md` 必须包含：
- 排序理由（为什么先动词后名词）
- 使用方法（第一遍只认不背、第二遍只背划掉的、每组配短文）
- 当前总词数与待补组数

## 验收

```bash
cd notebook/kaoyan/words
total=0
for f in [0-9]*.md; do
  case "$f" in *短文*) continue;; esac
  n=$(grep -cE '^[a-zA-Z][a-zA-Z'"'"' -]* (n|v|adj|adv|prep|conj)\.' "$f")
  total=$((total+n)); printf "%-28s %4s\n" "$f" "$n"
done
echo "合计 $total 词（目标 5500）"
```

**判据**：合计 ≥ 5500。不足就继续加组，不要用"约"糊过去。
