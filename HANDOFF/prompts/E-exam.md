# 任务 E1–E3 · exam 层（分章详细讲解 = 辅导书正文）

## 背景

`exam/` 是**辅导书正文**：比 `quick/` 详细，比真题多推导。
读者在这里不是"过一遍"，而是"学懂一章"。

**结构变了**：旧版是"一个考点一个文件"（112 个文件），现在改为**一章一个文件**。
理由：用户要的是"分章节的详细版本"，一章一个文件才读得下去；考点级拆分是给索引用的，
`quick/` 第一部分的表格已经承担了索引功能。

```
exam/408/ds/01-绪论.md            exam/math1/hs/01-函数极限连续.md
exam/408/ds/02-线性表.md          exam/math1/hs/02-一元微分.md

```

## 每章固定四段

```markdown
# NN 章名

## 一、本章考点与档位
（从 syllabus 抄表格，不重写）

## 二、正文
   概念 → 为什么这样设计 → 关键推导 → 例题（带完整计算过程）
   不要只给结论，推导过程要能跟着算

## 三、真题落点
   本章哪些考点考过、以什么形式考、关键一步是什么
   **不冒充原题**：没有题干就写"考点还原"

## 四、易错清单
   3–8 条，每条格式：错误做法 → 为什么错 → 正确做法
```

## 篇幅

每章 2000–4000 字。低于 2000 是没展开，高于 4000 该拆章（先改 syllabus）。

## 硬性约束

1. **不写工程细节**（那是 `projects/` 的事），不写代码实现。
2. **公式用 KaTeX**，推导步骤不能跳。
3. **例题必须给完整过程**，不能只写答案。
4. **不编造真题**。
5. 每章开头必须有一段 100 字左右的"这一章在整科里的位置"——读者需要知道先学什么后学什么。

## 工作量提示

408 共 25 章，数一 22 章，加英政约 60 章。**必须拆成多个独立任务派发**：

- 建议按"科"拆：`E1a 408-数据结构`（7 章）、`E1b 408-组成`（7 章）…
- 每章再按"两段"生成（正文一段、真题+易错一段），避免单次输出过长

按 `SCHEDULING.md`：讲解式每块 5–6 个考点，约 3000 字。
