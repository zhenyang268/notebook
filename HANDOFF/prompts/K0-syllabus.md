# 任务 K0 · 考纲强化（所有内容任务的底座）

## 背景

`notebook/kaoyan/syllabus/` 是整套考研笔记的**唯一坐标系**，四份文件：
`408.md`（112 个考点）、`math1.md`（72 个）、`english1.md`（12 项能力）、`politics.md`（6 模块）。

现在它只有"一行定义"，不够用：写 quick 的人不知道**这个考点要求到什么程度**、
**真题怎么考**，只能凭感觉发挥。你的任务就是把这个信息补上。

## 你的任务

改造 `syllabus/408.md` 与 `syllabus/math1.md` 的每个考点表格行，
从「主键 | 名称 | 要点」升级为**六列**：

| 列 | 内容 | 要求 |
|---|---|---|
| 主键 | 原有，不改 | `408-CO-0305` |
| 名称 | 原有，不改 | Cache |
| 要点 | 原有，可微调 | 一句话 |
| **档位** | 了解 / 理解 / 掌握 / 应用 | 只能四选一 |
| **真题落点** | 哪年、以什么形式考 | 没有把握就写"常见考法：…" |
| **一课位置** | 在 `quick/` 的哪一节讲 | 如 `quick/408-co.md §三` |

档位的判断标准：

- **了解**：知道名词、能选对概念题
- **理解**：能说清为什么，能判断对错
- **掌握**：能算、能推导
- **应用**：能放进综合题、能迁移到新情境

## 硬性约束

1. **不新增、不删除、不改写任何考点主键**。这是坐标系，动了全部下游都要重算。
2. **真题落点不许编造**。你不确定某年考过什么，就写"常见考法：选择题考地址拆分"，
   **绝对不要**写"2023 年真题第 15 题"。用户手边有纸质真题，编错一眼就露馅。
3. **一课位置**可以留空（如果 `quick/` 还没写），但要标 `待定`。
4. 保持 Markdown 表格格式，不要改成列表。

## 顺序建议

先做 408（112 条，工作量最大），再做数一（72 条）。英语和政治结构不同，
只要在 `english1.md` 每个题型后补一列"档位 + 一课位置"即可，不必硬套六列。
