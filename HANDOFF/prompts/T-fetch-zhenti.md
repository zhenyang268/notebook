# 任务 T · 续抓 408 真题（2019 及更早）

## 现状

`kaoyan/exam/真题/` 已有 **2021、2022、2023、2024** 四年（各 40 道选择题）。
缺：2019 及更早，以及所有年份的**综合应用题（41–47）**。

## 抓取源（2026-11-02 实测可用）

| 源 | 形态 | 适用 |
|---|---|---|
| `csgraduates.com/study_methods/408quiz/YYYY/` | 纯文本 HTML，按年份归档 | **首选**，40 题 + 缺图标注齐全 |
| 厦门工学院 PDF（`xit.edu.cn`） | 含解析 | 交叉核对用 |
| 聚创考研 / 七彩学科 PDF | 扫描件 | 需 OCR，最后手段 |

URL 模式固定：把 `YYYY` 换成目标年份即可。

## 每年四步

### 1. 抓两个源

```
web_fetch  https://www.csgraduates.com/study_methods/408quiz/2019/
fetchInfo  "提取 2019 年 408 真题全部 40 道选择题（题干 + 选项），
           按题号输出，标注哪些题原卷有图。不要解析。"
```

同一套抓 PDF 做交叉核对（PDF 抓不全也关系不大，主要用来对题干措辞）。

### 2. 对齐、标差异

两份来源的题干措辞常有出入（例如选项排版、错别字）。处理原则：

- **以纯文本源为主**，PDF 只用来判断"哪边是笔误"
- 差异无法判断时，两种措辞都保留并标注
- **不要"修正"成自己想当然的样子**——回忆版本来就可能有错

### 3. 写要点（这一步可以交给模型批量）

每题给一行：

```
→ `CO-03`｜要点：先算页内偏移，剩下的才是虚页号；别用主存位数去切。
```

要求：
- 一句话，20–40 字，说**第一步做什么**
- **不写答案**（不写"选 C"）
- 考点主键必须真实存在于 `syllabus/408.md`

### 4. 人工验算（这一步不能交给模型）

以下题型**必须自己算一遍**再写要点，模型在这些题上出错率高：

| 题型 | 易错点 |
|---|---|
| IP 分片 | 数据部分必须是 8 字节倍数 |
| C-SCAN / SSTF | 回程空跑要算、初始磁头位置 |
| 总线带宽 | 分母是**整个事务周期**，不是只数传数据的拍 |
| TCP 建连/关闭 | 1.5 RTT、2MSL 容易记混 |
| UDP 校验和 | 最高位进位要回卷，最后要取反 |
| 散列 ASL | 失败 ASL 分母是**表长**，墓碑要继续探测 |
| 子网划分 | 掩码按位与，注意"最小可分配"要 +1 |
| IEEE754 | 阶码全 0 是非规格化数，无隐含 1 |
| 页表/位图 | 页框数 = 容量/页大小，位图 = 页框数 bit |

## 输出格式（与已有年份一致）

```markdown
# 2019 年 408 真题（题干 + 考点 + 要点）

> **来源**：xxx，考生回忆整理版；版权归教育部考试中心，仅供个人备考。
> **缺图**：第 x、y 题。
> **要点**一句话；详细三步思路见 `note/<考点>.md`。

## 一、数据结构（1–11）
**1.** 题干……
A. … B. … C. … D. …
→ `DS-02`｜要点：……
…
```

## 交付检查

```bash
cd notebook
python3 HANDOFF/tools/verify.py kaoyan/exam/真题
```

它会检查：每年题目数 ≥30、有来源与版权说明、缺图有标注。

**另外人工看一眼**：随机抽 5 道计算题，把要点里的数字重新算一遍。
这一步脚本做不了，但漏了会带错一批。
