# 任务 N1–N3 · note 层（分章配题，以真题为主）

## 背景

这是**练习层**，与 `exam/` 一章对应一章。用户原话：
「exam 和 note 这俩就是分章节的详细版本了，还是以考纲和**真题汇总**的详细版本，
所以这俩就是真正的**辅导书笔记和配题**。」

所以：`exam/` = 笔记正文，`note/` = 配题。**一章一文件**，与 exam 同名对应。

## 一个必须先说清的红线

用户手边有纸质真题，但**没有把原文给我**。所以：

> **绝对不许编造 "2023 年第 15 题" 这种题干与题号。**
> 一旦编错，用户对照纸面立刻发现，整层作废。

正确写法：
- 有把握的：`2018 年 · 选择题 · 考 IP 分片的数据部分必须是 8 字节倍数`
- 没把握的：`常见考法：给 MTU 与数据报长度，问分几片`

## 每章三段

```markdown
# NN 章名 · 配题

## 一、真题落点
| 年份 | 考点 | 考法 | 关键一步 |
|---|---|---|---|
（只写有实证的；没有就一行"本章暂无实证，见下方常见考法"）

## 二、变式练习
8–15 题，覆盖本章全部考点，由易到难。
难度标记：★ 基础 / ★★ 综合 / ★★★ 压轴

## 三、答案与判据
每题给：答案 + 一句话"为什么" + 一个常见错法
```

## 题目设计要求

1. **覆盖本章所有考点**，不能只挑好写的。写完对一遍 syllabus 的本章考点表。
2. **计算题必须有完整过程**，不能只给最终数字。
3. **选择题的错误选项要有迷惑性**——错在"看起来对但有一步不成立"，不是明显错。
4. **每 5 题里至少 1 题是综合题**（跨本章多个考点，或跨章）。

## 篇幅

每章：真题落点 100–300 字 + 题 8–15 道 + 答案 500–1000 字，总 1500–3000 字。

## 生成方式

按章一块（约 2000 字），**不要一次写多章**。答案部分可以拆成独立任务
（先出题、后出答案），这样两边的质量都更稳。

## 交付检查

```bash
cd notebook/kaoyan
for d in note/408/ds note/408/co note/408/os note/408/net note/math1/hs note/math1/la note/math1/ps; do
  printf "%-16s %2s 章\n" "$d" "$(ls $d/*.md 2>/dev/null | wc -l | tr -d ' ')"
done
# 每章三段是否齐
grep -L "## 三、答案" note/**/*.md 2>/dev/null || echo "全部三段齐"
# 是否出现可疑的"真题原文"表述
grep -rn "年第.*题" note/ | head
```

最后一条要人工看一眼：如果出现"XX 年第 N 题"且没有实证来源，改写成"常见考法"。
