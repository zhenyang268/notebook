## CO-05 中央处理器

### 408-CO-0501 CPU 结构与功能

CPU 由运算器和控制器两大部分构成。运算器含 ALU、通用寄存器组、暂存寄存器、程序状态字寄存器 PSW 和移位器，完成算术逻辑运算；控制器含 PC、IR、指令译码器、时序电路和微操作信号发生器，实现指令控制、操作控制、时间控制和中断异常处理。

寄存器是否“对程序员可见”，取决于能否用指令直接访问：PC、通用寄存器、PSW 可见；IR、MAR、MDR、暂存寄存器不可见。

位数关系是常考点：MAR 有 $n$ 位则主存地址空间为 $2^n$ 个编址单元，MDR 位数等于存储字长，PC 位数通常与 MAR 相同。易错点是把 MAR、MDR 的位数与机器字长混为一谈——机器字长指运算器一次能处理的数据位数，三者由不同因素决定。

### 408-CO-0502 指令执行过程

一条指令的执行分为取指、间址、执行、中断四个阶段，每个阶段构成一个工作周期，由若干机器周期、时钟周期组成。取指阶段的数据流为：PC→MAR，M(MAR)→MDR，MDR→IR，(PC)+1→PC；间址阶段的数据流为：IR 的形式地址→MAR，M(MAR)→MDR，MDR→IR 的地址字段。指令周期等于各阶段时间之和，其中间址周期与中断周期可以缺省。

典型计算：某机主频 1 GHz，一条指令含 3 个机器周期，每个机器周期含 2 个时钟周期，则指令周期为 $3\times 2\times 1\,\text{ns}=6\,\text{ns}$。

易错点：PC 的自增量由指令字长和编址单位共同决定，按字节编址、指令字长 4 B 时应为 PC+4，而非 PC+1。

### 408-CO-0503 数据通路

数据通路是功能部件之间传送数据的路径，由总线或专用连线加控制信号构成，分为单总线、双总线、三总线和专用数据通路几种组织方式。

单总线结构同一时刻只允许一个数据在总线上传送，一次 ALU 运算需多个时钟周期。以 R0+R1→R2 为例：第一拍 R0 送出，打入 ALU 的 A 端暂存器；第二拍 R1 送出，ALU 执行加运算，结果存入暂存器 Z；第三拍 Z 送出，打入 R2。

易错点：单总线数据通路所需的节拍数取决于操作数位置，两个操作数都在寄存器中的加法需 3 拍；改用双总线可让两个操作数同时到达 ALU，只需 2 拍。专用数据通路性能最高但连线复杂，控制信号也最多。

### 408-CO-0504 控制器

控制器产生全机控制信号，分硬布线与微程序两类。硬布线控制器用组合逻辑电路直接产生控制信号，速度快、难以修改和扩充；微程序控制器把控制信号编成微指令存入控制存储器 CM，一条机器指令对应一段微程序，执行时逐条取出微指令译码产生微命令。

CM 容量 $=m\times n$ 位，$m$ 为全部微指令条数，$n$ 为微指令字长。典型计算：某机有 32 条机器指令，各对应 4 条微指令，微指令字长 40 位，则 CM 容量为 $32\times 4\times 40=5120$ 位。

易错点：微程序的入口地址由机器指令操作码映射得到，并非顺序排列；水平型微指令并行能力强、字长长、微程序短，垂直型恰好相反。

### 408-CO-0505 异常与中断

异常由 CPU 内部事件引起，中断由外部设备请求引起。异常分为故障（fault，如缺页、非法操作码，处理后重新执行当前指令）、自陷（trap，如系统调用、断点，处理后执行下一条指令）、终止（abort，硬件故障，程序无法继续）。中断分为可屏蔽中断 INTR 与不可屏蔽中断 NMI。

响应条件为：有中断请求、CPU 允许（可屏蔽中断要求 IF=1）、一条指令执行结束。中断隐指令由硬件完成三件事：关中断、保存断点 PC、依据中断向量引出服务程序；通用寄存器和 PSW 由服务程序用指令保存。

易错点：中断屏蔽字改变的是处理次序，某级屏蔽字中置 1 的位越多，它能屏蔽的级别越多，优先级越高。

### 408-CO-0506 指令流水线

流水线把指令执行划分为若干阶段，由独立部件分别承担，使多条指令在时间上重叠执行。$k$ 段流水线执行 $n$ 条指令、时钟周期为 $T$ 时，总时间为 $T_k=(k+n-1)T$，吞吐率 $TP=\dfrac{n}{(k+n-1)T}$，加速比 $S=\dfrac{nk}{k+n-1}$，效率 $E=\dfrac{S}{k}$。

相关冒险有三类：结构冒险源于资源冲突，数据冒险可用转发（旁路）、停顿、编译调度缓解，控制冒险可用延迟转移、分支预测缓解。

典型计算：5 段流水线每段 2 ns，执行 100 条指令需 $(5+100-1)\times 2=208$ ns，不流水时需 $100\times 10=1000$ ns。

易错点：时钟周期取最长时间段加锁存器延迟，并非各段的平均值。

### 408-CO-0507 多处理器概念

按 Flynn 分类：SISD 为传统单处理器；SIMD 为阵列处理机、向量处理机，挖掘数据级并行；MISD 无实际模型；MIMD 为多处理机与多核处理器，挖掘线程级并行。

共享存储多处理器按访存模型分为 UMA 与 NUMA。硬件多线程分为细粒度、粗粒度与同时多线程 SMT（超线程），SMT 在同一周期发射多个线程的指令，但物理核仍只有一个。多处理机的 Cache 一致性由协议维护：监听协议适合总线结构，目录协议适合大规模系统。

易错点：超线程通过复制寄存器状态提高流水线利用率，并非增加物理核，性能提升有限；SIMD 与 MIMD 的并行层次不同，不可混用。

## CO-06 总线

### 408-CO-0601 总线概述

总线是多个部件共享的传输线路。按功能分为片内总线、系统总线和通信总线；系统总线又分数据总线、地址总线和控制总线。按传输方式分为串行总线与并行总线。

总线宽度指数据线的条数，总线带宽指单位时间内传送的数据量：
$$B=\text{总线宽度}\times\frac{\text{总线工作频率}}{\text{每次传送所需时钟数}}$$

典型计算：数据线 32 位，总线时钟 66 MHz，每 2 个时钟周期传送一次，带宽为 $\dfrac{32}{8}\times\dfrac{66}{2}=132$ MB/s。

易错点：地址总线宽度决定可寻址空间 $2^n$ 个单元；并行总线未必快于串行总线，串行总线可通过提高工作频率、采用差分传输获得更高带宽，且成本低、抗干扰强。

### 408-CO-0602 总线事务与定时

总线事务是一次完整的总线操作，含请求、仲裁、寻址、数据传输、释放五个阶段。定时方式有四类：同步定时使用统一时钟，速度快、设计简单，但各设备须按最慢设备取齐；异步定时采用握手，分不互锁、半互锁、全互锁三种，全互锁最可靠也最慢；半同步定时在同步基础上增设 WAIT 信号，兼顾两者；分离事务把一次传输拆成请求与应答两个子过程，中间释放总线以提高利用率。

突发传送在一次寻址后连续传送多个数据，减少地址开销，提高有效带宽。

易错点：同步定时适合速度相近的设备，异步定时适合速度差异大的设备；分离事务提高的是总线利用率，而非单次传输的延迟。

## CO-07 输入/输出系统

### 408-CO-0701 I/O 系统概述

I/O 系统由外部设备、I/O 接口、系统总线以及 DMA 控制器、通道等组成，层次为：用户程序→I/O 软件（设备无关软件、设备驱动程序）→I/O 接口→设备。

I/O 端口编址有两种方式：统一编址与主存共用地址空间，用访存指令访问，无需专门的 I/O 指令，但占用主存地址范围；独立编址使用独立的端口空间，需专门的 I/O 指令与 I/O 控制信号，不影响主存容量。

CPU 与 I/O 之间交换三类信息：数据、状态、控制。

易错点：统一编址靠地址范围或访存控制信号区分主存与 I/O，译码电路较复杂；独立编址增加了指令系统和控制信号的开销。

### 408-CO-0703 I/O 接口

I/O 接口是 CPU 与外设之间的转换层，基本组成是**数据端口、状态端口、控制端口**加地址译码与控制逻辑。CPU 访问它们有两种编址方式：**统一编址**把端口当作主存单元，用普通访存指令读写，代价是**占用主存地址空间**；**独立编址**给端口单独的地址空间，需要专门的 `IN`/`OUT` 指令，好处是不占用主存空间。接口要完成的事包括：地址译码选中设备、数据缓冲（解决速度不匹配）、格式转换（串并转换）、状态上报（忙/就绪）。易错点：题目问"是否需要专门指令"时，判据是**编址方式**而不是接口本身；统一编址下 CPU 分不清访存还是访端口，靠地址范围区分。

### 408-CO-0704 I/O 方式

四种方式的区别在于**谁在数据传送中干活**。程序查询方式下 CPU 反复读状态寄存器，忙等浪费 CPU；中断方式下外设就绪时发中断，CPU 响应后仍**通过自己的寄存器搬运数据**；DMA 方式下 DMA 控制器接管总线，**数据在外设与主存之间直接传送，不经过 CPU**，CPU 只在开始（初始化）和结束（收到中断）时介入。易错点有三：一是" DMA 不占 CPU"不等于"不占总线"，DMA 要**窃取总线周期**，与 CPU 争用内存；二是中断方式下数据仍要过 CPU，只是不必忙等；三是程序中断方式适合少量、随机数据，DMA 适合大批量、连续数据，判据是数据量与是否要求 CPU 参与。
