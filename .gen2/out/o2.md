## OS-04 文件管理

### 408-OS-0401 文件系统基础

文件是有名字的相关信息集合，由 FCB 描述其名字、类型、位置、大小、保护位与时间戳等属性。逻辑结构分无结构流式文件与有结构文件：顺序文件按记录顺序存放，适合顺序存取，查找第 $i$ 条记录须扫描前 $i-1$ 条；索引文件为记录建索引表以支持随机存取，代价是索引表占空间；索引顺序文件对两者折中。目录本质是 FCB 的集合，线性表目录平均查找 $O(n)$，哈希目录平均 $O(1)$。硬链接是多个目录项共享同一索引节点，链接计数减为 $0$ 且无进程打开时才真正删除，但它不能跨文件系统、一般不允许指向目录；符号链接是独立文件，内容为路径名，原文件删除后成为悬空链接。

### 408-OS-0402 文件系统实现

磁盘上自底向上依次为引导块、超级块、空闲块位图、i 节点位图、i 节点区和数据区。索引节点存放除文件名外的全部元数据与索引表，目录项只保留文件名与 i 节点号。连续分配支持顺序与随机存取且寻道少，但有外部碎片、文件难动态增长；隐式链接无外部碎片却只支持顺序访问，显式链接把指针集中到 FAT；索引分配支持随机访问，代价是多读一次索引块。混合索引的最大文件长度等于直接块、一级、二级、三级间接块可指块数之和，如盘块 $4\text{KB}$、指针 $4\text{B}$、$12$ 个直接块加三级间接，则 $48\text{KB}+4\text{MB}+4\text{GB}+4\text{TB}$。空闲空间常用位图与成组链接管理。

### 408-OS-0403 磁盘与 SSD

磁盘由盘面、磁道、柱面、扇区组成，一次读写的平均时间为 $T_a=T_s+\dfrac{1}{2r}+\dfrac{b}{rN}$，其中 $T_s$ 是寻道时间，$r$ 是转速（转/秒），$N$ 是每磁道字节数，$b$ 是读写字节数，旋转延迟取平均半圈。调度算法中 FCFS 公平但寻道长；SSTF 每次选距当前磁头最近的请求，平均寻道最短却可能饥饿；SCAN 单向扫至端点再折返；C-SCAN 回程不服务，等待时间更均匀；LOOK 与 C-LOOK 到最远请求即折返。SSD 以闪存页为单位读写、以块为单位擦除，无寻道与旋转延迟，由 FTL 完成逻辑地址到物理地址的映射，并需磨损均衡与垃圾回收；写前必须擦除，故随机写明显慢于随机读。

## OS-05 输入/输出管理

### 408-OS-0501 概述与控制方式

I/O 设备按信息交换单位分为块设备与字符设备：块设备可寻址、以数据块为单位传输，字符设备以字节流方式传输。I/O 控制器含数据、控制、状态三类寄存器，其端口可用独立编址（须专门的 I/O 指令）或内存映射编址（用普通访存指令访问）。控制方式的演进体现 CPU 干预程度的降低：程序查询方式由 CPU 反复读状态寄存器，CPU 与设备串行工作；中断驱动方式每传一个字便中断一次，两者可并行但中断过于频繁；DMA 方式以数据块为单位，传送全程由 DMA 控制器完成，只在开始与结束时打扰 CPU，其间采用周期挪用；通道方式执行通道程序，可控制多台设备。易错点在于中断方式仍由 CPU 逐字搬运，只有 DMA 才免去逐字干预。

### 408-OS-0502 设备独立软件

设备独立性软件位于设备驱动程序之上，向上提供与设备无关的统一接口（如 read、write、open、close），并负责设备命名与保护、缓冲管理、设备分配与回收、差错控制，还通过逻辑设备表 LUT 完成逻辑设备名到物理设备及驱动程序的映射。缓冲用于缓和 CPU 与 I/O 的速度差、减少中断次数、解决数据粒度不匹配。单缓冲下每块数据的处理时间约为 $\max(C,T)+M$，其中 $T$ 为输入到缓冲区、$M$ 为从缓冲区送到用户区、$C$ 为 CPU 处理时间；双缓冲为 $\max(T,\,C+M)$，使输入与处理得以并行。SPOOLing 在磁盘上设输入井与输出井，把独占设备虚拟为共享设备。易错点：缓冲管理属于设备独立性软件，不由驱动程序实现。
