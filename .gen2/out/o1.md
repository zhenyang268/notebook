## OS-01 操作系统概述

### OS-01.01 基本概念

操作系统是控制和管理整个计算机系统软硬件资源、合理组织调度与资源分配，并为用户和其他软件提供方便接口与环境的程序集合。其职能可归纳为处理机管理、存储器管理、设备管理、文件管理和用户接口；基本特征为并发、共享、虚拟和异步，其中并发与共享互为存在条件，是最基本的两个特征。

从资源管理角度看，操作系统是资源管理器；从用户角度看，它是一台扩展的机器。并发指两个或多个事件在同一时间间隔内发生，区别于同一时刻的并行；共享分为互斥共享与同时共享；虚拟依靠时分复用与空分复用实现；异步指进程以不可预知的速度推进。易错点：单处理机上多道程序只能并发不能并行，并行需要多处理机或专用部件。

### OS-01.02 发展与分类

操作系统经历了手工操作、单道批处理、多道批处理、分时和实时等阶段。单道批处理一次只允许一道程序驻留内存，CPU 与 I/O 串行，资源利用率低；多道批处理在内存中同时驻留多道程序，一道因 I/O 暂停时切换另一道，实现宏观并行、微观串行，显著提高 CPU 与设备利用率，代价是缺乏交互性、响应慢。分时系统把 CPU 时间划分为时间片轮流分配给各终端用户，具有多路性、独立性、及时性和交互性；实时系统强调在截止时间内完成处理并保证高可靠性，分为硬实时与软实时。

多道程序下若每道程序等待 I/O 的概率为 $p$，内存中 $n$ 道程序时 CPU 利用率近似为 $U=1-p^{n}$，道数增加收益递减。易错点：分时系统的响应时间取决于时间片长度、用户数与切换开销，而非仅由时间片决定。

### OS-01.03 运行环境

CPU 通常设置用户态（目态）与内核态（管态）两种状态，由程序状态字中的模式位标识。特权指令只能在内核态执行，如关中断、设置时钟、修改页表基址、I/O 指令；用户态执行特权指令将引发异常。用户程序通过系统调用请求操作系统服务，系统调用的调用发生在用户态、执行在内核态，是用户态进入内核态的唯一合法入口。

中断按来源分为外中断（中断，如时钟、I/O 完成）与内中断（异常，如陷入 trap、故障 fault、终止 abort）。系统调用属于陷入，缺页属于故障，除零或非法指令属于终止。易错点：中断处理程序和系统调用服务例程均运行在内核态；用户态到内核态的切换由中断或异常触发，内核态返回用户态由中断返回指令完成。

### OS-01.04 体系结构

操作系统内核结构主要有大内核（单体内核）与微内核。大内核把进程管理、存储管理、文件系统、设备驱动等全部功能放在内核态，模块间直接函数调用，因此性能高，但内核庞大、耦合紧、可靠性与可维护性差。微内核只把最基本的功能——进程管理、低级存储管理、中断与陷入处理、进程间通信——留在内核态，其余服务以用户态服务器进程实现，客户与服务器通过消息传递通信。

微内核的优点是可靠性高、易扩展、易移植，缺点是频繁的态切换与消息传递带来性能开销。分层结构按层次组织，调试方便但层次定义困难；外核把资源以极小粒度交给用户程序自行管理。易错点：微内核中设备驱动运行在用户态，故其性能通常低于大内核。

### OS-01.05 引导与虚拟机

计算机加电后先执行固件中的引导程序：由 BIOS/UEFI 完成加电自检，按启动顺序读取磁盘的主引导记录（MBR，位于 0 号扇区）或 EFI 系统分区，把引导加载程序装入内存；引导加载程序（如 GRUB）再把操作系统内核映像装入内存并移交控制权，内核完成初始化后创建第一个进程。磁盘引导块中存放的是引导加载程序而非内核本身。

虚拟机通过虚拟机监视器 VMM 在物理机上虚拟出多台逻辑计算机。第一类 VMM 直接运行在硬件上（如 Xen），性能好；第二类 VMM 运行在宿主操作系统之上（如 VMware Workstation），安装方便。全虚拟化由 VMM 动态翻译特权指令，客户机无需修改；半虚拟化需修改客户机操作系统，性能更优。易错点：VMM 运行在最高特权级，客户机操作系统运行在较低特权级。

## OS-02 进程与线程

### OS-02.01 进程与线程

进程是程序在一个数据集合上的一次运行过程，是系统进行资源分配的基本单位；其唯一标志是进程控制块 PCB，进程实体由 PCB、程序段和数据段组成。进程具有动态性、并发性、独立性、异步性和结构性。基本状态为就绪、运行、阻塞：就绪是已获得除 CPU 外的全部资源，阻塞是因等待事件而暂停。阻塞到就绪必须由事件完成触发，不能由调度直接转换；运行到阻塞是进程自身主动行为。

线程是 CPU 调度的基本单位，同一进程的线程共享地址空间、代码段、数据段和打开的文件，但各有独立的线程 ID、程序计数器、寄存器组和栈，故线程切换开销小于进程切换。用户级线程由库管理，内核不可见，阻塞一个线程会阻塞整个进程；内核级线程可并行于多处理机；多对多模型兼顾两者。易错点：引入线程后，进程仍是资源分配单位。

### OS-02.02 CPU 调度

处理机调度分为三级：高级调度（作业调度，从外存后备队列选作业入内存）、中级调度（内存对换，解决内存紧张）、低级调度（进程调度，从就绪队列选进程分配 CPU），其中低级调度频率最高。调度方式有抢占式与非抢占式。评价指标包括 CPU 利用率、吞吐量、周转时间 $T_i$（完成时间减到达时间）、带权周转时间（$T_i$ 除以服务时间）、等待时间和响应时间，通常求平均值。

常用算法：先来先服务 FCFS 简单但存在队头阻塞；短作业优先 SJF 的平均等待时间最小，但长作业可能饥饿；优先级调度分静态与动态，低优先级可能饥饿，可用老化缓解；时间片轮转 RR 响应快，时间片过大退化为 FCFS、过小则切换开销大；多级反馈队列兼顾响应与周转。易错点：SJF 的最优性以作业运行时间已知为前提。

### OS-02.03 同步与互斥

临界资源一次仅允许一个进程使用，访问它的代码段称为临界区，进程进入前须申请、退出后须释放。互斥须满足空闲让进、忙则等待、有限等待、让权等待四个准则。软件方案有单标志、双标志与 Peterson 算法；硬件方案有关中断、TestAndSet 与 Swap 指令，硬件方法简单但忙等浪费 CPU。

信号量 $S$ 只能由 P、V 两个原语访问：$P(S)$ 使 $S=S-1$，若 $S<0$ 则阻塞；$V(S)$ 使 $S=S+1$，若 $S\leq 0$ 则唤醒一个阻塞进程。互斥时初值为 1，同步（前驱后继）时初值为 0。经典模型有生产者—消费者、读者—写者、哲学家进餐。易错点：互斥中 P 操作顺序颠倒可能死锁；$S<0$ 时其绝对值等于等待队列中的进程数，而非可用资源数。

### OS-02.04 死锁

死锁指多个进程因竞争资源而相互等待对方释放资源，若无外力介入均无法推进。产生死锁须同时满足四个必要条件：互斥、不可剥夺、请求并保持、循环等待，破坏其中任一即可预防。预防策略分别对应一次性分配全部资源、允许剥夺、申请新资源前先释放已有资源、给资源编号并规定按序申请。避免死锁在分配前用银行家算法判断系统能否处于安全状态：令 $Need=Max-Allocation$，若存在安全序列使所有进程依次完成，则分配可行。

检测可用资源分配图化简，能消去所有请求边即无死锁；解除手段有资源剥夺、撤销进程、进程回退。易错点：不安全状态不等于已死锁，只是可能死锁；死锁与饥饿不同，后者是长期得不到资源但系统仍在推进。

## OS-03 内存管理

### OS-03.01 内存管理基础

内存管理的主要功能是地址转换、内存分配与回收、内存保护与共享、内存扩充。逻辑地址经重定位变为物理地址：静态重定位在装入时一次完成，程序不可移动；动态重定位在访问时由硬件完成，需重定位寄存器，便于程序浮动。保护靠基址寄存器与限长寄存器判断地址合法性。

连续分配中固定分区产生内部碎片，动态分区产生外部碎片，可用紧凑消除但代价大；分配算法有首次适应、邻近适应、最佳适应（空闲区按大小递增，易产生小碎片）、最坏适应。分页把逻辑地址分为页号与页内偏移：页号 $=\lfloor A/L\rfloor$，偏移 $=A\bmod L$，页表由页号查到物理块号，物理地址 $=$ 块号 $\times L+$ 偏移，只产生内部碎片。分段按逻辑模块划分，便于共享与保护，但产生外部碎片。易错点：页表项数与逻辑地址空间页数一致。

### OS-03.02 虚拟内存管理

虚拟内存基于局部性原理，只把当前需要的部分调入内存，其余留在外存，由请求调页与页面置换实现逻辑上扩充内存。请求分页的页表项增加状态位、访问位、修改位与外存地址；访问的页不在内存时产生缺页中断，它属于内中断中的故障，处理完成后重新执行被中断的指令。

置换算法中 OPT 缺页率最低但不可实现，可作基准；FIFO 简单，可能出现 Belady 异常（物理块增多缺页反增）；LRU 性能接近 OPT，需硬件支持；CLOCK 用访问位循环扫描，是 LRU 的近似。设内存访问时间为 $t$、缺页处理时间为 $t_f$、缺页率为 $p$，则有效访问时间约为 $(1-p)t+pt_f$。驻留集过小会引起抖动。易错点：页面换出时若修改位为 1 须写回外存，成本更高。
