# M1-HS-0702 幂级数

> 章：HS-07 无穷级数　｜　档位：掌握　｜　真题落点：近四年真题库未收录数学一，按常见考法组织，不冒充原题

## 考法 1：求收敛半径与收敛域，端点必须单独判

**思路**：第一步只认系数：对 $\sum a_n(x-x_0)^n$ 算 $\rho=\lim\left|\frac{a_n}{a_{n+1}}\right|$ 或 $R=\dfrac{1}{\lim\sqrt[n]{|a_n|}}$，得到以 $x_0$ 为中心的 $R$。第二步把 $x=x_0\pm R$ 代回原级数，各得一个数项级数，分别用 0701 的手段判敛散，最后把四个区间碎片拼成收敛域。核心认识：$R$ 只由系数决定，与平移中心 $x_0$ 无关。

**坑**：遇到缺项级数（只有 $x^{2n}$、$x^{3n}$）直接套 $R=1/\lim\sqrt[n]{|a_n|}$，把收敛半径算大一倍；正确做法是先令 $t=x^2$ 求出 $t$ 的范围再开方。第二个坑是把 $(-R,R)$ 当成最终收敛域交卷，端点一个都不代——端点恰恰是命题人放分的地方。

## 考法 2：求和函数 $S(x)$——看分母决定积分、看分子决定求导

**思路**：第一步看系数形态定动作：分母带 $n$、$n+1$、$2n+1$ 就想到积分能把它消掉；分子带 $n$ 就想到求导能把它消掉。第二步把级数凑成几何级数 $\sum t^n=\frac{1}{1-t}$ 的标准形，做完求导/积分后再把 $t$ 换回 $x$。第三步统一下标起点（求导后 $n$ 从 1 起、积分后可能从 0 起），别让首项凭空消失。第四步定常数：积分出来的 $S(x)$ 含任意常数，代一个使级数显然为 0 的点（通常是 $x=0$）定出来。

**坑**：求导或积分后忘记回代或忘记对齐下标，导致答案差一个首项；更隐蔽的是代点定常数时取了收敛域外的点，或取了端点却没意识到端点处和函数可能不连续，代进去的值根本不属于 $S(x)$ 的表达式。

## 考法 3：逐项求导、逐项积分的合法性——区间内部才行

**思路**：第一步先看 $x$ 落在哪：只有 $x$ 严格位于收敛区间内部，逐项求导、逐项积分才保号保收敛；若题目要的是端点处的和，走阿贝尔定理，让 $x$ 从内部取单侧极限逼近端点。

**坑**：在 $x=\pm R$ 处直接对和函数求导再代值——端点处的收敛性不保证可以逐项操作，这样做出来的数往往还“看着挺对”，是最难自查的错误。

## 考法 4：展开成幂级数——认母函数，不硬算泰勒系数

**思路**：第一步认母函数：$e^x$、$\sin x$、$\cos x$、$\frac{1}{1-x}$、$\ln(1+x)$、$(1+x)^{\alpha}$ 六族的标准展开与成立区间要能默写。第二步把待展函数化成“母函数 + 变量替换”的形式：分式先拆部分分式，含 $\arctan x$、$\arcsin x$ 的先求导变成有理式，展完再积回去。第三步在展开点不是 0 时，整体写成 $(x-x_0)^n$ 的幂，并同步改写成立区间。

**坑**：只写通项不写成立区间；替换变量时漏配系数——把 $x$ 换成 $2x$ 后通项里该出现的 $2^n$ 没出现，或者 $\ln(1+2x)$ 里的 $2^n$ 只加在分母上；先求导再积分回来时忘记补 $\int_0^x$ 的上下限，把常数项丢掉。
