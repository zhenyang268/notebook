# 408-NET-0405 IPv6、组播与移动 IP

> 章：NET-04 网络层　｜　档位：掌握　｜　真题落点：1 题：2023 #40

## 考法 1：IPv6 地址书写与首部“简化了什么”

**思路**：地址题第一步是“先补零再压缩”：找连续的全 0 组用 `::` 代替，其余每组的前导 0 可省。首部题盯三条：固定 40 B；取消了首部检验和；把分片相关字段与选项挪进扩展首部。由此推出结论：沿途路由器不再重算首部校验和，转发更快。

**坑**：一条地址里写出两个 `::`；把“去掉首部检验和”误记成“去掉生存时间（跳数限制）”。还有以为 IPv6 彻底不分片——实际是源主机可以分片、路由器不分片，路径 MTU 由 ICMPv6 报文反馈。

## 考法 2：三种过渡技术怎么选

**思路**：按“两端是什么、中间是什么”来定：两端都支持 IPv6、中间是 IPv4 网络，用隧道（把整个 IPv6 数据报封进 IPv4 数据报）；一台主机同时装两套协议栈、按目的地址选用，是双协议栈；纯 IPv6 主机要与纯 IPv4 主机直接对话、必须改报文头，用协议转换（NAT64 一类）。判题时先问“谁和谁通信、路径上跑的是什么版本”。

**坑**：看到“隧道”就以为要把 IPv6 报文拆成分片塞进 IPv4；实际是整体封装，IPv4 首部的协议号指向上层是 IPv6。也常把双协议栈说成“两种地址互相翻译”。

## 考法 3：组播地址的映射与 IGMP 的作用范围

**思路**：先立两条前提：组播地址只能做目的地址、绝不能做源地址；IPv4 组播地址用其低 28 位组标识中的低 23 位映射到 MAC 地址低 23 位，MAC 前缀固定为 `01-00-5E` 且其后的第 25 位恒为 0。再分层：IGMP 只解决“本网段内还有没有主机要这个组”，跨网段的组播分发靠组播路由协议。

**坑**：把映射写成“IP 地址的低 32 位整体搬进 MAC”，或把前缀写成 24 位、丢掉恒 0 的那一位。也常把 IGMP 当组播路由协议；它只在主机与本地组播路由器之间运行。别忘了映射丢位的后果：多个组播组会映射到同一个 MAC 地址。

## 考法 4：移动 IP 的注册与“两条隧道、三类地址”

**思路**：按角色和顺序走：移动节点在家网用归属地址正常通信；到了外地网，向归属代理注册得到转交地址；归属代理截获所有发往归属地址的报文，用隧道（再封装）送到转交地址，再由外地代理交付给移动节点；移动节点发出的报文一般直接发给通信对端，于是形成三角路由。

**坑**：把转交地址和归属地址混用，以为通信对端直接把报文发给转交地址。也常漏掉“归属代理代答 ARP、替移动节点接收”这一环，误以为归属代理靠广播宣告移动节点的新位置。
