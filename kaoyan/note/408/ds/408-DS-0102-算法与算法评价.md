# 408-DS-0102 算法与算法评价

> 章：DS-01 绪论　｜　档位：掌握　｜　真题落点：2 题：2017 #1；2022 #1

**在考什么**：能否把循环或递归的执行次数化为增长阶，并用有穷、确定等判据区分算法与程序。

## 考法 1：算法五个特性与“算法≠程序”判断

**题目：常见考法——给出若干语句或描述，判断是否满足有穷性、确定性、可行性、输入、输出；或问算法与程序的区别。**

**思路**：第一步逐项核对五个特性，尤其注意两个边界：输入可以为零个，输出至少有一个；有穷性要求执行步骤有限，而不是“运行时间短”。第二步再看描述是否依赖具体语言、具体机器，若依赖则更像程序实现而不是算法本身。

**坑**：看到“输入”就以为算法必须有输入，把零输入判成错误；看到“输出”又以为可以没有输出。另一个常见误判是把“效率高”“代码短”当成算法五特性，或把“程序”直接等同于“算法”。

## 考法 2：循环程序段的执行次数计数

**题目：2022#1 下列程序段的时间复杂度是**

**思路**：第一步先看循环变量如何变化：是 `i++` 这类等差推进，还是 `i*=2` 这类等比推进；二者对应的循环次数增长完全不同。第二步对每个外层取值统计内层实际执行次数，若内层上界依赖外层变量，就不能简单把两层循环次数相乘，而要把各次执行次数相加或找总次数的增长上界。

**坑**：看到两层 `for` 就条件反射写成 $O(n^2)$；或者看到 `i*=2` 只想到对数级，却漏掉内层 `j<i` 的累计工作量。最容易错的是把内层上界当成固定 $n$，从而把“依赖外层变量的内层次数”误判成固定次数。

**题目：常见考法——给出单层循环、双层循环、循环变量按加法或乘法变化的小程序段，判断时间复杂度。**

**思路**：第一步写出循环变量的取值序列，明确终止条件；第二步把“循环体执行总次数”表示成关于 $n$ 的求和式或递推式，再只保留增长最快的主项。若循环变量每次乘除常数，优先考虑对数级；若每次加常数且上界为 $n$，优先考虑线性级；若内外层都线性且互不依赖，才考虑相乘。

**坑**：把“循环层数”直接当成“复杂度指数”，看到三层循环就写 $O(n^3)$，却不检查内层是否真的跑满 $n$ 次。另一个坑是忽略常数因子和低阶项，把 $O(n+n\log n)$ 误判成两个独立阶相加后的错误阶。

## 考法 3：递归与分治程序的复杂度分析

**题目：常见考法——给出递归函数或递推式，如 $T(n)=aT(n/b)+f(n)$，判断时间复杂度；或问二分、归并类过程的递归深度与每层代价。**

**思路**：第一步把递归过程写成“子问题个数 × 子问题规模 + 划分/合并代价”的形式；第二步用递归树看每一层总代价，或代入递推式展开，区分“递归深度”和“总工作量”。关键一步是判断每层代价是否随层数变化，以及子问题是否真的缩小为原来的 $1/b$。

**坑**：看到“二分”就写 $O(\log n)$，却漏掉划分或合并本身可能带来线性代价；看到递归深度是 $\log n$ 就以为总时间也是 $\log n$。另一个误判是把递归调用次数直接当时间复杂度，而不乘每次调用的工作量。

## 考法 4：空间复杂度与渐进阶比较

**题目：常见考法——问某算法辅助空间是多少；或比较 $O(1)$、$O(\log n)$、$O(n)$、$O(n\log n)$、$O(n^2)$ 的增长快慢，判断某函数的上界/下界。**

**思路**：第一步空间复杂度只数“额外辅助空间”：临时变量、辅助数组、递归栈帧、显式申请的堆空间；输入数据本身通常不计入辅助空间。第二步比较渐进阶时抓主导项：常数因子和低阶项先丢掉，再看 $n$ 增大时谁增长更快；递归算法还要把递归深度计入栈空间。

**坑**：把输入数组占用的空间算进辅助空间，导致把原地算法误判成线性空间；或者递归算法只数局部变量，漏掉递归调用栈。比较阶时容易把 $O(\log n)$ 与 $O(n)$ 的先后关系弄反，也容易把“嵌套循环”直接等同于“高空间复杂度”，忽略是否真的申请了与 $n$ 同阶的辅助结构。

### 2017 #1 循环求和复杂度
下列函数的时间复杂度是（ ）。 int func(int n) { int i = 0, sum = 0; while(sum < n) sum += ++i; return i; }

A. O(log₂n)
B. O(n^{1/2})
C. O(n)
D. O(n log₂n)

**思路**：把循环执行次数记为 k，累加和为 1+2+…+k=k(k+1)/2，令其达到 n，解出 k 的量级。

**坑**：看到 `sum += ++i` 容易当成每轮加固定值而判成线性，或忽略 `++i` 先自增再累加。

### 2022 #1 程序段时间复杂度
下列程序段的时间复杂度是（ ）
```c
int sum = 0;
for (int i = 1; i < n; i *= 2)
    for (int j = 0; j < i; j++) sum++;
```

A. O(log₂n)
B. O(n)
C. O(nlog₂n)
D. O(n²)

**要点**：外层取 log 次 i 值，内层对每个 i 跑 i 次，求和是等比数列 ⇒ O(n)。
