# 408-DS-0702 插入排序

> 章：DS-07 排序　｜　档位：掌握　｜　真题落点：2 题：2018 #1、#10

## 考法 1：直接插入的过程、哨兵的作用、比较与移动次数

**思路**：第一步把待插元素暂存到 `A[0]` 作哨兵，此后“边比较边后移”不再需要单独判下标越界，循环条件只剩 `A[0] < A[j]`。数次数要分开：每趟**比较次数**取决于它往前比了几个，**移动次数**等于后移次数 + 2（存哨兵一次、落位一次）。

**坑**：把哨兵当成“少一次比较”的技巧。哨兵省的是**越界判断**，比较次数一次没少。另一处是算最好情况时，把每趟那 1 次比较也漏掉；初始有序时每趟仍需比较 1 次，总比较次数是 $n-1$ 而不是 0。

## 考法 2：折半插入，比较次数与移动次数必须分开算

**思路**：第一步分清它只优化“找位置”这一段，把每趟比较次数从 $O(i)$ 降到 $O(\log i)$，总比较次数约 $O(n\log n)$；找到位置后仍要**整段后移**，移动次数与直接插入完全一致，总时间仍是 $O(n^2)$。

**坑**：看到“折半”就写总时间 $O(n\log n)$；被优化的是比较，不是移动。另一处是把折半查找的失败位置直接当插入位置：为保持稳定必须插在所有相等元素之后，所以 `A[mid] == key` 时还要继续往右半区找，写成“相等即停”会破坏稳定性。

## 考法 3：希尔排序，增量序列决定“一趟之后的序列”，也决定复杂度

**思路**：第一步按**下标模 $d$ 的同余类**分组，而不是按元素值或连续区间分组；每组内部做直接插入。做完一趟后只有“每组内有序”，全局仍无序。要写“某趟之后的结果”，必须逐组算完再按原下标拼回序列。

**坑**：把分组理解成“把序列切成 $d$ 段连续的块”，这是最常见的错法，会导致整趟结果全错。另一处是误以为希尔一定比直接插入快：增量最后一步为 1 时它退化成直接插入，若增量序列没取到 1，序列根本没排完。

### 2018 #1 希尔排序增量判定
对初始数据序列 (8, 3, 9, 11, 2, 1, 4, 7, 5, 10, 6) 进行希尔排序。若第一趟排序结果为 (1, 3, 7, 5, 2, 6, 4, 9, 11, 10, 8)，第二趟排序结果为 (1, 2, 6, 4, 3, 7, 5, 8, 11, 10, 9)，则两趟排序采用的增量（间隔）依次是（ ）。 排序算法

A. 3,1
B. 3,2
C. 5,2
D. 5,3

**思路**：按候选增量把结果序列分成若干组，逐组检查组内元素是否已按非递减排列；第一趟结果用于筛出可行增量，第二趟结果用于进一步确认后一增量。

**坑**：容易把“相隔一个增量的元素”误当成连续位置上的元素，或只检查前几个元素就下结论；看到局部相邻元素有序就误判为整体已按某增量分组有序。

### 2018 #10 希尔排序增量判定
对初始数据序列 (8, 3, 9, 11, 2, 1, 4, 7, 5, 10, 6) 进行希尔排序。若第一趟排序结果为 (1, 3, 7, 5, 2, 6, 4, 9, 11, 10, 8)，第二趟排序结果为 (1, 2, 6, 4, 3, 7, 5, 8, 11, 10, 9)，则两趟排序采用的增量（间隔）依次是（ ）。 排序算法

A. 3,1
B. 3,2
C. 5,2
D. 5,3

**思路**：希尔排序每趟按当前增量把序列分成若干子序列分别做直接插入排序；应检查结果中相隔该增量的元素是否各自构成有序子序列。用第一趟结果验证第一个候选增量，再用第二趟结果验证第二个候选增量，逐步排除不符合的间隔。

**坑**：容易把“一趟排序后”误看成整个序列相邻元素都有序，看到结果中仍有相邻逆序就误判间隔不合理；实际只需看间隔为候选值的同组元素是否有序。
