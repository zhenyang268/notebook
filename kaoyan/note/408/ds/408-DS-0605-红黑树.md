# 408-DS-0605 红黑树

> 章：DS-06 查找　｜　档位：掌握　｜　真题落点：本考点 2016–2024 无对应题目

**在考什么**：能否判树合法，并按插入或删除破坏的类型选对变色旋转，再用黑高与AVL权衡。

## 考法 1：性质判断题

**题目：常见考法变形（判断关于红黑树的若干叙述是否正确）**

**思路**：先把五条性质默写成标尺：结点非红即黑；根为黑；外部叶（NIL）为黑；红结点的两个孩子必为黑（不出现双红）；任一结点到其所有后代 NIL 的路径上黑结点个数相同。然后逐项对照，凡叙述里出现“高度差”“左右子树层数”字样的，先标可疑。

**坑**：把“叶结点为黑”读成普通叶子（度为 0 的实结点），实际指的是扩充出来的外部空结点；看到“红黑树是平衡二叉树”就判对——它只保证最长路径不超过最短路径的两倍，并不保证左右子树高度差 $\le 1$。

## 考法 2：插入后的修复 Case

**题目：常见考法变形（插入新结点后要做哪些操作、调整后子树根是谁）**

**思路**：新结点一律染红，唯一可能被破坏的是“不出现双红”。第一步找叔叔：叔叔为红，就把父与叔染黑、祖父染红，并把祖父当作新的“当前结点”继续向上查；叔叔为黑或 NIL，就看“当前结点—父—祖父”的拐向，同侧单旋、异侧双旋，旋完把新的子树根染黑、原祖父染红。

**坑**：叔叔为红时也去做旋转，其实这一档只变色不旋转；变色上推后不再检查祖父与它父亲是否又构成双红，漏掉继续上传；旋完忘记把新子树根染黑，黑高被破坏。

## 考法 3：黑高与高度界、与 AVL 的取舍

**题目：常见考法变形（黑高为 $bh$ 的红黑树最少／最多结点数，或红黑树与 AVL 的比较）**

**思路**：黑高指从某结点（不含自身）到任一 NIL 路径上的黑结点数。由“不出现双红”得最长路径 $\le 2bh$；最少结点按“全黑满树”构造，最多结点按“黑处尽量挂红”构造。比较 AVL 与红黑树时，从平衡的严格程度、调整次数、查找／插入／删除的渐进复杂度三条线上分别说。

**坑**：算黑高时把起点结点自身算进去，或漏掉末端 NIL 这个黑结点，高度界整体差 1；比较时误说红黑树查找比 AVL 差一个量级——二者都是 $O(\log n)$，差别在常数与调整频率。
