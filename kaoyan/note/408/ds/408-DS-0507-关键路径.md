# 408-DS-0507 关键路径

> 章：DS-05 图　｜　档位：掌握　｜　真题落点：2 题：2020 #8；2022 #7

## 考法 1：$ve/vl/e/l$ 四张表的正推与逆推

**题目**：常见考法（给 AOE 网，要求填出各事件的 $ve$、$vl$ 与各活动的 $e$、$l$）

**思路**：$ve$ 按拓扑序正推，源点取 0，$ve[j]=\max\{ve[i]+w_{ij}\}$——取 max 是因为事件 $j$ 要等所有前驱活动都完成；$vl$ 按逆拓扑序反推，汇点 $vl=ve$，$vl[i]=\min\{vl[j]-w_{ij}\}$——取 min 是因为不能拖累任何一个后继的最迟开始。活动 $a=\langle i,j\rangle$ 的 $e=ve[i]$、$l=vl[j]-w$。关键一步：先把 $ve$ 一整列算完再动 $vl$，不要两列交替推。

**坑**：把逆推时的 min 写成 max，$vl$ 越算越大，余量 $l-e$ 会出现负值；另一个是把活动的 $e$、$l$ 的弧头弧尾取反（用 $ve[j]$ 当 $e$、$vl[i]-w$ 当 $l$），算出的余量正好错位。

## 考法 2：时间余量最大的活动

**题目**：2022#7（10 个活动的 AOE 网，时间余量最大的活动）

**思路**：余量 $d=l-e$，关键活动是 $d=0$ 的那些。问“余量最大”，就必须把所有活动的 $e$、$l$ 都列出来逐个相减，不能只盯关键活动；可以先标出关键路径、把其上活动的余量记为 0 排除，再看剩下哪个的 $e$ 与 $l$ 相距最远。关键一步：余量是“活动的”，不是“事件的”，别拿 $vl-ve$ 去比。

**坑**：把“时间余量最大”误读成“持续时间最长”或“最早开始时间最晚”，直接去比边权；另一个是看到余量 0 就以为最大，把关键活动选了出来。

## 考法 3：关键路径的条数，以及压缩关键活动能否缩短工期

**题目**：常见考法（问缩短某关键活动能否缩短总工期 / 关键路径是否唯一）

**思路**：先把所有关键路径都列出来（余量为 0 的活动连成的通路），再判断被改动的活动是否被“每一条”关键路径共用：只有它被全部关键路径经过时，压缩它才一定能缩短工期。关键一步：压缩之后关键路径可能发生转移，原来看似不关键的路径会变长成新的瓶颈。

**坑**：认为“关键活动一定落在唯一的关键路径上”，于是压缩任意一个关键活动都断言工期缩短；实际上存在多条关键路径时，只压缩其中一条上的活动，工期一点不变。

## 考法 4：AOV 网与 AOE 网的区分，以及关键路径与拓扑排序的先后关系

**题目**：常见考法（问某网是 AOV 还是 AOE、求关键路径前必须先做什么）

**思路**：AOV 网顶点表示活动、弧表示先后约束，服务于拓扑排序；AOE 网顶点表示事件、弧表示活动（带持续时间），服务于关键路径。求关键路径要先对 AOE 网做一次拓扑排序拿到 $ve$ 的推进顺序，再按逆拓扑序求 $vl$。关键一步：先把“顶点是什么”认清楚——顶点是事件，$ve$、$vl$ 就是事件的最早、最迟发生时间；顶点是活动就跑到 AOV 上去了。

**坑**：把 AOE 网的顶点当成活动，对着顶点去算时间余量，得到一堆没有意义的 0 和非 0；另一个是对含回路的有向网求关键路径——有环就没有拓扑序，$ve$ 根本推不出来，此时应当先判环而不是硬算。

### 2020 #8 AOE关键路径叙述
若使 AOE 网估算工程进度则下列叙述中正确的是（ ）。

A. 关键路径是从原点到汇点边数最多的一条路径
B. 关键路径是从原点到汇点路径长度最长的路径
C. 增加任一关键活动的时间不会延长工程的工期
D. 缩短任一关键活动的时间将会缩短工程的工期

**思路**：关键路径看的是从源点到汇点的路径上权值（活动持续时间）之和最大，而不是边数最多；再结合是否存在多条关键路径分析单个关键活动时间变化对总工期的影响。

**坑**：容易把“边数最多”误当成关键路径；或一看到“关键活动”就认为缩短它一定缩短工期，忽略多条关键路径并存时的情况。

B. g

**要点**：余量 = 最迟开始 − 最早开始；关键活动余量为 0，余量最大者最"闲"。
