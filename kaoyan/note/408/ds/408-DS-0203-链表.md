# 408-DS-0203 链表

> 章：DS-02 线性表　｜　档位：掌握　｜　真题落点：5 题：2016 #1、#2；2021 #1；2023 #2；2024 #1

**在考什么**：先锁定目标结点的前驱，再按不断链的顺序改指针。

## 考法 1：循环链表“删尾”考的是前驱可得性（2021#1）

**思路**：删除一个结点必须改它**前驱**的指针，所以第一步回答：题目给的指针（头指针 $h$、尾指针 $p$）里，谁能一步拿到尾结点的前驱？单链表只有 $next$ 没有 $prev$，即便整体成环，“往回走”也只能绕一整圈。于是结论取决于“手上有没有能直接指到前驱的指针”，而不是取决于“是不是循环”。

**坑**：看到“循环链表”就以为从尾指针能 $O(1)$ 回到前驱，把单向环当成双向环；另一个坑是删完之后忘了同步更新尾指针与头结点的 $next$（表空与否要分开讨论）。

## 考法 2：双链表插入/删除的“改边顺序”（2023#2）

**思路**：先把待改的边列全：删除 $p$ 要动两条边——前驱的 $next$、后继的 $prev$；插入要动四条边。第一步永远是**先把 $p$ 的 $prev$、$next$ 存到临时变量里**，再动边；否则一旦某条边被改，后续取到的就不是原来的邻居。至于顺序，原则是“先接后断”：新链接建立之前不要切断旧链接。

**坑**：先改 `p->prev->next` 再想去读 `p->next`，若中间夹了释放或覆盖操作，读到的已经是失效值；以及忘记判 $p$ 是首元结点或尾结点——此时 `p->prev` 或 `p->next` 为空，那一条边要单独处理。

## 考法 3：单链表操作里“动指针”不等于“移结点”（2024#1）

**思路**：单链表的插入删除只改指针，数据元素原地不动，代价全在“走到位置”。第一步先把两件事分开计数：需要沿链访问多少个结点才能定位，以及定位后改几条指针。前者随 $n$ 增长，后者是常数。

**坑**：把“指针后移”当成“结点搬移”，得出“单链表插入要移动 $O(n)$ 个元素”的错误结论；另一处细节是带头结点时定位第 $i$ 个结点从哪个结点起步，容易整体差一格。

> 常见考法变形（自拟）：统计在长度为 $n$ 的单链表上“删除第 $i$ 个结点”所需访问的结点个数与所需修改的指针条数。

**思路**：访问数由 $i$ 与是否带头结点决定，指针修改条数恒为常数。

**坑**：把访问数也算作“移动元素个数”。

## 考法 4：逆置、快慢指针、合并、倒数第 $k$（模板族）

**思路**：这四个模板共用一个动作——**先在动指针之前把 next 存下来**。逆置用头插法重建，指针三步一轮；快慢指针靠“一步两跳与一步一跳”的位移差找中点或判环；倒数第 $k$ 个用两个相距 $k$ 个结点的指针同步后移，先让前指针走 $k$ 步；合并两条有序链用尾插，先决定头结点是复用还是新建。第一步统一都是“画三个格子的草图，标出改完指针后各结点的可见性”。

**坑**：逆置时没先保存 `cur->next` 就改指，链断在半路；快慢指针找中点时，偶数个结点的“中点”落在前半还是后半要按题目定义，两种写法的循环条件不同；倒数第 $k$ 个没先判 $k$ 是否超过表长，前指针提前走空。

### 2016 #1 单链表链接地址
已知表头元素为 c 的单链表在内存中的存储状态如下表所示。现将 f 存放于 1014H 处并插入单链表，若 f 在逻辑上位于 a 和 e 之间，则 a,e,f 的 “链接地址” 依次是（ ）。 a 1010H b 100CH c 1000H d NULL e 1004H 元素 链接地址 地址 1000H 1004H 1008H 100CH 1010H 1014H〔原卷附图，纯文本从略〕

A. 1010H，1014H，1004H
B. 1010H，1004H，1014H
C. 1014H，1010H，1004H
D. 1014H，1004H，1010H

**思路**：先按地址还原各结点的 next 指向，再把 f 插入到 a 与 e 之间，关键是看 a、e、f 各自 next 应指向哪个地址，而不是看结点自身地址。

**坑**：看到“f 位于 a 和 e 之间”会误以为 a 的链接地址仍填 e 的地址；也容易把“链接地址”误判成结点所在地址。

### 2016 #2 双向循环链表删除
已知一个带有表头结点的双向循环链表  L ，结点结构为  prev|data|next ， prev  和  next  分别是指向其直接前驱和直接后继结点的指针。现要删除指针  p  所指的结点，正确的语句序列是（ ）。

A. p->next->prev = p->prev; p->prev->next = p->prev; free(p);
B. p->next->prev = p->next; p->prev->next = p->next; free(p);
C. p->next->prev = p->next; p-> prev->next = p->prev; free(p);
D. p->next->prev = p->prev; p->prev->next = p->next; free(p);

**思路**：删除 p 结点要让其直接后继的 prev 改指 p 的前驱，同时让其直接前驱的 next 改指 p 的后继，两个方向都要改写后再释放 p。

**坑**：看到 prev/next 成对出现容易把手误写成同侧指针，造成自指或断链；也可能先 free(p) 再访问 p 的指针。

### 2021 #1 单循环链表删首
头指针 h 指向带头结点的非空单循环链表，p 是尾指针，q 临时指针。删除第一个元素的正确语句序列是（ ）。〔原卷有结点结构示意〕

A. `h->next = h->next->next; q = h->next; free(q);`
B. `q = h->next; h->next = h->next->next; free(q);`
C. `q = h->next; h->next = q->next; if (p != q) p = h; free(q);`
D. `q = h->next; h->next = q->next; if (p == q) p = h; free(q);`

**要点**：单循环链表删首元要考虑"表只剩一个元素"时尾指针要指回头结点。

### 2023 #2 双向链表插入指针
非空双向链表 L，结点 `prev|data|next`，在 p（非尾结点）之后插入 s。已执行 `s->next=p->next; p->next=s;`，还需（ ）

A. `s->next->prev=p; s->prev=p;`
B. `p->next->prev=s; s->prev=p;`
C. `s->prev=s->next->prev; s->next->prev=s;`
D. `p->next->prev=s->prev; s->next->prev=p;`

**要点**：插入后要让"后继的 prev 指向 s"和"s 的 prev 指向 p"，顺序不能颠倒（否则丢指针）。

### 2024 #1 单链表结点移动
已知带头结点的非空单链表 L 的头指针为 h，结点结构为 `[data|next]`。指针 p 指向 L 中非首非尾结点，执行
`q = p->next; p->next = q->next; q->next = h->next; h->next = q;`

A. 在 p 后插入 q
B. 在 q 后插入 p
C. p 移到头结点后
D. q 移到头结点后

**思路**：四句按顺序追踪指针。第 1、2 句把 q 从 p 后面摘下来（p 直接指向 q 的后继）；第 3、4 句把 q 插到 h 与 h->next 之间。所以是"摘下 q，插到头"。

**坑**：看到"p->next = q->next"就以为"删 q"，其实 q 没释放，只是被移走。选 D 而非 C 的关键是最后一句话把 q 挂给 h 而不是 p。
