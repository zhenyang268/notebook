# 408-DS-0303 数组与特殊矩阵

> 章：DS-03 栈、队列和数组　｜　档位：掌握　｜　真题落点：6 题：2016 #4；2017 #3；2018 #3；2020 #1；2021 #3；2023 #3

## 考法 1：多维数组行优先/列优先的地址计算

**2021#3**
- **思路**：不要一上来就写公式，先在草稿上数“目标元素之前一共排了多少个元素”：行优先时是“整行数 × 每行元素个数 + 本行内偏移”，列优先时整行数那一项要换成“整列数 × 每列元素个数”。数完元素个数再乘每个元素占的单元数、加上首地址。关键一步：把题目里 $A[m][n]$ 的 $m$、$n$ 谁表示行数谁表示列数先标注清楚。
- **坑**：行优先却拿“总行数”当乘数（应该用每行的列数）；下标起点不统一，题干用 0 起、自己按 1 起算，边界差一整行；还有把“数组首地址”与“第一个元素所在位置”“第 0 行第 0 列元素的地址”重复相加，多算或少算一个元素。

## 考法 2：对称矩阵、三角矩阵的压缩映射

**常见考法（自拟变形）**：把 $n$ 阶对称矩阵按行优先只存下三角（含主对角线）到一维数组，问 $a_{ij}$ 在一维数组中的下标。
- **思路**：第一步先判断 $i$ 与 $j$ 的大小关系：落在被存储的那一半就直接数，落在另一半先用对称性换成转置位置的元素，再用同一个公式。数法是“前 $i-1$ 行的元素个数（一个等差数列求和）+ 本行内它是第几个”。三角矩阵还要额外确认那个“常数区”单元被放在一维数组的最前还是最后。
- **坑**：等差数列求和时把“前 $i-1$ 行”写成“前 $i$ 行”，或把 $i(i+1)/2$ 与 $i(i-1)/2$ 用反（本质是 $i$ 从 0 起还是 1 起没统一）；忘记“含主对角线”导致每行少算一个；对称矩阵里拿到上三角元素直接套下三角公式而不先转置成 $(j,i)$；三角矩阵漏掉常数单元，整体偏移错一位。

## 考法 3：三对角（带状）矩阵的映射

**常见考法（自拟变形）**：把满足 $|i-j|\le 1$ 的 $n$ 阶三对角矩阵按行优先压缩成一维数组，问元素下标或数组长度。
- **思路**：第一步先用 $|i-j|\le 1$ 判断目标元素是否落在带内（带外的元素值为 0，不做映射）。然后分段数元素：首行只有 2 个非零元，中间各行 3 个，末行 2 个，把目标行之前的部分按“首行 + 若干满行”拆开求和，再算行内偏移。行内偏移要盯住“本行第一个非零元素的列号”。
- **坑**：对每一行都按 3 个非零元计算，忘了首行、末行各只有 2 个，于是前面行数一多就整体偏移；把第 $i$ 行的第一个非零元素当成第 $i$ 列（实际是从第 $i-1$ 列起）；问压缩后一维数组长度时直接答 $3n$，没有扣除首末行少掉的那两个位置。

## 考法 4：稀疏矩阵的三元组表还缺什么信息

**2023#3**
- **思路**：把问题拆成两问来问自己——“三元组里已经写明了什么”和“光凭这些能不能唯一还原出原来的矩阵”。三元组里只有非零元的位置和值，所以逐条检验候选字段：对每个候选，问“它能否由已有信息推出”“缺了它会不会导致矩阵形状不确定”。同时把“矩阵本身的规模”和“三元组表本身有多长”当成两件事分开看。
- **坑**：只盯着“位置信息够不够”，忽略了矩阵的行数、列数只是位置的上界而不是位置的取值，从而把“形状信息”漏掉；反向的误判是只存（行、列、值）三元组却不记录矩阵的总行数与总列数，压缩后无法还原形状。

### 2016 #4 三对角矩阵压缩下标
有一个 100 阶的三对角矩阵 M ，其元素 m_{i,j} (1 ≤ i ≤ 100, 1 ≤ j ≤ 100) 按行优先依次压缩存入下标从 0 开始的一维数组 N 中。元素 m_{30,30} 在数组 N 中的下标是（ ）。 特殊矩阵

A. 86
B. 87
C. 88
D. 89

**思路**：按行优先数出目标元素之前存了多少个元素：第一行有 2 个，完整中间行每行 3 个，本行前面还剩若干对角元素；关键是分清下标从 0 开始与元素从 1 开始计数。

**坑**：看到三对角矩阵会直接套“每行 3 个”而漏掉第一行只有 2 个；也容易在“前有多少个元素”和“下标是多少”之间多减或少减 1。

### 2017 #3 稀疏矩阵压缩存储
适用于压缩存储稀疏矩阵的两种存储结构是（）

A. 三元组表和十字链表
B. 三元组表和邻接矩阵
C. 十字链表和二叉链表
D. 邻接矩阵和十字链表

**思路**：压缩稀疏矩阵要只存非零元及其行列位置，比较三元组表与十字链表这两种按非零元组织的方式。

**坑**：看到矩阵就联想邻接矩阵或二叉链表，误把普通二维数组或树结构当作稀疏矩阵压缩结构。

### 2018 #3 对称矩阵压缩下标
设有一个 12 × 12 的对称矩阵 M ，将其上三角部分的元素 m_{i,j} ( 1 ≤ i ≤ j ≤ 12 ) 按行优先存入 C 语言的一维数组 N 中，元素 m_{6,6} 在 N 中的下标是（ ）。

A. 50
B. 51
C. 55
D. 66

**思路**：按上三角逐行计数；关键一步是先算 m_{6,6} 前面完整的 5 行共有多少元素，再看它在本行是第几个，最后把“第几个”转成 C 数组从 0 开始的下标。

**坑**：看到 12×12 就按每行 12 个元素硬算，忽略上三角每行长度递减；或数出“第几个元素”后忘记数组下标从 0 开始而直接当作下标。

### 2020 #1 对称矩阵按列存储
将一个 10*10 对称矩阵 M 的上三角部分的元素 m_{i,j}（1 ≤ i ≤ j ≤ 10），按列优先存入 C 语言的一维数组 N 中，元素 m_{7,2} 在 N 中的下标是（ ）。

A. 15
B. 16
C. 22
D. 23

**思路**：先利用对称性把下三角元素转成上三角对应位置，再按列优先累加它前面各列及本列之前的元素个数，最后注意数组下标从 0 开始。

**坑**：容易直接按 m_{7,2} 所在的上三角位置套公式，或累加完元素个数后忘记下标从 0 起而整体错一位。

### 2021 #3 行优先数组地址
二维数组 A 按行优先存储，每个元素占 1 单元。A[0][0] 地址 100，A[3][3] 地址 220，则 A[5][5] 地址是（ ）

A. 295
B. 300
C. 301
D. 306

**要点**：先由两点差反解列数（每行多少元素），再推 A[5][5]。

### 2023 #3 稀疏矩阵三元组表
用三元组表存储稀疏矩阵 M，除三元组外还需保存（ ）
Ⅰ M 的行数　Ⅱ M 中含非零元素的行数　Ⅲ M 的列数　Ⅳ M 中含非零元素的列数

A. 仅Ⅰ和Ⅲ
B. 仅Ⅰ和Ⅳ
C. 仅Ⅱ和Ⅳ
D. 全部

**要点**：三元组表要能还原矩阵形状，只需总行数与总列数。
