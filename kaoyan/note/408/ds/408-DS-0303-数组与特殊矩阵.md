# 408-DS-0303 数组与特殊矩阵

> 章：DS-03 栈、队列和数组　｜　档位：掌握　｜　真题落点：5 题：2021 #2、#3；2022 #2；2023 #3；2024 #2

## 考法 1：多维数组行优先/列优先的地址计算

**2021#3**
- **思路**：不要一上来就写公式，先在草稿上数“目标元素之前一共排了多少个元素”：行优先时是“整行数 × 每行元素个数 + 本行内偏移”，列优先时整行数那一项要换成“整列数 × 每列元素个数”。数完元素个数再乘每个元素占的单元数、加上首地址。关键一步：把题目里 $A[m][n]$ 的 $m$、$n$ 谁表示行数谁表示列数先标注清楚。
- **坑**：行优先却拿“总行数”当乘数（应该用每行的列数）；下标起点不统一，题干用 0 起、自己按 1 起算，边界差一整行；还有把“数组首地址”与“第一个元素所在位置”“第 0 行第 0 列元素的地址”重复相加，多算或少算一个元素。

## 考法 2：对称矩阵、三角矩阵的压缩映射

**常见考法（自拟变形）**：把 $n$ 阶对称矩阵按行优先只存下三角（含主对角线）到一维数组，问 $a_{ij}$ 在一维数组中的下标。
- **思路**：第一步先判断 $i$ 与 $j$ 的大小关系：落在被存储的那一半就直接数，落在另一半先用对称性换成转置位置的元素，再用同一个公式。数法是“前 $i-1$ 行的元素个数（一个等差数列求和）+ 本行内它是第几个”。三角矩阵还要额外确认那个“常数区”单元被放在一维数组的最前还是最后。
- **坑**：等差数列求和时把“前 $i-1$ 行”写成“前 $i$ 行”，或把 $i(i+1)/2$ 与 $i(i-1)/2$ 用反（本质是 $i$ 从 0 起还是 1 起没统一）；忘记“含主对角线”导致每行少算一个；对称矩阵里拿到上三角元素直接套下三角公式而不先转置成 $(j,i)$；三角矩阵漏掉常数单元，整体偏移错一位。

## 考法 3：三对角（带状）矩阵的映射

**常见考法（自拟变形）**：把满足 $|i-j|\le 1$ 的 $n$ 阶三对角矩阵按行优先压缩成一维数组，问元素下标或数组长度。
- **思路**：第一步先用 $|i-j|\le 1$ 判断目标元素是否落在带内（带外的元素值为 0，不做映射）。然后分段数元素：首行只有 2 个非零元，中间各行 3 个，末行 2 个，把目标行之前的部分按“首行 + 若干满行”拆开求和，再算行内偏移。行内偏移要盯住“本行第一个非零元素的列号”。
- **坑**：对每一行都按 3 个非零元计算，忘了首行、末行各只有 2 个，于是前面行数一多就整体偏移；把第 $i$ 行的第一个非零元素当成第 $i$ 列（实际是从第 $i-1$ 列起）；问压缩后一维数组长度时直接答 $3n$，没有扣除首末行少掉的那两个位置。

## 考法 4：稀疏矩阵的三元组表还缺什么信息

**2023#3**
- **思路**：把问题拆成两问来问自己——“三元组里已经写明了什么”和“光凭这些能不能唯一还原出原来的矩阵”。三元组里只有非零元的位置和值，所以逐条检验候选字段：对每个候选，问“它能否由已有信息推出”“缺了它会不会导致矩阵形状不确定”。同时把“矩阵本身的规模”和“三元组表本身有多长”当成两件事分开看。
