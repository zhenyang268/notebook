# 408-DS-0704 选择排序与堆

> 章：DS-07 排序　｜　档位：掌握　｜　真题落点：4 题：2018 #11；2020 #9；2021 #11；2024 #9

## 考法 1：简单选择的趟数、比较次数与“已到位元素集合”

**思路**：第一步记住每趟成果：从无序区选出最小值，与本趟无序区首元素**交换**。比较次数与初始序列无关，恒为 $n(n-1)/2$；移动次数可能为 0（本来就在位）。判断“做了几趟”，看前端有几个元素构成“全局最小的前 $k$ 个且有序”。

**坑**：把简单选择和冒泡混为一谈。冒泡做**相邻**交换、每趟把最值送到末端；选择做**距离较远**的交换、每趟把最小值送到前端。正因为距离较远地交换，简单选择**不稳定**；看到“每趟只交换一次”就判它稳定是典型误判。

## 考法 2：建堆，自底向上筛选是 $O(n)$，与逐个插入建堆不是一回事

**思路**：第一步定位最后一个非叶结点 $\lfloor n/2 \rfloor$，从它开始**自底向上、由右向左**逐结点下沉（筛选）；每做完一棵子树它就是合法堆。复杂度用“结点高度求和”估：多数结点在底层、下沉距离小，总和 $O(n)$。

**坑**：把建堆当成“$n$ 次插入、每次 $O(\log n)$”得 $O(n\log n)$；两者不仅复杂度不同，得到的堆也可能不同。另一处是下沉方向搞反：大根堆要求父 $\ge$ 子，下沉时拿待调整结点只与一个孩子比较（应先选出较大的那个孩子再比），或者交换一次就停手，忘了继续向下检查被破坏的子树。

### 2018 #11 建大根堆过程
在将数据序列 (6, 1, 5, 9, 8, 4, 7) 建成大根堆时，正确的序列变化过程是（）。

A. 6,1,7,9,8,4,5 → 6,9,7,1,8,4,5 → 9,6,7,1,8,4,5 → 9,8,7,1,6,4,5
B. 6,9,5,1,8,4,7 → 6,9,7,1,8,4,5 → 9,6,7,1,8,4,5 → 9,8,7,1,6,4,5
C. 6,9,5,1,8,4,7 → 9,6,5,1,8,4,7 → 9,6,7,1,8,4,5 → 9,8,7,1,6,4,5
D. 6,1,7,9,8,4,5 → 7,1,6,9,8,4,5 → 7,9,6,1,8,4,5 → 9,7,6,1,8,4,5 → 9,8,6,1,7,4,5

**思路**：从最后一个非叶结点开始向前逐个调整，每次与较大的子结点比较，若逆序则交换，并沿被破坏的子树继续向下调整。

**坑**：容易从根开始调整或只交换一次就停止，忽略交换后子树需继续下沉，导致初始几步误判。

### 2020 #9 大根堆性质判断
下列关于大根堆（至少含 2 个元素）的叙述中正确的是（ ）。 I. 可以将堆看成一颗完全二叉树；II. 可采用顺序存储方式保存堆； III. 可以将堆看成一棵二叉排序树；IV. 堆中的次大值一定在根的下一层。

A. 仅 I，II
B. 仅 II，III
C. 仅 I，II，IV
D. 仅 I，III，IV

**思路**：抓住堆的结构性质与存储性质：堆是完整树形、适合数组存储，但只保证父结点与孩子之间的大小关系，不保证整棵树的中序有序；再分析次大值在根与根的直接孩子中的位置关系。

**坑**：把堆的“父大于子”误认为二叉排序树的全局有序；又因根的两个孩子大小不定，误判次大值可能落在更深的层次。

### 2021 #11 大根堆插入结果
关键字 6,9,1,5,8,4,7 依次插入空大根堆，得到的堆是（ ）

A. 9,8,7,6,5,4,1
B. 9,8,7,5,6,1,4
C. 9,8,7,5,6,4,1
D. 9,6,7,5,8,4,1

**要点**：边插边上浮，每次与父结点比较，比父大就交换。

### 2024 #9 大根堆删两次
28,22,20,19,8,12,15,5 是大根堆，删除两次后的新堆是

A. 20,19,15,12,8,5
B. 20,19,15,5,8,12
C. 20,19,12,15,8,5
D. 20,19,8,12,15,5

**思路**：每次删除 = **末尾元素移到堆顶 + 向下调整**。调整时与"较大的那个孩子"交换。删 28 后得 `22,19,20,5,8,12,15`；再删 22 得 `20,19,15,5,8,12`。

**坑**：下沉时与较小孩子交换（大根堆要和大的换）。另外选项 A 元素集合相同只是顺序不同，说明出题人在考"下沉后的具体形状"。
