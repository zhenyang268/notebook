# 408-DS-0506 拓扑排序

> 章：DS-05 图　｜　档位：掌握　｜　真题落点：4 题：2016 #7；2018 #7；2020 #6；2021 #7

## 考法 1：入度法逐轮摘点，判断给定序列是否为合法拓扑序列

**题目**：常见考法（给出 AOV 网和若干候选序列，问哪一个合法）

**思路**：不必真跑算法，先把边集整理成“$u\to v$”的清单，再按候选序列给每个顶点标上位置序号，逐条边检查是否满足“弧尾位置 < 弧头位置”，一条不满足就否掉。关键一步：把跨越多位的边（不直接相邻的两个顶点）也逐条核对，不要只看相邻项。

**坑**：只检查序列中相邻两个顶点之间有没有边，遇到 $a\to d$ 却在序列中 $d$ 排在 $a$ 前面这种跨位违规就漏判，把非法序列当成合法。

## 考法 2：拓扑序列的个数

**题目**：2021#7（有向图拓扑有序序列的个数）

**思路**：用“逐个摘除入度为 0 顶点”的枚举树：每步把当前所有入度为 0 的顶点都列为候选，分别摘掉一个、更新出边终点的入度，再递归下去，最后把各分支得到的序列数相加。关键一步：候选集合必须靠“删点后重新计算入度”得出，不能凭图上直观只挑一个；候选只有一个时不必分支，直接往下走。

**坑**：把“拓扑序列不唯一”理解成“若干个零入度顶点可以任意交换”，于是只算排列数。实际上摘掉一个候选后，新顶点会补进候选集，候选的“可交换”关系是动态的，静态算排列会算多或算少。

## 考法 3：用拓扑排序判环，以及输出序列长度与顶点数的关系

**题目**：常见考法（问某有向图是否存在回路 / 拓扑排序输出顶点数说明了什么）

**思路**：入度法结束时若输出的顶点数小于 $n$，说明剩下的顶点入度都 ≥1，它们之间必有环；DFS 判环则看有没有指向“当前递归栈中顶点”的回边。关键一步：把“输出序列长度”和“顶点总数 $n$”作对比，这是判环的唯一依据。

**坑**：把“存在入度为 0 的顶点”当成无环的充分条件——有环的图完全可能还有别的入度为 0 的顶点（环之外的孤立部分），于是误判成无环。

## 考法 4：存储结构与复杂度、拓扑序与逆拓扑序的关系

**题目**：常见考法（问拓扑排序在邻接表 / 邻接矩阵下的时间复杂度；问逆拓扑序怎么来）

**思路**：入度法要反复取入度为 0 的顶点，用栈或队列暂存候选，每个顶点、每条边各处理一次，邻接表下是 $O(n+e)$；换成邻接矩阵，找邻点要扫一整行，退化为 $O(n^2)$。关键一步：先确认存储结构再写复杂度。逆拓扑序把拓扑序整体反转即可，在 AOE 网里它正好是求 $vl$ 的顺序。

**坑**：不管存储结构一律写 $O(n+e)$；另一个是把“拓扑序列一般不唯一”记成“一定不唯一”，在顶点构成一条链时仍去找第二种排法。

### 2016 #7 拓扑排序时间复杂度
若将 n 个顶点 e 条弧的有向图采用邻接表存储，则拓扑排序算法的时间复杂度是（） 复杂度分析 邻接表

A. O  (  n  )
B. O ( n + e )
C. O  (  n  2  )
D. O ( n ∗ e )

**思路**：拓扑排序要对每个顶点处理入度，并沿邻接表删除每条弧，总工作量由顶点扫描量和弧扫描量相加决定。

**坑**：看到“邻接表”会误按邻接矩阵的代价想成平方级；也可能把每个顶点又扫全部边，误判成顶点数与边数相乘级。

### 2018 #7 拓扑序列判定
下列选项中，不是如下有向图的拓扑序列的是（ ） 1 5 3 6 4 2〔原卷附图，纯文本从略〕

A. 1, 5, 2, 3, 6, 4
B. 5, 1, 2, 6, 3, 4
C. 5, 1, 2, 3, 6, 4
D. 5, 2, 1, 6, 3, 4

**思路**：拓扑排序每次选入度为 0 的结点输出并删除其出边；关键一步是动态检查删除前驱后各后继结点的入度是否依次变为 0。

**坑**：看到首元素属于初始入度为零的结点就放过，误把“开头合法”当成整个序列合法；还要检查中途是否提前输出了仍有前驱未删除的结点。

### 2020 #6 修改DFS输出序列
修改递归方式实现的图的深度优先搜索（DFS）算法，将输出（访问）定点信息的语句移到退出递归前（即执行输出语句后立刻退出递归）。采用修改后的算法遍历有向无环图 G，若输出结果中包含 G 中的全部顶点，则输出的顶点序列是 G 的（ ）。

A. 拓扑有序序列
B. 逆拓扑有序序列
C. 广度优先搜索序列
D. 深度优先搜索序列

**思路**：输出语句移到递归退出前，表示当前顶点要在它的所有后继顶点都处理完以后才输出；结合有向无环图中前驱、后继的先后关系判断序列性质。

**坑**：看到 DFS 就误认为是普通的深度优先遍历序列，或把“先访问先输出”的正向次序与“回溯时输出”的次序混为一谈。
