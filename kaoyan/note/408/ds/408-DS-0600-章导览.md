# 408-DS-0600 章导览

> 章：DS-06 查找　｜　档位：掌握　｜　真题落点：本考点 2016–2024 无对应题目

**在考什么**：考的是辨认每种结构用哪条不变量限制树高，并判断不同平衡策略的松紧与同一规模下查找长度的差异。

## 考法 1：拿"不变量"做结构辨析，问某种树凭什么把高度压住

**思路**：第一步先把题目给的结构归到两类约束里——**序约束**（只规定谁在谁左边）还是**形约束**（规定子树高度、结点数、叶层）。BST 只有序约束，压不住高度；AVL 加"左右子树高度差 $\le 1$"；红黑树换成"黑高相等 + 无连续红 + 根黑"；B 树、B+ 树换成"所有叶结点在同一层 + 每个结点关键字数有上下界"。归完类再回答"靠哪条不变量推出 $O(\log n)$"。

**坑**：看到"查找树"三个字就默认高度是 $O(\log n)$——BST 的序约束只管相对位置、不管形状，退化成单支链时高度是 $O(n)$；把 BST 的结论和 AVL 的结论混着用，是最常见的一步错。

## 考法 2：几种"平衡"的松紧对比，考的是概念而不是数值

**思路**：第一步不背高度公式，而是问"它用几个局部条件换来了什么全局上界"。AVL 的要求最严（每个结点都卡高度差），所以查找路径最短但插入删除时调整最频繁；红黑树的约束松（只卡黑高和红结点位置），最长路径不超过最短路径的 2 倍，代价是路径略长、但旋转次数少。答题时把"查找效率"和"维护代价"分开说。

**坑**：以为"红黑树更平衡所以更好"——方向正好反了：红黑树的平衡更**松**，它的优势在更新时的调整代价，不在查找路径更短。看到"红黑树查找比 AVL 快"这类表述要先怀疑。

## 考法 3：同一 n 下 ASL 不是定值

**思路**：第一步确认"这棵树的形态唯不唯一"。n 个结点的完全二叉树形态唯一，所以其 ASL 是定值；而 n 个结点的 AVL 树、BST、甚至 B 树，形态都可以有多种，ASL 只能给范围或量级。凡是题目问"n 个结点的 AVL 树 ASL 是多少"，先反问形态是否唯一。

**坑**：直接把 $\lceil \log_2(n+1)\rceil$ 当成 AVL 的 ASL 抄上去——那是完全二叉树的高度公式，AVL 不保证最后一层填满，同 n 的两棵 AVL 平均深度可以差一层。
