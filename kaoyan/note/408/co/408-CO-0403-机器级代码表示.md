# 408-CO-0403 机器级代码表示

> 章：CO-04 指令系统　｜　档位：掌握　｜　真题落点：5 题：2022 #18、#19、#20；2023 #17；2024 #13

## 考法 1：从源程序到可执行文件，以及“CPU 能直接执行的形式”（2022#20、2024#13）

**思路**：第一步把四个阶段串成链并锁定每步的输入输出：预处理（.c → .i，展开宏与头文件）→ 编译（.i → .s，生成汇编）→ 汇编（.s → .o，汇编器把汇编翻成机器指令、形成可重定位目标文件）→ 链接（多个 .o 与库 → 可执行文件，做符号解析与重定位）。第二步判断“谁能被 CPU 直接执行”：只有装载进内存的机器指令序列；汇编语言、高级语言、.o 文件都不是。

**坑**：把“汇编”阶段的方向弄反，误以为是“把机器码翻译成汇编程序”；或者把可重定位目标文件当成可直接运行的成品，忽略它还没有完成地址重定位和外部符号的解析。

## 考法 2：if / 循环 / 过程调用的翻译、栈帧与返回地址

**思路**：第一步把高级语句拆成“比较 + 条件转移”的组合，if 的关键是标志位由比较指令设置、条件转移指令读取它；第二步处理循环时在汇编里找出四段——初始化、条件判断（在循环体前）、循环体、循环变量更新与跳回；第三步处理过程调用时盯住两条指令：`call` 把返回地址（调用指令的下一条）压栈并跳转，`ret` 从栈顶弹出该地址并跳回；再看栈帧里依次是参数区、返回地址、保存的旧帧指针、局部变量。

**坑**：想当然地认为“函数调用的实参一定通过栈传递”，忽略现代调用约定里前若干实参走寄存器；或者把返回地址混成“被调用者要保存的局部数据”，答错栈帧布局；还有在判断“条件转移指令跳转目标地址怎么算”时，用绝对地址相加而忘记它是相对寻址、以 PC（已指向下条指令）为基准加带符号偏移。

## 考法 3：缓冲区溢出的原理

**思路**：第一步画出栈帧从高地址到低地址的排布顺序（返回地址处在局部数组的高地址一侧，数组向低地址方向分配空间）；第二步判断读入函数不做越界检查时，超长输入在内存里向高地址覆盖，会依次冲掉填充、保存的寄存器、旧帧指针，最后是返回地址；第三步说明执行 `ret` 时被改写的返回地址被弹入 PC，控制流因此跳到攻击者指定位置。

**坑**：把栈的增长方向与数组写入方向弄反，误以为超长输入先覆盖返回地址；或者以为溢出的危害只是把局部变量改坏，没意识到真正的关键是 `ret` 会取用被篡改的返回地址。
