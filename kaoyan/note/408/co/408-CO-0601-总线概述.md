# 408-CO-0601 总线概述

> 章：CO-06 总线　｜　档位：理解　｜　真题落点：3 题：2021 #19；2023 #20；2024 #20

## 考法 1：概念辨析型选错题——给一串说法，挑出与总线特性不符的那条

**思路**：第一步把每个选项拆成“可判定的最小陈述”，一条只留一个判断点：是不是共享、是不是分时、带宽的单位是位还是字节、这条线属于片内总线、系统总线还是通信总线中的哪一层。第二步对每条陈述核对三件事——层次归属（芯片内部、插件板之间、设备之间远距离）、共享性（多部件挂同一组线）、分时性（同一时刻只能有一个主设备驱动）。2021#19 这类“关于总线，错误的是”的题，错项几乎都在这三处中某一处被偷换，先定位再判断。

**坑**：看到“总线是各部件之间的传输介质”就觉得对，不去追问共享与独占；看到“带宽”默认单位是 B/s，而选项里写的是 b/s，或 MB/s 与 Mb/s 混用；把“片内总线”当系统总线的一部分、把“通信总线”当系统总线的延伸——层次一错整条陈述就废，但句子读起来完全通顺。

## 考法 2：已知总线宽度与时钟频率，直接算带宽（2023#20 这一类）

**思路**：第一步是先对齐题给的三个量，不必急着套公式：①总线宽度多少位，立刻除以 8 换成字节，不要留在“位”上；②时钟频率多少，一个时钟周期传几次（每周期一次，还是上、下沿各一次）；③这条总线是否“地址/数据复用”，复用则一个周期只能干一件事。对齐后再写 $B=\dfrac{W}{8}\times f\times n$，其中 $n$ 是每周期传送次数。2023#20 给的是 64 位宽、1GHz，关键就在先把宽度折成字节、再确认每周期传几次，这两步都对才敢相乘。

**坑**：最容易在单位出错——算出 $64\times10^9$ bit/s 就直接写成 64GB/s，忘了除 8；或把 GHz 当 MHz，差三个数量级。第二个坑是把“总线宽度”和“总线带宽”当同一个东西，看到“宽 64 位”就拿 64 当带宽。第三个坑是题里一出现“地址”就自动扣掉一半带宽，而题目根本没说复用。

## 考法 3：总线仲裁——集中式与非集中式，判“谁先拿到总线”

**思路**：第一步判断是集中式（仲裁器统一裁决）还是分布式（各设备自带仲裁逻辑、按优先级竞争）。若是集中式，继续看“请求→授权”的传递路径分三小类：链式查询是请求线串到底、授权逐级下传；计数器定时查询是仲裁器发计数值、各设备比对自身编号；独立请求是每设备一对请求/授权线。判优先级时抓住“授权信号从谁开始、往哪走、走几级”。

**坑**：看到“优先级固定”就一律归成链式查询——计数器查询从 0 开始数也是固定优先级，独立请求同样可以固定优先级，“优先级可否改变”区分不了三类。另一个坑是“对电路故障最敏感”误判为独立请求（线多不等于敏感），授权链一断后面全瘫的是链式查询。

## 考法 4：地址线、数据线分配与“地址/数据复用”的额外开销

**思路**：第一步看线数分配：地址线 $k$ 根决定可寻址范围 $2^k$，但要先确认是按字节编址还是按字编址，再决定乘不乘字长。若题中说地址/数据复用，则同一组线要分时传两遍，做时序核算时先给地址留出一个或几个周期，剩下的周期才算数据。

**坑**：把地址线根数直接当寻址范围而不分辨“$2^k$ 字节”与“$2^k$ 个字”；或者复用题里忘了地址周期也占时间，带宽算得偏高，而数值看上去很“整”，很容易让人放过。
