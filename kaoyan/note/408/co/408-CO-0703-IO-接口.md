# 408-CO-0703 I/O 接口

> 章：CO-07 输入/输出系统　｜　档位：掌握　｜　真题落点：1 题：2021 #20

**在考什么**：某部件是否真处在主机与外设之间是分水岭，凭名字里带 I/O 或接口字样就认定，会把中断控制器这类主机侧部件误判成 I/O 接口。

## 考法 1：判断某部件是否属于 I/O 接口

**题目**：2021#20 不属于 I/O 接口的是

**思路**：第一步先立标准——I/O 接口是“主机与外部设备之间”的硬件界面部件，必须一端挂系统总线、一端接外设，内部含数据/状态/控制寄存器与地址译码。第二步拿这个标准逐个筛：一端直接挂在 CPU 内部、属于主机侧功能单元的，或本身就是外设/软件的，都不满足“界面”这个身份。

**坑**：只凭名字里有“I/O”“接口”就认定是 I/O 接口，而不检查它是否真的处在主机与外设之间；也容易把总线控制器、中断控制器这类主机侧部件当成 I/O 接口。

## 考法 2：三类寄存器的方向与访问权限

**题目（常见考法）**：给定数据寄存器、状态寄存器、控制寄存器，问 CPU 读/写方向、以及哪个寄存器由外设写入。

**思路**：第一步按“谁产生信息”定方向：状态寄存器由接口/外设写入、CPU 读出（对 CPU 只读）；控制寄存器由 CPU 写入、接口接收（对 CPU 只写）；数据寄存器双向往返，读/写都可能。第二步联系具体动作：CPU 启动设备写控制寄存器，查询时读状态寄存器，传送时读写数据寄存器。

**坑**：把状态寄存器说成“CPU 可读可写”；把控制寄存器和状态寄存器合并成一个“命令/状态寄存器”后方向判反；忽略数据寄存器在中断方式下是双向的。

## 考法 3：接口功能与内部结构的对应

**题目（常见考法）**：问地址译码、数据缓冲、串并转换、电平匹配、中断请求产生分别由接口的哪部分完成，或问接口为什么需要数据缓冲。

**思路**：第一步把功能归类为“寻址”“速度匹配”“格式转换”“状态与中断”四类；第二步落到具体部件：地址译码器管选址，数据缓冲寄存器管速度匹配，移位/格式逻辑管串并转换，状态寄存器加中断逻辑管联络。速度匹配的根本原因是外设与主机在工作速度上差几个数量级。

**坑**：把“数据缓冲”的目的说成“扩大容量”而不是“补偿速度差异”；把中断请求的产生归到 CPU 侧而不是接口侧。
