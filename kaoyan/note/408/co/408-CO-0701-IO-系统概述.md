# 408-CO-0701 I/O 系统概述

> 章：CO-07 输入/输出系统　｜　档位：掌握　｜　真题落点：1 题：2017 #21

**在考什么**：能否凭“用访存指令访问端口”判成统一编址而非独立编址，是本题的关键。看到访存指令就误判为独立编址，最常见。

## 考法 1：给定一种编址方式，问指令形式、地址空间大小以及外设寻址边界

**题目（常见考法）**：某机器把 I/O 端口和主存单元放在同一个地址空间内统一分配地址，问访存指令能否直接访问端口、地址译码器需要区分什么。

**思路**：第一步抓住“端口与主存是否共享同一个地址空间”这个判据：共享就是统一编址（存储器映射），不共享就是独立编址。统一编址下，端口地址只是普通地址总线上的一个地址，普通 `LOAD/STORE` 就能访问；独立编址必须有专门的 I/O 指令，并由专门的 I/O 地址线（或 `M/IO̅` 之类控制信号）参与区分。第二步再推后果：主存可用空间是否被切走、指令种类是否增加、译码电路是否需要多一路。

**坑**：看到“可以用访存指令访问端口”就误判成独立编址——恰恰相反，能共用访存指令是统一编址的特征；反过来，看到机器指令表里有 `IN/OUT` 才能判定为独立编址。

**题目（常见考法）**：比较两种编址方式各自的代价与收益，问哪一种使主存可用地址空间变小、哪一种外设寻址指令更丰富。

**思路**：第一步把两种方式按“代价”和“收益”两栏列出：统一编址牺牲主存地址空间，换来丰富寻址方式、无需专用 I/O 指令；独立编址保住完整主存空间，换来一套额外的 I/O 指令与控制信号。第二步看题干问的是“空间”还是“灵活性”，不要答反方向。

**坑**：把“独立编址主存空间完整”顺口说成“独立编址更好”，忽略它寻址方式受限、必须配专用指令这一面；也容易把“统一编址访问外设一定更快”当结论——省掉的只是指令开销，不等于访问本身更快。

## 考法 2：I/O 系统层次划分与功能归属

**题目（常见考法）**：给出“用户程序—I/O 管理软件/设备驱动—I/O 接口—外设”的层次，问地址译码、数据缓冲、格式转换、设备时序控制分别落在哪一层。

**思路**：第一步按离设备的远近排层：应用程序→OS 与驱动程序→I/O 接口（硬件）→外设。第二步把功能往层里塞：与具体设备电气时序、寄存器读写、状态锁存、串并转换有关的属于接口硬件；与设备无关的策略、调度、缓冲区管理属于软件层。

**坑**：把“设备驱动程序”当成接口硬件的一部分；把“数据缓冲”笼统答成 OS 缓冲区，而题干明确问“接口内部的寄存器”时又错位。

## 考法 3：I/O 端口地址与端口数量、地址线位数的换算

**题目（常见考法）**：给出 I/O 地址线根数或端口地址范围，问可寻址的端口个数，或问按字节编址与按字编址时端口数的差别。

**思路**：第一步确认地址单位：一个端口通常对应一个字节（或一个字），地址线 $n$ 根对应 $2^n$ 个端口地址，再按编址单位折算成端口数。第二步注意“端口地址”与“主存地址”是否共用同一组地址线，共用时先扣掉被主存占用的区间。

**坑**：把“地址线根数”直接当成“端口个数”，漏掉 $2^n$ 这一步；或在统一编址下忘了端口地址是从主存空间里划出来的，重复计算地址范围。

### 2017 #21 I/O指令传送位置
I/O 指令实现的数据传送通常发生在（ ）。

A. I/O 设备和 I/O 端口之间
B. 通用寄存器和 I/O 设备之间
C. I/O 端口和 I/O 端口之间
D. 通用寄存器和 I/O 端口之间

**思路**：I/O 指令由 CPU 执行，数据一端在通用寄存器，另一端经 I/O 端口与设备交互；端口是主机与设备的交接面。

**坑**：把 I/O 端口等同于 I/O 设备，误以为指令直接在通用寄存器与设备之间传送数据。
