# 408-CO-0303 主存与 CPU 连接

> 章：CO-03 存储系统　｜　档位：掌握　｜　真题落点：9 题：2021 #15、#16；2022 #15、#16、#17；2023 #15；2024 #16、#17、#18

## 考法 1：位扩展 / 字扩展的判断与芯片片数

**思路**：第一步分别比两个方向——芯片每字位数与系统字长比（不等就要位扩展），芯片字数与所需单元数比（不够就要字扩展）。片数写成「字数比 × 位数比」最稳：$\dfrac{\text{总单元数}}{\text{单片单元数}}\times\dfrac{\text{系统字长}}{\text{单片位宽}}$。位扩展时各片地址线全并联、数据线分段接；字扩展时数据线并联、靠片选区分。

**坑**：把 $8\text{K}\times4$ 位芯片当成 $8\text{KB}$ 去除总容量，位宽那一维被吞掉；位扩展时误以为需要译码器——位扩展的各片地址完全一样，地址线直接并接，压根不需要片选。

## 考法 2：地址线分配与片选译码

**思路**：第一步把系统地址总线切成「片内地址 / 片间地址」两段：片内地址位数 $=\log_2(\text{每片字数})$，剩下高位作片选。再用「需要几个片选信号」决定用线选还是译码器：片数多时用译码器（$n$ 根高位地址可产生 $2^{n}$ 个片选）更省信号且不产生地址重叠。

**坑**：片内地址位数拿「主存总容量」而不是「单片容量」去取对数，导致地址线全被吃掉；以及多片时把高位地址直接一根线接一个片选，地址空间出现重叠区，同一单元被多个片同时选中。

## 考法 3：地址范围与「占满全空间」的推算

**思路**：第一步由地址线数定出整个空间的字节数 $2^{n}$，末地址为全 1；再按每片（每组）容量切成若干段。给一段起始地址推下一段起点，用「起始地址 + 容量」；十六进制与容量对齐时，$2^{10}=0\text{x}400$、$2^{20}=0\text{x}100000$ 这类边界先记住更好算。判断某芯片的地址范围时，先写片内地址位数，再看片选译码对应的取值。

**坑**：十六进制末地址算错一位——把 $2^{20}$ 字节的末地址当成 $0\text{x}FFFFF$ 之外的数，或把「起始 + 容量」直接当成末地址（末地址是起始 + 容量 − 1）；还有按字编址与按字节编址混用，地址范围整体差一个倍数。
