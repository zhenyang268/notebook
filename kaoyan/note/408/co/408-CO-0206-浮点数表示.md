# 408-CO-0206 浮点数表示

> 章：CO-02 数据的表示和运算　｜　档位：掌握　｜　真题落点：5 题：2018 #14；2021 #14；2022 #14；2023 #14；2024 #14

## 考法 1：位段划分与偏移量

**思路**：先默写三段结构“符号 1 位 + 阶码 $k$ 位 + 尾数 $m$ 位”，单精度 $1/8/23$、双精度 $1/11/52$；阶码用移码（偏置常数 $2^{k-1}-1$，即单精度 127、双精度 1023），尾数存的是隐藏位之后的纯小数部分。关键一步：把所有“给定位串求值”的题先按此三段切开，再谈其他。

**坑**：把阶码偏置当成 $2^{k-1}$（128）而不是 $2^{k-1}-1$（127）；把隐含的整数位 1 算进尾数 23 位里，导致尾数有效位少算一位。

## 考法 2：由十进制真值写出机器数

**思路**：第一步先把十进制小数按“乘 2 取整”展开成二进制小数，再规格化成 $1.M\times 2^{E}$ 的形式；阶码字段写 $E+127$，尾数字段只留 $M$ 并补 0 到 23 位，符号位单独看正负。关键一步：规格化时小数点左移还是右移，决定了 $E$ 的正负，这一步错了后面全错。

**坑**：把 $0.4375$ 这类“看起来是四位小数”的数直接按十进制位写进尾数；或者把负数的符号位与阶码最高位混在一起，忘了符号位单独占最高 1 位。

## 考法 3：由机器数读真值（含非规格化与特殊值）

**思路**：展开成二进制后先看阶码字段是不是全 0 或全 1，再决定走哪条解释路径：全 0 → 非规格化数（阶码真值取 $1-127$，尾数前补 0、无隐藏位）；全 1 → 尾数全 0 为无穷、尾数非 0 为 NaN；其余 → 规格化数（补隐藏位 1，阶码减 127）。关键一步：先判阶码，再动尾数。

**坑**：看到尾数非 0 就直接按“$1.M$”补隐藏位 1，把非规格化数当规格化数算，结果整整差 $2^{-126}$ 倍；看到阶码全 1、尾数非 0 仍去算一个“很大的数”，而不是判成 NaN。

## 考法 4：能否精确表示与表示范围边界

**思路**：判“能否精确表示”看两条：该十进制小数转二进制后是否为有限小数（分母只含因子 2），以及规格化后有效位数是否不超过 24 位（单精度）；判范围则要找四个端点——最大正数 $(2-2^{-23})\times 2^{127}$、最小规格化正数 $2^{-126}$、最小非规格化正数 $2^{-149}$、以及负侧的对称。关键一步：把“精度不够”与“阶码越界”分开讨论，前者是表示不精确，后者是根本表示不了。

**坑**：只用“十进制位数多不多”判断能否精确表示，忽略 $0.5$、$0.25$ 这类短小数固然精确，但某些位数更长的十进制小数（如 0.125 的倍数）同样精确；求“最小正数”时取成最小规格化数，漏掉非规格化数能到 $2^{-149}$。

### 2018 #14 最小规格化正数
IEEE 754 单精度浮点格式表示的数中，最小的规格化正数是 (  )

A. 1.0 × 2^(−126)
B. 1.0 × 2^(−127)
C. 1.0 × 2^(−128)
D. 1.0 × 2^(−149)

**思路**：单精度阶码 8 位、偏置 127，规格化数阶码字段最小取 1，尾数取全 0，阶码真值为 1−127。

**坑**：把阶码字段可取 0 的非规格化情况混入，或把最小正数误算成尾数最低位对应的极小值。

### 2021 #14 浮点精确表示限制
不能用 IEEE754 精确表示的是（ ）

A. 1.2
B. 1.25
C. 2.0
D. 2.5

**要点**：判断小数能否写成 1.M×2^E，1.2 的二进制是无限循环。

### 2022 #14 单精度浮点数编码
−0.4375 的 IEEE754 单精度表示是（ ）

A. BEE0 0000H
B. BF60 0000H
C. BF70 0000H
D. C0E0 0000H

**要点**：先转二进制（0.375=3/8，0.4375=7/16），规格化成 1.M×2^E，再填符号/阶码偏移 127/尾数。

### 2023 #14 单精度浮点数值
IEEE754 单精度，x 机器数 8020 0000H，则 x 的值（ ）

A. −2⁻¹²⁸
B. −1.01×2⁻¹²⁷
C. −1.01×2⁻¹²⁶
D. 非数（NaN）

**要点**：8020 0000H 阶码字段全 0 ⇒ **非规格化数**，阶码按 1−127 算，且不含隐含 1。

### 2024 #14 数据表示方法的选择
α 范围 $\pm2^{20}$，β 范围 $\pm2^{40}$，为保精度又想快，最适宜的是

A. 32 位整数、32 位整数
B. 单精度、单精度
C. 32 位整数、双精度
D. 单精度、双精度

**思路**：先看"整型参数"这个前提——**整型用定点整数表示是精确的，浮点只能近似**。再比位宽：$\pm2^{20}$ 需 21 位有效位（加符号 22 位）→ 32 位整数够；$\pm2^{40}$ 需 41 位 → 32 位整数不够，只能上双精度浮点（53 位尾数）。

**坑**：看到"提高运算速度"就选浮点。浮点快但**不精确**，题干说"保证表数精度"，整数在范围内是零误差。
