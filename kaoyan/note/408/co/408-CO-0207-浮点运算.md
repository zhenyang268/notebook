# 408-CO-0207 浮点运算

> 章：CO-02 数据的表示和运算　｜　档位：掌握　｜　真题落点：本考点 2016–2024 无对应题目

**在考什么**：这个考点真正拉开差距的是对阶方向和对阶时移出位的保留，一旦让大阶向小阶看齐或把右移出的位直接扔掉，舍入就无位可用、末位必错；另一个高频错是看到尾数进位就判溢出，其实那只是尾数溢出、一次右规即可恢复。

## 考法 1：加减运算的五步流程与对阶

**思路**：按“对阶 → 尾数加减 → 规格化 → 舍入 → 溢出判断”的顺序走，对阶的规则是**小阶向大阶看齐**：小阶尾数右移、阶码加到与大阶相等，右移出去的位要保留（作为保护位参与后面舍入）。关键一步：先算阶差 $\Delta E$，若 $\Delta E$ 大于尾数位数，小操作数已被“淹没”，直接令其为 0，不必再列竖式。

**坑**：反过来让大阶向小阶看齐（尾数左移），一移就把高位有效数字移丢；对阶右移时把移出的位直接扔掉，等舍入时无位可用，结果末位错。

## 考法 2：规格化（左规/右规）与溢出判断

**思路**：用双符号位判形态：形如 $00.1\times\cdots$ 或 $11.0\times\cdots$ 才是规格化。尾数绝对值太小（$00.0\cdots$ 或 $11.1\cdots$）就**左规**：尾数每左移一位、阶码减 1；尾数加减后出现 $01.x$ 或 $10.x$ 就**右规**：尾数右移一位、阶码加 1，右规最多一次。关键一步：把“尾数溢出”和“真溢出”分开——尾数溢出靠右规就能救回，只有阶码超出上限才是上溢（必须报溢出），阶码低于下限按下溢处理成机器零。

**坑**：看到尾数最高位进位就判“结果溢出”，其实那只是尾数溢出，一次右规即可恢复；另外左规时把阶码也加 1（方向搞反），越规越离谱。

## 考法 3：四种舍入方式的取舍

**思路**：先认清四种模式——就近舍入到偶数（IEEE 754 默认，“恰为一半”时向末位为偶的方向靠）、朝零舍入（截断）、朝 $+\infty$、朝 $-\infty$。关键一步：判断是否发生“恰好一半”的情形，只有这一情形才需要区分“就近舍入到偶数”和“四舍五入”。

**坑**：把“就近舍入到偶数”当成“四舍五入”（一半时一律进位），在 $1.0101\cdots$ 这类尾数上结果末位差 1；舍入后尾数进位成 $1.111\cdots1+1=10.0\cdots$ 时忘记再做一次右规并调整阶码。

## 考法 4：浮点乘除的阶码与尾数处理

**思路**：乘法是“阶码相加再减偏置、尾数相乘、结果规格化、判溢出”；除法是“阶码相减再加偏置、尾数相除、规格化”。关键一步：先写出两个操作数各自的阶码字段值 $E_1,E_2$，直接对字段做加减后要**补回/减去一个偏置**，这才是真正的阶码运算，别漏掉这一步。

**坑**：直接把两个阶码字段相加当成结果阶码，忘记减去一个偏置（除法时忘记加回一个偏置），结果阶码整体偏了 127；尾数相乘后结果为 $1.xxx\times 1.xxx$ 的两位整数部分没做右规，就把阶码当成最终值。
