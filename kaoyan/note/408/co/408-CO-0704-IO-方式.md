# 408-CO-0704 I/O 方式

> 章：CO-07 输入/输出系统　｜　档位：掌握　｜　真题落点：7 题：2019 #21、#22；2020 #22；2022 #21；2023 #22；2024 #21、#22

**在考什么**：判断数据传送是否经CPU、谁控制起止和总线，据此定方式、开销与优先级。

## 考法 1：中断 I/O 方式的流程与正误判断

**题目**：2022#21 关于中断 I/O，不正确的是

**思路**：第一步抓住中断方式的本质特征逐条核对：外设准备数据期间 CPU 继续执行原程序（两者并行），外设准备好后由接口向 CPU 发中断请求，CPU 在一条指令执行结束时响应，转入中断服务程序用指令完成一次数据传送，每传送一个数据就要经历一次完整的中断过程。第二步用“串行还是并行”“谁发起”“谁完成传送”三问去检验每个选项。

**坑**：把“CPU 与外设在中断方式下并行工作”误判为“串行”，从而放过真正错误的选项；也容易把“数据传送由中断服务程序用指令完成”错记成“由接口自动完成”（后者是 DMA 的特征）。

**题目**：2024#21 中断 I/O 方式

**思路**：第一步按时间轴拆：设备发出请求→CPU 在指令周期末尾检查并响应（中断隐指令完成关中断、保存断点、引出服务程序）→服务程序中保护现场、传送数据、恢复现场、开中断返回。第二步盯两个关键时机：响应时刻在“当前指令执行完”，返回时刻在“执行中断返回指令”，并注意中断屏蔽字只影响可屏蔽中断的响应次序。

**坑**：把响应时刻说成“一个总线周期结束”或“取指后立即”；把保存断点（PC）与保护现场（通用寄存器）混为一谈；以为开中断后同一级中断可以嵌套自身。

## 考法 2：三种 I/O 控制方式的特征辨析

**题目**：2023#22 关于 I/O 控制方式，错误的是

**思路**：第一步画一张三列对照表：程序查询——CPU 反复读状态、原地踏步、CPU 与外设完全串行；程序中断——CPU 与外设并行，但每个数据一次中断，开销与数据量成正比；DMA——以数据块为单位，由 DMA 控制器接管总线、直接在主存与设备间传送，CPU 只在前后做预处理与后处理。第二步用“传送粒度”“谁控制总线”“CPU 是否被长期占用”三问逐项判错。

**坑**：看到“中断方式下 CPU 与外设并行”就以为是错的（其实对）；把 DMA 说成“每传送一个字就中断一次 CPU”；把查询方式说成“CPU 不参与传送”。

**题目（常见考法）**：给出一个高速块设备、一个低速字符设备、一个偶发事件设备，问分别最适合哪种方式。

**思路**：第一步按“数据量大小”与“是否需要 CPU 及时响应”两个维度判断：成块高速传送选 DMA，低速且不频繁选查询或中断，需要 CPU 立即处理的异步事件选中断。

**坑**：只按“速度快慢”选，忽略“数据块/字符”这个粒度维度；把中断方式默认成“CPU 开销最小”。

## 考法 3：DMA 的数据通路与总线占用

**题目**：2024#22 DMA 的数据通路

**思路**：第一步画出两端：一端是主存，一端是设备，中间是 DMA 控制器；数据通路是“设备↔DMA 控制器↔主存”，CPU 不在这条通路上。第二步确认“过不过 CPU”：块传送阶段数据不经过 CPU、也不经过 CPU 寄存器；DMA 控制器内部用地址寄存器、字计数器、数据缓冲寄存器维持这次传送。第三步确认总线关系：DMA 控制器必须先申请并获得总线控制权，才能以自身为总线主设备向主存发读写命令（周期窃取或成组传送）。

**坑**：把数据通路写成“设备→DMA→CPU→主存”，以为总要经过 CPU 中转；认为 DMA 传送不需要占用总线；把“预处理/后处理由 CPU 完成”误推成“数据传送阶段 CPU 也参与”。

## 考法 4：CPU 开销与中断/DMA 优先级

**题目（常见考法）**：比较三种方式下 CPU 用于 I/O 的时间占比，或问 DMA 请求与中断请求谁先被响应、为什么。

**思路**：第一步把开销分成“传送期间的占用”和“每次传送的固定开销”两部分：查询方式全程占用；中断方式每字一次固定开销；DMA 每块一次固定开销，块内几乎不占 CPU。第二步用“数据量×单次开销”估算总时间。优先级上用“谁等不起”判断：DMA 请求对应的是设备侧的数据缓冲即将溢出，丢失无法补救，所以 DMA 请求优先于普通中断请求。

**坑**：只比“单次开销”而不乘传送次数，得出与总量相反的结论；把优先级判据说成“谁快谁先”，而不是“谁的请求不能被延迟”。

**题目（常见考法）**：问 DMA 传送结束后为什么还要一次中断。

**思路**：第一步分清“数据搬完了”和“这次 I/O 事务结束了”不是一回事：搬运由硬件完成，但校验、置状态、唤醒等待进程、启动下一次 I/O 属于软件职责。第二步据此解释后处理中断的必要性。

**坑**：把 DMA 的后处理中断当成“每个数据一次中断”，从而在开销比较中把 DMA 的优势抹掉。

### 2019 #21 中断I/O时间占比
某设备以中断方式与 CPU 进行数据交换，CPU 主频为 1GHz，设备接口中的数据缓冲寄存器为 32 位，设备的数据传输率为 50KBps。若每次中断开销（包括中断响应和中断处理）为 1000 个时钟周期，则 CPU 用于该设备输入/输出的时间占整个 CPU 时间的百分比最多是（ ）。

A. 1.25%
B. 2.5%
C. 5%
D. 12.5%

**思路**：先算每秒中断次数=传输率÷单次中断字节数（32 位缓冲即 4B），再乘每次中断周期数，最后除以主频得占比。

**坑**：把 32 位误当 32B，或把 50KBps 当成 50Kb/s；也可能忘记乘中断次数后除以 1GHz。

### 2019 #22 DMA方式叙述辨析
下列关于 DMA 方式的叙述中，正确的是（ ）。 Ⅰ. DMA 传送前由设备驱动程序设置传送参数 Ⅱ. 数据传送前由 DMA 控制器请求总线使用权 Ⅲ. 数据传送由 DMA 控制器直接控制总线完成 Ⅳ. DMA 传送结束后的处理由中断服务程序完成

A. 仅Ⅰ、Ⅱ
B. 仅Ⅰ、Ⅲ、Ⅳ
C. 仅Ⅱ、Ⅲ、Ⅳ
D. Ⅰ、Ⅱ、Ⅲ、Ⅳ

**思路**：按 DMA 三阶段拆：预处理由 CPU/设备驱动设置参数；传送前 DMA 控制器申请总线，传送时由 DMA 控制总线；结束后发中断，由中断服务程序收尾。

**坑**：只记住“DMA 不需要 CPU”就把参数设置和结束处理判掉；或把设备驱动设置的预处理误认为用户程序直接操作 DMA。

### 2020 #22 周期挪用DMA
若设备采用周期挪用 DMA 方式进行输入输出，每次 DMA 传送的数据块大小为 512 字节，相应的 I/O 接口中有一个 32 位数数据缓冲寄存器，对于数据输入过程，下列叙述中错误的是（ ）。

A. 每准备好 32 位数据，DMA 控制器就发出一次总线请求；
B. 相对于 CPU，DMA 控制器的总线使用权的优先级更高；
C. 在整个数据块的传送过过程中，CPU 不可以访问主存储器；
D. 数据块传送结束时，会产生“DMA 传送结束”的中断请求。

**思路**：明确周期挪用只在每个字或缓冲寄存器宽度对应的传送时刻占用一个主存周期，块结束时才发中断。

**坑**：把周期挪用误解为整块传送期间一直霸占总线，从而误判 CPU 全程不能访存。

### 2022 #21 中断输入输出方式
关于中断 I/O，不正确的是（ ）

A. 适用于键盘、针式打印机
B. 数据传送通过软件完成
C. 外设准备数据时间应小于中断处理时间
D. 外设准备数据时 CPU 可运行其他进程

**要点**：外设准备时间应**远大于**中断处理时间，否则中断开销不划算。

### 2023 #22 输入输出控制方式
关于 I/O 控制方式，错误的是（ ）

A. 查询方式靠 CPU 执行查询程序
B. 中断方式靠 CPU 执行中断服务程序
C. DMA 方式靠 CPU 执行 DMA 传送程序
D. SSD、网卡等高速设备用 DMA

**要点**：DMA 的数据传送由 DMA 控制器完成，CPU 只在开始/结束介入。

### 2024 #21 中断 I/O 方式
关于中断 I/O，错误的是

A. 中断屏蔽字用于确定中断响应的优先级
B. 保存断点和 PSW 在中断响应阶段完成
C. 保存通用寄存器和设置新屏蔽字由软件实现
D. 单重中断下中断处理时 CPU 关中断

**思路**：分清"中断响应"（硬件自动，隐指令）与"中断处理"（软件，服务程序）。B 正确（硬件）；C 中"保存通用寄存器"是软件做的，"设置新屏蔽字"也是软件写寄存器；D 正确（单重中断处理期间关中断）。

**坑**：A 的措辞——屏蔽字是**改变处理优先级**（通过修改屏蔽字实现嵌套），不是"确定响应优先级"（响应优先级由硬件排队器决定）。这一字之差就是错项。

### 2024 #22 DMA 的数据通路
DMA 方式下，数据传送通路位于

A. CPU 与主存
B. CPU 与 DMA 控制器
C. 设备接口与主存
D. 设备接口与 DMA 控制器

**思路**：DMA 的本质就是"**数据不经过 CPU**"。所以通路是设备接口 ↔ 主存，DMA 控制器只负责发地址和控制信号。

**坑**：选 D，以为数据要先进 DMA 控制器。控制器是"指挥官"不是"中转站"。
