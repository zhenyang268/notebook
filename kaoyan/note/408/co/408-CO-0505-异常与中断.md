# 408-CO-0505 异常与中断

> 章：CO-05 中央处理器　｜　档位：掌握　｜　真题落点：9 题：2016 #22；2017 #22；2018 #22；2020 #18、#20、#21；2021 #21、#22；2023 #21

## 考法 1：给出一个具体事件或现象，判定内中断/外中断、可屏蔽/不可屏蔽

**题目一（变式）**：从几个事件里挑出属于内中断的。

**思路**：第一步不看事件名字，只看“它与当前指令的关系”——凡是由正在执行的这条指令自身引起的（除数为 0、地址越界、缺页、非法操作码、陷入指令即系统调用），一律归内中断（异常）；剩下那些由外部设备、时钟异步提出、与当前指令无关的，归外中断。第二步再谈屏蔽：只有外中断才讨论能否被 IF 屏蔽。

**坑**：看到“缺页”就联想到“去主存取页、属于 I/O”，误判成外中断；或者看到“系统调用”里有“系统”两个字，误判成外中断——它恰恰是内中断里由陷入指令触发的那一类。判据永远只有“是否由当前指令执行产生”，而不是“事情发生在 CPU 内还是 CPU 外”。

**题目二（变式）**：问哪一类中断不能被屏蔽、必须立即响应。

**思路**：第一步先排除异常——异常根本不受 IF 控制，不进入“屏蔽”这个话题；第二步在剩下的外中断里，找由紧急硬件事件（电源故障、总线错误一类）产生的那一个。

**坑**：把“不可屏蔽”读成“不可响应”，于是挑了一个异常选项；也容易把 I/O 设备的中断请求当成不可屏蔽，因为它“来自硬件”。

## 考法 2：多重中断的响应时机、优先级与屏蔽字

**题目一（2021#22，关于多重中断，错误的是）**

**思路**：第一步把四个选项逐一还原成“中断处理流程中的某一时刻”——判优在哪一步做、开中断在哪一步做、保护现场在哪一步做、恢复现场之后又该做什么。第二步专门盯“开中断”的位置：只有保护完现场之后开中断，才可能被更高级的请求再次打断，凡“一进中断就开中断”或“关中断期间仍能响应更高级请求”的表述都要打问号。

**坑**：把“中断隐指令”和“中断服务程序”干的事混成一锅，于是看到“保护断点由中断服务程序完成”觉得顺理成章。要分清：断点（PC）和 PSW 由隐指令完成，通用寄存器的现场才是服务程序用指令压栈保存的。

**题目二（2023#21，关于硬件与异常/中断，错误的是）**

**思路**：第一步给四个选项各贴一个标签，分成“中断隐指令做的 / 纯硬件自动做的 / 服务程序（软件）做的”三栏；第二步只检查“职责错位”的选项——把软件的活说成硬件，或把硬件的活说成软件。

**坑**：看到“硬件”二字就认为“凡是检测到异常都是硬件的事”，于是放过“现场恢复也由硬件自动完成”这类描述；现场恢复要逐条弹出寄存器，是服务程序里的指令行为。

**题目三（变式）**：给一个中断屏蔽字表，问某级中断处理过程中还能响应哪些请求。

**思路**：第一步先看当前级别自己的屏蔽字——哪一位是 0 才允许对应级打断；第二步不要忘记“同级和低级一定被屏蔽”这条默认前提，再回去核对屏蔽字是否与之矛盾。

**坑**：只看屏蔽字表里为 0 的位，忘了优先级比较，把“屏蔽字为 0 但优先级更低”的级也答成可响应。

## 考法 3：处理程序返回后回到哪条指令（断点与现场）

**题目一（2021#21，处理程序执行后必须回到当前指令重新执行的是）**

**思路**：第一步按“出错时本条指令已经完成了多少”分类：一条都还没真正执行就出问题（缺页、越界、非法指令）→ 处理完要把本条重来；本条已经执行完才产生（陷入指令、调试用的陷阱）→ 返回下一条；程序根本无法继续 → 终止。第二步用题干“必须回到当前指令”这个限定词去筛，只在“故障”那一类里挑。

**坑**：把缺页当成“执行完才产生”的陷阱，答成返回下一条；反过来把系统调用（陷入）当成故障，答成重新执行当前指令。

**题目二（变式）**：外中断处理完返回哪里？

**思路**：第一步单独处理外中断——它在一条指令执行完之后才被响应，断点就是“下一条本该执行的指令”；第二步不要把它和异常共用一套判断规则。

**坑**：套用“中断打断当前指令”的直觉，答成“重新执行被打断的那条指令”。

## 考法 4：中断隐指令的内容与执行主体

**题目一（变式）**：中断响应过程中，由隐指令完成的是哪些操作。

**思路**：第一步把隐指令的三件事按顺序默写出来——关中断、保存断点（PC）与 PSW、引出中断服务程序（给出入口地址）；第二步凡涉及通用寄存器内容、屏蔽字修改的，一律推给服务程序中的指令。

**坑**：把“保存通用寄存器现场”塞进隐指令；或者把“修改中断屏蔽字”当成硬件自动完成——那是服务程序用指令改的。

**题目二（变式）**：中断响应发生在什么时刻。

**思路**：第一步把响应时刻固定到“一条指令执行结束、取下一条指令之前”这个时间窗；第二步对任何“指令执行中间就能响应外中断”的说法直接否定。

**坑**：看到“CPU 在每个机器周期结束时都检测中断请求”就推成“指令中间也能响应”——检测可以随时做，响应必须等到指令边界。

### 2016 #22 中断与异常来源
异常是指令执行过程中在处理器内部发生的特殊事件，中断是来自处理器外部的请求事件。下列关于中断或异常情况的叙述中，错误的是（ ）。

A. “访存时缺页” 属于中断
B. “整数除以 0” 属于异常
C. “DMA 传送结束” 属于中断
D. “存储保护错” 属于异常

**思路**：先把事件按来源分成来自处理器执行内部还是外部设备；关键一步是访存缺页发生在指令执行过程，应归入内部异常。

**坑**：看到“缺页”与访存、磁盘有关，就误判为外部中断；或把 DMA 结束当成执行内部异常。

### 2017 #22 多重中断系统
下列关于多重中断系统的叙述中，错误的是（ ）。

A. 在一条指令执行结束时响应中断
B. 中断处理期间 CPU 处于关中断状态
C. 中断请求的产生与当前指令的执行无关
D. CPU 通过采样中断请求信号检测中断请求

**思路**：多重中断允许中断嵌套，关键一步是区分“保护现场”与“执行中断处理程序”两个阶段的开关中断状态。

**坑**：把保护现场时的短暂关中断误扩大为整个中断处理期间都关中断。

### 2018 #22 外部I/O中断
下列关于外部 I/O 中断的叙述中，正确的是（ ）。

A. 中断控制器按所接收中断请求的先后次序进行中断优先级排队
B. CPU 响应中断时，通过执行中断隐指令完成通用寄存器的保护
C. CPU 只有在处于中断允许状态时，才能响应外部设备的中断请求
D. 有中断请求时，CPU 立即暂停当前指令执行，转去执行中断服务程序

**思路**：区分中断响应条件、中断隐指令职责和中断服务程序职责，逐项核对谁保存什么、何时可响应。

**坑**：容易把通用寄存器保护误归给中断隐指令，或把“有请求”误判成可立即打断当前指令。

### 2020 #18 自陷性质辨析
下列关于“自陷”（Trap，也称陷阱）的叙述中错误的是（ ）。

A. 自陷是通过陷阱指令预先设定的一类外部中断事件；
B. 自陷可用于实现程序调试时的断点设置和单步跟踪；
C. 自陷发生后 CPU 将转去执行操作系统内核相应程序；
D. 自陷处理完成后返回到陷阱指令的下一条指令执行。

**思路**：先定位自陷属于内部异常而非外部中断，再核对断点单步、转入内核处理和返回到下一条指令的常规流程；关键一步是分清“陷阱指令引起”与“外部事件引起”。

**坑**：看到“陷阱指令”就误判为外部中断事件；同时忽略题干问的是“错误”叙述，把符合事实的描述当成要选项。

### 2020 #20 外部中断事件判定
下列事件中属于外部中断事件的是（ ）。 I、访存时缺页； II、定时器到时； III、网络数据包到达； 异常和中断

A. 仅 I、II
B. 仅 I、III
C. 仅 II、III
D. I、II、III

**思路**：按事件是否由当前指令执行直接引发来分类，缺页由访存指令触发，定时器和网络包到达来自 CPU 外部；关键一步是看事件来源而非只看是否涉及硬件。

**坑**：看到“访存时缺页”中的访存就误判为外部中断；看到定时器、网络包是硬件事件又可能误判为内部异常。

### 2020 #21 外部中断叙述辨析
外部中断包括不可屏蔽中断（NMI）和可屏蔽中断，下列关于外部中断的叙述中错误的是（ ）。 中断屏蔽

A. CPU 处于关中断状态时也能响应 NMI 请求；
B. 一旦可屏蔽中断请求信号有效，CPU 将立即响应；
C. 不可屏蔽中断的优先级比可屏蔽中断的优先级高；
D. 可通过中断屏蔽字改变可屏蔽中断的处理优先级。

**思路**：先抓中断响应需同时满足请求、开中断或屏蔽通过、指令执行完等条件；NMI 不受关中断门控。

**坑**：看到可屏蔽中断请求有效就误判为立即响应，忽略中断允许标志与指令边界。

### 2021 #21 异常处理重执行
处理程序执行后必须回到当前指令重新执行的是（ ）

A. 系统调用
B. 页缺失
C. DMA 传送结束
D. 打印机缺纸

**要点**：故障类异常（缺页、除零）要重执行当前指令；陷阱类（系统调用）返回下一条。

### 2021 #22 多重中断嵌套机制
关于多重中断，错误的是（ ）

A. 仅在用户态才能检测响应中断
B. 检测到请求才进入响应周期
C. 进入响应周期时一定开中断
D. 检测到请求则必有未被屏蔽的源

**要点**：内核态也能被中断；"仅在用户态"是错的。A 错。

### 2023 #21 中断异常处理机制
关于硬件与异常/中断，错误的是（ ）

A. 执行一条指令过程中检测异常事件
B. 执行完一条指令时检测中断请求
C. 开中断下检测到中断请求就进行响应
D. 外部设备通过中断控制器向 CPU 发中断结束信号

**要点**：中断结束信号（EOI）是 CPU 发给中断控制器，方向反了。
