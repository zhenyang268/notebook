# 408-CO-0305 Cache

> 章：CO-03 存储系统　｜　档位：掌握　｜　真题落点：4 题：2016 #15；2017 #14；2021 #16；2022 #16

**在考什么**：先按映射方式切出标记、组号和块内偏移，再据命中与缺失代价算平均访问时间。

## 考法 1：直接/全相联/组相联的地址字段划分（2021#16、2022#16 这一类）

**思路**：第一步一定是“先算行数、再算组数”，而不是直接拿 Cache 容量去除块大小就完事：要判断题给的是“Cache 容量”还是“Cache 数据区容量”，后者不含标记、有效位、脏位。得到行数后，按相联度分组，组数取以 2 为底的对数就是组号位数；块内地址位数由块大小与编址单位决定；剩下的位全部归标记。

**坑**：把标记位、有效位、脏位算进“块数”的分母里，导致行数偏小、组数偏小、标记位数整体算错；另一个高频错是主存“按字节编址”而块大小写成“$2^k$ 个字”，没有把字换算成字节，块内地址位数直接少算。

**思路**：若题目反过来给标记位数问相联度或块大小，第一步仍是写出“主存地址位数 = 标记 + 组号 + 块内”这条恒等式，把已知量代进去，未知量用组数的对数表示。

**坑**：直接把“标记位数”当“组号位数”去解方程，忘了中间还夹着一层块内地址。

## 考法 2：命中率、缺失代价与平均访问时间（2024#16 这一类层次结构题）

**思路**：第一步先定性：Cache 与主存是“并行/同时启动”还是“串行/先查 Cache 再查主存”，这决定用 $t_c+(1-h)t_m$ 还是 $h\,t_c+(1-h)(t_c+t_m)$。多级 Cache 则把上一级的缺失代价整段替换成下一级的平均访问时间，自内向外逐层套。

**坑**：把题给的“缺失率”当命中率代入；或者在写回/写直达、TLB 命中等场景里，默认“Cache 命中就不必再访存”，忘记有些情形即使命中也要写主存或先访问页表。

## 考法 3：LRU 等替换算法下的命中序列与缺失次数

**思路**：第一步把地址序列先翻译成“组号 + 标记”的序列，同一个地址只可能落在同一组，所以分组做互不干扰。组内用一个“最近使用到最久未用”的有序表维护，每次访问后把该块移到表头，缺失时从表尾淘汰。

**坑**：**命中之后**忘记把该块提到最近使用端，导致后面几次淘汰对象全错；或者在组相联下把所有块当成一个全相联的大池子做 LRU，忽略了“替换只在本组内进行”。

## 考法 4：写直达 vs 写回、写分配 vs 非写分配的搭配与访存次数

**思路**：第一步问两个独立的问题：写命中时“要不要同时写主存”（写回只写 Cache 并置脏位，写直达两边都写）；写不命中时“要不要先把块调入”（写分配调入，非写分配直接写主存）。两问的答案才组成完整策略，再据此数访存次数。

**坑**：把“写回”和“非写分配”凑成一对、把“写直达”和“写分配”凑成一对；或者忘了写回策略下脏块只在**被替换时**才写回，把每一次写都算成一次主存访问。

## 考法 5：程序局部性与数组遍历的命中率分析

**思路**：第一步确认数组的存放顺序（行优先还是列优先）以及“一个块能装下几个数组元素”，然后把内层循环的地址步长与块大小对照：步长等于一个元素时，块内元素被连续用尽才换块；步长跨行时，每次访问几乎都落在新块上。

**坑**：看到内层循环“步长为 1”就认为必命中，忽略了外层每换一次行，行首地址已经跳到另一个块；反之看到按列访问就断言“零命中”，忘记总行数小于块能容纳的元素数时仍然有复用。

### 2016 #15 直接映射缺失率
有如下 C 语言程序段： for ( k = 0 ; k < 1000 ; k ++ ) a [ k ] = a [ k ] + 32 ; 若数组 a 以及变量 k 均为 int 型，int 型数据占 4B，数据 Cache 采用直接映射方式，数据区大小是 1KB，块大小是 16B，该程序段执行前 Cache 为空，则该程序段执行过程中，访问数组 a 的 Cache 的缺失率是（ ）。 cache概念

A. 1.25%
B. 2.5%
C. 12.5%
D. 25%

**思路**：先算一个主存块能装几个 int；每个 a[k] 有读、写两次访问，但首次把整块调入后，同块内后续元素的读写都能命中。

**坑**：把 a[k]=a[k]+32 拆成读和写各算一次缺失，误以为每个元素都会缺两次；或把缺失率的分母只按块数算，忽略每个元素实际访问两次。

### 2017 #14 数组访问局部性
某 C 语言程序段如下： for ( i = 0 ; i <= 9 ; i ++ ) { temp = 1 ; for ( j = 0 ; j <= i ; j ++ ) { temp *= a [ j ]; } sum += temp ; } 下列关于数组 a 的访问局部性的描述中，正确的是（ ）。

A. 时间局部性和空间局部性皆有
B. 无时间局部性，有空间局部性
C. 有时间局部性，无空间局部性
D. 时间局部性和空间局部性皆无

**思路**：看数组 a 的访问序列：内层 j 递增，地址连续；外层反复从头扫描前缀，使同一批元素被多次使用。连续访问对应空间局部性，重复使用对应时间局部性。

**坑**：只盯内层一次循环，会误判只有空间局部性；或把循环控制指令的局部性误当成数组 a 本身的局部性。

### 2021 #16 直接映射行位数
主存 32 位按字节编址，Cache 数据区 32KB，块 32B，直接映射，回写策略，Cache 行位数至少（ ）

A. 275
B. 274
C. 258
D. 257

**要点**：行 = 标记 + 有效位 + 脏位 + 数据。标记位数 = 主存地址 − 行号 − 块内偏移。

### 2022 #16 组相联比较器位数
主存 32 位、按字节编址，Cache 数据区 32KB、块 64B、8 路组相联，比较器个数与位数分别是（ ）

A. 8, 20
B. 8, 23
C. 64, 20
D. 64, 23

**要点**：比较器个数 = 路数；位数 = 标记位数 = 主存地址 − 组号 − 块内偏移。
