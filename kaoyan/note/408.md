# 408 · 课堂笔记

> **用法**：不要通读。每节四行——信号 / 答案 / 必背 / 易混。
> 做题卡住时按「题目里出现了哪个词」去查【信号】，三秒定位。
> 背不下来时只记【答案】那一行，其余是它的支撑。

### DS-01 绪论

#### 408-DS-0101 基本概念

- **信号**：看到“数据项、数据元素、数据对象”辨析，或问“逻辑结构与存储结构分类”，或问“抽象数据类型”，就是这一条。
- **答案**：数据项是数据最小不可分单位；数据结构=逻辑结构+存储结构+运算。
- **必背**：
  - 逻辑结构：集合、线性、树、图
  - 存储结构：顺序、链式、索引、散列
- **易混**：逻辑结构面向问题，存储结构面向计算机；同一逻辑结构可有多种存储实现。

#### 408-DS-0102 算法与算法评价

- **信号**：问“算法五个特性”，或给一段循环让你算时间复杂度，或问“空间复杂度、原地工作”，就是这一条。
- **答案**：五特性为有穷、确定、可行、输入、输出；复杂度看基本语句频度。
- **必背**：
  - $O(1)<O(\log n)<O(n)<O(n\log n)<O(n^2)<O(2^n)$
  - 空间复杂度只计辅助空间，原地工作为 $O(1)$
- **易混**：算法必须有穷且可零个输入；程序可不有穷（如操作系统）。

### DS-02 线性表

#### 408-DS-0201 定义与基本操作

- **信号**：问线性表逻辑特征，或列出 InitList、ListInsert 等操作名，或问何时传引用，就是这一条。
- **答案**：n 个同类型元素的有限序列；除首尾外每个元素有且仅有一个前驱和一个后继。
- **必背**：
  - 基本操作：InitList、Length、LocateElem、GetElem、ListInsert、ListDelete
  - 插入删除会改表长，须传引用（C++ 写 `&L`）
- **易混**：线性表是逻辑结构；顺序表、链表是它的两种存储结构。

#### 408-DS-0202 顺序表

- **信号**：问插入、删除的平均移动次数，或问“随机存取”，或给首地址算某元素地址，就是这一条。
- **答案**：插入平均移动 $n/2$，删除平均移动 $(n-1)/2$；支持随机存取。
- **必背**：
  - $Loc(a_i)=Loc(a_1)+(i-1)L$
  - 插入位置 n+1 个，最好移 0 次、最坏移 n 次
  - 删除最好 0 次、最坏 n-1 次
- **易混**：插入是 $n/2$、删除是 $(n-1)/2$，别记反。

#### 408-DS-0203 链表

- **信号**：问头结点作用，或问单链表、双链表、循环链表的插入删除，或问静态链表，就是这一条。
- **答案**：头结点让空表与非空表操作统一，插入删除不必改头指针。
- **必背**：
  - 单链表插入删除需找前驱 $O(n)$；双链表已知结点 $O(1)$
  - 带头结点循环单链表判空：`head->next==head`
  - 静态链表用数组存“指针”（下标）
- **易混**：带头结点判空 `head->next==NULL`；不带头 `head==NULL`。

#### 408-DS-0204 串与模式匹配

- **信号**：问串的存储，或给 next/nextval 数组填空，或问 KMP 复杂度，就是这一条。
- **答案**：KMP 利用部分匹配信息，主串指针不回溯，时间 $O(m+n)$。
- **必背**：
  - next[j]=最长相等前后缀长度+1（从1起，next[1]=0）
  - 朴素匹配最坏 $O(mn)$
- **易混**：nextval 在 $p_j=p_{next[j]}$ 时取 nextval[next[j]]，比 next 更优。

### DS-03 栈、队列和数组

#### 408-DS-0301 栈

- **信号**：问后进先出、合法出栈序列个数、括号匹配、表达式求值、递归，就是这一条。
- **答案**：只在栈顶插入删除的线性表，LIFO。
- **必背**：
  - n 个元素出栈序列数 $\frac{1}{n+1}C_{2n}^n$
  - 中缀转后缀：操作数直接输出，运算符弹出优先级≥它的再入栈
- **易混**：栈是操作受限的线性表（逻辑结构），不是存储结构。

#### 408-DS-0302 队列

- **信号**：问先进先出、循环队列判空判满、队长计算、双端队列，就是这一条。
- **答案**：队尾入、队头出，FIFO；循环队列常用牺牲一个单元区分空满。
- **必背**：
  - 队空 `front==rear`；队满 `(rear+1)%MaxSize==front`
  - 队长 `(rear-front+MaxSize)%MaxSize`
- **易混**：也可用 size 计数或 tag 标记判满，此时不牺牲单元。

#### 408-DS-0303 数组与特殊矩阵

- **信号**：问二维数组地址计算，或对称、三角、稀疏矩阵压缩，或三元组表，就是这一条。
- **答案**：对称矩阵只存下三角，$a_{ij}$ 与 $a_{ji}$ 共用一个单元。
- **必背**：
  - 行优先：$Loc(a_{ij})=Loc(a_{11})+[(i-1)n+(j-1)]L$
  - 下三角（含主对角）元素数 $\frac{n(n+1)}{2}$
- **易混**：行优先与列优先公式不同，先看题目声明。

### DS-04 树与二叉树

#### 408-DS-0401 树的基本概念

- **信号**：问结点数、度、高度，或问叶结点与度为 2 结点的数量关系，就是这一条。
- **答案**：n 个结点的有限集，n=0 为空树；除根外每个结点只有一个前驱。
- **必背**：
  - 结点数 = 所有结点度之和 + 1
  - $n_0=1+\sum_{i=1}^{m}(i-1)n_i$
- **易混**：树的度是结点度的最大值；二叉树度≤2 且左右有序。

#### 408-DS-0402 二叉树

- **信号**：问性质、满/完全二叉树、遍历序列，或由遍历序列构造二叉树，就是这一条。
- **答案**：$n_0=n_2+1$；完全二叉树按层编号，双亲为 $\lfloor i/2\rfloor$。
- **必背**：
  - 第 i 层最多 $2^{i-1}$；高 h 最多 $2^h-1$、最少 $2^{h-1}$
  - n 个结点的完全二叉树叶子数 $\lceil n/2\rceil$
  - 前序+中序、后序+中序可唯一确定；前序+后序不行
- **易混**：先序+后序不能唯一确定一棵二叉树。

#### 408-DS-0403 线索二叉树

- **信号**：问利用空指针、线索化过程，或问找前驱、后继，就是这一条。
- **答案**：用空指针域存遍历序列的前驱后继；n 个结点有 n+1 个空链域。
- **必背**：
  - 中序线索找后继：有右孩子取右子树最左，否则取右线索
  - 中序线索找前驱：有左孩子取左子树最右，否则取左线索
- **易混**：先序线索找前驱、后序线索找后继，都需借助双亲。

#### 408-DS-0404 树与森林

- **信号**：问树、森林转二叉树，或问树的遍历与二叉树遍历对应关系，就是这一条。
- **答案**：左孩子右兄弟；树的先根遍历对应二叉树先序，后根对应中序。
- **必背**：
  - 森林先序对应二叉树先序，森林中序（后根）对应中序
  - 树转二叉树后根结点无右子树
- **易混**：树的后根遍历 = 对应二叉树的中序，不是后序。

#### 408-DS-0405 哈夫曼树与编码

- **信号**：问 WPL、哈夫曼构造、前缀编码、编码长度，就是这一条。
- **答案**：每次取最小两权合并，WPL 最小；树中无度为 1 的结点。
- **必背**：
  - $WPL=\sum w_i l_i$
  - n 个叶子的哈夫曼树共 $2n-1$ 个结点
  - 哈夫曼编码是前缀编码，不等长
- **易混**：哈夫曼树不唯一（左右可换），但 WPL 唯一。

#### 408-DS-0406 并查集

- **信号**：出现“合并集合”“判断是否同一连通分量”“Kruskal 选边判环”“等价类”，就选并查集。
- **答案**：数组存双亲，根自指；Find 查根并路径压缩，Union 按秩合并。
- **必背**：
  - 初始化 $parent[i]=i$；Find 沿 parent 上溯到根。
  - Union 先 Find 两根，再按秩/规模挂接，只改根。
  - 路径压缩+按秩合并，单次近似 $O(\alpha(n))$，可视为常数。
- **易混**：并查集只支持合并，不支持删除/分裂；求连通分量数可用它，也可用遍历。

### DS-05 图

#### 408-DS-0501 基本概念

- **信号**：给顶点数问最多/最少边数、判断连通/强连通、给度序列、问生成树边数。
- **答案**：$n$ 顶点无向连通图至少 $n-1$ 条边，完全图至多 $n(n-1)/2$ 条。
- **必背**：
  - 无向完全图 $n(n-1)/2$ 条边；有向完全图 $n(n-1)$ 条弧。
  - 度之和 $\sum \deg(v)=2e$；有向图 $\sum$ 入度 $=\sum$ 出度 $=e$。
  - 生成树含 $n-1$ 条边；连通分量是极大连通子图。
- **易混**：极大连通子图=连通分量；极小连通子图=生成树，“极”字方向相反。

#### 408-DS-0502 存储结构

- **信号**：问“适合稠密/稀疏图”“判边 $O(1)$”“求入度出度”“空间 $O(n^2)$ 还是 $O(n+e)$”。
- **答案**：稠密图用邻接矩阵，稀疏图用邻接表；有向图十字链表，无向图邻接多重表。
- **必背**：
  - 邻接矩阵空间 $O(n^2)$，判边 $O(1)$，无向图矩阵对称。
  - 邻接表空间 $O(n+e)$；无向图边结点共 $2e$ 个。
  - 有向图：邻接矩阵行和=出度，列和=入度。
- **易混**：邻接表求有向图入度要遍历全表 $O(n+e)$；求无向图度只需该顶点链表长度。

#### 408-DS-0503 遍历

- **信号**：给邻接表/矩阵问 DFS、BFS 序列；问“无权图单源最短路径”“连通分量个数”“遍历次数”。
- **答案**：BFS 用队列、DFS 用栈/递归；邻接表 $O(n+e)$，邻接矩阵 $O(n^2)$。
- **必背**：
  - BFS 按层扩展，可求无权图单源最短路径。
  - 对每个未访问顶点启动一次遍历，次数=连通分量数。
  - 邻接矩阵遍历 $O(n^2)$，邻接表遍历 $O(n+e)$。
- **易混**：BFS 生成树层数最少；DFS 生成树随存储次序而变，序列不唯一。

#### 408-DS-0504 最小生成树

- **信号**：要求“连通所有顶点且总权最小”“给边权选边”，问 Prim/Kruskal 适用图与复杂度。
- **答案**：Prim 从顶点扩展、$O(n^2)$ 适稠密；Kruskal 按边排序+并查集、$O(e\log e)$ 适稀疏。
- **必背**：
  - MST 含 $n-1$ 条边，总权值唯一；边权互异时 MST 唯一。
  - Prim 维护 lowcost，每步选最小跨切边。
  - Kruskal 边升序，用并查集判环，不成环则加入。
- **易混**：MST 是全局总权最小；最短路径树是到源点距离最小，两者不同。

#### 408-DS-0505 最短路径

- **信号**：给源点求到各点距离、问负权边、问任意两点、问算法复杂度。
- **答案**：Dijkstra 单源非负权；Floyd 全源可负权但无负环；无权图用 BFS。
- **必背**：
  - Dijkstra 邻接矩阵 $O(n^2)$，堆优化 $O(e\log n)$。
  - Floyd 三重循环 $O(n^3)$：$D[i][j]=\min(D[i][j],D[i][k]+D[k][j])$。
  - BFS 求无权图单源最短路径 $O(n+e)$。
- **易混**：Dijkstra 与 Prim 都是贪心选最小，但 Dijkstra 更新 $dist[u]+w$，Prim 更新边权 $w$。

#### 408-DS-0506 拓扑排序

- **信号**：给课程/任务先后关系求可行顺序、判断有向图有无环、问 AOV 网。
- **答案**：反复输出入度为 0 的顶点并删其出边；输出不足 $n$ 个即有环。
- **必背**：
  - 时间复杂度 $O(n+e)$，用入度数组+栈/队列。
  - 拓扑序列一般不唯一；入度为零者可选多个。
  - AOV 网：顶点表示活动，有向边表示先后次序。
- **易混**：拓扑排序判 AOV 有无环；关键路径在 AOE 网，边才是活动。

#### 408-DS-0507 关键路径

- **信号**：给工程工期、活动持续时间，求“最短完工时间”“关键活动”“松弛时间”。
- **答案**：按拓扑序求 $ve$ 取最大，逆拓扑序求 $vl$ 取最小，$l-e=0$ 为关键活动。
- **必背**：
  - $ve[j]=\max(ve[i]+w_{ij})$；$vl[i]=\min(vl[j]-w_{ij})$。
  - 活动最早 $e=ve[i]$，最迟 $l=vl[j]-w_{ij}$，$d=l-e$。
  - 关键路径长度=工期，可能有多条；AOE 网边表示活动。
- **易混**：关键路径是源点到汇点的最长路径，不是最短路径；缩短关键活动未必缩短工期。

### DS-06 查找

#### 408-DS-0600 章导览

- **信号**：问“平均查找长度 ASL”“静态/动态查找”“哪种结构适合动态插入删除”。
- **答案**：ASL 是查找概率加权的平均比较次数；静态表用顺序/折半，动态表用树/散列。
- **必背**：
  - $ASL=\sum p_i c_i$，等概率时 $p_i=1/n$。
  - 成功 ASL 按内部结点算，失败 ASL 按外部结点算。
  - 静态查找：顺序、分块、折半；动态查找：BST、AVL、红黑树、B 树、散列。
- **易混**：ASL 成功与失败口径不同，不能混用同一个结点集计算。

#### 408-DS-0601 顺序查找与分块查找

#### 408-DS-0602 折半查找
- **信号**：题目说“有序顺序表”“二分查找”“比较次数最多/最少”“查找成功/失败的平均长度”。
- **答案**：仅适用于有序顺序表；判定树是平衡二叉树，比较次数不超过 $\lceil\log_2(n+1)\rceil$。
- **必背**：$mid=\lfloor(low+high)/2\rfloor$；成功 $ASL=\frac{1}{n}\sum_i l_i$，失败 $ASL=\frac{1}{n+1}\sum_j (l_j-1)$ 中的层数按判定树外部结点计算；查找长度即判定树层数。
- **易混**：折半查找的判定树唯一，而二叉排序树的形态取决于插入顺序；折半只能用于顺序存储，不能用于链表。

#### 408-DS-0603 二叉排序树 BST
- **信号**：“二叉排序树/二叉查找树”“中序遍历有序”“插入/删除结点”“查找效率”“最坏情况”。
- **答案**：左<根<右，中序遍历得递增序列；查找、插入、删除平均 $O(\log n)$，退化成单支树时为 $O(n)$。
- **必背**：删除双分支结点用中序前驱或后继替代；$ASL$ 取决于树的形态，最好 $O(\log n)$、最坏 $O(n)$；插入总在叶位置。
- **易混**：BST 只保证有序性，不保证平衡；AVL 是加了平衡条件的 BST，因此 BST 删除后无需旋转，AVL 需要。

#### 408-DS-0604 平衡二叉树 AVL
- **信号**：“平衡因子”“最小不平衡子树”“LL/RR/LR/RL 型调整”“高度为 h 的 AVL 最少结点数”。
- **答案**：任结点平衡因子绝对值≤1；插入后从最小不平衡子树旋转，四种类型各对应单旋或双旋。
- **必背**：$n_h=n_{h-1}+n_{h-2}+1$，$n_0=0,n_1=1,n_2=2$；LL、RR 单旋，LR、RL 双旋；平衡因子=左子树高−右子树高。
- **易混**：AVL 只对“最小不平衡子树”旋转，不是整棵树重排；LR 先对左孩子左旋再对根右旋，顺序不可颠倒。

#### 408-DS-0605 红黑树
- **信号**：“红黑树性质”“黑高”“插入调整”“最长路径不超过最短路径 2 倍”“与 AVL 比较”。
- **答案**：红黑树用颜色约束维持近似平衡，插入最多 2 次旋转、删除最多 3 次，查找最坏 $O(\log n)$。
- **必背**：根黑、叶(NIL)黑、红结点孩子必黑、任一结点到叶的所有路径黑结点数相同；最长路径≤2×最短路径。
- **易混**：红黑树不是 AVL 那样的严格高度平衡，它靠黑高相等；插入新结点初始染红，只在叔结点为红时变色、为黑时旋转。

#### 408-DS-0606 B 树与 B+ 树

- **信号**：看到“m 阶、关键字个数上下限、磁盘 I/O、范围查询、关键字全在叶”就选本条。
- **答案**：B 树非叶存数据，B+ 树非叶只索引，关键字全在叶且叶间链表。
- **必背**：非根 B 树关键字 $\lceil m/2\rceil-1\sim m-1$；B+ 树非根非叶子树 $\lceil m/2\rceil\sim m$；B+ 树叶链表支持范围查询。
- **易混**：B 树可在非叶命中，B+ 树必须到叶；B+ 树非叶仅索引。

#### 408-DS-0607 散列表

- **信号**：看到“装填因子、冲突、同义词、除留余数、线性探测、链地址、ASL”就选本条。
- **答案**：ASL 由装填因子和冲突处理方法决定；开放定址易堆积，链地址不堆积。
- **必背**：装填因子 $\alpha=n/m$；线性探测 $d_i=1,2,\dots,m-1$；链地址同义词成链。
- **易混**：开放定址删除需删除标记，不能直接置空；链地址可直接删结点。

### DS-07 排序

#### 408-DS-0701 基本概念

- **信号**：看到“稳定性、就地、比较次数、关键字比较、排序趟数、内外排序”就选本条。
- **答案**：稳定性看相等关键字相对次序是否变；内部排序在内存完成。
- **必背**：稳定：直接插入、冒泡、归并、基数；不稳定：希尔、快排、简单选择、堆。
- **易混**：冒泡可提前结束，趟数与初始有关；直接插入每趟只插入一个元素。

#### 408-DS-0702 插入排序

- **信号**：看到“直接插入、折半插入、希尔、哨兵、增量、局部有序”就选本条。
- **答案**：直接插入稳定、最坏 $O(n^2)$；折半插入只减比较；希尔不稳定。
- **必背**：直接插入最好 $O(n)$、最坏/平均 $O(n^2)$、空间 $O(1)$、稳定；折半插入比较 $O(n\log n)$、移动不变；希尔按增量分组。
- **易混**：折半插入不是希尔；它仍逐元素插入，希尔跨增量分组。

#### 408-DS-0704 选择排序与堆
- **信号**：“简单选择排序比较次数”“建堆”“向下调整”“删除堆顶”“插入元素”“与初始状态无关”
- **答案**：简单选择比较次数恒为 $n(n-1)/2$；堆排序时间 $O(n\log n)$、空间 $O(1)$，两者均不稳定。
- **必背**：比较次数 $n(n-1)/2$ 与初态无关，移动最多 $3(n-1)$；建堆 $O(n)$，单次调整 $O(\log n)$，总计 $O(n\log n)$；下标从 1 起，$i$ 的孩子为 $2i$、$2i+1$，建堆从 $\lfloor n/2\rfloor$ 起下滤。
- **易混**：与直接插入排序差在——选择排序比较次数与初态无关、始终 $n(n-1)/2$；插入排序最好可到 $O(n)$。

#### 408-DS-0705 归并排序
- **信号**：“2-路归并”“归并趟数”“辅助空间 $O(n)$”“稳定”“与初始状态无关”
- **答案**：2-路归并时间 $O(n\log n)$ 与初态无关，辅助空间 $O(n)$，是稳定排序。
- **必背**：递推 $T(n)=2T(n/2)+O(n)$，解得 $O(n\log n)$；归并趟数 $\lceil \log_2 n\rceil$；空间 $O(n)$。
- **易混**：与快速排序差在——归并稳定、空间 $O(n)$、最坏仍 $O(n\log n)$；快排不稳定、空间 $O(\log n)$、最坏 $O(n^2)$。

#### 408-DS-0706 基数排序
- **信号**：“分配-收集”“LSD/MSD”“$d$ 趟”“$r$ 个队列”“不基于比较”
- **答案**：按位分配-收集，时间 $O(d(n+r))$，空间 $O(r)$，稳定，不基于比较。
- **必背**：$d$ 为关键字位数（趟数），$r$ 为基数；空间为 $r$ 个队列 $O(r)$；LSD 从最低位到最高位，靠队列先进先出保持稳定。
- **易混**：与计数排序差在——计数排序一趟按值计数；基数排序是多趟计数排序按位分桶，$d=1$ 时退化为计数排序。

#### 408-DS-0707 外部排序
- **信号**：“多路归并”“归并趟数”“败者树”“置换-选择”“最佳归并树”“虚段”“磁盘读写次数”
- **答案**：$k$ 路归并趟数 $\lceil\log_k m\rceil$；败者树减少比较，最佳归并树按 Huffman 构造以减 IO。
- **必背**：$m$ 个初始归并段、$k$ 路，趟数 $S=\lceil\log_k m\rceil$；总读写次数 $=2\times$ 记录数 $\times S$；$k$ 路最佳归并树补虚段 $(m-1)\bmod(k-1)$ 个。
- **易混**：与内排序差在——外部排序瓶颈是 IO，靠增大 $k$、置换-选择加长归并段降趟数；败者树只降比较次数，不减 IO。

#### 408-DS-0708 算法比较
- **信号**：“稳定的排序”“时间与初始状态无关”“最坏 $O(n\log n)$”“辅助空间最小”
- **答案**：稳定者为插入、冒泡、归并、基数；不稳定者为选择、希尔、快速、堆。
- **必背**：与初态无关：选择、堆、归并、基数；最坏仍 $O(n\log n)$：堆、归并；空间：快排 $O(\log n)$、归并 $O(n)$、基数 $O(r)$、其余 $O(1)$。
- **易混**：希尔与插入差在——插入稳定、$O(n^2)$；希尔不稳定、时间依赖增量序列，最坏仍 $O(n^2)$。

### CO-01 计算机系统概述

#### 408-CO-0101 发展历程

- **信号**：看到“代际划分”“电子管/晶体管/集成电路”“存储程序”“冯·诺依曼”就考此条。
- **答案**：四代按器件分：电子管→晶体管→中小规模IC→大规模/超大规模IC。
- **必背**：
  - 冯·诺依曼五大部件：运算器、控制器、存储器、输入、输出
  - 存储程序：程序与数据同存，按地址顺序执行
  - 哈佛结构：指令与数据分开存储，可并行取指
- **易混**：冯·诺依曼机指令数据同存储器，哈佛结构分开。

#### 408-CO-0102 层次结构

- **信号**：问“计算机系统层次”“机器语言/汇编/高级语言”“ISA属于哪层”“软硬件界面”。
- **答案**：由低到高：微程序机器→传统机器→操作系统→汇编语言→高级语言。
- **必背**：
  - 微程序层由硬件直接执行；传统机器层即机器语言
  - ISA是软硬件界面，属传统机器层
  - 编译一次生成目标程序，解释逐句执行
- **易混**：ISA是机器语言级接口，微架构是其硬件实现。

#### 408-CO-0103 性能指标

- **信号**：出现CPI、MIPS、主频、FLOPS、响应时间、吞吐量、加速比。
- **答案**：CPU时间=指令数×CPI×时钟周期；MIPS=主频/(CPI×10^6)。
- **必背**：
  - CPU执行时间 = IC × CPI × T = IC × CPI / f
  - MIPS = f / (CPI × 10^6)
  - Amdahl：加速比 = 1 / ((1-p) + p/s)
- **易混**：主频高不等于性能高，CPI不同；MIPS不能跨指令集比较。

### CO-02 数据的表示和运算

#### 408-CO-0201 数制与定点编码

- **信号**：求原码/反码/补码/移码、真值范围、零的表示、“补码符号扩展”。
- **答案**：n位补码范围 $-2^{n-1}\sim 2^{n-1}-1$，零唯一，加减统一。
- **必背**：
  - 原码/反码范围 $\pm(2^{n-1}-1)$；补码 $-2^{n-1}\sim 2^{n-1}-1$
  - 补码=反码+1；移码=补码符号位取反
  - 补码符号扩展：高位补符号位
- **易混**：移码与补码只差符号位；反码零有+0/-0两种。

#### 408-CO-0202 字符与字符串

- **信号**：ASCII码、'A'/'a'/'0'编码、汉字区位码/国标码/机内码、大小端。
- **答案**：ASCII 7位；汉字机内码=国标码+8080H=区位码+A0A0H。
- **必背**：
  - '0'=30H，'A'=41H，'a'=61H，大小写差20H
  - 区位码+2020H=国标码；国标码+8080H=机内码
  - 大端：高字节在低地址；小端相反
- **易混**：国标码与机内码差8080H；区位码转国标码是各加20H。

#### 408-CO-0203 校验码

- **信号**：奇偶校验、海明码、CRC、码距、检错纠错位数。
- **答案**：码距d可检d-1错、纠$\lfloor(d-1)/2\rfloor$错；海明码$2^k\ge n+k+1$。
- **必背**：
  - 检e错需 $d\ge e+1$；纠t错需 $d\ge 2t+1$
  - 海明校验位在 $2^i$ 位，$2^k\ge n+k+1$
  - CRC用模2除，余数为校验位
- **易混**：奇偶校验码距2只能检1位错；海明码可纠1位。

#### 408-CO-0204 定点运算与溢出

- **信号**：补码加减、溢出判断、双符号位、CF/OF、进位。
- **答案**：补码减法化加 $[-y]_{补}$；溢出看双符号位或进位异或。
- **必背**：
  - 单符号位：$OF=C_{n}\oplus C_{n-1}$
  - 双符号位：00/11正常，01上溢，10下溢
  - 无符号溢出看CF，有符号看OF
- **易混**：最高位进位CF≠溢出OF；无符号数谈CF，有符号数谈OF。

#### 408-CO-0205 乘除运算与 ALU

- **信号**：原码一位乘、Booth补码乘、恢复余数/加减交替除法、ALU。
- **答案**：原码乘符号单独处理；Booth看相邻两位差；除法用加减交替。
- **必背**：
  - Booth：$y_{i+1}-y_i=+1$加，$-1$减，0不变
  - 恢复余数法：余数为负加除数恢复
  - 阵列乘法器：并行进位，速度快、面积大
- **易混**：原码乘符号异或单独算；补码Booth符号参与运算。

#### 408-CO-0206 浮点数表示

- **信号**：IEEE 754、单/双精度、阶码偏移、规格化、隐藏位、特殊值。
- **答案**：单精度1+8+23偏移127；双精度1+11+52偏移1023。
- **必背**：
  - 真值 $(-1)^S\times1.M\times2^{E-127}$（单精度）
  - 阶码全0/全1为特殊值：0、非规格化、∞、NaN
  - 规格化尾数隐藏最高位1
- **易混**：阶码用移码（偏置）不是补码；隐藏位只在规格化数中有。

#### 408-CO-0207 浮点运算

- **信号**：浮点加减步骤、对阶、规格化、舍入、浮点溢出。
- **答案**：对阶小阶向大阶看齐；尾数右移、阶码加，最后判阶码溢出。
- **必背**：
  - 五步：对阶→尾数加减→规格化→舍入→溢出判断
  - 对阶：小阶尾数右移，每移1位阶码+1
  - 左规尾数左移阶码减；右规尾数右移阶码加
- **易混**：浮点上溢看阶码，尾数溢出用右规解决，不是真溢出。

### CO-03 存储系统

#### 408-CO-0301 存储器概述

- **信号**：存储层次、Cache-主存、主存-辅存、局部性、存取周期、带宽。
- **答案**：Cache-主存提速度，主存-辅存扩容量，均靠局部性。
- **必背**：
  - 层次：寄存器→Cache→主存→辅存，越上越快越小越贵
  - 时间局部性：刚访问的还会访问；空间局部性：邻近的会访问
  - Cache-主存由硬件实现，对程序员透明
- **易混**：Cache-主存与虚拟存储器都靠局部性，前者硬件、后者OS+硬件。

#### 408-CO-0302 主存储器

- **信号**：SRAM/DRAM、刷新、ROM、存储芯片、行列地址、刷新方式。
- **答案**：SRAM用触发器不需刷新；DRAM用电容需按行刷新。
- **必背**：
  - SRAM快贵、集成度低，作Cache；DRAM慢廉、集成度高，作主存
  - 刷新方式：集中（有死区）、分散、异步
  - DRAM地址分行/列两次传送，引脚复用
- **易混**：DRAM刷新按行、与读写无关；SRAM不刷新。

#### 408-CO-0303 主存与 CPU 连接

- **信号**：芯片扩展、位扩展、字扩展、地址线、数据线、片选译码。
- **答案**：位扩展并接数据线，字扩展用片选扩展地址空间。
- **必背**：
  - 芯片数 = 总容量 / 单片容量
  - 位扩展：地址线共用，数据线拼接
  - 字扩展：数据线共用，高位地址译码产生片选
- **易混**：位扩展不改地址线，字扩展增加高位地址和片选。

#### 408-CO-0304 外部存储器

- **信号**：磁盘、磁道/扇区、寻道时间、旋转延迟、传输率、RAID。
- **答案**：磁盘存取时间=寻道+平均旋转延迟+传输；RAID0无冗余。
- **必背**：
  - 平均旋转延迟 = $1/(2r)$，r为转速
  - 数据传输率 = 转速 × 每道容量
  - RAID0条带无冗余，RAID1镜像，RAID5分布式奇偶
- **易混**：寻道时间是移臂，旋转延迟是等扇区转到磁头下。

#### 408-CO-0305 Cache

- **信号**：出现“平均访问时间”“命中率 $h$”“替换算法 LRU”“写回/写直达”“地址划分 tag/组号/块内地址”，就是考 Cache。
- **答案**：Cache 按块复制主存内容，靠地址划分定位，命中率越高平均访问时间越短。
- **必背**：
  - 同时访问：$T=ht_c+(1-h)t_m$；先查 Cache：$T=t_c+(1-h)t_m$
  - 地址 = 标记 tag | 组号(行号) | 块内地址，块大小 $=2^b$
  - 写回法需脏位；写直达命中即写主存，无需脏位
- **易混**：虚存按页调度、由 OS 参与；Cache 全硬件完成、对程序员透明。

#### 408-CO-0306 虚拟存储器

- **信号**：出现“页表”“TLB”“缺页”“虚拟地址转物理地址”“段页式”，就是考虚存。
- **答案**：虚存用页表把虚页号映射为物理页号，缺页由 OS 调页，页内偏移不变。
- **必背**：
  - 虚地址 = 虚页号 | 页内偏移；物理地址 = 物理页号 | 页内偏移
  - 查找顺序：TLB → 页表 → Cache → 主存 → 外存
  - 页表项含有效位、修改位、访问位、外存地址
- **易混**：TLB 缺失不等于缺页；Cache 缺失由硬件处理，缺页由 OS 处理。

### CO-04 指令系统

#### 408-CO-0401 指令格式与数据存放

- **信号**：出现“操作码位数”“扩展操作码”“边界对齐”“大端/小端”“按字节/字编址”，就是考本条。
- **答案**：指令 = 操作码 + 地址码；多字节数据按边界对齐存放，大小端定字节次序。
- **必背**：
  - 扩展操作码：短码不能是长码的前缀
  - 大端：高字节在低地址；小端：低字节在低地址
  - 边界对齐：起始地址是数据长度的整数倍
- **易混**：编址单位指地址加 1 代表的位数，与数据自身长度不是一回事。

#### 408-CO-0402 寻址方式

- **信号**：出现“有效地址 EA”“寄存器间接”“基址/变址”“相对寻址”“访存次数”，就是考寻址方式。
- **答案**：寻址方式决定 EA 的算法，进而决定访存次数与指令执行时间。
- **必背**：
  - 立即数：操作数在指令中，0 次访存；寄存器直接 0 次
  - 直接、间接、基址、变址：1 次访存（一次间接）
  - 相对寻址 $EA=(PC)+A$，$A$ 为补码偏移
- **易混**：基址寄存器内容由系统设定、面向系统；变址寄存器由用户改、面向数组。

#### 408-CO-0403 机器级代码表示

- **信号**：出现“汇编指令”“AT&T 格式”“mov / lea / push / call”“栈帧”，就是考机器级代码。
- **答案**：汇编是机器指令的符号形式，一条汇编对应一条机器指令，与 C 语句非一一对应。
- **必背**：
  - AT&T：`op src, dst`，寄存器加 `%`，立即数加 `$`
  - `lea` 只算有效地址不访存；`mov` 访存
  - 过程调用：参数与返回地址入栈，`call`/`ret` 改写 PC
- **易混**：`lea` 与 `mov` 形式相近，区别在于是否真正访问存储器。

#### 408-CO-0404 CISC 与 RISC

- **信号**：出现“指令条数多/少”“定长指令字”“只有 load/store 访存”“通用寄存器多”“硬布线控制”，就是考 CISC/RISC 对比。
- **答案**：RISC 指令少而定长、只有 load/store 访存、寄存器多、多用硬布线控制。
- **必背**：
  - RISC：定长、寻址方式少、流水线友好、组合逻辑控制
  - CISC：变长、寻址方式多、多用微程序控制
  - RISC 更适合流水，CISC 同样可流水
- **易混**：RISC 指令条数少但单条功能弱，完成同一程序代码可能更长。

### CO-05 中央处理器

#### 408-CO-0501 CPU 结构与功能

- **信号**：出现“用户可见寄存器”“PC/IR/MAR/MDR 作用”“运算器与控制器组成”，就是考 CPU 结构。
- **答案**：CPU = 运算器 + 控制器 + 寄存器组；PC、通用寄存器用户可见，MAR/MDR/IR 不可见。
- **必背**：
  - 用户可见：PC、通用寄存器、PSW（部分位）
  - 不可见：MAR、MDR、IR、暂存寄存器
  - PC 存下条指令地址；IR 存当前指令
- **易混**：PC 位数由存储器地址空间决定，不由机器字长决定。

#### 408-CO-0502 指令执行过程

- **信号**：出现“取指—间址—执行—中断周期”“微操作序列”“指令周期/机器周期/时钟周期”，就是考执行过程。
- **答案**：每条指令按取指、间址、执行、中断四个周期推进，由微操作序列逐步完成。
- **必背**：
  - 取指：PC→MAR，M(MAR)→MDR，MDR→IR，PC+1
  - 间址周期取有效地址；执行周期完成运算
  - 指令周期 > 机器周期 > 时钟周期
- **易混**：间址周期只在间接寻址时出现，中断周期只在有中断请求且允许时出现。

#### 408-CO-0503 数据通路

- **信号**：出现“数据通路”“单总线/多总线”“ALU 输入端来源”“控制信号 MemWr/ALUop”，就是考数据通路。
- **答案**：数据通路是部件之间传送数据的路径，由控制信号决定每次传送的源和目的。
- **必背**：
  - 单总线：一次只传一个数据，指令执行需多个时钟
  - 多总线/专用通路：可并行传送，速度快、硬件多
  - 控制信号由控制器按指令译码产生
- **易混**：数据通路只描述“路”，不含控制逻辑；控制信号决定路的通断。

#### 408-CO-0504 控制器

- **信号**：出现“硬布线控制器”“微程序控制器”“微指令/微命令”“控制存储器 CM”“水平型/垂直型”，就是考控制器。
- **答案**：硬布线用组合逻辑直接产生控制信号；微程序用 CM 中微指令产生，慢但易修改。
- **必背**：
  - 微指令 = 操作控制字段 + 顺序控制字段
  - 一条机器指令对应一段微程序
  - 水平型并行度高、微程序短；垂直型相反
- **易混**：微命令是最基本控制信号，微指令是若干微命令的集合。

#### 408-CO-0505 异常与中断

- **信号**：出现“故障 fault/自陷 trap/终止 abort”“中断响应条件”“中断隐指令”，就是考异常与中断。
- **答案**：异常由 CPU 内部引起、与指令同步；中断由外部请求引起、异步，响应需保护断点。
- **必背**：
  - 故障：执行中检测、可恢复；自陷：执行后、用于系统调用
  - 终止：硬件故障，不可恢复
  - 中断隐指令：关中断、保存断点、引出服务程序
- **易混**：缺页属故障类异常，处理后重新执行该指令；外部中断在指令执行结束时响应。

#### 408-CO-0506 指令流水线

- **信号**：出现“加速比”“吞吐率”“结构/数据/控制冒险”“转发、暂停、延迟槽”“超标量”，就是考流水线。
- **答案**：流水线靠重叠执行提高吞吐率；冒险用转发、暂停、分支预测等手段消除影响。
- **必背**：
  - 加速比 $S=\dfrac{nk}{k+n-1}$，理想时 $S\to k$
  - 吞吐率 $TP=\dfrac{n}{(k+n-1)\Delta t}$
  - 数据冒险用转发/暂停；控制冒险用分支预测/延迟槽
- **易混**：结构冒险是资源冲突，数据冒险是数据相关，控制冒险由转移指令引起。

#### 408-CO-0507 多处理器概念

- **信号**：出现“SISD/SIMD/MIMD”“多核”“共享内存”“Cache 一致性协议”，就是考多处理器。
- **答案**：Flynn 按指令流与数据流分类；多核共享内存靠 Cache 一致性协议保证可见性。
- **必背**：
  - SISD 单处理器；SIMD 阵列/向量；MIMD 多核与多处理器
  - 共享内存：UMA 统一访问、NUMA 非统一访问
  - 一致性协议：写无效、写更新
- **易混**：多核属 MIMD；SIMD 是一条指令处理多个数据，属数据并行。

### CO-06 总线

#### 408-CO-0601 总线概述

- **信号**：出现“总线带宽”“总线宽度”“总线复用”“同步/异步定时”“总线仲裁”，就是考总线概述。
- **答案**：总线是共享传输介质，带宽 = 总线宽度 × 工作频率，分数据、地址、控制线。
- **必背**：
  - 带宽 $=$ 宽度（字节）$\times$ 频率；32 位、66 MHz → 264 MB/s
  - 同步定时统一时钟、快但受最慢设备限制；异步定时握手、灵活但慢
  - 集中仲裁：链式查询、计数器定时、独立请求
- **易混**：数据线宽度决定一次传输位数，地址线宽度决定寻址空间，两者不同。

#### 408-CO-0602 总线事务与定时

- **信号**：题目给出一个主设备、一个从设备完成一次数据传送；或要求判断“需要几个时钟周期”“读/写事务先后顺序”“存储器与 CPU 如何握手”，或要求区分同步/异步/半同步/分离式事务，都是在考这一条。
- **答案**：总线事务即一次总线操作全过程；定时决定各信号在时间轴上的先后与时长。
- **必背**：
  - 一次读事务：请求→仲裁→寻址→传数→释放
  - 同步定时：统一时钟，速度快、适应差；异步定时：握手信号，灵活、慢
  - 半同步定时：时钟＋握手；分离式：申请与传数分两段，期间释放总线
- **易混**：同步与异步的差别在于有无公共时钟约束，不在传输速度快慢本身。

### CO-07 输入/输出系统

#### 408-CO-0701 I/O 系统概述

- **信号**：问“I/O 系统由哪几部分组成”“I/O 设备如何与主机连接”“I/O 系统的层次结构”“谁管理 I/O 操作”，就是在考这一条。
- **答案**：I/O 系统由外设、接口、总线与 I/O 管理软件组成，实现主机与外设的信息交换。
- **必背**：
  - 组成：外设＋接口＋I/O 总线＋I/O 软件
  - 层次：用户程序→I/O 软件→I/O 接口→设备
  - 编址：统一编址、独立编址两类
- **易混**：I/O 系统不等于 I/O 设备，前者含接口、总线与控制软件，范围更大。

#### 408-CO-0702 外部设备

- **信号**：看到“键盘属于什么设备”“磁盘容量/转速/平均存取时间”“显示器分辨率与刷新率”“打印机分类”等具体外设参数或分类问法，就是在考这一条。
- **答案**：外设分输入、输出、存储三类；磁盘性能看容量、转速、平均存取时间。
- **必背**：
  - 磁盘容量＝记录面数×每面磁道数×每道扇区数×扇区容量
  - 平均存取时间＝平均寻道时间＋平均等待时间＋传输时间（其中平均等待时间＝旋转周期/2）
  - 显示器：分辨率×刷新率×每像素位数 决定带宽需求
- **易混**：磁盘平均等待时间取旋转周期的一半，不取整个旋转周期；存取时间不等于传输时间。

#### 408-CO-0703 I/O 接口

- **信号**：题目提到“接口中有哪些寄存器”“数据缓冲寄存器与状态寄存器分工”“端口地址与存储器统一编址”“统一编址还是独立编址”，就是在考这一条。
- **答案**：接口是设备与总线之间的桥梁，负责地址译码、数据缓冲、状态与控制。
- **必背**：
  - 数据缓冲寄存器：暂存数据，解决速度不匹配
  - 控制/状态寄存器：存放 CPU 命令与设备状态
  - 统一编址：I/O 端口占用存储地址空间，用普通访存指令；独立编址：单独 I/O 指令
- **易混**：接口与设备不同，接口在主机侧，设备是外设本体；端口是接口中可被编址访问的寄存器。

#### 408-CO-0704 I/O 方式

- **信号**：看到“CPU 反复查询设备状态”“设备就绪向 CPU 发中断请求”“DMA 控制器直接与主存交换数据”“通道执行通道程序”就分别对应程序查询、中断、DMA、通道方式。
- **答案**：按 CPU 参与程度从高到低：查询>中断>DMA>通道，效率依次提高。
- **必背**：
  - 查询：CPU 与设备串行，CPU 空转等待
  - 中断：每传一字一次中断，CPU 需保护现场
  - DMA：以数据块为单位，直接访存，仅在传送开始/结束时用 CPU
  - DMA 与 CPU 访存冲突：停止 CPU 访存、周期挪用、交替访存
- **易混**：中断方式由 CPU 执行程序传送数据，DMA 由硬件直接控制数据传送，不经过 CPU。

### OS-01 操作系统概述

#### 408-OS-0101 基本概念

- **信号**：问“OS 四大特征”“并发与共享谁为前提”，出现并发、共享、虚拟、异步即考此条。
- **答案**：OS 管理软硬件资源并提供接口，最基本特征是并发与共享。
- **必背**：
  - 并发与共享互为存在条件，没有并发就无需共享。
  - 并发＝宏观同时、微观交替；并行需多处理机。
  - 系统调用是程序接口；命令接口、GUI 面向用户。
- **易混**：并发是同一时间段内交替执行，并行是同一时刻真正同时执行。

#### 408-OS-0102 发展与分类

- **信号**：出现批处理、分时、实时、吞吐量、响应时间，问某系统类别或优缺点。
- **答案**：批处理求吞吐量，分时求交互响应，实时求在截止期限内响应。
- **必背**：
  - 单道批：自动、顺序、单道；多道批：多道、宏观并行、吞吐高、无交互。
  - 分时：同时性、交互性、独立性、及时性，靠时间片轮转。
  - 实时：及时性、可靠性、过载保护，分硬实时与软实时。
- **易混**：分时的“及时”是用户可接受的响应，实时的“及时”是严格截止期限。

#### 408-OS-0103 运行环境

- **信号**：问用户态进内核态的方式、中断与异常分类、系统调用执行过程。
- **答案**：用户态只执行非特权指令，进入内核态的唯一途径是中断或异常。
- **必背**：
  - 特权指令：I/O、关中断、置中断屏蔽字、修改 PSW、切换页表基址。
  - 异常（内中断）：陷入、故障、终止；外中断：I/O 完成、时钟。
  - 系统调用：用户态传参→陷入→内核态执行→返回用户态。
- **易混**：中断由外部事件引起、异常由当前指令引起；系统调用属自愿陷入。

#### 408-OS-0104 体系结构

- **信号**：出现微内核、大内核、分层、模块化、外核，问谁性能最高、谁可靠性最好。
- **答案**：微内核只把最基本功能留在内核，靠消息传递，可靠但切换开销大。
- **必背**：
  - 大内核性能高、可维护性差；微内核可扩展、态切换频繁开销大。
  - 分层：调试容易、层次难划分、效率低；模块化：接口难定义、可动态加载。
  - 外核给用户分配未映射的物理资源，减少地址映射开销。
- **易混**：微内核把文件系统与驱动移出内核，模块化各模块仍在内核态运行。

#### 408-OS-0105 引导与虚拟机

- **信号**：问上电后第一条指令在哪、BIOS 与 MBR 的作用、第一类与第二类 VMM。
- **答案**：上电先执行 ROM 中 BIOS，再依次装入 MBR、引导程序与 OS 内核。
- **必背**：
  - 顺序：BIOS 自检→读 MBR（0 号扇区）→活动分区引导记录→加载内核。
  - 第一类 VMM 直接跑在硬件上（Xen）；第二类寄宿在宿主 OS 上（VMware）。
  - 虚拟机三条件：资源控制、等价性、高效性。
- **易混**：第一类自身充当 OS 层、性能高；第二类依赖宿主 OS，易用但开销大。

### OS-02 进程与线程

#### 408-OS-0201 进程与线程

- **信号**：问进程与线程区别、三态转换、PCB 内容、用户级与内核级线程。
- **答案**：进程是资源分配单位，线程是 CPU 调度单位，线程共享进程地址空间。
- **必背**：
  - 就绪↔运行→阻塞→就绪；阻塞不能直接转运行，就绪不能直接转阻塞。
  - 线程私有：寄存器、栈、PC、状态；共享：地址空间、全局变量、打开文件表。
  - 进程切换要换页表、开销大；同进程内线程切换开销小。
- **易混**：用户级线程切换不进内核，但一个线程阻塞会使整个进程一起阻塞。

#### 408-OS-0202 CPU 调度

- **信号**：给到达与服务时间求平均周转、带权周转、等待时间，问哪种算法饥饿、算响应比。
- **答案**：SJF 平均周转最短但长作业饥饿；RR 靠时间片保证交互响应。
- **必背**：
  - 周转＝完成−到达；带权周转＝周转/服务；响应比＝(等待+服务)/服务。
  - FCFS 对短作业不利；SJF 最短但饥饿；RR 时间片过大退化为 FCFS。
  - 优先级分抢占/非抢占，动态优先级可防饥饿；多级反馈队列折中。
- **易混**：SJF 只看服务时间；高响应比优先兼顾等待，长作业等久响应比升高。

#### 408-OS-0203 同步与互斥

- **信号**：出现临界区、P/V 操作、信号量、生产者-消费者、读者-写者、管程。
- **答案**：互斥信号量初值 1，同步信号量初值为资源数；P 在前、V 在后。
- **必背**：
  - P：S=S−1，S<0 则阻塞；V：S=S+1，S≤0 则唤醒一个。
  - 四准则：空闲让进、忙则等待、有限等待、让权等待。
  - 实现：软件 Peterson、硬件 TSL/Swap、信号量、管程。
- **易混**：互斥的多个 P 顺序颠倒会死锁，同步的 V 顺序可交换。

#### 408-OS-0204 死锁

- **信号**：问死锁原因与必要条件、银行家算法求安全序列、资源分配图能否化简。
- **答案**：四个必要条件同时成立才可能死锁；银行家算法分配前判断是否仍安全。
- **必背**：
  - 四条件：互斥、不可剥夺、请求并保持、循环等待。
  - 策略：预防（破坏条件）、避免（银行家）、检测（化简图）、解除（剥夺/撤销）。
  - 安全状态一定无死锁；不安全状态只是可能死锁。
- **易混**：预防是静态破坏必要条件，避免是动态判断每次分配后是否安全。

### OS-03 内存管理

#### 408-OS-0301 内存管理基础

- **信号**：问首次/最佳/最坏适应、页表与快表、分页与分段区别、逻辑地址转物理地址。
- **答案**：分页一维定长、产生内部碎片；分段二维变长、产生外部碎片。
- **必背**：
  - 页号＝逻辑地址/页大小，页内偏移＝逻辑地址 mod 页大小。
  - 快表命中省一次访存；未命中则查页表再访存。
  - 首次适应快、最佳适应碎片小但多、最坏适应留大块。
- **易混**：分页按物理定长划分、对用户不可见；分段按逻辑功能划分、用户可见。

#### 408-OS-0302 虚拟内存管理

- **信号**：问 LRU/OPT/CLOCK 置换、缺页率、Belady 异常、抖动与工作集。
- **答案**：虚拟内存靠请求分页加置换实现，缺页由缺页中断调入并重执行指令。
- **必背**：
  - OPT 最优不可实现；FIFO 有 Belady 异常；LRU 接近 OPT；CLOCK 近似 LRU。
  - 抖动根源：分配页框数少于工作集；用局部置换加工工作集模型缓解。
  - 页表项含有效位、访问位、修改位、外存地址。
- **易混**：缺页是内中断中的故障，处理完重新执行当前指令，不是重新调度进程。

### OS-04 文件管理

#### 408-OS-0401 文件系统基础

- **信号**：问文件逻辑结构、目录结构、硬链接与软链接区别、文件保护方式。
- **答案**：FCB 存文件元数据，目录是 FCB 的有序集合，实现按名存取。
- **必背**：
  - 逻辑结构：流式、顺序、索引、索引顺序；定长顺序文件可随机存取。
  - 目录：单级、两级、树形、无环图；无环图才便于共享。
  - 硬链接共用 inode、计数减一；软链接是存路径的独立文件。
- **易混**：硬链接不能跨文件系统；软链接可跨但原文件删除即失效。

#### 408-OS-0402 文件系统实现

- **信号**：问连续/链接/索引分配、inode 与多级索引、位示图与成组链接、FAT。
- **答案**：inode 存元数据与索引地址；分配方式决定能否随机访问与碎片。
- **必背**：
  - 连续：可随机访问、有外部碎片、难扩展；链接：无碎片、只能顺序访问。
  - 索引：可随机访问、索引块占空间；UNIX 用直接加一/二/三级索引。
  - 空闲管理：位示图、成组链接、空闲链表；位示图便于找连续块。
- **易混**：FAT 是链接分配的显式实现，FAT 常驻内存故支持随机访问。

#### 408-OS-0403 磁盘与 SSD

- **信号**：给磁道/扇区/转速算存取时间、问 SCAN/SSTF 调度、RAID 级别、SSD 磨损均衡。
- **答案**：存取时间＝寻道＋旋转延迟＋传输时间；调度算法比磁头移动距离。
- **必背**：
  - 平均旋转延迟＝1/(2r)，r 为每秒转

### OS-05 输入/输出管理

#### 408-OS-0501 概述与控制方式

- **信号**：看到"CPU 与 I/O 并行度""CPU 干预频率""设备与内存间数据传送由谁完成"，就是在考控制方式；看到"字/块""寻址""周期挪用"就问 DMA。
- **答案**：控制方式按 CPU 干预度从高到低排列为程序查询、中断、DMA；DMA 以数据块为单位，由硬件直接传送数据。
- **必背**：
  - 程序查询：CPU 忙等；中断：每字节中断一次，CPU 参与字节传送；DMA：每块中断一次，CPU 不参与传送。
  - DMA 传送方式：停止 CPU 访存、周期挪用（周期窃取）、DMA 与 CPU 交替访存。
  - DMA 优先级高于 CPU 访存，因 DMA 请求不能等待。
- **易混**：中断方式以字节为单位、CPU 负责传送；DMA 以数据块为单位、硬件负责传送，只在开始和结束时需 CPU。

#### 408-OS-0502 设备独立软件

- **信号**：出现"与设备无关""逻辑设备名/物理设备名""缓冲区""SPOOLing""设备分配表"，就考设备独立软件层。
- **答案**：设备独立性指用户用逻辑设备名申请设备，由系统映射为物理设备；缓冲与 SPOOLing 都在此层。
- **必背**：
  - 逻辑设备表 LUT：实现逻辑设备名到物理设备名的映射，每进程一张或全系统一张。
  - 单缓冲/双缓冲/循环缓冲用于匹配 CPU 与 I/O 速度；缓冲在设备独立层实现。
  - SPOOLing 用输入井、输出井加输入/输出进程，把独占设备虚拟为共享设备。
- **易混**：设备驱动与中断处理属设备相关层，靠设备控制器的具体细节；逻辑设备名映射、缓冲、SPOOLing 属设备无关层。

### NET-01 体系结构

#### 408-NET-0101 概述与性能指标

- **信号**：看到“时延带宽积”“RTT”“发送时延和传播时延谁大”“吞吐量是多少”，就是在考性能指标。
- **答案**：发送时延 = 数据长度/带宽，传播时延 = 距离/电磁波速，两者互不相干，不能互相换算。
- **必背**：
  - 总时延 = 发送时延 + 传播时延 + 处理时延 + 排队时延
  - 时延带宽积 = 传播时延 × 带宽，即链路中“正在路上”的比特数
  - 吞吐量取瓶颈链路带宽（各段最小值）
- **易混**：提高带宽只减小发送时延，传播时延只由距离和介质决定，提速缩短不了它。

#### 408-NET-0102 分层与参考模型

- **信号**：给出“某层负责做什么”问 OSI 层号，或问 TCP/IP 与 OSI 的层次对应。
- **答案**：OSI 自下而上七层：物理、数据链路、网络、传输、会话、表示、应用。
- **必背**：
  - 数据单元：比特—帧—分组（数据报）—报文段—报文
  - TCP/IP 四层：网络接口层、网际层、传输层、应用层
  - 传输层及以上端到端，网络层及以下逐跳（点到点）
- **易混**：表示层管编码、加密、压缩，会话层管会话建立与同步，两层的功能最容易被写反。

### NET-02 物理层

#### 408-NET-0201 通信基础

- **信号**：给出带宽、信噪比、码元种类数，问“极限数据率”；或问“波特率与比特率如何换算”。
- **答案**：无噪声用奈氏 $C=2W\log_2 N$，有噪声用香农 $C=W\log_2(1+S/N)$。
- **必背**：
  - 奈氏：$C=2W\log_2 N$，$N$ 为码元种类数，限于理想低通信道
  - 香农：$C=W\log_2(1+S/N)$，且 $S/N|_{\mathrm{dB}}=10\lg(S/N)$
  - 比特率 = 波特率 × $\log_2 N$
- **易混**：奈氏受码元种类限制，香农受信噪比限制；两式给出两个上限时就取较小值。

#### 408-NET-0202 传输介质与设备

- **信号**：问“哪种介质带宽最高、抗干扰最好”，或问“中继器、集线器工作在哪个层次”。
- **答案**：光纤带宽大、抗电磁干扰、保密性好；中继器和集线器都是物理层设备。
- **必背**：
  - 双绞线传输距离约 100 m；同轴电缆抗干扰较强；光纤传输距离远
  - 中继器：整形、放大、再生，只用来扩展传输距离
  - 集线器：多端口中继器，所有端口共享带宽、工作在（宏）半双工
- **易混**：中继器和集线器都不隔离冲突域，只有网桥、交换机才隔离冲突域。

### NET-03 数据链路层

#### 408-NET-0301 功能与组帧

- **信号**：问“接收方怎样判断一帧的开始和结束”或“哪种组帧方式需要字节填充或比特填充”。
- **答案**：组帧用来把比特流划成帧，常用字符计数、字符填充、比特填充和违规编码四种方法。
- **必背**：
  - 比特填充：发送方每 5 个连续 1 后插 1 个 0，接收方删除
  - 字符填充：在定界符前插入转义字符 ESC
  - 字符计数法一旦计数字段出错就失去同步，故很少单独使用
- **易混**：比特填充面向比特，HDLC 使用；字符填充面向字节，PPP 使用。

#### 408-NET-0302 差错控制

- **信号**：给出数据和生成多项式，求“冗余码或 FCS”；或问“海明码需要几位校验位、能纠几位错”。
- **答案**：CRC 用模 2 除法取余数作 FCS；海明码满足 $2^k\ge n+k+1$ 可纠一位错。
- **必背**：
  - CRC：数据后补 $r$ 个 0（$r$ 为生成多项式最高次幂），模 2 除，余数即 FCS
  - 码距 $d$：可检 $d-1$ 位错，可纠 $\lfloor (d-1)/2\rfloor$ 位错
  - 纠 1 位错要求 $d\ge 3$，检 1 位错要求 $d\ge 2$
- **易混**：CRC 只检错不纠错；奇偶校验码距为 2，同样只检 1 位错、不能纠错。

#### 408-NET-0303 流量控制与可靠传输

- **信号**：给出窗口、序号位数、RTT，问“信道最大利用率”“序号至少几位”“窗口上限”。
- **答案**：停等效率最低；GBN 出错后回退重传，SR 只重传出错的那一帧。
- **必背**：
  - 停等：$U=\dfrac{T_D}{T_D+\mathrm{RTT}+T_A}$
  - GBN：发送窗口 $W\le 2^n-1$，接收窗口 = 1
  - SR：收发窗口均满足 $W\le 2^{n-1}$
- **易混**：GBN 丢弃失序帧并重传其后全部；SR 缓存失序帧，只重传出错帧。

#### 408-NET-0304 介质访问控制

- **信号**：问“最小帧长或争用期是多少”“第 i 次冲突退避范围”“CSMA/CA 为何用 RTS/CTS”。
- **答案**：CSMA/CD 边发边听检测冲突，最小帧长保证发送时间不小于争用期。
- **必背**：
  - 最小帧长 = $2\tau\times$ 数据率；10 Mb/s 以太网争用期 51.2 μs、最小帧 64 B
  - 第 $i$ 次冲突从 $\{0,1,\dots,2^i-1\}$ 中取 $k$，$i>10$ 后固定取 $2^{10}-1$
  - 冲突次数越多，退避时间越长（截断二进制指数退避）
- **易混**：CSMA/CD 用于有线总线，发送的同时也在监听线路；CSMA/CA 用于无线，先随机退避再发送并用 ACK 确认。

#### 408-NET-0305 局域网与广域网

- **信号**：问“MAC 帧各字段长度”“最短或最长帧长”“VLAN 标签几位”“PPP 的特点”。
- **答案**：以太网 MAC 帧最短 64 B、最长 1518 B；802.1Q 标签 4 B，用于划分 VLAN。
- **必背**：
  - 帧格式：目的 6 B + 源 6 B + 类型 2 B + 数据 46~1500 B + FCS 4 B
  - 前导码 8 B 不计入帧长；数据不足 46 B 须填充
  - VLAN 隔离广播域，但不隔离冲突域
- **易混**：以太网提供无连接、不可靠服务；PPP 面向字节、无编号无确认、不保证顺序。

#### 408-NET-0306 链路层设备

- **信号**：问“交换机收到目的 MAC 未知的帧怎么办”“图中有几个冲突域、几个广播域”。
- **答案**：交换机按 MAC 地址自学习建立转发表，隔离冲突域但不隔离广播域。
- **必背**：
  - 自学习：把源 MAC 与入端口写入转发表；目的未知则从其他端口泛洪
  - 交换机每个端口是一个冲突域，全部端口同属一个广播域
  - 透明网桥用生成树协议 STP 消除环路
- **易混**：集线器既不隔离冲突域也不隔离广播域，路由器两者都隔离。

### NET-04 网络层

#### 408-NET-0401 功能与路由算法

- **信号**：给出拓扑和链路代价，问“下一跳、路由表怎样更新”，或问“RIP 与 OSPF 各属哪种算法”。
- **答案**：距离向量算法用“到邻居的代价加邻居的表”迭代更新，链路状态算法用 Dijkstra 求最短路径树。
- **必背**：
  - DV 更新：$D(x,y)=\min_v\{c(x,v)+D(v,y)\}$，与邻居交换整张路由表
  - LS：洪泛链路状态分组，各路由器独立执行 Dijkstra
  - 分类：静态、动态；全局式（LS）、分散式（DV）
- **易混**：DV 收敛慢、有计数到无穷问题；LS 收敛快但洪泛开销大。

#### 408-NET-0402 路由协议

- **信号**：问“RIP 最大跳数、更新周期、用哪个传输层协议”“OSPF 协议号”“BGP 端口号”。
- **答案**：RIP 走 UDP 520、最大跳数 15；OSPF 直接封装在 IP 中（协议号 89）；BGP 走 TCP 179。
- **必背**：
  - RIP：每 30 s 更新，180 s 未收到即判不可达，16 表示不可达
  - OSPF：洪泛 LSA，支持区域划分和等价多路径负载均衡
  - BGP：路径向量协议，用于 AS 之间
- **易混**：RIP、OSPF 属内部网关协议 IGP；BGP 属外部网关协议 EGP。

#### 408-NET-0403 IPv4 地址与子网

- **信号**：给出 IP 地址和子网掩码，问“网络地址、广播地址、可用主机数、可划子网数”。
- **答案**：网络地址 = IP 与掩码按位与，广播地址 = 网络地址的主机

#### 408-NET-0404 分片与配套协议

- **信号**：题干出现 MTU、片偏移、MF/DF 标志、分片重组，或 ARP、ICMP、DHCP 与 IP 配合的描述。
- **答案**：分片按 MTU 切、片偏移以 8 字节为单位，重组只在目的主机；ARP 解析 MAC，ICMP 报差错。

- **必背**：① 除最后一片外，每片数据长度须为 8 的倍数；片偏移 = 该片首字节位置 / 8；每片总长 ≤ MTU；② MF=1 表示后续还有分片，最后一片 MF=0；DF=1 禁止分片，若超 MTU 则丢弃并回 ICMP 类型 3 代码 4；③ ARP 请求广播、应答单播；ICMP 报文封装在 IP 中。

- **易混**：片偏移单位是 8 字节，总长度单位是 1 字节；ARP 只在本局域网内解析 MAC 地址，ICMP 是网络层的差错与控制协议，二者都不传输用户数据。

#### 408-NET-0405 IPv6、组播与移动 IP

- **信号**：看到“IPv6 首部 40B、路由器不分片、`::` 压缩、双协议栈/隧道”→IPv6；看到“D 类地址、IGMP”→组播；看到“归属代理、转交地址”→移动 IP。
- **答案**：IPv6 首部定长 40B、路由器不分片；移动 IP 靠转交地址加隧道。
- **必背**：IPv6 地址 128 位、冒号十六进制，`::` 只能出现一次；组播 IPv4 为 D 类 224.0.0.0~239.255.255.255，IGMP 管组成员；过渡用双协议栈、隧道。
- **易混**：路由器不分片不等于 IPv6 不能分片，源端仍可用分片扩展首部。

#### 408-NET-0406 网络层设备

- **信号**：看到“能隔离广播域/抑制广播风暴的是”“按 IP 选路、逐跳转发”→路由器。
- **答案**：路由器工作在网络层，冲突域与广播域都隔离。
- **必背**：集线器（物理层）两者都不隔离；网桥/二层交换机隔离冲突域、不隔离广播域；路由器、三层交换机、VLAN 隔离广播域。
- **易混**：二层交换机与路由器只差在是否隔离广播域，二者都隔离冲突域。

### NET-05 传输层

#### 408-NET-0501 服务与端口

- **信号**：看到“进程到进程/端到端通信”“端口号几位”“××协议默认端口号”→本条。
- **答案**：传输层提供进程间通信，端口号 16 位，熟知端口 0~1023。
- **必背**：0~1023 熟知、1024~49151 登记、49152~65535 临时；FTP 20/21、SSH 22、Telnet 23、SMTP 25、DNS 53、DHCP 67/68、TFTP 69、HTTP 80、POP3 110、HTTPS 443。
- **易混**：复用是发送方多进程共用传输层服务，分用是接收方按端口交付，方向相反。

#### 408-NET-0502 UDP

- **信号**：看到“首部仅 8B”“伪首部校验和”“实时业务该选谁”→UDP。
- **答案**：UDP 无连接、不可靠、面向报文，首部 8B，无拥塞控制。
- **必背**：首部四字段各 2B：源端口、目的端口、长度、校验和；校验和加 12B 伪首部（源/目 IP、0、17、UDP 长度）；长度字段最小为 8。
- **易混**：UDP 面向报文，一次交付一个完整报文不合并不拆分；TCP 面向字节流。

#### 408-NET-0503 TCP 连接管理

- **信号**：看到“为什么三次不是两次”“TIME_WAIT 等多长”“SYN 洪泛攻击”→连接管理。
- **答案**：三次握手建连接，四次挥手释放，TIME_WAIT 等 2MSL。
- **必背**：SYN(seq=x)→SYN+ACK(seq=y,ack=x+1)→ACK(ack=y+1)；第三次握手可带数据，前两次不带；FIN 各耗一个序号。
- **易混**：释放是四次挥手且支持半关闭，只一方先关；不是三次。

#### 408-NET-0504 可靠传输与流量控制

- **信号**：看到“rwnd 由谁决定”“收到 3 个冗余 ACK”“零窗口怎么办”→本条。
- **答案**：可靠性靠序号+确认+重传，流量控制靠接收方通告 rwnd。
- **必背**：发送窗口 $W=\min(\text{rwnd},\text{cwnd})$；累积确认；3 个冗余 ACK 触发快重传，超时计时器到则重传。
- **易混**：流量控制看接收方能力 rwnd，拥塞控制看网络能力 cwnd，取小者。

#### 408-NET-0505 拥塞控制

- **信号**：看到“画 cwnd 随 RTT 变化曲线”“超时后 ssthresh 怎么变”→拥塞控制。
- **答案**：超时则 ssthresh 减半、cwnd=1 回慢开始；冗余 ACK 走快恢复。
- **必背**：慢开始每 RTT 翻倍，拥塞避免每 RTT 加 1；超时：$\text{ssthresh}=\max(\text{cwnd}/2,2)$，cwnd=1；快恢复：ssthresh=cwnd/2，cwnd=ssthresh。
- **易混**：快重传/快恢复由冗余 ACK 触发，cwnd 不降到 1；超时才降到 1。

### NET-06 应用层

#### 408-NET-0601 模型

- **信号**：看到“C/S 还是 P2P”“该协议基于 TCP 还是 UDP”→应用层模型与协议支撑。
- **答案**：应用层协议按传输层支撑分 TCP 类与 UDP 类。
- **必背**：TCP：HTTP、FTP、SMTP、POP3、IMAP、Telnet；UDP：DNS、DHCP、TFTP、SNMP、RIP；DNS 区域传送用 TCP 53。
- **易混**：DNS 常规查询走 UDP 53，区域传送或响应过大走 TCP 53，别一律说 DNS 用 UDP。

#### 408-NET-0602 DNS

- **信号**：看到“递归查询还是迭代查询”“根域名服务器”“高速缓存作用”→DNS。
- **答案**：主机到本地域名服务器用递归，本地到根/顶级用迭代。
- **必背**：层次为根、顶级、权限、本地域名服务器；查询 UDP 53，区域传送 TCP 53；高速缓存需设 TTL 保证一致性。
- **易混**：递归是“你替我问到底”，迭代是“你只告诉我下一步问谁”。

#### 408-NET-0603 FTP 与电子邮件

- **信号**：看到“控制连接/数据连接”“主动与被动模式”“MIME 作用”“POP3 与 IMAP 差别”→本条。
- **答案**：FTP 用两条 TCP 连接，控制 21 持久、数据 20 临时；邮件 SMTP 发、POP3/IMAP 收。
- **必背**：控制连接先建且全程保持，数据连接每次传输新建；SMTP 25 只传 7 位 ASCII，MIME 扩展；POP3 110 下载即删，IMAP 143 留在服务器。
- **易混**：SMTP 是推送（发送），POP3 是拉取（收取），方向相反。

#### 408-NET-0604 WWW 与 HTTP

- **信号**：看到“持久/非持久连接”“取 N 个对象要几个 RTT”“状态码 304/404”→WWW 与 HTTP。
- **答案**：HTTP/1.0 非持久、HTTP/1.1 持久；HTTP 无状态靠 Cookie 补。
- **必背**：非持久每对象 2 RTT（1 建连+1 请求响应）；持久非流水线：建连 1 RTT 后每对象 1 RTT；流水线：建连后全部对象共 1 RTT。
- **易混**：持久连接只是复用一条 TCP；流水线才是连续发请求不等响应。
