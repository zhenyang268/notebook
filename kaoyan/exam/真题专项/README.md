# 真题专项 — 以真题考点为纲的练习层

> 这一层**不按 KP 组织**，按**真题考点**组织。它是 `exam/` 的补充：`exam/` 讲知识，
> 这里讲"真题怎么考、错在哪、怎么练"。
>
> 与 `syllabus/` 的关系：每条的 KP 在 `syllabus/README.md` 附录 B 有实证登记，这里做展开。

## 为什么单独立一层

`note/` 的铁律是**一考点一文件**。但真题点是**跨 KP** 的：一道综合题可能同时考
混合索引（OS-04）和地址计算（CO-03）。强行塞进某个 KP 文件，两边都不对。

所以这一层的单位是**题点**，不是 KP。文件里每条都标 `→ KP` 指针，能反查回 `exam/`。

## 两条硬规矩

1. **不冒充原题**。手头没有真题原文的地方，只写"考点还原 + 常见错误 + 练什么"，
   绝不编造题干、选项、题号。凡标注了年份的，都来自 `syllabus/README.md` 附录 B 的实证登记。
2. **每条必须能落到一个动作**。写完"这个考点"，读者要知道"下一步翻哪一页、练哪一手"，
   否则就是废话。

## 怎么用

- **考前两周**：只看本层，每天过一个子科，把"坑在哪"那列抄进错题本。
- **刷题时**：错了先查这里，看是"没记住"还是"踩了坑"，归因比刷题量重要。
- **看完想去补知识**：顺着 `→ KP` 回 `exam/`，或者去 `quick/` 看这一科的整段主线。
