# 数学一 真题考点还原

> 数一的真题不像 408 那样有逐条实证登记（`syllabus/README.md` 附录 B 只到章节），
> 所以这份文件按**题型的固定套路**写：每类题在考什么、第一步做什么、坑在哪。
> 年份只在有明确出处时标注；没有就不标，避免编造。
>
> `→ KP` 指向 `exam/math1/<子科>/`；还没写的去 `syllabus/math1.md` 对应章。

## 怎么用

数一的特点是**题型高度固定**：每年就是那十几类，换数不换型。所以复习的正确姿势不是刷题量，
而是**把每类的"第一步"练成条件反射**。本文件每条就是那个"第一步"。

## 一、高等数学（约 82 分）

### 1. 极限与连续 → `HS-01`

**第一步**：先判型（$\frac00$、$\frac\infty\infty$、$0\cdot\infty$、$\infty-\infty$、$1^\infty$、$0^0$、$\infty^0$），
再选工具：等价无穷小 → 洛必达 → 泰勒 → 夹逼 → 单调有界。

**坑在哪**：
- **等价无穷小只能在乘除因子中整体替换**。$\tan x-\sin x$ 直接换成 $x-x=0$ 就错了
  （正确是 $x^3/2$，用泰勒展开）。
- $1^\infty$ 型用 $e^{\lim (f-1)g}$，**不能直接代 1**。
- 洛必达**只对 $\frac00$ 或 $\frac\infty\infty$**，且用完要检查是否循环、是否变复杂。
- 数列极限用"单调有界"时，**有界性和单调性都要证**，只证一个不给分。

**练什么**：把七个未定式各写一个代表题，每个写出完整第一步。

### 2. 中值定理与导数应用 → `HS-02`

**第一步**：看到"存在 $\xi$ 使某个含 $f'(\xi)$ 的等式成立"，就想**构造辅助函数 $F$ 使 $F'(\xi)=0$**。
常见构造：把结论移项成 $G(\xi)=0$，再找 $G$ 是某个 $F'$。

**坑在哪**：
- **罗尔定理要三个条件**（闭区间连续、开区间可导、两端相等），缺一不可，答题要逐个验证。
- 极值 ≠ 最值：最值要考虑**端点、不可导点、驻点**三类。
- 拐点是**凹凸性改变的点**，$f''=0$ 只是必要条件（如 $y=x^4$ 在 0 处 $f''=0$ 但不是拐点）。

**练什么**：给三个结论，各构造一个辅助函数（不用解完）。

### 3. 一元积分 → `HS-03`

**第一步**：不定积分先看能不能凑微分（换元），再看分部（"反对幂三指"顺序选 $u$），
最后才是有理函数分解。定积分先看**对称性**（奇偶、周期）能不能砍一半。

**坑在哪**：
- **变上限积分求导**：$\dfrac{d}{dx}\int_{a(x)}^{b(x)}f(t)dt=f(b)b'-f(a)a'$，**上下限都要导**。
- 反常积分：$\int_1^\infty x^{-p}dx$ 在 $p>1$ 收敛，$\int_0^1 x^{-p}dx$ 在 $p<1$ 收敛——**两个方向相反**。
- **旋转体侧面积**用 $\sqrt{1+y'^2}$（弧长微元），不是直接用 $y$ 积。
- 定积分换元**必须换上下限**，别忘了。

**练什么**：写一遍"奇偶性砍半"的三个例子；写一遍侧面积公式并说明与体积公式的差别。

### 4. 多元微分 → `HS-05`

**第一步**：求偏导就是"对其余变量当常数"；求全微分先写 $dz=f_xdx+f_ydy$；
条件极值直接上拉格朗日。

**坑在哪**：
- **可微 ⇒ 偏导存在，反之不成立**；偏导连续 ⇒ 可微。答题问"是否可微"要按定义验证，不能只看偏导。
- 方向导数的最大值就是**梯度的模**，方向是梯度方向。
- 拉格朗日乘数：**约束个数 = 乘子个数**；解完要判断是极大还是极小（比较函数值或看二阶条件）。

**练什么**：给一个 $f(x,y)$ 和约束 $g=0$，写出拉格朗日函数并解出驻点。

### 5. 多元积分（数一重头） → `HS-06`

**第一步**：看边界形状选坐标——圆/圆环用极坐标，柱体用柱坐标，球/锥用球坐标。
看到**闭曲线**想格林，**闭曲面**想高斯，**空间闭曲线**想斯托克斯。

**坑在哪**：
- **极坐标别忘了雅可比 $r$**；**球坐标别忘了 $r^2\sin\varphi$**。这两个漏了整题错。
- **第二类曲线/曲面积分与方向有关**，反向变号；第一类无关。
- 用格林/高斯前必须确认**闭 + 正向**（外侧、逆时针）；不闭合要**补线/补面再减去**。
- 高斯公式要求内部**偏导连续**；有奇点（如 $\frac{1}{r^2}$ 型）要**挖去小球**再算。

**练什么**：各写一道：极坐标二重、球坐标三重、格林补线、高斯挖奇点。

### 6. 无穷级数 → `HS-07`

**第一步**：正项级数先看通项量级（$1/n^p$ 型），选比较/比值/根值；
交错级数用莱布尼茨（**单调递减 + 趋于 0** 两条都要验）；幂级数先求收敛半径再判端点。

**坑在哪**：
- 比值/根值法**在 $\rho=1$ 时失效**，必须换比较法，别停在那里。
- 收敛半径 $R=1/\rho$（$\rho=\lim|a_{n+1}/a_n|$）；**端点必须单独代入判敛**，不能默认收敛。
- 傅里叶级数：**奇延拓只出正弦项，偶延拓只出余弦项**；狄利克雷定理给的是**左右极限的平均**，
  在间断点处不等于函数值。

**练什么**：给一个幂级数，求 $R$、判两个端点、写和函数（可能要用逐项求导/积分）。

### 7. 常微分方程 → `HS-08`

**第一步**：先判类型（可分离 / 齐次 / 一阶线性 / 伯努利 / 二阶常系数 / 欧拉），
再套对应公式。二阶非齐次**先求齐次通解，再定特解形式**。

**坑在哪**：
- 一阶线性公式法前**必须先化成标准形** $y'+P(x)y=Q(x)$，$y'$ 的系数必须是 1。
- 二阶非齐次特解的设法：**先看 $\lambda$ 是不是特征根**，决定乘 $x^k$ 的 $k$（0/1/2）。
  这是最容易错的一步。
- 欧拉方程 $x^2y''+axy'+by=0$ 令 $x=e^t$ 化常系数，**前提 $x>0$**。
- 通解里的常数个数要等于阶数。

**练什么**：写一遍二阶非齐次特解形式表（三种 $f(x)$ 类型 × 是否特征根）。

## 二、线性代数（约 34 分）

### 8. 秩与方程组 → `LA-02` `LA-04`

**第一步**：任何"解的存在性/个数"问题，先算 $r(A)$ 和 $r(A|b)$，比较。

**坑在哪**：
- 有解 $\iff r(A)=r(A|b)$；唯一解还要 $=n$；无穷多解时**自由度 $=n-r(A)$**。
- **基础解系含 $n-r$ 个向量**，不是 $n$ 个。
- 通解 = **一个特解 + 齐次通解**，特解不唯一但结构固定。

**练什么**：给一个含参数的方程组，分情况讨论 $\lambda$ 取何值时无解/唯一/无穷多。

### 9. 特征值与对角化 → `LA-05`

**第一步**：算特征多项式 $|\lambda I-A|=0$ 得特征值，再对每个特征值解 $(\lambda I-A)x=0$ 得特征向量。

**坑在哪**：
- **特征向量不能是零向量**；$\lambda=0$ 是合法特征值（此时 $A$ 不可逆）。
- 可对角化 $\iff$ 有 $n$ 个线性无关特征向量 $\iff$ **每个特征值的几何重数 = 代数重数**。
  重根时必须单独检查几何重数，不能想当然。
- **实对称矩阵一定能正交对角化**，这是它和一般矩阵最大的区别，不用检查。
- $|A|=\prod\lambda_i$，$\mathrm{tr}(A)=\sum\lambda_i$——用来验算。

**练什么**：给一个 $3\times3$ 矩阵，走完"特征值 → 特征向量 → 判可对角化 → 写 $P^{-1}AP$"全流程。

### 10. 二次型与正定 → `LA-06`

**第一步**：写出二次型矩阵 $A$（**对角线是平方项系数，非对角线是交叉项系数的一半**），
再用配方法或正交变换化标准形。

**坑在哪**：
- **正定判定用顺序主子式**（左上角 $1\times1,2\times2,\dots,n\times n$ 全 $>0$），**不是任意主子式**。
- 合同变换 $C^TAC$ **保惯性指数，不保特征值**；相似才保特征值。两个概念别混。
- 配方法化标准形时，**系数不是特征值**；只有正交变换法得到的才是特征值。

**练什么**：给一个二次型，先写矩阵，再判正定，再用正交变换化标准形。

## 三、概率论与数理统计（约 34 分）

### 11. 条件概率与贝叶斯 → `PS-01`

**第一步**：画树状图或列全概率公式，把"由因推果"和"由果推因"分开。

**坑在哪**：
- $P(A|B)$ 与 $P(B|A)$ **完全不同**，贝叶斯题最容易混。
- **互斥 ≠ 独立**：两个非零概率事件若互斥，则 $P(AB)=0\ne P(A)P(B)$，**一定不独立**。

**练什么**：一道"两工厂次品"型的贝叶斯题，写出先验、似然、后验三行。

### 12. 随机变量函数的分布 → `PS-02`

**第一步**：**先求分布函数 $F_Y(y)=P(g(X)\le y)$，再求导得密度**。不要直接套 $f_X(g^{-1}(y))$。

**坑在哪**：直接套公式必须乘 $|dx/dy|$（雅可比），且要求 $g$ 单调；**不单调要分段**。
分布函数法永远安全，只是慢一点。

**练什么**：$Y=X^2$、$X\sim N(0,1)$，用分布函数法求 $f_Y$。

### 13. 数字特征 → `PS-04`

**第一步**：期望直接线性拆分（**无需独立**）；方差用 $D(X)=E(X^2)-[E(X)]^2$；
协方差用 $Cov=E(XY)-E(X)E(Y)$。

**坑在哪**：
- $E(XY)=E(X)E(Y)$ **只在独立时成立**。
- $D(X-Y)=D(X)+D(Y)-2Cov(X,Y)$，**不是** $D(X)-D(Y)$。
- $E(g(X))\ne g(E(X))$（除非 $g$ 线性）。
- **不相关 ⇒ 独立不成立**（正态是例外）。

**练什么**：给联合分布表，算 $E(X)$、$D(X)$、$Cov(X,Y)$、$\rho$，并判断是否独立。

### 14. 抽样分布与区间估计 → `PS-06` `PS-07`

**第一步**：先看**总体方差已知还是未知**——已知用 $u$ 分布（正态），未知用 $t$ 分布。
这是选择统计量的唯一判据。

**坑在哪**：
- 样本方差 $S^2$ 的分母是 **$n-1$**（无偏），用 $n$ 是有偏的。
- 自由度要数对：$t(n-1)$、$\chi^2(n-1)$、$F(n_1-1,n_2-1)$。
- 最大似然：**先取对数再求导**（乘积变求和），并检查参数空间边界。

**练什么**：同一个场景（$\sigma$ 已知 / 未知）各写一次置信区间公式，说明为什么换统计量。

### 15. 假设检验 → `PS-08`

**第一步**：写原假设 $H_0$ 与备择假设 $H_1$，由 $H_1$ 的方向定**单侧还是双侧**，再定拒绝域。

**坑在哪**：
- 第一类错误（弃真）概率 $=\alpha$；第二类（取伪）$=\beta$。**减小 $\alpha$ 会增大 $\beta$**。
- 单侧检验的拒绝域**只在一侧**，别写成双侧。
- 结论的措辞是"**不拒绝** $H_0$"，不是"接受 $H_0$"。

**练什么**：给一个场景，写出 $H_0/H_1$、统计量、拒绝域、结论句式。

## 四、跨章提醒

数一的大题常把两章串起来，最常见的三种：

| 组合 | 例子 | 关键 |
|---|---|---|
| 中值定理 + 积分 | 证 $\int_0^1 f=\ldots$ 型等式 | 构造 $F(x)=\int_0^x f$，对 $F$ 用罗尔 |
| 级数 + 微分方程 | 幂级数求和 | 逐项求导后得到微分方程，解完再求和函数 |
| 多元积分 + 格林 | 曲线积分化二重 | 补线闭合，再用格林，最后减去补的部分 |

**练法**：每类找一道，只写"第一步做什么"，不写完整解答。
