## 怎么用

1. 先扫一遍本文件的三列，把"坑在哪"里没印象的抄进错题本（**只抄坑，不抄题**）。
2. 做题时错了，回来查这条，判断是"知识没记住"还是"踩了坑"——两者补救方式不同。
3. 每条末尾的"怎么练"是最小动作，做完就算这条过关。

## 一、数据结构

### 2023 · 散列表删除后的失败 ASL → `DS-06`

- **考什么**：开放定址法删除元素后，查找失败的平均查找长度（ASL）怎么算。
- **坑在哪**：删除**不能直接置空**，否则会截断探测链，后面的元素查不到。标准做法是**打删除标记**
  （墓碑），查找时"墓碑继续探测，空单元才停"。因此**失败 ASL 的分母是散列表长度，不是元素个数**，
  而且墓碑仍要被计入探测长度。
- **怎么练**：画一张 11 个槽的表，线性探测插入 8 个元素，删掉 2 个，手算失败 ASL；
  再把"直接置空"和"打标记"两种做法各算一次，对比差异。

### 2024 · 败者树与散列应用题 → `DS-07`

- **考什么**：败者树出现在选择题；散列函数的设计与冲突处理。
- **坑在哪**：败者树是**外部排序多路归并**的选择结构，它省的是**比较次数**，
  **不减少归并趟数**（趟数只由初始归并段数 $m$ 和路数 $k$ 决定，$\lceil\log_k m\rceil$）。
  很多人把"败者树加速"误记成"减少 I/O"。
- **怎么练**：给 8 个初始归并段、4 路归并，算需要几趟；再说明败者树在哪一步省了什么。

## 二、计算机组成原理

### 2012 · 流水线时空图数周期 → `CO-05`

- **考什么**：给指令序列和流水段，画时空图，数总周期数。
- **坑在哪**：**流水线填充（fill）和排空（drain）都要算**。$n$ 条指令、$k$ 段流水线、
  无冲突时总周期 $=k+(n-1)$。有数据冒险要插气泡，气泡也占周期。
- **怎么练**：5 段流水线、10 条指令，先算无冒险的 14 拍；再加入一次 load-use 冒险，重算。

### 2016 · 单周期 CPU 不能用单总线数据通路 → `CO-05`

- **考什么**：数据通路的构成约束。
- **坑在哪**：**一条总线在一个周期内只能传一个数据**。单周期要求取指、译码、执行、访存、
  写回都在一个周期完成，至少要同时传多个值，所以单总线做不到——必须多总线或分离通路。
- **怎么练**：列出单周期一条 `lw` 需要同时进行的传输（PC→MAR、读指令、寄存器读两个、ALU 两个输入…），
  数一数至少需要几条通路。

### 2016 / 2018 · 异常与中断返回哪条指令 → `CO-05`

- **考什么**：故障（fault）、陷阱（trap）、中止（abort）三类，返回地址不同。
- **坑在哪**：
  - **故障**：指令**未完成**，处理后**重新执行该指令**（返回出错指令）。
  - **陷阱**：指令**已执行完**，处理后**返回下一条**（如系统调用、断点）。
  - **中止**：无法恢复，**不返回**。
  另一组易混：**内部中断（异常）** 由指令引起（除零、缺页），**外部中断** 由外设引起（I/O 完成、时钟）。
- **怎么练**：给五个场景（缺页、断点、除零、键盘中断、时钟中断），逐个判"内部还是外部 / 返回哪条"。

### 2017 / 2023 · 数据通路与超标量、组合逻辑与时序逻辑 → `CO-05`

- **考什么**：数据通路的组成；超标量的收益边界；逻辑元件分类。
- **坑在哪**：
  - **数据通路不含控制部件**——控制器是"发信号"的，数据通路是"被控制"的。
  - **超标量提高的是并行度（吞吐），不缩短单条指令的延迟**。
  - **组合逻辑**输出只依赖当前输入（加法器、译码器）；**时序逻辑**含存储（触发器、寄存器）。
- **怎么练**：各举两个例子；再说明"五段流水线 + 旁路"为什么仍可能阻塞（load-use 等一拍）。

### 2023 · Cache 四路组相联 + 请求分页综合 → `CO-03` `OS-03`

- **考什么**：Cache 与虚拟内存两套地址转换串起来算。
- **坑在哪**：**两套结构不要混**：TLB 缓存的是**页表项**，Cache 缓存的是**数据块**。
  虚拟地址先查 TLB 得物理地址，再用物理地址查 Cache。**TLB 未命中不等于缺页**（可能只是页表在内存里）。
- **怎么练**：给 32 位虚地址、页大小 4 KB、Cache 4 路组相联 64 组块 64 B，
  拆出「虚页号 / 页内偏移 → 物理页框号 → 标记 / 组号 / 块内偏移」。

## 三、操作系统

### 2012 · 页面回收策略的扫描与访问时间先后 → `OS-03`

- **考什么**：自定义页面置换策略时，判断"访问位"何时被清、何时被读。
- **坑在哪**：**扫描和访问的先后顺序决定结果**。如果先清访问位再检查，本轮访问会被漏掉；
  如果先检查再清，行为等价于 CLOCK 的一个变体。**题目给了顺序就严格按顺序模拟**，
  不要凭"LRU 的印象"答。
- **怎么练**：给访问串和 3 个页框，按题目给的顺序一步步画表，标出每次置换谁。

### 2012 / 2019 · 混合索引的地址计算 → `OS-04`

- **考什么**：给索引结点里的直接块数、一级/二级/三级间接，算最大文件大小或某偏移落在哪一级。
- **坑在哪**：**最容易漏一级间接**（2019 年约 35% 考生错）。
  正确顺序：先算直接块覆盖的字节数，再依次加一级、二级、三级间接的容量。
  另一个坑是**每个指针占几个字节**——题目会给，不给就按 4 B 算并注明假设。
- **怎么练**：12 个直接块、块大小 4 KB、指针 4 KB/4 B = 1024 项，算一级间接能覆盖多少，
  再算偏移 500 KB 落在哪一级、第几个块。

### 2016 · 磁盘调度的初始磁头位置 → `OS-04`

- **考什么**：FCFS / SSTF / SCAN / C-SCAN 的移动距离。
- **坑在哪**：**必须先确定初始磁头位置和移动方向**，再决定先服务哪个请求。
  漏了这一步，SCAN 的方向会反，整题错。另外 C-SCAN 回程**不服务**，但距离仍要算。
- **怎么练**：给磁头在 100、请求序列，分别算四种算法的总移动距离，注意 SCAN 要说明方向。

### 2018 · 段表项不含页框号 → `OS-03` `CO-03`

- **考什么**：分段与分页的表项内容。
- **坑在哪**：**页表项存页框号**（虚页→物理页框）；**段表项存段基址和段长**，不存页框号。
  段页式里，段表指向页表，页表才存页框号。这三个"表"的职责必须分清。
- **怎么练**：画段页式的三级结构（段表 → 页表 → 物理内存），标出每级存什么。

### 2021 · 硬链接不能跨文件系统 → `OS-04`

- **考什么**：硬链接与符号链接的区别。
- **坑在哪**：**硬链接指向同一 inode，而 inode 编号只在同一文件系统内唯一**，所以跨文件系统不行；
  **符号链接存的是路径字符串**，可以跨文件系统，但原文件删了就成了悬空链接。
- **怎么练**：列一张表对比两者的「存什么 / 能否跨文件系统 / 原文件删除后 / 是否占新 inode」。

### 2025 · 优先级调度 + 单链表就绪队列 → `OS-02` `DS-02`

- **考什么**：调度算法与数据结构的交叉：用单链表实现按优先级插入。
- **坑在哪**：**插入是 $O(n)$（要找位置），选出是 $O(1)$（取表头）**。
  如果改成"每次遍历找最高优先级"，插入 $O(1)$ 但选出 $O(n)$。**题目问的是哪一边的代价，要看清楚**。
- **怎么练**：写出两种实现的插入与取出复杂度，说明各自适合什么场景。

## 四、计算机网络

### 2010 · ICMP 封装在 IP 中 → `NET-04`

- **考什么**：ICMP 的层次归属与封装。
- **坑在哪**：**ICMP 是网络层协议，但它的报文封装在 IP 数据报的数据部分**，不是独立的一层。
  同理 ARP 介于网络层与链路层之间，也常被问"属于哪层"。
- **怎么练**：写出「ICMP 报文 → IP 首部 → 以太网帧」的封装顺序，标出每层加什么。

### 2013 / 2019 · 物理层与链路层的几个"死记点" → `NET-02` `NET-03`

- **考什么**：电路交换、PPP、HDLC 零比特填充、光纤模式、交换机与冲突域。
- **坑在哪**：
  - **电路交换建立连接后独占，不分组建**；
  - **PPP 是全双工**，用**零比特填充**（HDLC 同样用零比特填充，但 PPP 是字节填充）；
  - **单模光纤用激光，多模用 LED**，单模传输距离更远；
  - **交换机是全双工，只隔离冲突域，不隔离广播域**；路由器两者都隔离。
- **怎么练**：把这五条做成一张"对不对"的判断表，每条写出反例。

### 2015 · GBN 最大发送窗口 $2^n-1$ → `NET-03`

- **考什么**：GBN 与 SR 的窗口上限。
- **坑在哪**：**GBN 是 $2^n-1$，SR 是 $2^{n-1}$**，原因是 GBN 接收窗口为 1，
  必须留一个序号用来区分"新帧"和"重传帧"。**GBN 出错重传该帧及其后所有帧**，SR 只重传出错的那一帧。
- **怎么练**：$n=3$ 时两种协议各能开多大窗口；画图说明 GBN 为什么不能用 $2^n$。

### 2018 / 2021 · 分片、复用分用、首部大小 → `NET-04` `NET-05`

- **考什么**：IP 分片规则；UDP 复用分用；TCP/UDP 首部长度。
- **坑在哪**：
  - **IP 分片的数据部分必须是 8 字节的倍数**（除最后一片），因为片偏移以 8 字节为单位；
  - **分片后只有第一片带传输层首部**；
  - **UDP 首部 8 字节，TCP 首部 20 字节**（不含选项）。
- **怎么练**：给 4000 字节的 IP 数据报、MTU 1500，算分几片、每片的数据长度与片偏移。

### 2018 · 停止-等待效率 → `NET-03`

- **考什么**：停等协议的效率公式。
- **坑在哪**：效率 $=\dfrac{1}{1+2a}$，其中 $a=\dfrac{\text{传播时延}}{\text{发送时延}}$。
  **分母是 $1+2a$ 不是 $1+a$**——一个来回是两个单程。
- **怎么练**：给带宽、帧长、距离，算出 $a$ 与效率；再换成 GBN，说明为什么窗口能提高效率。

### 2020 · 虚电路、三次握手、NAT、DNS 查询时间 → `NET-04` `NET-05`

- **考什么**：几个高频细节的综合。
- **坑在哪**：
  - **虚电路分永久（PVC）与交换（SVC）两种**；
  - **TCP 第三次握手可以携带数据**，前两次不行（此时连接未建立）；
  - **NAT 转换的是 IP 与端口**，外部看到的是路由器的地址；
  - **DNS 查询时间要含 TCP 建连**（若走 TCP）或按 UDP 单程算，题目说清楚才算。
- **怎么练**：算一次"访问网页的总时间"，把 DNS、TCP 握手、HTTP 请求/响应四段分开列。

### 2020 / 2021 · 差分曼彻斯特与编码 → `NET-02`

- **考什么**：编码规则。
- **坑在哪**：**曼彻斯特每位中间必有跳变**（自带时钟，效率 50%）；
  **差分曼彻斯特看的是"位开始处有无跳变"**（有跳变表示 0 还是 1 要按题目约定），中间仍要跳变。
  两者别混。
- **怎么练**：给比特串 `1011001`，画出两种编码的波形。

## 五、跨科综合（近年趋势）

近三年 408 越来越爱**跨科出题**（2025 年那道是 OS 调度 × 数据结构）。识别方法：

1. 题干出现"用某某结构实现某某机制"——这是两科的交界。
2. 问"复杂度"的是数据结构，问"语义/状态"的是 OS。
3. **答的时候两边都要答**：先说数据结构的代价，再说 OS 的语义，别只答一半。

**练习方式**：把 `OS-02`（进程与线程）和 `DS-02`（线性表）、`DS-03`（队列）三章的
"实现方式"各列一遍，找重叠点（就绪队列、缓冲队列、消息队列都是队列）。
