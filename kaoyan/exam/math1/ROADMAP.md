## 块1 极限的定义与存在性 ★核心（2026-10-14 展开）

### 必考点清单（先亮，刷题时对号入座）

1. 极限定义的理解（ε-N / ε-δ，去心邻域，与 f(x0) 无关）
2. 分段函数 / 含绝对值的极限存在性（求参数）
3. 判定极限不存在（归结原则：找两条路径给出不同极限）
4. 夹逼准则（和式极限：n 项求和的放大缩小）
5. 单调有界准则（递推数列 x_{n+1} = f(x_n) 的收敛与求值）
6. **无界 ≠ 无穷大**（高频陷阱）
7. 数列极限与函数极限的互推（海涅定理）

### 1.1 机制层（①）

**数列极限（ε-N）**：对任意 ε > 0，存在 N，当 n > N 时 |x_n − a| < ε。
- 直觉：a 是"最终归宿"，N 是"入场时刻"。**ε 是任给的**（对手先出牌），N 随 ε 变（你可以后选）。
- 记法：`lim_{n->∞} x_n = a`。

**函数极限（ε-δ / ε-X）**，六种过程：

| 过程 | 定义骨架 | 关键 |
|---|---|---|
| x -> x0 | 0 < |x − x0| < δ 时 |f(x) − A| < ε | **去心**，f(x0) 可无定义 |
| x -> x0+ / x0− | 单侧区间 | 左右极限 |
| x -> ∞ / +∞ / −∞ | |x| > X 时 |f(x) − A| < ε | X 随 ε 变 |

- **去心邻域是核心考点**：极限描述**趋势**，不描述取值。所以 x->x0 的极限与 f 在 x0 处**有没有定义、取什么值完全无关**。
- **存在充要条件**：`lim_{x->x0} f(x) = A` ⟺ 左极限 = 右极限 = A。
- **不存在 ≠ 发散到 ∞**：振荡（如 `(-1)^n`、`sin(1/x)` 在 x->0）也是有界但不存在。

**夹逼准则**：若 a_n ≤ x_n ≤ b_n 且两端同趋于 A，则 x_n -> A。函数版同理。

**单调有界准则**：单调递增 + 有上界（或递减 + 有下界）⟹ 收敛。
- 本质是**实数完备性**（确界存在定理）。在有理数集里不成立——单调有界的有理数列极限可以是 √2。

**海涅定理（归结原则）**：`lim_{x->x0} f(x) = A` ⟺ 对任意 x_n -> x0 且 x_n ≠ x0，都有 f(x_n) -> A。
- 主要用途：**证不存在**——找两个数列给出不同极限即可（如 x_n = 1/(2nπ+π/2) 与 1/(2nπ) 代入 sin(1/x)）。

### 1.2 设计层（②）

- **为什么要 ε 语言**：被"无穷小到底是不是 0"的争论逼出来的（贝克莱悖论）。把动态直觉翻译成静态不等式，才能**证明**而不是"看起来对"。
- **为什么去心**：为了让**可去间断点**有意义，也让导数定义 `lim_{h->0} (f(x0+h) − f(x0))/h` 在 h = 0 处 0/0 仍有极限。
- **为什么单调有界要"单调 + 有界"两条**：只有有界不够（振荡）；只有单调不够（可能跑向 ±∞）。两条合起来才把自由度锁死。
- **现实视角与边界**：这些定义在考研里主要考**概念判断题**（给四个命题选正确的），几乎不要求默写 ε-δ 证明。**边界**：证明训练只用于建立直觉，不是得分动作；得分靠题型模板。

### 1.3 验收层（③）—— 题型清单

| # | 题型 | 模板要点 | 优先级 |
|---|---|---|---|
| 1 | 概念判断（定义正误） | 四句口诀：ε 任给 / N 依赖 ε / 去心 / 与 f(x0) 无关 | ★核心 |
| 2 | 分段函数或含绝对值求参数 | 分区间去绝对值 → 写左右极限 → 令相等 → 解参数 → 回代检验 | ★核心 |
| 3 | 判定极限不存在 | 取两条路径（两个数列 / 两条直线 y = kx）得不同值 | ★核心 |
| 4 | 夹逼求和式极限 | 各项放大到最大项、缩小到最小项 → n·max 与 n·min 同极限 | ★核心 |
| 5 | 递推数列收敛并求值 | ①证有界（归纳）②证单调（作差/作商）③设极限 A 代回方程 ④由有界性选根 | ★核心 |
| 6 | 无界 vs 无穷大辨析 | 无界 = 存在子列趋于 ∞；无穷大 = 任意子列趋于 ∞ | ★核心 |
| 7 | 海涅定理应用 | 函数极限 → 数列极限（证不存在）；数列极限 → 函数极限（少考） | ☆常规 |

**易错点**：
- 把"极限不存在"直接等同于"趋于 ∞"（漏掉振荡）。
- 左右极限算对了，但忘了**回代检验**参数是否让原函数在该点有定义。
- 夹逼时两端极限不相等，等于白夹（必须同极限）。
- 递推数列只证了单调没证有界（或反之）就设极限代回 —— **缺一步整题作废**。

## 块1 随机事件与概率 ★核心（2026-10-14 展开）

### 必考点清单

1. 事件的关系与运算（并 / 交 / 差 / 对立、互斥、德摩根律）
2. 概率三公理与推导性质（减法公式、加法公式、对立）
3. 古典概型（有限等可能）：抽球、分房、配对、可重复排列
4. 几何概型（长度 / 面积 / 体积比）：会面问题、截段成三角形
5. **互斥 vs 独立的辨析**（高频陷阱）
6. 概率不等式与范围估计（P(AB) 的上下界）

### 1.1 机制层（①）

**公理（柯尔莫哥洛夫）**：非负性 P(A) ≥ 0；规范性 P(Ω) = 1；**可列可加性**——两两互斥的事件之并，概率等于概率之和。
- 直觉：概率就是给样本空间 Ω 的子集**分配面积**，总面积 1。

**事件运算 ↔ 集合运算 ↔ 逻辑**：并 = 或、交 = 且、对立 = 非、差 A−B = A 发生且 B 不发生。
- **德摩根律**：`∪Aᵢ` 的对立 = `∩Āᵢ`；`∩Aᵢ` 的对立 = `∪Āᵢ`。（"都不发生" = "至少一个发生"的反面）

**四条常用公式**（由公理推出，必须能默写）：
- 对立：P(Ā) = 1 − P(A)
- 减法：P(A − B) = P(A) − P(AB)　（A−B 与 AB 是 A 的一个划分）
- 加法：P(A∪B) = P(A) + P(B) − P(AB)　（AB 被数了两遍）
- 三事件：P(A∪B∪C) = P(A)+P(B)+P(C) − P(AB) − P(BC) − P(CA) + P(ABC)

**互斥 vs 独立**（本块最大陷阱）：

| | 定义 | 性质 |
|---|---|---|
| 互斥 | AB = ∅（集合关系，与概率值无关） | P(A∪B) = P(A)+P(B) |
| 独立 | P(AB) = P(A)P(B)（概率关系） | 独立时 P(A|B) = P(A) |

- **互斥且 P(A), P(B) > 0 ⟹ 必不独立**：因为 P(AB) = 0 ≠ P(A)P(B) > 0。"互斥"说的是不能同时发生，"独立"说的是互不影响——恰恰相反。

**古典概型**：样本点有限且等可能，P(A) = |A| / |Ω|。计数工具：组合（不放回）、可重复排列（有放回 / 分房）、多项式系数（分组）。
- **判别手势**：先问"什么是等可能的基本结果"——分房问题里基本结果是"每个球的落点序列"（N^n 种），不是"各盒球数的分布"。

**几何概型**：P(A) = A 的测度 / Ω 的测度（长度、面积、体积）。
- **前提**：必须是对**几何测度均匀**——否则会掉进贝特朗悖论。真题里的"随机"默认对长度/面积均匀。

### 1.2 设计层（②）

- **为什么要公理化**：古典概型只能处理有限等可能；几何概型里"随机"的含义不唯一（贝特朗悖论给出 1/2、1/3、1/4 三个答案）。公理体系把"概率是什么"变成"概率必须满足什么"，才谈得上推定理。
- **为什么加法公式要减 P(AB)**：容斥原理——交集在两边各被数了一次。三事件公式就是容斥的二阶展开，规律是"奇加偶减"。
- **为什么强调"零概率事件 ≠ 不可能事件"**：连续场景下取到某一点的概率是 0，但它可能发生（几何概型里每个点概率都是 0，可总有一个点被取到）。这条是概念判断题的固定弹药。
- **现实视角与边界**：公理体系本身考研只在**概念判断题**里出现，不要求默写证明；得分动作是套公式与计数。

### 1.3 验收层（③）—— 题型清单

| # | 题型 | 模板要点 | 优先级 |
|---|---|---|---|
| 1 | 用运算表示事件 / 德摩根化简 | "至少一个" = 1 − "全不"；"恰好一个" 分情况加 | ★核心 |
| 2 | 给 P(A)、P(B)、P(A∪B) 或 P(A−B) 推其他 | 先求 P(AB) = P(A)+P(B)−P(A∪B)，再用减法公式 | ★核心 |
| 3 | 独立性验证 | **必须算 P(AB) 与 P(A)P(B) 比数值**，不能凭"看起来无关" | ★核心 |
| 4 | 古典概型计数 | 先定基本结果空间（等可能的是什么）→ 有利数 / 总数 | ★核心 |
| 5 | 几何概型 | 画区域 → 面积比 → 定积分或初等几何算面积 | ★核心 |
| 6 | 概率范围估计 | 0 ≤ P(AB) ≤ min(P(A),P(B))；P(A∪B) ≤ P(A)+P(B) | ☆常规 |

**易错点**：
- 独立性**不验证**就下结论（数值接近但不是相等，照样不独立）。
- 分房问题用错样本空间（把"每盒球数的组合"当基本结果 → 不等可能，全错）。
- 减法公式写成 P(A−B) = P(A) − P(B)（漏掉 AB，只有 B⊂A 时才对）。
- "互斥"和"独立"混为一谈（互斥是更强的"不相容"，与独立几乎对立）。
