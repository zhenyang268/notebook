## 二、正文

### 2.1 线性表的逻辑特征与接口语义

线性表是 $n$ 个**同类型**数据元素的有限序列。逻辑上的硬约束只有两条：有唯一的首元素和唯一的尾元素；除首尾外，每个元素有且仅有一个直接前驱和一个直接后继。它解决的是“按位置访问”这件事的抽象：一旦把“第 $i$ 个”抽象成接口，底下是数组还是结点链，上层算法就不用管了。

必须背准的是接口的参数合法域，因为两种存储实现下它不同：

- `GetElem(L, i, &e)`：$1 \le i \le n$；
- `ListInsert(L, i, e)`：$1 \le i \le n+1$，允许插在表尾之后；
- `ListDelete(L, i, &e)`：$1 \le i \le n$。

同一句“在第 $i$ 个位置插入”，顺序表凭下标直接定位，链表却要先走 $i-1$ 步找到前驱，这个差别正是整章的分水岭。

### 2.2 顺序表：随机访问的代价

顺序表用一段连续单元存放元素，逻辑相邻即物理相邻。设每个元素占 $L$ 个单元，则

$$LOC(a_i) = LOC(a_1) + (i-1)L$$

下标到地址是等值计算，与 $n$ 无关，故存取为 $O(1)$，这就是**随机访问**（直接存取）。代价落在增删上：插入第 $i$ 个元素前需把 $a_i \sim a_n$ 整体后移，移动次数 $n-i+1$；删除第 $i$ 个元素需把 $a_{i+1}\sim a_n$ 前移，移动次数 $n-i$。

设 $n+1$ 个插入位置等概率，则插入的平均移动次数为

$$E_{\text{ins}} = \frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1) = \frac{1}{n+1}\cdot\frac{(n+1)(n+2)}{2} = \frac{n+2}{2}$$

删除时 $n$ 个位置等概率：

$$E_{\text{del}} = \frac{1}{n}\sum_{i=1}^{n}(n-i) = \frac{n-1}{2}$$

按量级统一记作插入 $\frac{n}{2}$、删除 $\frac{n-1}{2}$，都是 $O(n)$。这也解释了为什么顺序表“查多改少”才划算：$n=8$ 时一次插入平均挪 5 个元素，插入到表头要挪满 8 个。

**扩容**：容量满时申请一块更大的连续空间（通常翻倍）并整体复制，单次 $O(n)$，但连续 $n$ 次尾插总代价与 $n$ 同阶，均摊 $O(1)$。注意扩容后首地址改变、旧空间必须释放，且顺序表整体长度上限受连续空间限制。

### 2.3 链表：用指针换移动

单链表结点为 `data | next`，逻辑相邻靠指针建立，物理位置任意。

**头结点的作用**是本章第一个必答点：它使空表与非空表结构一致，插入/删除首元素时不必修改头指针本身，从而把“在 $p$ 后插入”“删除 $p$ 的后继”这类操作的边界情况消掉；判空条件变为 `L->next == NULL`（带头结点）而非 `L == NULL`。代价是浪费一个结点、表长计算与遍历都从 `L->next` 起。

**插入与删除的指针次序**必须能自己写出。在 $p$ 之后插入 $s$：

```
s->next = p->next;  p->next = s;
```

两行交换就断链——先执行 `p->next = s` 会丢掉 $p$ 原后继。删除 $p$ 的后继 $q$：`p->next = q->next; free(q);`。这两个操作本身 $O(1)$，但“找到 $p$”要 $O(n)$，所以按位插入删除整体仍是 $O(n)$。

**双链表** `prev | data | next`：在 $p$ 后插入 $s$ 要改四个指针，次序原则是“先让新结点接好两边，再改老结点”：

$$s\text{->next}=p\text{->next};\quad p\text{->next->prev}=s;\quad s\text{->prev}=p;\quad p\text{->next}=s$$

删除 $p$ 时 `p->prev->next = p->next; p->next->prev = p->prev;`，两条语句顺序无所谓，但都必须用 $p$ 自己的指针去改邻居，不能先 `free(p)`。双链表的价值就是 $O(1)$ 拿到前驱，这是单链表给不了的。

**循环链表**：尾结点 `next` 指回头结点，判尾条件是 `p->next == L`。单循环链表最大的好处是从任一结点出发都能遍历全表，因此“只知道 $p$，删 $p$”这类题才成立（先绕一圈找到 $p$ 的前驱）。**静态链表**用数组模拟，`next` 存下标，用 $-1$ 或 $0$ 表示终止，适合不支持指针的场合，插入删除仍靠改下标。

三个高频指针技巧的推导要会：

- **逆置**：三指针 `pre = NULL, cur = L->next`，循环体 `nxt = cur->next; cur->next = pre; pre = cur; cur = nxt;`，走完 `L->next = pre`。时间 $O(n)$、空间 $O(1)$。
- **快慢指针**：`slow` 每步 1、`fast` 每步 2。有环时两者相对速度为 1，环长有限，故必相遇且最多走一圈。设头到入口长 $a$、入口到相遇点长 $b$、环长 $r$，则 $a+b$ 与 $2(a+b)$ 相差整数圈：$a+b+kr = 2(a+b)$，得 $a = (k-1)r + (r-b)$——所以相遇后一个指针回到头，两指针同速前进，再遇即为环入口。
- **倒数第 $k$ 个**：先让 $p$ 走 $k$ 步，再让 $p,q$ 同步走；$p$ 到尾时 $q$ 与尾相距 $k$，正好指向倒数第 $k$ 个。总时间 $O(n)$、一趟完成，优于“先求长度再走 $n-k$ 步”的两趟。

### 2.4 串与模式匹配

串是元素限定为字符的线性表，存储分定长顺序、堆分配（`malloc` 按实际长度分配）和块链三种。匹配问题：在 $S$ 中找 $P$ 首次出现的位置。

**朴素匹配**失配后 $i$ 回退到 $i-j+2$、$j$ 回到 1，主串指针反复回溯，最坏 $O(nm)$，例如 $S=\texttt{aaaab}$、$P=\texttt{aaab}$ 时前面每个位置都要比到第 4 个字符才失配。

**KMP 的核心观察**：失配时 $S[i-j+1 \sim i-1] = P[1\sim j-1]$ 已经比对成功，这段信息完全已知，所以主串指针 $i$ 不必回退，只需把 $j$ 退到某个 $k$，使 $P[1\sim k-1]$ 恰好等于刚才那段的后缀。而“那段的后缀”又等于 $P[1\sim j-1]$ 的后缀，于是 $k$ 只由模式串自己决定：

$$P[1\sim k-1] = P[j-k+1 \sim j-1]$$

即 $k-1$ 是 $P[1\sim j-1]$ 的**最长相等前后缀长度**。把这个长度记作 $\pi(j-1)$，则 1-based 约定下

$$next[j] = \pi(j-1) + 1,\qquad next[1] = 0$$

失配时执行 $j = next[j]$；若 $j$ 退到 0，说明模式串首字符也不匹配，$i$、$j$ 同时后移一位。求 $next$ 的过程是对模式串自己做一次 KMP，故总时间 $O(n+m)$。

**nextval 的优化依据**：若回退后 $P[j] = P[next[j]]$，那么这一位必然再次失配，回退没有意义，可直接继承：

$$nextval[j] = \begin{cases} nextval[next[j]], & P[j] = P[next[j]] \\ next[j], & \text{否则} \end{cases}$$

**三套约定**是本章最容易被扣分的地方：$\pi$ 的定义（长度）唯一，但写进数组时有 1-based（$next[1]=0$）、0-based（$next[0]=-1$）与“教材版”整体加 1 三种写法，彼此只差一个常数。做题第一步先看模式串下标从 0 还是 1 起，第二步看题目给的 $next[1]$ 是 0 还是 1，确认后用 $\pm 1$ 整体换算，不要重推。

### 例题

**例 1（顺序表平均移动次数，$n=8$）** 长度为 8 的顺序表，等概率在 9 个合法位置插入。

在第 $i$ 个位置（$1\le i\le 9$）插入，需把原来第 $i$ 到第 8 个元素后移一位，移动次数 $8-i+1$。总移动次数

$$\sum_{i=1}^{9}(9-i)=8+7+\cdots+1+0=36$$

平均移动 $36/9=4=\dfrac{n}{2}$。若在第 3 个位置插入，则移动 $8-3+1=6$ 个元素。

删除同理：删第 $i$ 个（$1\le i\le 8$）移动 $8-i$ 次，总和 $7+6+\cdots+1+0=28$，平均 $28/8=3.5=\dfrac{n-1}{2}$。这两个数说明：顺序表插入删除是 $O(n)$ 的，代价全在“搬元素”上。

**例 2（单链表就地逆置）** 表 $1\to2\to3\to4$，用三指针 `pre/p/q`。

| 轮次 | 操作 | 结果 |
|---|---|---|
| 初始 | `pre=NULL, p=①` | — |
| 1 | `q=p->next`（②）；`p->next=pre`（①→NULL）；`pre=p`；`p=q` | NULL←①，p=② |
| 2 | `q=③`；②→①；`pre=②`；`p=③` | ①←② |
| 3 | `q=④`；③→②；`pre=③`；`p=④` | ②←③ |
| 4 | `q=NULL`；④→③；`pre=④`；`p=NULL` | ③←④ |

退出后头结点指向 `pre`，得 $4\to3\to2\to1$。关键次序必须是“先存 `q=p->next`，再改 `p->next`”，否则断链。

**例 3（快慢指针）** $n=7$，`slow` 每轮 1 步、`fast` 每轮 2 步，同起点于①：

第 1 轮 $\text{slow}=②,\text{fast}=③$；第 2 轮 $③,⑤$；第 3 轮 $④,⑦$；此时 `fast->next==NULL`，停，`slow` 在第 4 个，即 $\lceil n/2\rceil$ 个（偶数 $n=6$ 时收敛到第 $\frac n2+1$ 个）。若让 `fast` 先走一步再同步，则 $n=7$ 得第 4 个、$n=6$ 得第 3 个——**起点约定不同结果差一位**，答题必须写清初值。

**例 4（倒数第 $k$ 个）** $n=8,k=3$，目标是第 $8-3+1=6$ 个。`q` 先走 $k-1=2$ 步到第 3 个；然后 `p`、`q` 同步，走 5 步后 `q` 到第 8 个（表尾），`p` 到第 $1+5=6$ 个，正确。总步数 $2+5=7=n-1$，一趟扫描。

**例 5（合并两有序链表）** $A:1\to4\to9$，$B:2\to3\to10$。每次取较小者尾插，比较序列为 $1{:}2,4{:}2,4{:}3,4{:}10,9{:}10$，得 $1\to2\to3\to4\to9\to10$；某表扫完后把另一表余段整段挂上，时间 $O(m+n)$，辅助空间 $O(1)$。

**例 6（KMP 的 next / nextval）** 取 $P=\texttt{ababaa}$，下标从 1 起。按 $\text{next}[j]=\pi[j-1]+1$（$\pi$ 为 $P[1..j-1]$ 的最长相等前后缀长度），$\text{next}[1]=0$：

- $j=2$：$P[1..1]=\texttt{a}$，$\pi=0\Rightarrow \text{next}[2]=1$
- $j=3$：$\texttt{ab}$，$\pi=0\Rightarrow 1$
- $j=4$：$\texttt{aba}$，$\pi=1(\texttt{a})\Rightarrow 2$
- $j=5$：$\texttt{abab}$，$\pi=2(\texttt{ab})\Rightarrow 3$
- $j=6$：$\texttt{ababa}$，$\pi=3(\texttt{aba})\Rightarrow 4$

得 $\text{next}=0,1,1,2,3,4$。

`nextval` 递推：$\text{nextval}[1]=0$；若 $P[j]=P[\text{next}[j]]$ 则 $\text{nextval}[j]=\text{nextval}[\text{next}[j]]$，否则取 $\text{next}[j]$。逐位算：$j=2$：$P[2]=\texttt{b}\ne P[1]=\texttt{a}\Rightarrow 1$；$j=3$：$\texttt{a}=\texttt{a}\Rightarrow \text{nextval}[1]=0$；$j=4$：$\texttt{b}=\texttt{b}\Rightarrow \text{nextval}[2]=1$；$j=5$：$\texttt{a}=\texttt{a}\Rightarrow \text{nextval}[3]=0$；$j=6$：$P[6]=\texttt{a}\ne P[4]=\texttt{b}\Rightarrow 4$。即 $\text{nextval}=0,1,0,1,0,4$。

三套约定的换算是同一张表的平移：设 $\pi[j]$ 为含 $P[j]$ 的前缀函数（$\pi=0,0,1,2,3,1$ 对 $j=1..6$），则

$$\text{next}_{\text{教材}}[j]=\pi[j-1]+1\ (j\ge2),\quad \text{next}_{0\text{起}}[j]=\text{next}_{\text{教材}}[j]-1,\quad \text{next}_{\pi}[j]=\pi[j]$$

例如 $j=6$：教材 $4$，0 起下标 $-1$ 约定下为 $3$，$\pi$ 表为 $1$，三者可互推。

失配后的右移量就是 $j-\text{next}[j]$：若已匹配 5 个字符而在 $P[6]$ 失配，移动 $6-4=2$ 位；若在 $P[3]$ 失配，移动 $3-1=2$ 位。朴素匹配在同样情形下最坏要退 $5$ 位，这正是 KMP 把 $O(nm)$ 压到 $O(n+m)$ 的地方。

## 三、真题落点

- 2021#1 选择：头指针 `h` 指向带头结点的非空单循环链表，判断 `p` 所指位置。考的是“头结点不存数据、`h->next` 才是首元结点”以及循环链表“尾结点 `next` 指回头结点”这一步，纯指针关系判定，不涉及移动。
- 2023#1 选择：长度为 $n$ 的顺序存储有序表各操作的平均时间。考的是把顺序表插入 $\frac n2$、删除 $\frac{n-1}2$ 的平均移动次数与随机访问 $O(1)$、按值查找 $O(\log n)$（二分）区分开这一步。
- 2023#2 选择：非空双向链表 `L`，结点 `prev|data|next` 的插删。考的是双链表改写指针的**先后次序**这一步：先接新结点的两个指针，再改前驱的 `next`，最后改后继的 `prev`。
- 2024#1 选择：单链表结点移动。考的是“链表插入删除只改指针、不搬元素，而顺序表要搬 $\frac n2$ 个元素”这一步的对比。
- 2024#6 选择：KMP 的最大滑动距离。考的是失配后 $j$ 回退到 $\text{next}[j]$、模式串右移 $j-\text{next}[j]$ 这一步，需要先按本章约定把 `next` 数组算对。

## 四、易错清单

1. 算顺序表插入平均移动时把位置数取成 $n$ → 合法插入位置有 $n+1$ 个，分母是 $n+1$，插入平均 $\frac n2$，删除平均 $\frac{n-1}2$，两者不能混。
2. 逆置时先写 `p->next=pre` 再取后继 → 必须先 `q=p->next` 存住后继，再改 `p->next`，最后 `pre=p; p=q`，否则后半条链丢失。
3. 快慢指针默认初值不声明 → 同起点时偶数 $n$ 收敛到第 $\frac n2+1$ 个，先让 `fast` 走一步则收敛到第 $\frac n2$ 个；答题时写明初值和循环条件 `fast && fast->next`。
4. 倒数第 $k$ 个让 `q` 先走 $k$ 步 → 应先走 $k-1$ 步，使同步结束时 `q` 停在表尾结点，`p` 恰为第 $n-k+1$ 个；走 $k$ 步会得到倒数第 $k-1$ 个。
5. 求 `next` 时把 $\pi[j]$（含 $P[j]$ 自身）当成 $\pi[j-1]$ → 教材 `next` 用的是 $P[1..j-1]$ 的最长相等前后缀长度 $+1$，且规定 $\text{next}[1]=0$。
6. 三套约定混用后直接套右移公式 → 先统一到同一约定再算 $j-\text{next}[j]$；0 起下标约定比教材约定整体小 1，$\pi$ 表与教材 `next` 差一个“加 1 后移一位”。
7. 双链表插入只改前驱 `next` 不改后继 `prev` → 四条指针（新结点 2 条、前驱 `next`、后继 `prev`）一条不能少，且后继 `prev` 要最后改前先判后继是否为空。
