## 二、正文

### 1. 基本概念

操作系统是管理硬件与软件资源、为用户和程序提供抽象与接口的系统软件。需要它，是因为裸机难用、资源会竞争、程序之间要隔离：OS 把 CPU 抽象成进程/线程，把内存抽象成地址空间，把设备抽象成文件或设备接口。

四大特征要能互相解释：**并发**是多个程序在同一时间间隔内交替推进；**共享**是资源可被多个并发程序共同使用；**虚拟**是把一个物理资源变成多个逻辑资源，如虚拟处理器、虚拟内存；**异步**是进程以不可预知速度推进，走走停停。资源管理包括处理机、存储器、文件、设备管理；用户接口包括命令接口、图形接口和系统调用。

推导多道程序的重叠效果。设每个作业 CPU 时间 $C$、I/O 时间 $I$，顺序执行 $n$ 个作业：
$$T_s=n(C+I)$$
若单 CPU、I/O 可并行，三作业 $C=10\text{ ms}, I=40\text{ ms}$，时间轴为：P1 CPU 0–10，P2 CPU 10–20，P3 CPU 20–30；P1 I/O 10–50，P2 I/O 20–60，P3 I/O 30–70，故 $T_m=70\text{ ms}$，而 $T_s=3\times50=150\text{ ms}$，加速比 $150/70\approx2.14$。注意单 CPU 同一时刻只有一个进程真正运行，这是并发不是并行。

### 2. 发展与分类

批处理系统解决“减少人工干预、提高吞吐量”，但交互性差；分时系统把 CPU 切成时间片轮转，解决“多用户交互响应”；实时系统强调截止期，硬实时不能错过，软实时可容忍偶尔超时；网络系统解决多机通信与资源共享；分布式系统让多台机器像一台一样协同；个人系统强调易用性。

分时系统可算最坏响应。设 $n$ 个用户、时间片 $q$，某用户最坏等待 $(n-1)q$，响应时间不超过：
$$T_{\text{resp}}\le nq$$
取 $n=50,q=20\text{ ms}$，最坏等待 $49\times20=980\text{ ms}$，响应约 $1000\text{ ms}$；若 $q=10\text{ ms}$，等待约 $490\text{ ms}$，响应约 $500\text{ ms}$。时间片越小响应越好，但切换开销占比上升。

### 3. 运行环境

CPU 用模式位区分**内核态**与**用户态**。特权指令只能在内核态执行，如 I/O 指令、关中断、修改 PSW、停机、装页表基址、切换栈指针等；普通算术、访存、访管指令可在用户态执行。访管指令的作用是主动陷入内核，不是特权指令。

中断是外部异步事件，如时钟、I/O 完成；异常是当前指令同步引起的，分为 fault（缺页，处理后重执行）、trap（系统调用/断点，处理后执行下一条）、abort（严重错误）。处理过程：保存 PC/PSW，按中断号查中断向量表，跳转处理程序，返回时恢复现场。中断向量表适合用数组：向量号作下标，$O(1)$ 取得入口地址。

系统调用全过程：用户程序准备参数和系统调用号 → 执行访管/trap 指令 → CPU 切内核态并保存现场 → 内核按系统调用号查分派表 → 执行服务例程 → 恢复现场并返回用户态。需要系统调用，是因为用户态不能直接操作设备、改页表、创建进程。

链接与装入：源程序经编译/汇编成目标模块，链接器完成符号解析与重定位，形成可执行文件；装入器把可执行文件放入内存。静态链接在装入前完成，动态链接可推迟到装入时或运行时。内存映像通常含代码段、数据段、BSS、堆、栈、共享库映射；地址空间是逻辑地址集合，MMU 把它翻译成物理地址。

设页大小 $4\text{ KB}=2^{12}$，则页内偏移 12 位：
$$\text{页号}=\left\lfloor \frac{LA}{2^{12}}\right\rfloor,\quad \text{偏移}=LA\bmod 2^{12}$$
若 $LA=0x0000A3F5$，页号 $0xA3=163$，偏移 $0x3F5=1013$；若装入帧号 $0x2B$，则
$$PA=0x2B\times2^{12}+0x3F5=0x2B3F5$$

### 4. 体系结构

宏内核把进程管理、内存管理、文件系统、驱动等大多放进内核，调用路径短，性能好，但内核大、故障隔离差。微内核只保留最基本机制，文件系统、驱动等作为用户态服务，靠 IPC 通信，可靠性、可扩展性好，但切换与通信开销大。分层结构按层次调用，便于调试；模块化按功能模块动态加载；外核把硬件资源直接暴露给用户态库 OS，减少抽象层。

比较一次服务调用。设一次模式切换 $1000$ 周期，一次 IPC $2000$ 周期，服务本身 $3000$ 周期。宏内核约：
$$1000+3000=4000$$
微内核若经“用户→内核→服务→内核→用户”两次 IPC：
$$4\times1000+2\times2000+3000=11000$$
比值 $11000/4000=2.75$。所以“微内核性能一定更好”是错的；它换来的是隔离与可靠性。

### 5. 引导与虚拟机

引导流程：加电 → 固件 POST 自检 → 按启动顺序读引导设备 → 引导加载程序 → 装入内核 → 内核初始化 → 创建第一个用户进程/init。以 MBR 为例，一个扇区 $512$ 字节，其中引导代码最多 $446$ 字节，分区表 $4\times16=64$ 字节，结尾签名 $2$ 字节：
$$446+64+2=512$$
所以首扇区放不下大型引导程序时，需要多级引导。

虚拟机中 VMM/hypervisor 负责虚拟 CPU、内存、设备，并截获 guest 的特权指令。第一类虚拟机直接运行在硬件上；第二类运行在宿主 OS 上。VMM 的作用是隔离 guest、模拟特权操作、转换地址。例：guest 执行关中断指令，VMM 陷入并模拟；guest 的 $GVA$ 先经 guest 页表成 $GPA$，再经 EPT/影子页表成 $HPA$，如 $0x1000\to0x3000\to0x8000$。

## 三、真题落点

- 2021#23 选择：只能在内核态执行的指令是。考的是特权指令判定：I/O、关中断、改 PSW、停机等只能内核态执行。
- 2021#32 选择：通过系统调用完成的操作是。考的是用户态不能直接完成的资源操作，必须经内核服务。
- 2022#23 选择：关于多道程序系统，不正确的是。考的是多道程序下并发、共享、异步特征及 CPU 与 I/O 重叠。
- 2022#24 选择：需要在操作系统初始化过程中创建的是。考的是引导后内核初始化建立的对象与用户程序运行时对象的区分。
- 2022#27 选择：关于 CPU 模式，正确的是。考的是内核态/用户态切换条件、特权指令执行位置。
- 2022#31 选择：执行系统调用过程由操作系统完成的是（ ）Ⅰ 保存。考的是系统调用全过程中现场保存、查表、服务执行、恢复现场的分工。
- 2023#23 选择：与宏内核相比，微内核具有的是（ ）Ⅰ 较好性能。考的是微内核可靠性/性能权衡，不能把“较好性能”当必然。
- 2023#24 选择：内核中中断向量表适合的数据结构是。考的是按中断号随机索引，数组可 $O(1)$ 定位入口。

## 四、易错清单

- 把并发当并行 → 单 CPU 同一时刻只有一个进程运行；用时间轴画 CPU 与 I/O 重叠，别直接说“同时运行”。
- 把系统调用当普通函数调用 → 系统调用要执行 trap、切内核态、换栈、保存 PSW/PC；按“准备参数→陷入→查分派表→返回”写。
