## 二、正文

### 408-CO-0101 发展历程

四代划分的依据只有一个：**构成计算机的电子元器件**。第一代电子管（ENIAC）、第二代晶体管、第三代中小规模集成电路、第四代大规模与超大规模集成电路。软件、操作系统、指令集的变化都是这一硬件代际更替的**结果**，不是划分依据；选择题常把“操作系统的出现”“高级语言的出现”塞进划分标准里干扰。

摩尔定律是对集成度的经验描述：**价格不变时，集成电路上可容纳的晶体管数目约每 18～24 个月翻一番**。它可由“成本约束”“物理极限”两方面说明，并不是物理定律。

**最小例子**：Intel 4004（1971 年）约 2300 个晶体管。按 24 个月翻一番，到 2015 年经过 $44/2=22$ 个周期，应有

$$2300 \times 2^{22} = 2300 \times 4.19\times10^{6} \approx 9.6\times10^{9}$$

即约 96 亿个晶体管。实际 2015 年单芯片在 $7\times10^9$ 量级，数量级吻合；这说明摩尔定律是**趋势公式，不是精确公式**，近十年周期已明显拉长到 3 年以上。

**软件硬件化**指的是把原本由软件（指令序列）完成的功能，下移到硬件或固件实现。典型链条如下：乘法从“用加法和移位循环实现”变成乘法指令，再变成专用乘法器；浮点运算从库函数变成协处理器；Cache 替换策略由硬件自动完成；图形与矩阵运算从 CPU 循环变成 GPU 与专用加速器。固件（存放在 ROM 中的微程序）是中间形态：它由硬件执行，但逻辑上仍可修改。

硬件化的动因是：硬件更便宜、并行度更高、单位运算能耗更低。这是理解后面 CISC 与 RISC、流水线、加速器的关键背景。

### 408-CO-0102 层次结构

冯·诺依曼结构出自 1945 年 EDVAC 报告，**五大部件**为运算器、控制器、存储器、输入设备、输出设备。其核心思想是**存储程序**：把编好的程序和原始数据事先送入主存，机器便能自动逐条取指、执行，无需人工干预。

由“存储程序”派生出五条要点：

1. 计算机由五大部件组成；
2. **指令和数据以同等地位存于同一存储器，都按地址访问**；
3. 指令和数据都用二进制表示；
4. 指令由操作码和地址码组成，操作码指出操作性质，地址码指出操作数位置；
5. 指令在存储器内按顺序存放，通常顺序执行，特定条件下可跳转。

第 2 条最容易被曲解。CPU 并不靠“长得不一样”来区分指令与数据，两者在存储器里都只是一串 0 和 1，**区分只发生在时序上**：取指周期从 PC 给出的地址取出的就是指令，执行周期由指令的地址码算出的地址取出的就是数据。这也是“同一段代码可以被当作数据读取，同一段数据可以被当作代码执行”这句常考表述的来源。

原始冯机**以运算器为中心**：输入输出设备与存储器之间的数据传送要经过运算器，运算器成为瓶颈。现代计算机改为**以存储器为中心**，输入输出与存储器之间可以直接传送，即 DMA 的思路。

**多级层次结构**（自下而上）：

- M0 微程序机器级：由硬件直接执行微指令，是纯硬件层。
- M1 传统机器级（机器语言级）：机器指令由微程序解释执行。
- M2 操作系统级：机器指令加系统调用（广义指令），系统调用由操作系统解释。
- M3 汇编语言级：汇编程序把它翻译成 M1 或 M2 的代码。
- M4 高级语言级：编译程序把它翻译成 M3 或 M1 的代码。
- M5 应用语言级：由应用程序解释执行。

两个关键判断：M0 与 M1 属于硬件、固件，M2 及以上属于软件；**翻译**一次生成完整的目标程序（编译、汇编），**解释**逐条边转换边执行（微程序解释机器指令、操作系统解释系统调用、解释型语言）。层次越低越接近硬件、执行越快、可移植性越差。

**编译、汇编、链接的位置**：

```
源程序 .c --[预处理]--> .i --[编译]--> .s 汇编 --[汇编]--> .o 目标文件
          --[链接]--> 可执行文件 --[装入]--> 主存
```

- 编译程序：高级语言源程序 → 汇编语言源程序，属 M4 到 M3 的翻译；
- 汇编程序：汇编源程序 → 机器语言目标文件，属 M3 到 M1 的翻译，此时外部符号地址尚未确定；
- 链接程序：把多个目标文件与库合并，完成符号解析与重定位，生成可执行文件。

三者都运行在 M2 之上，都是**软件**，不是体系结构的一部分。

**最小例子**：`c = a + b;`（a、b、c 为 int 型全局变量）。编译后得到 `mov eax,[a]` / `add eax,[b]` / `mov [c],eax` 三条汇编；汇编后变成三条机器指令，add 指令的机器码形如 `03 05 xx xx xx xx` 共 6 字节，其中 a、b、c 的地址写成待重定位符号；链接后把 a、b、c 的虚拟地址（比如 `0x404020`）填实。这里要记住的结论是：**一条高级语言语句 ≠ 一条机器指令**，后面算 CPI 时 $N$ 一律指机器指令条数，而不是源程序语句数。

### 408-CO-0103 性能指标

**字长**要分四种：机器字长（CPU 一次整数运算能处理的位数，等于 ALU 宽度与通用寄存器位数，决定数的表示范围与精度）、指令字长（一条指令的二进制位数，通常为字节的整数倍，可定长可变长）、存储字长（一个存储单元存放的位数）、数据字长。主存容量由“存储单元数 × 存储字长”决定，**与机器字长没有直接关系**。

**时钟与 CPI**。设主频为 $f$，时钟周期 $T_{clk}=1/f$，程序共含 $N$ 条机器指令，平均每条指令需 $CPI$ 个时钟周期，则

$$T_{cpu} = N \times CPI \times T_{clk} = \frac{N \times CPI}{f}$$

这是本章唯一的核心公式，其余公式都由它变形而来。混合指令流的 CPI 必须**按比例加权**：

$$CPI = \sum_i CPI_i \cdot p_i,\qquad \sum_i p_i = 1$$

等价写法是先算总周期数 $C=\sum_i CPI_i N_i$，再取 $CPI=C/N$。

**IPS、MIPS**：

$$MIPS=\frac{N}{T_{cpu}\times10^6}=\frac{f}{CPI\times10^6}$$

若 $f$ 以 MHz 代入，则 $MIPS=f(\text{MHz})/CPI$。**MFLOPS** 换成浮点运算次数：$MFLOPS=N_{flop}/(T\times10^6)$；$1\,\text{PFLOPS}=10^{15}\,\text{FLOPS}$，是十进制词头，不是 $2^{50}$。

**例题 3.1** 主频 2 GHz，程序 $10^8$ 条指令，CPI = 1.5。

$$T_{cpu}=\frac{10^8\times1.5}{2\times10^{9}}=0.075\ \text{s}=75\ \text{ms},\qquad MIPS=\frac{2000}{1.5}=1333.3$$

若主频提到 2.5 GHz，但 CPI 因流水线加深涨到 1.8：

$$T'=\frac{10^8\times1.8}{2.5\times10^{9}}=0.072\ \text{s},\qquad \frac{T_{cpu}}{T'}=\frac{0.075}{0.072}=1.042$$

主频提高 25%，实际只快 4.2%，可见“主频高就快”并不成立。

**例题 3.2（加权 CPI）** 指令分三类：A 占 40%、CPI = 1；B 占 30%、CPI = 2；C 占 30%、CPI = 4。$N=1.5\times10^6$，$f=1.5$ GHz。

$$CPI=0.4\times1+0.3\times2+0.3\times4=0.4+0.6+1.2=2.2$$

$$T_{cpu}=\frac{1.5\times10^6\times2.2}{1.5\times10^{9}}=2.2\times10^{-3}\ \text{s}=2.2\ \text{ms},\qquad MIPS=\frac{1500}{2.2}\approx681.8$$

## 三、真题落点

**2021 #12 选择：考的是「浮点运算速度」的单位换算这一步。** 把「每秒浮点运算次数」按 $10^3$ 逐级进位（K→M→G→T→P），再与主频、核数、每周期浮点操作数相乘的结果对照，判断 93.014 该配哪个量级单位。落点在换算式 $1\,\text{PFLOPS}=10^{15}\,\text{FLOPS}$，不在硬件结构。

**2022 #12 选择：考的是 CPI 与执行时间的串联这一步。** 主频 1GHz、执行 10000 条指令，路径是「指令条数 → 时钟周期数（乘 CPI）→ 执行时间（除主频）」。落点有两个：一是 $1\,\text{G}=10^9$ 而非 $2^{30}$；二是先乘 CPI 再除主频的次序不能颠倒，否则算出的既不是周期数也不是时间。

**2023 #12 选择：考的是同一串联式的反向使用与单位对齐这一步。** 主频 1.5GHz、执行 $5\times10^{5}$ 条指令，通常要落回 $T=\dfrac{N\times \text{CPI}}{f}$ 或由 $T$ 反求 CPI/MIPS。落点在 $1/f\approx 0.667\,\text{ns}$ 这个每周期时间，以及把结果从秒改写成 ns/μs 时指数不能错位。

## 四、易错清单

1. **错在把 $1\,\text{GHz}$ 当作 $2^{30}\,\text{Hz}$ →** 主频、传输率一律用 $10^9$；只有存储容量、编址单元数才用 $2^{30}$。写式子时先在旁边标一行「$1\text{G}=10^9$」再代数字。
2. **错在把 $T=N/f$ 当公式直接套 →** 必须先算时钟周期数 $C=N\times \text{CPI}$，再 $T=C/f$。缺 CPI 时先由题给条件反求 CPI，不许默认 CPI$=1$。
3. **错在 MIPS 与 CPI 互为倒数 →** 正确关系是 $\text{MIPS}=\dfrac{f(\text{MHz})}{\text{CPI}}$。代入前把主频先化成 MHz，算完检查量级是否落在几十到几千之间。
4. **错在浮点速度换算时混用 $1024$ →** FLOPS 体系一律 $10^3$ 进级，$93.014$ 后面接的单位要与 $10^{15}$ 这类指数严格对应，不能把 PFLOPS 当 $2^{50}$。
5. **错在结果位数随手补零 →** 题目给 93.014（五位有效数字）就按五位对齐，多留或少留都算错；中间量至少保留一位多余位，最后一步再舍。
6. **错在用「主频提高一倍，时间减半」直接下结论 →** 这条只在指令条数与 CPI 均不变时成立。答题时先把「$N$ 不变、CPI 不变」写成前提，再作比例推理。
7. **错在把每周期时间算成 $1.5\,\text{ns}$ →** $1/f=1/(1.5\times10^{9})\approx 6.67\times10^{-10}\,\text{s}=0.667\,\text{ns}$。先把 $f$ 写成 $1.5\times10^{9}$ 的幂形式，再取倒数。
8. **错在混淆时钟周期与机器周期 →** 若题给「机器周期含 $k$ 个时钟周期」，先算时钟周期数 $C=N\times\text{CPI}\times k$，再除主频；不要漏乘 $k$。
