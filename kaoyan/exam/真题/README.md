# 真题目录

## 这是什么

按年份还原的 408 真题，**每题给「题干 + 思路 + 坑」**。
本层是**题干源头**（2026-11-04 起）：`note/` 各考点内嵌一份副本供自测；改题干只改本层，再同步副本。

用途两个：① 整套做一遍，做完对照思路检查哪里想偏；② 记录掌握度——错哪题 → 反查哪几个 KP。
按考点看考法在 `note/`，那里按「考法」聚类；本目录按年份、按试卷顺序。

## 两种写法（都合法，各有用途）

| 年份 | 写法 | 每题给什么 |
|---|---|---|
| 2021–2023 | `**N.** 题干` + `→ 考点｜要点：一句话` | 一句话说「第一步做什么」 |
| 2016–2020、2024 | `### N. 小标题` + 题干 + 选项 + `**思路**` + `**坑**` + `→ \`章代码\`` | 关键一步 + 一个具体坑 |

两代题都把「思路」与「坑」分开写，不写答案字母。

## 2016–2020 这五年是怎么来的（口径必须写清）

1. 从 csgraduates.com 的公开页面抓**题干、选项、原解析**（脚本：`.gen/w4/zhenti_parse.py`）；
2. **题干与选项照录**，不做任何改写；
3. 只让模型做一件事：把原解析压成「**思路**（往哪想、关键一步）」与「**坑**（最容易错在哪一步）」，**不许写答案字母**；
4. 拼装时按题号排序（`.gen/w4/assemble_zhenti.py`），缺的题号单独补跑（`zhenti_fix.py`）。

所以这五年的**事实部分（题干/选项/年份/题号）来自原页面**，分析部分是二次加工。

## 三条使用须知

1. **都是回忆版**。命题版权归教育部考试中心，仅供个人备考，不要对外分发。
   不同来源措辞有差异，与纸质原卷不一致时**以原卷为准**。
2. **缺图的题只能看题干**。标了〔原卷附图，纯文本从略〕的题，没有图判断不了选项，
   但思路那一行仍然有效——它讲的是「这题该往哪想」。
3. **答案不在文件里**。刻意的：你在纸上做，对不上思路再回来看。

## 续抓（还缺 2009–2015）

来源与坑见下表（本层已冻结，**不再续抓**：纸质原卷在用户手上，比回忆版可靠）。

- 每年抓 **2 个来源**交叉核对（纯文本页 + PDF 各一份）
- 抓完立刻标出缺图题
- **计算题必须人工验算**：分片数、C-SCAN 距离、总线带宽、TCP 时间、校验和回卷、
  散列 ASL、子网划分——这些模型最容易算错
- 存成 `YYYY.md`，文首写来源与版权

## 优先级

2009–2015 收益递减：2016 年后题型稳定（40 选择 + 7 大题），更早年份选择题结构有变化。
对第 3 步（考点 × 真题）来说，**近 9 年已经够用**：高频考点在 9 年里至少出现 4–6 次。
