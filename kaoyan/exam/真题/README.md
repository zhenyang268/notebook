# 真题目录

## 这是什么

按年份还原的 408 真题，每题给「题干 + 考点主键 + 一句要点」。
用途是复习流程的**第 4 步**：多余时间整套做一遍，做完对照要点检查思路。

第 3 步（按考点看）在 `note/`，那里有详细的三步思路；本目录只给一句要点，
因为刷题时不需要长篇推导。

## 两种写法（都合法，各有用途）

| 年份 | 写法 | 每题给什么 | 适合 |
|---|---|---|---|
| 2021–2023 | `**N.** 题干` + `→ 考点｜要点：一句话` | 一句话说"第一步做什么" | 刷题时快速对照 |
| 2024 | `### N. 小标题` + 题干 + `**思路**` + `**坑**` | 三步思路 + 一个具体坑 | 也是 `note/` 层的写法示范 |

两种都能过 `verify.py`。新抓的年份建议用**紧凑版**（一句话要点），
因为详细三步思路属于 `note/` 层，年度文件重复写会两处维护。

## 三条使用须知

1. **都是回忆版**。命题版权归教育部考试中心，仅供个人备考，不要对外分发。
   不同来源措辞有差异，遇到与纸质原卷不一致时**以原卷为准**。
2. **缺图的题只能看题干**。标了〔原卷有图〕的题，没有图就判断不了选项，
   但思路那一行仍然有效——它讲的是"这题该往哪想"。
3. **答案不在文件里**。这是刻意的：你在纸上做，对不上思路再回来看要点。

## 续抓（还缺 2020 及更早）

流程见 `HANDOFF/prompts/T-fetch-zhenti.md`。要点：

- 每年抓 **2 个来源**交叉核对（纯文本页 + PDF 各一份）
- 抓完立刻标出缺图题
- **计算题必须人工验算**：分片数、C-SCAN 距离、总线带宽、TCP 时间、校验和回卷、
  散列 ASL、子网划分——这些模型最容易算错
- 存成 `YYYY.md`，文首写来源与版权

## 优先级

2019–2020 补齐 → 2016–2018 → 2009–2015。

理由：2016 年后题型稳定（40 选择 + 7 大题），更早的年份选择题结构有变化，
参考价值递减。对第 3 步（考点×真题）来说，**近 7 年已经够用**：
高频考点在 7 年里至少出现 3–4 次，足够做"按考法去重"。
