## 三条铁律（细节见 `AGENTS.md`）

1. **三层分工**：`syllabus/`（L1 考纲）→ `quick/`（L2 按大纲详解，一门学科一份，每个主键一小节）→ `exam/`（L3 详细，一个 KP 一个文件）。
2. **一个 KP 节 = 一个文件 = 一个复习单元**（**仅约束 `exam/`**）。文件膨胀就是 KP 拆得不够细，去改 `syllabus/`，不要在一个文件里堆。
3. **双线隔离**：`exam/` 里不写工程细节，`projects/` 里不抄考试正文，两边只共享 KP 号。
