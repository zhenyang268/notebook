## 1 主线：从"已知分布算概率"到"已知样本猜分布"

```
随机事件（古典/几何/条件/全概率/贝叶斯）        ← 第一章：怎么算概率
      ↓ 用随机变量描述
一维分布（分布函数、密度、常见分布）             ← 第二章
      ↓ 多个变量
多维分布（联合、边缘、条件、独立性）             ← 第三章
      ↓ 概括特征
数字特征（期望、方差、协方差、相关系数）         ← 第四章
      ↓ 极限行为
大数定律 / 中心极限定理                          ← 第五章：样本均值为什么近似正态
      ↓ 反过来用
统计：抽样分布（χ²/t/F）→ 参数估计（点估计/区间）→ 假设检验
```

**一条总纲**：**前五章是"概率论"（正向：分布 → 数据），后三章是"数理统计"（反向：数据 → 分布）**。
分界线是**中心极限定理**：它保证"不管总体什么分布，样本均值近似正态"，所以后面所有统计推断都建立在正态上。

**四个必背分布**（占了 80% 的题）：

| 分布 | 记号 | 期望 | 方差 | 什么时候用 |
|---|---|---|---|---|
| 二项 | $B(n,p)$ | $np$ | $np(1-p)$ | $n$ 次独立试验成功次数 |
| 泊松 | $P(\lambda)$ | $\lambda$ | $\lambda$ | 单位时间事件数（稀有事件） |
| 均匀 | $U(a,b)$ | $\frac{a+b}{2}$ | $\frac{(b-a)^2}{12}$ | 等可能落在区间 |
| 正态 | $N(\mu,\sigma^2)$ | $\mu$ | $\sigma^2$ | 大量独立因素叠加 |

## 2 必考清单（按章）

| 章 | 必须会算 | 一句话 |
|---|---|---|
| 01 事件与概率 | 古典概型；条件概率；**全概率公式**；**贝叶斯公式**；独立性 | 贝叶斯 = "由果推因" |
| 02 一维分布 | 分布函数性质；密度与分布函数互求；常见分布；**随机变量函数的分布** | 求 $Y=g(X)$ 的密度要**先求分布函数再求导** |
| 03 多维分布 | 联合分布/密度；边缘；条件分布；独立性判定；$Z=X+Y$ 的分布（卷积） | 独立 ⇔ $f(x,y)=f_X(x)f_Y(y)$ |
| 04 数字特征 | 期望性质；方差公式 $D(X)=E(X^2)-[E(X)]^2$；协方差；相关系数；**不相关 ≠ 独立** | 正态下不相关 ⇔ 独立（特例） |
| 05 极限定理 | 切比雪夫不等式；大数定律（辛钦/伯努利）；**中心极限定理（列维-林德伯格 / 棣莫弗-拉普拉斯）** | CLT 用于"近似算概率" |
| 06 抽样分布 | 总体/样本/统计量；$\chi^2$、$t$、$F$ 分布的构造；**正态总体的样本均值与样本方差** | $\frac{(n-1)S^2}{\sigma^2}\sim\chi^2(n-1)$ |
| 07 参数估计 | 矩估计；**最大似然估计**；估计量的无偏性/有效性/一致性；**置信区间** | 最大似然：求导令零，或取对数再求导 |
| 08 假设检验 | 原假设与备择假设；两类错误；**单侧/双侧检验**；$u$ 检验/$t$ 检验/$\chi^2$ 检验 | 拒绝域由**显著性水平 $\alpha$** 定 |

**必背公式**：

```
全概率：P(A) = Σ P(B_i)P(A|B_i)
贝叶斯：P(B_i|A) = P(B_i)P(A|B_i) / Σ P(B_j)P(A|B_j)
期望性质：E(aX+bY) = aE(X)+bE(Y)，无需独立
方差：D(aX+b) = a²D(X)
      D(X±Y) = D(X)+D(Y) ± 2Cov(X,Y)
Cov(X,Y) = E(XY) - E(X)E(Y)
相关系数：ρ = Cov(X,Y) / (√D(X)·√D(Y))，|ρ|≤1
切比雪夫：P(|X-E(X)| ≥ ε) ≤ D(X)/ε²
CLT：ΣX_i 近似 N(nμ, nσ²)，即 (ΣX_i - nμ)/(σ√n) 近似 N(0,1)
样本方差：S² = 1/(n-1)·Σ(X_i - X̄)²     ← 分母是 n-1（无偏）
```

## 3 陷阱（抄进错题本）

- `PS-01` 条件概率 $P(A|B)$ 与 $P(B|A)$ **完全不同**，贝叶斯题最容易混。
- `PS-01` 互斥 ≠ 独立：**互斥的两个非零概率事件一定不独立**（$P(AB)=0\ne P(A)P(B)$）。
- `PS-02` 分布函数 $F(x)$ 必须**右连续、单调不减、$F(-\infty)=0$、$F(+\infty)=1$**。
- `PS-02` 求 $Y=g(X)$ 的密度：**先求 $F_Y(y)=P(g(X)\le y)$，再求导**；不要直接用 $f_X(g^{-1}(y))$ 套（要乘 $|dx/dy|$）。
- `PS-02` 正态 $N(\mu,\sigma^2)$ 标准化：$Z=\frac{X-\mu}{\sigma}$，查表用 $\Phi$；注意 $\Phi(-z)=1-\Phi(z)$。
- `PS-03` 边缘密度 = 联合密度**对另一个变量积分**；条件密度 = 联合 / 边缘。
- `PS-03` 独立 ⇒ 不相关，**反之不成立**（除非正态）。
- `PS-03` $Z=X+Y$ 的密度是**卷积**：$f_Z(z)=\int f(x,z-x)dx$（独立时）。
- `PS-04` $E(XY)=E(X)E(Y)$ **只在独立时成立**；一般要用 $Cov$。
- `PS-04` $D(X-Y)=D(X)+D(Y)-2Cov(X,Y)$，**不是** $D(X)-D(Y)$。
- `PS-04` $E(g(X))\ne g(E(X))$（除非 $g$ 线性）；这是 Jensen 不等式的方向。
- `PS-05` 大数定律说"**依概率收敛到期望**"，不说"分布趋近"；CLT 才给分布。
- `PS-05` 棣莫弗-拉普拉斯是二项分布的正态近似，**要加连续性修正**（$\pm0.5$）。
- `PS-06` 样本方差 $S^2$ 的分母是 **$n-1$**（无偏）；用 $n$ 的是有偏的。
- `PS-06` $\chi^2$、$t$、$F$ 的**自由度**要数对：$t(n-1)$、$\chi^2(n-1)$、$F(n_1-1,n_2-1)$。
- `PS-07` 最大似然：**先取对数再求导**（乘积变求和），别忘了检查边界（参数空间端点）。
- `PS-07` 矩估计用**样本矩 = 总体矩**，几个参数列几个方程。
- `PS-07` 置信区间：$\sigma$ 已知用 $u$ 分布，$\sigma$ 未知用 $t$ 分布——**这是最常考的选择**。
- `PS-08` 第一类错误（弃真）= $\alpha$；第二类错误（取伪）= $\beta$。**减小 $\alpha$ 会增大 $\beta$**。
- `PS-08` 单侧 vs 双侧：**拒绝域的位置**由备择假设的方向定。

## 4 一小时怎么用

1. **15 分钟**：默写四个分布的期望方差 + 方差/协方差公式 + CLT 形式。
2. **30 分钟**：手算两道：① 一道贝叶斯（给先验和似然，求后验）；② 一道最大似然（给密度，求估计量）。
3. **15 分钟**：扫 §3，重点记「互斥≠独立」「$D(X-Y)$ 的符号」「$S^2$ 分母 $n-1$」「$\sigma$ 已知用 $u$ 未知用 $t$」。
