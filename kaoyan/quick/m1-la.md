# 线性代数 · 一小时速通

> **对应考纲**：`M1-LA`（约 34 分）｜ 6 章 ｜ 详细内容见 `exam/math1/la/<章>-<节>-<名>.md`
> **读法**：§1 主线 15 分钟 → §2 必考清单 30 分钟 → §3 陷阱 15 分钟。
> **这一科的特点**：**概念少、串得紧、题型固定**。全部内容就是"解方程组"一件事的六种说法。

---

## 1 主线：六个概念是一条线

```
行列式（判可逆的工具）
   ↓
矩阵（把线性变换写成表）
   ↓
向量组（矩阵的列，问"能不能互相表示"）
   ↓
线性方程组（Ax=b 有没有解、解集结构）
   ↓
特征值 / 特征向量（找"不被旋转、只被拉伸"的方向）
   ↓
二次型（把二次多项式写成 xᵀAx，判断正负定）
```

**一条总纲**：**整个线代在回答三个问题**：

1. **可逆吗？** → 行列式 $\ne0$ ⇔ 满秩 ⇔ 列向量线性无关 ⇔ $Ax=0$ 只有零解。
2. **有多少解？** → $r(A)$ 与 $r(A|b)$ 的关系（秩决定自由度）。
3. **能不能对角化？** → 有没有 $n$ 个线性无关的特征向量。

**秩是唯一的核心不变量**。所有"等价/相似/合同"的判断，最后都落到秩和特征值。

## 2 必考清单（按章）

| 章 | 必须会算 | 一句话 |
|---|---|---|
| 01 行列式 | 按行/列展开；范德蒙德；行列式性质（换行变号、倍加不变）；$|AB|=|A||B|$ | 上三角行列式 = 对角线乘积 |
| 02 矩阵 | 运算律；逆矩阵（伴随/初等变换）；秩；分块矩阵；初等变换与初等矩阵 | $r(A)=r(A^T)$；初等变换不改变秩 |
| 03 向量 | 线性相关/无关判定；极大无关组；秩；Schmidt 正交化；向量空间 | **相关性看秩，不看个数** |
| 04 方程组 | $Ax=0$ 基础解系；$Ax=b$ 通解 = 特解 + 齐次通解；解的结构 | 有解 ⇔ $r(A)=r(A|b)$ |
| 05 特征值 | 特征多项式；特征值与行列式/迹的关系；相似对角化；实对称矩阵正交对角化 | $|A|=\prod\lambda_i$，$\mathrm{tr}(A)=\sum\lambda_i$ |
| 06 二次型 | 标准形（配方法/正交变换）；惯性定理；正定判定（顺序主子式） | 正定 ⇔ 所有顺序主子式 $>0$ |

**必背结论**：

```
可逆的等价说法：|A|≠0 ⇔ r(A)=n ⇔ 列无关 ⇔ Ax=0 只有零解 ⇔ 特征值全不为 0
Ax=b 解的判定：
  r(A) ≠ r(A|b)          → 无解
  r(A) = r(A|b) = n      → 唯一解
  r(A) = r(A|b) < n      → 无穷多解，自由度 = n - r
相似：A ~ B ⇔ 存在可逆 P 使 P⁻¹AP = B  （特征值相同、行列式相同、迹相同）
可对角化 ⇔ 有 n 个线性无关的特征向量 ⇔ 每个特征值的几何重数 = 代数重数
实对称矩阵：一定可正交对角化，不同特征值的特征向量必正交
正定 ⇔ 顺序主子式全 >0 ⇔ 特征值全 >0 ⇔ 合同于单位阵
惯性定理：标准形中正、负项个数由 A 唯一确定（与变换无关）
```

## 3 陷阱（抄进错题本）

- `M1-LA-01xx` 行列式**换行变号**、**某行乘 k 则行列式乘 k**；但"某行加另一行的 k 倍"**不变**。
- `M1-LA-01xx` $|A+B|\ne|A|+|B|$；$|kA|=k^n|A|$（$n$ 阶）。
- `M1-LA-02xx` $(AB)^{-1}=B^{-1}A^{-1}$，**顺序要反**；$(AB)^T=B^TA^T$ 同理。
- `M1-LA-02xx` $(A+B)^{-1}\ne A^{-1}+B^{-1}$；只有 $A,B$ 可交换时才有 $(AB)^k=A^kB^k$。
- `M1-LA-02xx` $r(AB)\le\min(r(A),r(B))$；$A$ 可逆时 $r(AB)=r(B)$。
- `M1-LA-03xx` **向量个数 > 维数必相关**；个数 ≤ 维数也可能相关（要看秩）。
- `M1-LA-03xx` 极大无关组**不唯一**，但**秩唯一**，且所含向量个数相同。
- `M1-LA-04xx` $Ax=b$ 的通解 = **一个特解 + 齐次通解**；特解不唯一，但结构固定。
- `M1-LA-04xx` 基础解系含 $n-r$ 个向量，**不是 $n$ 个**。
- `M1-LA-05xx` 特征向量**不能是零向量**；$\lambda$ 可以是 0（此时 $A$ 不可逆）。
- `M1-LA-05xx` 不同特征值的特征向量线性无关；**同一特征值的多个特征向量可能相关**。
- `M1-LA-05xx` 可对角化的**必要条件**是有 $n$ 个线性无关特征向量；重根时要单独检查几何重数。
- `M1-LA-05xx` 实对称矩阵**一定能**正交对角化，**不需要**检查（这是它和一般矩阵最大的区别）。
- `M1-LA-06xx` 正定判定用**顺序主子式**（从左上角开始，$1\times1,2\times2,\dots,n\times n$ 全 $>0$），不是任意主子式。
- `M1-LA-06xx` 合同变换 $C^TAC$ **不改变惯性指数**，但**改变特征值**（相似才保特征值）。
- `M1-LA-06xx` 配方法化标准形时，**系数不是特征值**；只有正交变换法得到的系数才是特征值。
