# 操作系统 · 一小时速通

> **对应考纲**：`408-OS`（35 分）｜ 5 章 ｜ 详细内容见 `exam/408/os/<章>-<节>-<名>.md`
> **读法**：§1 主线 15 分钟 → §2 必考清单 30 分钟 → §3 陷阱 15 分钟。
> **这一科的特点**：**所有概念都是"资源不够怎么分"** —— CPU 不够就调度、内存不够就换页、磁盘不够就调度。

---

## 1 主线：一个 OS 在管四样东西

```
进程管理（CPU 虚化）  ：进程/线程、状态转换、调度算法、同步互斥、死锁
内存管理（内存虚化）  ：分页/分段/段页式、虚拟内存、页面置换、抖动
文件管理（磁盘虚化）  ：目录、分配方式（连续/链接/索引）、空闲空间管理
I/O 管理              ：I/O 软件层次、设备分配、磁盘调度、缓冲区
```

**一条总纲**：**"虚拟化 + 抽象 + 调度"**。
- 虚拟化：一个 CPU 变成多个进程、一块内存变成多份地址空间、一块磁盘变成多个文件。
- 抽象：进程、文件、设备都是"让上层不用管硬件"。
- 调度：资源不够时，**按什么规则分配给谁**——这是所有算法的共同结构。

**所有的"算法题"都是同一个模子**：给定一组对象（进程/页/磁盘请求）+ 一个规则（FCFS/SJF/LRU/SCAN…）→ 求平均等待时间 / 缺页率 / 移动距离。

## 2 必考清单（按章）

| 章 | 必须会算 / 会写 | 一句话 |
|---|---|---|
| 01 概述 | 四大特征（并发/共享/虚拟/异步）；内核态与用户态；系统调用 | 并发 ≠ 并行（并发是交替，并行是真同时） |
| 02 进程线程 | 进程状态转换图；PCB；线程与进程的区别；调度算法（FCFS/SJF/SRTN/HRRN/RR/多级反馈）；同步互斥（PV 操作、管程）；死锁四条件与银行家算法 | **PV 操作是必考大题**；信号量初值决定语义 |
| 03 内存 | 连续分配（首次/最佳/最坏适应）；分页/分段/段页式；地址转换；虚拟内存；页面置换（OPT/FIFO/LRU/CLOCK）；抖动与工作集 | **页表项不含页框号**（那是反过来的） |
| 04 文件 | 目录结构；文件分配（连续/链接/索引）；**混合索引**的地址计算；空闲空间（位示图/成组链接） | 混合索引要逐级算，**别漏一级间接** |
| 05 I/O | I/O 软件四层；SPOOLing；磁盘调度（FCFS/SSTF/SCAN/C-SCAN）；磁盘存取时间 | 磁盘调度**必须先看初始磁头位置** |

**必背公式**：

```
周转时间   = 完成时间 - 到达时间
带权周转   = 周转时间 / 服务时间
平均周转   = Σ周转 / n
缺页率     = 缺页次数 / 访问次数
有效访问时间 EAT = (1-p)×内存时间 + p×缺页处理时间      p = 缺页率
磁盘存取时间 = 寻道时间 + 旋转延迟(平均半圈) + 传输时间
混合索引最大文件 = 直接块数×块大小 + 一级间接 + 二级 + 三级
```

**调度算法一句话**：
- FCFS：先来先服务，**对短作业不利**。
- SJF / SRTN：短作业优先，**平均等待最短但可能饿死长作业**。
- HRRN：响应比 = (等待 + 服务) / 服务，**兼顾长短**。
- RR：时间片轮转，**时间片太大退化成 FCFS，太小上下文切换开销大**。
- 多级反馈队列：**综合最优，无需预知运行时间**。

## 3 陷阱（抄进错题本）

- `408-OS-01xx` 并发是**一段时间内多个程序交替执行**；并行是**同一时刻**多个程序执行。单核只有并发。
- `408-OS-01xx` 用户态 → 内核态**只能通过中断/异常/系统调用**，不能直接跳。
- `408-OS-02xx` 进程状态：**就绪 → 运行**要调度，**运行 → 就绪**是时间片到，**运行 → 阻塞**是主动等待，**阻塞 → 就绪**是被唤醒。**没有"阻塞 → 运行"**。
- `408-OS-02xx` 进程是**资源分配**单位，线程是**调度**单位。
- `408-OS-02xx` PV 操作：`P` 是申请（可能阻塞），`V` 是释放（可能唤醒）。**信号量初值 = 可用资源数**；互斥信号量初值 = 1。
- `408-OS-02xx` 死锁四条件：互斥、占有并等待、不可剥夺、循环等待。**破坏任一即可**；银行家算法是**避免**（不是检测）。
- `408-OS-03xx` **页表项不含页框号**——页表项里存的是页框号，题目问"段表项是否含页框号"答案是**不含**（段表存段基址）。
- `408-OS-03xx` 分页对用户**不可见**，分段**可见**（是逻辑单位）；段页式 = 先分段再分页。
- `408-OS-03xx` 页面置换 **OPT 是理论最优（不可实现）**，FIFO 有 **Belady 异常**（分配页框多反而缺页多），LRU 没有。
- `408-OS-03xx` 抖动 = 分配的页框数 < 工作集；解决办法是**局部置换 + 工作集模型**。
- `408-OS-04xx` **混合索引最容易漏一级间接**：先算直接块能覆盖多少字节，再逐级加。
- `408-OS-04xx` **硬链接不能跨文件系统**（inode 只在同一分区内唯一）；符号链接可以。
- `408-OS-04xx` 文件分配：连续分配**支持随机访问但产生外部碎片**；链接分配**不支持随机访问**；索引分配**支持随机访问但索引块占空间**。
- `408-OS-05xx` 磁盘调度**先确定初始磁头位置**，再决定先服务哪个方向——漏了这一步整题错。
- `408-OS-05xx` SCAN 是**电梯算法**（到端点折返），C-SCAN 是**单向扫描**（回程不服务）。
- `408-OS-05xx` SPOOLing 是**用磁盘模拟独占设备**为共享设备，**不减少 I/O 次数**。

## 4 一小时怎么用

1. **15 分钟**：画两遍**进程状态转换图**（五个状态、四条边），写一遍 PV 的模板。
2. **25 分钟**：手算一道**页面置换**（给访问串，算 FIFO 与 LRU 的缺页次数）——这是最容易拿分的大题。
3. **20 分钟**：扫 §3，重点记「页表项不含页框号」「混合索引漏级」「磁盘调度看初始位置」「Belady 异常」。
