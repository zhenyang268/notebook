## 1 主线：一条数据从应用到网线

```
应用层  HTTP / DNS / FTP / SMTP        ← 报文
   ↓ 加端口号
传输层  TCP / UDP                       ← 段（segment）
   ↓ 加 IP
网络层  IP / ICMP / ARP / 路由          ← 分组（packet）
   ↓ 加帧头帧尾
链路层  以太网 / PPP / HDLC / CSMA-CD   ← 帧（frame）
   ↓
物理层  编码 / 调制 / 传输介质          ← 比特
```

**一条总纲**：**每层都在做"加头 + 转发 + 去头"，只是寻址单位不同**（端口 / IP / MAC / 比特）。

**三个必须分清的东西**：
- **端口**定"哪个进程"（传输层）。
- **IP** 定"哪台主机、哪个网络"（网络层，逻辑地址，可变）。
- **MAC** 定"下一跳给谁"（链路层，物理地址，不变但随网卡）。

**四种时延**（所有计算题的骨架）：
```
发送时延 = 数据长度 / 带宽
传播时延 = 距离 / 光速
处理时延 = 常数（题目通常忽略或给定）
排队时延 = 不可预测（题目通常忽略）
总时延 = 四者之和
时延带宽积 = 传播时延 × 带宽   ← "管道里能装多少比特"
```

## 2 必考清单（按章）

| 章 | 必须会算 / 会写 | 一句话 |
|---|---|---|
| 01 体系结构 | OSI 七层 vs TCP/IP 四层；时延四分量；吞吐量 | 时延带宽积 = 管道容量 |
| 02 物理层 | 奈奎斯特定理（无噪声）；香农定理（有噪声）；编码（曼彻斯特/差分曼彻斯特/4B5B） | 奈氏看**码元**，香农看**信噪比** |
| 03 链路层 | 差错控制（CRC、海明码）；流量控制（停等、GBN、SR）；介质访问（CSMA/CD、CSMA/CA）；以太网帧格式 | GBN 窗口上限 $2^n-1$，SR 是 $2^{n-1}$ |
| 04 网络层 | IPv4 首部与分片；子网划分与 CIDR；ARP/ICMP/DHCP；路由算法（RIP/OSPF/BGP） | 分片数据必须是 **8 的倍数** |
| 05 传输层 | UDP 首部；TCP 首部；三次握手/四次挥手；可靠传输与滑动窗口；拥塞控制（慢开始/拥塞避免/快重传/快恢复） | 拥塞窗口按 **RTT** 变，不是按报文 |
| 06 应用层 | DNS 查询过程；HTTP 请求/响应；FTP 双连接；电子邮件协议 | DNS 查询**含建连时间**要单独算 |

**必背公式**：

```
奈奎斯特：C = 2W·log2(V)          W=带宽(Hz)，V=码元种类数
香农：    C = W·log2(1 + S/N)     S/N 是功率比，dB = 10·log10(S/N)
停等协议效率 = 1 / (1 + 2a)        a = 传播时延 / 发送时延
GBN 窗口上限 = 2^n - 1             n = 帧序号位数
SR  窗口上限 = 2^(n-1)
TCP 有效窗口 = min(接收窗口, 拥塞窗口)
子网数 = 2^借位数；每子网主机数 = 2^主机位 - 2
```

**TCP 状态机必记**：`CLOSED → SYN_SENT → ESTABLISHED → FIN_WAIT_1 → FIN_WAIT_2 → TIME_WAIT → CLOSED`。
`TIME_WAIT` 等 **2MSL**，目的是"确保最后一个 ACK 到达 + 让旧报文消亡"。

## 3 陷阱（抄进错题本）

- `408-NET-01xx` TCP/IP 四层 vs OSI 七层：**TCP/IP 没有会话层和表示层**，应用层把这三层合并。
- `408-NET-01xx` 时延带宽积是"**管道里能装多少比特**"，不是"带宽×总时延"。
- `408-NET-02xx` 奈氏定理的前提是**理想无噪声低通信道**；香农是**有噪声**。两者不能混用。
- `408-NET-02xx` 曼彻斯特编码**每位中间都有跳变**（自带时钟），效率只有 50%。
- `408-NET-02xx` 差分曼彻斯特看的是**位开始处有无跳变**，不是中间。
- `408-NET-03xx` **GBN 的接收窗口 = 1**（只收按序的下一帧）；**SR 的接收窗口 > 1**（可乱序缓存）。
- `408-NET-03xx` GBN 出错后**重传该帧及其后所有帧**；SR 只重传出错的那一帧。
- `408-NET-03xx` 停等协议效率低是因为**每个帧都要等一个 RTT**；连续 ARQ 才谈窗口。
- `408-NET-03xx` CSMA/CD 用于**有线**（冲突检测），CSMA/CA 用于**无线**（冲突避免，因为无线不能边发边听）。
- `408-NET-03xx` 以太网最小帧长 64 字节，是为了**保证发送方在发送完之前能检测到冲突**。
- `408-NET-03xx` 交换机**只隔离冲突域，不隔离广播域**；路由器两者都隔离。
- `408-NET-04xx` IP 分片：**数据部分必须是 8 字节的倍数**，除最后一片。
- `408-NET-04xx` 分片后**只有第一片有传输层首部**，其余片没有。
- `408-NET-04xx` 子网划分：**借位从主机位高位借**；主机位全 0 是网络地址、全 1 是广播地址，都要减 2。
- `408-NET-04xx` **路由器的一个接口占一个 IP**；点对点链路两端各一个 IP。
- `408-NET-04xx` ARP 是"**IP 找 MAC**"，在**同一局域网内**；跨网段要先找网关的 MAC。
- `408-NET-04xx` RIP 用**跳数**（最大 15，16 视为不可达），OSPF 用**链路状态**，BGP 用**路径向量**。
- `408-NET-05xx` TCP 三次握手：**第三次握手可以带数据**（前两次不行）。
- `408-NET-05xx` 四次挥手：**主动关闭方进入 TIME_WAIT**，等 2MSL。
- `408-NET-05xx` 拥塞控制：慢开始**每 RTT 翻倍**（指数），到阈值后**每 RTT 加 1**（线性）。
- `408-NET-05xx` 快重传是**收到 3 个重复 ACK** 就重传，不等超时；快恢复是**减半后线性增长**（不是回到 1）。
- `408-NET-05xx` TCP 首部 20 字节（不含选项），UDP 首部 **8 字节**。
- `408-NET-06xx` DNS 查询：**递归查询**由服务器代劳，**迭代查询**由客户端逐级问；算总时间要含建连。
- `408-NET-06xx` HTTP/1.0 默认**非持久连接**（每个对象一个 TCP），HTTP/1.1 默认**持久连接**。

## 4 一小时怎么用

1. **10 分钟**：抄 §2 的公式块（奈氏/香农/停等效率/窗口上限/子网数）。
2. **30 分钟**：手算两道：① 给带宽和距离算时延带宽积；② 给一个 IP 和子网掩码算子网数与可用主机数。
3. **20 分钟**：扫 §3，重点记「分片 8 的倍数」「GBN vs SR 窗口」「交换机不隔离广播域」「慢开始翻倍」。
