## 1 主线：一条"从离散到连续"的链

```
极限 ──▶ 连续 ──▶ 导数 ──▶ 微分 ──▶ 积分 ──▶ 微分方程
 │                          │
 │                          └──▶ 多元：偏导 → 全微分 → 方向导 → 极值
 │
 └──▶ 级数（把函数拆成无穷项和：泰勒 / 傅里叶）
                    
积分三兄弟（数一重点）：
  定积分（一元，区间） → 二重/三重积分（区域）
  曲线积分（第一类：长度；第二类：做功） → 曲面积分（第一类：面积；第二类：通量）
```

**总纲一句话**：**极限是地基，导数和积分是互逆的两把刀，级数是"用简单函数逼近复杂函数"**。

**三大公式把所有积分串起来**（数一必考）：

```
格林公式：  ∮_L P dx + Q dy = ∬_D (∂Q/∂x - ∂P/∂y) dxdy          平面曲线 ↔ 二重积分
高斯公式：  ∮∮_Σ P dy dz + Q dz dx + R dx dy = ∭_Ω (∂P/∂x+∂Q/∂y+∂R/∂z) dV   曲面 ↔ 三重
斯托克斯：  ∮_Γ P dx + Q dy + R dz = ∬_Σ curl F · n dS            空间曲线 ↔ 曲面积分
```

**这条链的意义**：**把难算的边界积分变成好算的区域积分**（或反过来）。考场上看到"闭曲线/闭曲面"，第一反应就是想这三大公式。

## 2 必考清单（按章）

| 章 | 必须会算 | 一句话 |
|---|---|---|
| 01 极限连续 | 七种未定式的解法；等价无穷小替换；洛必达；夹逼；单调有界 | **等价替换只能在乘除中用**，加减中要慎 |
| 02 一元微分 | 复合/隐函数/参数方程/高阶求导；微分中值定理（罗尔/拉格朗日/柯西/泰勒）；单调性极值凹凸拐点 | 中值定理题的核心是**构造辅助函数** |
| 03 一元积分 | 不定积分（换元/分部/有理函数）；定积分性质；变上限积分求导；反常积分判敛；**定积分几何应用（面积/体积/弧长/侧面积）** | 变上限求导是高频小题 |
| 04 向量与空间 | 数量积/向量积/混合积；平面与直线方程；距离与夹角 | 混合积 = 平行六面体体积 |
| 05 多元微分 | 偏导/全微分；复合与隐函数求导；方向导数与梯度；无条件极值；**条件极值（拉格朗日乘数）** | 可微 ⇒ 偏导存在，反之不然 |
| 06 多元积分 | 二重（直角/极坐标）；三重（直角/柱/球）；**第一二类曲线积分**；**第一二类曲面积分**；三大公式 | 极坐标别忘 $r$；球坐标别忘 $r^2\sin\varphi$ |
| 07 无穷级数 | 正项级数判敛（比较/比值/根值/积分）；交错级数（莱布尼茨）；**幂级数收敛半径与和函数**；**傅里叶级数** | 收敛半径 $R=1/\rho$，端点要单独判 |
| 08 常微分方程 | 可分离变量；齐次；一阶线性（公式法）；伯努利；**二阶常系数（齐次 + 非齐次特解）**；欧拉方程 | 特解形式由**非齐次项类型**决定 |

**必背公式**：

```
泰勒（佩亚诺）：f(x) = Σ f^(k)(0)/k! · x^k + o(x^n)
常用展开：e^x, sin x, cos x, ln(1+x), (1+x)^α, 1/(1-x)
一阶线性：y' + P(x)y = Q(x)  ⇒  y = e^(-∫P)(∫Q·e^(∫P)dx + C)
二阶齐次：特征方程 r²+pr+q=0，Δ>0/=/<0 对应三种通解形式
二阶非齐次特解：
  f(x)=P_m(x)e^(λx)      ⇒ 试 y*=x^k Q_m(x)e^(λx)，k=λ 是特征根的重数
  f(x)=e^(λx)(A cos ωx + B sin ωx) ⇒ 试 y*=x^k e^(λx)(a cos ωx + b sin ωx)
曲率：κ = |y''| / (1+y'²)^(3/2)
旋转体体积：V = π∫y²dx（绕 x 轴）；侧面积：S = 2π∫y√(1+y'²)dx
```

## 3 陷阱（抄进错题本）

- `HS-01` 等价无穷小替换**只能在乘除因子中整体替换**，加减中直接换会出错（如 $\tan x-\sin x$ 不能换）。
- `HS-01` $1^\infty$ 型用 $e^{\lim (f-1)g}$，**不是**直接代 1。
- `HS-01` 洛必达**只对 $0/0$ 或 $\infty/\infty$** 用；用前先确认，用完要检查是否循环。
- `HS-02` 中值定理题：看到"存在 $\xi$ 使 $f'(\xi)=...$" 就想**构造 $F(x)$ 使 $F'(\xi)=0$**。
- `HS-02` 极值 vs 最值：极值是局部，最值要考虑**端点 + 不可导点 + 驻点**。
- `HS-02` 拐点是**凹凸性改变的点**，$f''=0$ 只是必要条件。
- `HS-03` 变上限积分求导：$\frac{d}{dx}\int_{a(x)}^{b(x)}f(t)dt = f(b)b' - f(a)a'$，**别只对上限求导**。
- `HS-03` 反常积分 $\int_1^\infty \frac{1}{x^p}dx$ 在 **$p>1$ 收敛**；$\int_0^1 \frac{1}{x^p}dx$ 在 **$p<1$ 收敛**。两个方向相反。
- `HS-03` 旋转体**侧面积**公式里是 $\sqrt{1+y'^2}$（弧长微元），**不是** $y$ 直接积。
- `HS-05` 可微 ⇒ 偏导存在，**反之不成立**；偏导连续 ⇒ 可微。
- `HS-05` 条件极值用拉格朗日乘数，**约束个数 = 乘子个数**；解完要验证是极大还是极小。
- `HS-06` 二重积分换极坐标**别忘了雅可比 $r$**；三重换球坐标**别忘了 $r^2\sin\varphi$**。
- `HS-06` 第二类曲线积分**与方向有关**，反向变号；第一类与方向无关。
- `HS-06` 用格林/高斯公式前必须确认**闭曲线/闭曲面 + 正向（外侧/逆时针）**；不闭合要补线/补面。
- `HS-06` 高斯公式要求 $P,Q,R$ 在闭曲面内有**连续偏导**；有奇点要挖去小球。
- `HS-07` 正项级数：**比值/根值法失效时（ρ=1）要用比较法**，别停在那里。
- `HS-07` 幂级数收敛半径 $R=1/\rho$（$\rho=\lim|a_{n+1}/a_n|$）；**端点必须单独代入判敛**。
- `HS-07` 傅里叶级数：**周期延拓**、**奇偶延拓**决定只有正弦或只有余弦项；狄利克雷定理给的是**左右极限的平均**。
- `HS-08` 一阶线性公式法：先化成**标准形** $y'+P(x)y=Q(x)$，系数必须是 1。
- `HS-08` 二阶非齐次特解：**先看 $\lambda$ 是不是特征根**，决定乘 $x^k$ 的 $k$（0/1/2）。
- `HS-08` 欧拉方程 $x^2y''+axy'+by=0$ 令 $x=e^t$ 化为常系数；**别忘了 $x>0$ 的前提**。

## 4 一小时怎么用

1. **15 分钟**：默写三大公式（格林/高斯/斯托克斯）+ 泰勒五个展开 + 二阶非齐次特解表。
2. **30 分钟**：手算两道：① 一个定积分（换元 + 分部）；② 一个二阶非齐次 ODE（定特解形式）。
3. **15 分钟**：扫 §3，重点记「等价替换只能乘除」「极坐标 $r$」「球坐标 $r^2\sin\varphi$」「端点单独判」。
