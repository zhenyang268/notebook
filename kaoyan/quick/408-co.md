> **对应考纲**：`408-CO`（45 分）｜ 7 章 ｜ 详细内容见 `exam/408/co/<章>-<节>-<名>.md`
> **读法**：§1 主线 15 分钟 → §2 必考清单 30 分钟 → §3 陷阱 15 分钟。
> **这一科的特点**：概念碎、计算多，但**所有计算都能归到"位宽 / 周期 / 命中率"三件事**。

## 1 主线：一台机器只有三层

```
指令层（ISA）      ：机器指令、寻址方式、CISC vs RISC
     ↕ 编译/解释
数据层（表示与运算）：补码、IEEE 754、ALU、溢出
     ↕ 通路
硬件层（数据通路）  ：寄存器、总线、Cache、流水线、中断
```

**一句话串起来**：一条 `add` 指令，先在**指令层**被取指译码（寻址方式决定操作数在哪），
在**数据层**被 ALU 算（补码加法，可能溢出），在**硬件层**走数据通路（可能要访存 → Cache 命中率决定快慢）。
**几乎所有综合题都是这三层串起来问。**

**存储层次是这一科的心脏**：
```
寄存器 < Cache < 主存 < 磁盘
  快、小、贵 ──────────────▶ 慢、大、便宜
```
每一层都在回答：**用什么换什么**（Cache 用 SRAM 换速度，虚拟内存用分页换容量）。

## 2 必考清单（按章）

| 章 | 必须会算 / 会写 | 一句话 |
|---|---|---|
| 01 概述 | 性能公式（CPI、MIPS、加速比）；Amdahl 定律 | 加速比受**不可加速部分**封顶 |
| 02 数据表示 | 原/反/补/移码互转；补码加减与溢出判断；IEEE 754 单双精度；大小端 | 补码减法 = 加负数补码；溢出看**符号位进位** |
| 02 运算 | 定点乘除（Booth / 恢复余数）；浮点加减四步（对阶/尾数运算/规格化/舍入） | 对阶**小阶向大阶看齐** |
| 03 存储 | Cache 三种映射（直接/全相联/组相联）；命中率与平均访问时间；写策略（写回/写直达）；虚拟内存、TLB、页表 | 标记阵列 ≠ 总容量；TLB 与 Cache 是两套 |
| 04 指令 | 寻址方式（立即/直接/间接/寄存器/变址/相对/基址）；指令格式与字段位宽 | 相对寻址是"PC + 偏移" |
| 05 CPU | 数据通路（单总线/多总线）；硬布线 vs 微程序；五段流水线；冒险（结构/数据/控制）；异常与中断 | 流水线**不缩短单条指令时间**，只提高吞吐 |
| 06 总线 | 总线带宽；同步 vs 异步；突发传输 | 突发传输省的是**地址传送时间** |
| 07 I/O | 程序查询 / 中断 / DMA；中断响应过程；磁盘容量与存取时间 | DMA **不经过 CPU**，但要**占用总线** |

**必背公式**：

```
CPU 时间 = 指令数 × CPI × 时钟周期 = 指令数 × CPI / 主频
MIPS     = 指令数 / (执行时间 × 10^6) = 主频 / (CPI × 10^6)
Amdahl   = 1 / ((1-f) + f/s)          f = 可加速比例，s = 加速倍数
平均访存 = 命中率×Cache时间 + (1-命中率)×主存时间
Cache 行 = 标记 + 有效位 + 脏位(写回时) + 数据
组相联   行数 = 组数 × 每组路数
```

## 3 陷阱（抄进错题本）

- `408-CO-02xx` 补码表示范围是**不对称**的：$n$ 位补码 $[-2^{n-1},\,2^{n-1}-1]$，负数多一个。
- `408-CO-02xx` 溢出判断：**同号相加得异号**才溢出；异号相加永不溢出。用"双符号位"看是否 $01/10$。
- `408-CO-02xx` IEEE 754 的阶码用**移码**（偏置 $127$ / $1023$），尾数**隐含最高位 1**（规格化数）。
- `408-CO-02xx` 浮点加减：**先对阶（小向大）、再尾数运算、再规格化、最后舍入**；舍入可能再次需规格化。
- `408-CO-02xx` 大端 = 高位字节在低地址；小端相反。**网络字节序是大端**。
- `408-CO-03xx` Cache 总容量 = **行数 × (标记 + 有效位 + 脏位 + 数据)**，不是"行数 × 数据块大小"。
- `408-CO-03xx` 直接映射：主存块号 mod Cache 行数；**冲突最多，命中率最低**。
- `408-CO-03xx` 组相联：块号 mod 组数 定组，组内全相联；**组数 × 路数 = 总行数**。
- `408-CO-03xx` 写回法要**脏位**；写直达法不需脏位但每次写都访存。
- `408-CO-03xx` TLB 是**页表项的 Cache**，命中则不查页表；**TLB 未命中不等于缺页**。
- `408-CO-03xx` 虚拟地址 = 虚页号 + 页内偏移；**页内偏移在虚实转换中不变**。
- `408-CO-04xx` 相对寻址：有效地址 = **PC（已加过指令长度）+ 偏移**；偏移是补码，可负。
- `408-CO-04xx` 变址 vs 基址：**变址**的寄存器内容可变（面向数组），**基址**的寄存器内容固定（面向程序重定位）。
- `408-CO-05xx` 五段流水线：**理想 CPI = 1**，但冒险会插入气泡；加速比上限 = 段数。
- `408-CO-05xx` 数据冒险用**旁路（forwarding）**解决，**load-use 冒险旁路也救不了**，必须暂停一拍。
- `408-CO-05xx` 单周期 CPU **不能用单总线数据通路**（一条总线一个周期只能传一个数据）。
- `408-CO-05xx` 异常/中断返回：**故障（fault）返回到出错指令**，**陷阱（trap）返回到下一条**，**中止（abort）不返回**。
- `408-CO-05xx` 超标量提高的是**并行度**，不缩短单条指令的延迟。
- `408-CO-06xx` 总线带宽 = 总线宽度 × 频率 / 每传输所需周期数；突发传输省地址周期。
- `408-CO-07xx` 中断响应过程：**关中断 → 保存断点 → 识别中断源 → 转服务程序**。
- `408-CO-07xx` DMA 与中断的区别：DMA **数据传送不经过 CPU**，但**总线控制权要交给 DMA**；结束时才发中断。

## 4 一小时怎么用

1. **10 分钟**：抄 §2 的公式块（CPU 时间、Amdahl、平均访存、Cache 行结构）——计算题全靠它。
2. **30 分钟**：手算两道：① 一个 32 位 IEEE 754 的十进制值；② 组相联 Cache 的标记/组号/块内地址位数拆解。
3. **20 分钟**：扫 §3，重点记「补码范围」「Cache 总容量」「流水线三类冒险」「异常返回哪条」。
