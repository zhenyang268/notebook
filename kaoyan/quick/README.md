# quick/ — 一口气讲完一科（三合一）

**形态**：每门一册「口语讲稿」，不是教材、不是速查手册。读者打开它的目的只有一个：
用半小时到一小时，把这一科从头到尾在脑子里跑一遍，建立一条完整的主线。

## 每份固定三段

```
## 第一部分 · 考纲依据（扫一眼，5 分钟）
   章 | 考点数 | 档位 | 真题落点（2021–2024）+ 逐章考点清单
   数据由脚本从 syllabus/ 与 exam/真题/ 生成，不由模型写

## 第二部分 · 概括版（半小时，一口气读完）
   顺着章讲主线：核心机制（为什么这样设计）→ 最小例子或手算 → 致命陷阱
   连读，不许清单罗列，不许表格堆砌

## 第三部分 · 口语版（最难的点讲透）
   只挑每科最难的 5–8 个点，每点五段：
   为什么需要 → 生活类比 → 最小例子（带数字）→ 常见误解 → 一句话带走
```

## 三条铁律

1. **不写成教材**：打开第一段如果像「XX 是指……」，重写。
2. **不编真题**：只写「常见考法」，不写「2023 年第 N 题」。
3. **公式走 KaTeX**：行内 `$...$`、独立 `$$...$$`；禁止 `\(...\)`、`\[...\]`。

## 与相邻层的关系

| 层 | 单位 | 深度 | 什么时候用 |
|---|---|---|---|
| `syllabus/` | 一个章（含考点表） | 考什么、要求到哪档、哪年考过 | 第 1 步：研究考纲 |
| **`quick/`（本层）** | **一科一册** | **串成主线，讲清为什么** | **第 2 步：建立直觉** |
| `note/` | 一个考点一个文件 | 考点与真题的复合版，只写思路不写答案 | 第 3 步：对思路 |
| `exam/` | 一章一个文件 | 推导 + 例题 + 真题落点 + 易错清单 | 第 5 步：深挖 |
