# quick/ — 一小时速通层

**这一层解决一个问题**：离考试只剩几周时，`exam/` 的详细文件太多读不完，
而 `syllabus/` 只有考点名没有内容。中间缺一层——**一小时能读完、读完能上手做题**的东西。

## 三层分工

| 层 | 目录 | 一个文件是什么 | 什么时候用 |
|---|---|---|---|
| **L1 大纲** | `syllabus/` | **考纲坐标系**：一个 KP 一行，给要求层次与标签 | 定位"这个考点归哪、要求到什么程度" |
| **L2 速通** | `quick/`（本目录） | **一小时**：一个子科一份，主线 + 必考 + 陷阱 | 快速过一遍、考前回炉、建立框架 |
| **L3 详细** | `exam/` | **一个 KP 一个文件**：①机制 ②设计 ③验收 | 具体学某个考点、练题型、查漏 |

**读法**：`quick/` 不替代 `exam/`。它只给骨架与命门，**手写代码和综合题还得去 `exam/` 按 KP 练**。

## 统一的六段结构

每份速通都按同一骨架写，便于横向对照：

```
1 主线        这一科在讲什么（一张因果链）
2 必考清单    按考纲章节：必须会算/会写什么 + 一句话
3 陷阱        带 KP 号的易错点（现象 → 原因）
4 一小时怎么用  如果只有 60 分钟，按什么顺序做哪三件事
5 通向详细    要更深的东西去哪找
```

**§4 是这一层存在的理由**。如果一份速通读完不知道该干什么，它就失败了。

## 维护规则

1. **一个文件对应一个子科**，不按章拆（按章拆就变成 `exam/` 了）。
2. **篇幅上限约 250 行**。超过说明想讲细节，该去 `exam/`。
3. **陷阱条目必须带 KP 号**，能反查到 `syllabus/` 的对应行。
4. **不写排期、不写"第几周"**（本层属"契约/参考"类）。
5. **不替代详细文件**：`quick/` 里不写完整推导、不贴长代码。
