# quick/ — 按大纲详解

**形态**：严格按 `syllabus/` 的章序与考点编号逐条展开的**详解本**。
每个考纲主键对应一个 `####` 小节，小节标题就是主键本身（如 `408-DS-0202 顺序表`），可反查考纲与 `exam/`。

**不是**：不是速览提纲（那样读不完整），也不是题目集（那在 `exam/真题专项/`）。

## 四份

| 文件 | 覆盖 | 规模 |
|---|---|---|
| `408.md` | 25 章 / 87 个考纲主键（数据结构 43 分、组成 45 分、OS 35 分、网络 25 分） | 约 4.5 万字符 |
| `math1.md` | 22 章 / 72 个考纲主键（高数 82 分、线代 34 分、概率 34 分） | 约 3.3 万字符 |

| `politics.md` | 6 模块 28 章（马原 22% / 新思想 22% / 史纲 15% / 思法 15% / 毛中特 13% / 时政 13%） | 约 1.4 万字符 |

## 结构约定

```
# 408 · 按大纲详解
## 一、数据结构                ← 科（章分组的上一级）
### DS-01 绪论                 ← 章，编号与 syllabus 一致
#### 408-DS-0101 基本概念      ← 节，标题即考纲主键
（正文：是什么 → 关键公式/机制 → 一个典型计算或易错点）
```

**标题里的主键必须与 `syllabus/` 完全一致**。这是本层唯一的硬约束：
有了它，读者可以从任意一条反查到 `syllabus/408.md` 的对应行与 `exam/` 的对应文件。

## 与相邻层的关系

| 层 | 单位 | 深度 | 什么时候用 |
|---|---|---|---|
| `syllabus/` | 一个 KP（一行） | 只说考什么、要求到哪档 | 定位、查要求、算覆盖 |
| **`quick/`（本层）** | **一个 KP（一小节）** | **讲清是什么、为什么、怎么算** | **系统过一遍、查漏补缺** |
| `exam/` | 一个 KP（一个文件） | 展开推导 + 题型 + 陷阱 | 攻一个具体考点 |
| `exam/真题专项/` | 一个真题题点 | 考什么 / 坑在哪 / 怎么练 | 刷题后归因 |

## 维护规则

1. **覆盖率是硬指标**：`syllabus/` 里每个 KP 在本层都必须有对应小节。
   可以用脚本核对（见下）。
2. **不新增考纲外的考点**。想加内容就先改 `syllabus/`，再回来扩写。
3. **每条 180–400 字**。低于 180 是提纲，高于 400 该去 `exam/` 单独成文。
4. **体量下限 8000 字符**（`tools/lint.py` 会拦）。
5. **不写分值、不写排期、不写复习建议**（本层属"契约/参考"类）。

## 覆盖率自检

```bash
cd notebook/kaoyan
python3 - <<'PY'
import re
from pathlib import Path
for sub, f, prefix in [('408','408.md','408-'), ('math1','math1.md','M1-')]:
    syl = Path(f'syllabus/{f}').read_text(encoding='utf-8')
    want = list(dict.fromkeys(re.findall(r'`(' + prefix + r'[A-Z]{2}-\d{4})`', syl)))
    got = set(re.findall(r'^#### (' + prefix + r'[A-Z]{2}-\d{4})',
                         Path(f'quick/{f}').read_text(encoding='utf-8'), flags=re.M))
    miss = [k for k in want if k not in got]
    print(f'{sub}: {len(want)} 个主键，覆盖 {len(got)}，缺 {len(miss)}', miss)
PY
```
