读者打开它的目的只有一个：用半小时到一小时，把这一科从头到尾在脑子里跑一遍。

## 每份固定四段

```
## 第一部分 · 考纲依据（已并入 syllabus/<科>.md）
   ★ 2026-11-04 起不再重复考纲表，只留三行指针。
     重复维护的代价是：考纲一改（KP 增删、落点更新）就要改两处，必有一处歪。

## 第二部分 · 概括版（半小时，一口气读完）
   顺着章讲主线：核心机制（为什么这样设计）→ 最小例子或手算 → 致命陷阱
   连读，不许清单罗列，不许表格堆砌

## 第三部分 · 口语版（最难的点讲透）
   只挑每科最难的 5–8 个点，每点五段：
   为什么需要 → 生活类比 → 最小例子（带数字）→ 常见误解 → 一句话带走

## 第四部分 · 自查清单（探测用）
   每章 3–4 句自答式判断句，读完第二部分立刻自答「能 / 不能 / 说不清」
   只探测「这一步能不能自己走一遍」；不给答案，不考记忆细节
   一科里 3 个以上「不能」的章，回去重读那一章，不要往下推
```

## 三条铁律

1. **不写成教材**：打开第一段如果像「XX 是指……」，重写。
2. **不编真题**：只写「常见考法」，不写「2023 年第 N 题」。
3. **公式走 KaTeX**：行内 `$...$`、独立 `$$...$$`；**不用**反斜杠圆括号 / 反斜杠方括号那套定界符（KaTeX 只认 `$` 与 `$$`）。
4. **自查句不考记忆**：判断句只指向该章最容易含糊的那一步（判型 / 建模型 / 选方法）；数值常数、定义原文不进自查清单。

## 与相邻层的关系

| 层 | 单位 | 回答 | 什么时候用 |
|---|---|---|---|
| `syllabus/` | 一个 KP（含章落点） | 考什么、要哪档、哪年考过、我现在哪档 | 查漏补缺的起点 |
| **`quick/`（本层）** | **一科一册** | **这一科的主线是什么** | 建立直觉 / 考前过一遍 |
| `note/` | 一个考点 | 这类题往哪想、坑在哪 | 对答案、补漏 |
| `exam/真题/` | 一年一份 | 这道题考什么 | 做完题对思路 |
| `drill/` | 一条题型线 | 满分那道坎怎么过 | 冲刺 |
