# quick/ — 一小时过完一门学科

**形态**：B 站那种"一小时学完 XX"的**连贯通讲**。顺着章节从头讲到尾，有机制、有例子、有陷阱，
不是清单，不是速查表。读完一遍，脑子里应该有一条完整的线。

**不是**：不是复习提纲，不是公式速查，不是题型清单。那些在 `exam/` 和 `exam/真题专项/`。

## 怎么读（这是关键）

1. **不要停**。遇到不熟的地方做个记号继续往下走，读完再回头补。
   这是"过一遍"不是"学一遍"，卡在一处就失去意义了。
2. **只记三样**：这一章的机制是什么、那个手算怎么算、那个坑在哪。
3. **读完立刻做一件事**：合上文件，用三句话向自己复述这一科的主线。说不出来说明白读了。

## 维护规则

1. **一门学科一份**，不按子科拆（拆了就变成"速查手册"，不是"通讲"）。
2. **必须连续叙述**。出现"知识点1、知识点2"式的罗列就是写错了。
3. **每章三样齐全**：机制、例子、陷阱。缺一样就是没写完。
4. **不写排期、不写"第几周"**（本层属"契约/参考"类）。
5. **体量下限 2500 字**（`tools/lint.py` 会拦）。低于这个数就是提纲，不是通讲。
