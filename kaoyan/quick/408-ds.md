## 1 主线：数据结构只有两个问题

**问题一：怎么存？** 逻辑结构（线性/树/图）→ 存储结构（顺序/链式/索引/散列）。
**问题二：多快？** 每个操作的时间/空间代价，用渐进量级比较。

整本书就是这两问在七种结构上的展开：

```
线性表 ──受限──▶ 栈 / 队列 ──扩展──▶ 数组（特殊矩阵压缩）
   │
   └──层次──▶ 树 / 二叉树 ──特化──▶ 二叉排序树 / 平衡树 / 堆 / 哈夫曼
                          └──▶ B 树 / B+ 树（磁盘友好）
   │
   └──网状──▶ 图 ──▶ 最小生成树 / 最短路 / 拓扑排序 / 关键路径
   
查找：顺序 / 折半 / 分块 / 散列 / B 树
排序：插入 / 交换 / 选择 / 归并 / 基数（外部排序）
```

**一条暗线**：越靠后的结构，越是在用**额外空间或额外约束**换时间。折半要有序，散列要哈希函数，B+ 树要多叉，堆要堆序。**所有优化的本质都是"先付一次代价，之后每次省"**。

## 2 必考清单（按章）

| 章 | 必须会算 / 会写 | 一句话 |
|---|---|---|
| 01 绪论 | 时间复杂度、空间复杂度渐进分析 | 只保留最高阶项，常数忽略 |
| 02 线性表 | 顺序表插删平均移动次数；单链表逆置、快慢指针、合并、倒数第 k | 头结点简化边界；改指针顺序不能错 |
| 02 串 | 朴素匹配 $O(nm)$；KMP 的 `next` / `nextval` | 三套约定必须按题干换算 |
| 03 栈队列 | 卡特兰数（合法出栈序列）；循环队列判空判满；表达式求值 | 判空判满三种约定要能互推 |
| 03 数组 | 行/列优先地址计算；对称/三角/三对角压缩映射 | 先算行内偏移，再算行基址 |
| 04 树 | 二叉树五个性质；遍历互推；线索二叉树；哈夫曼编码；并查集 | 完全二叉树的下标关系是命门 |
| 05 图 | 邻接矩阵 vs 邻接表选型；DFS/BFS；Prim/Kruskal；Dijkstra/Floyd；拓扑排序；关键路径 | "最短路"与"关键路径"不是一回事 |
| 06 查找 | 折半判定树；分块查找 ASL；散列表 ASL（成功/失败）；B/B+ 树 | 失败 ASL 的分母是"槽数"不是"元素数" |
| 07 排序 | 各排序的时间/空间/稳定性；堆调整；归并；基数；外部排序 | 稳定性与是否原地是两问 |

**必背量级**（考场直接写）：

| 结构/操作 | 平均 | 最坏 |
|---|---|---|
| 顺序表插/删 | $O(n)$ | $O(n)$ |
| 单链表查找 | $O(n)$ | $O(n)$ |
| 折半查找 | $O(\log n)$ | $O(\log n)$ |
| 二叉排序树 | $O(\log n)$ | $O(n)$（退化成链） |
| 散列查找 | $O(1)$ | $O(n)$（全冲突） |
| 堆插入/删除 | $O(\log n)$ | $O(\log n)$ |
| 建堆 | $O(n)$ | $O(n)$ |
| 快速排序 | $O(n\log n)$ | $O(n^2)$（已有序） |
| 归并排序 | $O(n\log n)$ | $O(n\log n)$ |

**稳定性**：稳定 = 插入、冒泡、归并、基数；不稳定 = 选择、希尔、快速、堆。

## 3 陷阱（抄进错题本）

- `408-DS-0202` 顺序表插删平均移动 $n/2$ 次 —— **忘了除以 2**。
- `408-DS-0203` 链表改指针：**先接后继，再断前驱**，否则断链。
- `408-DS-0203` 408 要求**纯 C 结构体 + 指针**，用 STL `vector` 直接判不合要求。
- `408-DS-0204` KMP 的 `next` 有三套约定（从 0 / 从 1 / 优化版 `nextval`），题干通常明示，**不换算就差 1**。
- `408-DS-0301` 卡特兰数 $C_n=\frac{1}{n+1}\binom{2n}{n}$ 数的是"合法出栈序列"，**不是"出栈方式"**。
- `408-DS-0302` 循环队列判空判满有**三种约定**（牺牲一个单元 / 设 `size` / 设 `tag`），题目给哪种就用哪种。
- `408-DS-0303` 多维数组地址：**先算行内偏移，再乘行长度**；行列优先别搞反。
- `DS-04` 完全二叉树：$n$ 个结点时叶子数 $=\lceil n/2\rceil$；结点 $i$ 的左孩子 $2i$、右孩子 $2i+1$、父 $\lfloor i/2\rfloor$。
- `DS-04` 由"前序 + 后序"**不能**唯一确定二叉树；必须有一个中序。
- `DS-04` 哈夫曼树**没有度为 1 的结点**；$n$ 个叶子共 $2n-1$ 个结点。
- `DS-05` 最小生成树用 Prim（稠密）或 Kruskal（稀疏）；**最短路**用 Dijkstra（非负权）或 Floyd（全源）。
- `DS-05` 关键路径是**最长**路径（工期），不是最短路径；关键活动延迟会拖整体工期。
- `DS-05` 拓扑排序能排完 ⇔ 图无环；有环时输出结点数小于总数。
- `DS-06` 折半查找**只能用于有序顺序表**，链表不行（不能随机访问）。
- `DS-06` 散列失败 ASL 的分母是**散列表长度（槽数）**，不是元素个数。
- `DS-06` 散列表**删除不能直接置空**（会截断探测链），要打删除标记。
- `DS-06` B 树关键字数 $\in[\lceil m/2\rceil-1,\,m-1]$；B+ 树**所有关键字都在叶子**，非叶只做索引。
- `DS-07` 快速排序在**已有序**时退化为 $O(n^2)$；选枢轴要随机化或三数取中。
- `DS-07` 堆排序建堆 $O(n)$ 但每次调整 $O(\log n)$，总 $O(n\log n)$；**建堆不是 $O(n\log n)$**。
- `DS-07` 外部排序的**归并趟数** $=\lceil\log_k m\rceil$（$k$ 路归并、$m$ 个初始归并段）；败者树只减少比较次数，不改变 I/O 趟数。

## 4 一小时怎么用

**只剩 1 小时**，按这个顺序：

1. **10 分钟**：抄 §2 的「必背量级」和「稳定性」两行——这是选择题送分点。
2. **30 分钟**：手写三个代码模板（不用跑）：单链表逆置、二叉树非递归中序、快速排序划分。
3. **20 分钟**：扫 §3 陷阱，把没印象的抄进错题本（**只抄现象 + 原因，不抄题**）。

**不要**在 1 小时里做综合题——那是 `exam/` 和刷题的时间，不是速通的时间。
