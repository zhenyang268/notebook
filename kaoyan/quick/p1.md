# 政治 · 一小时速通

> **对应考纲**：`P1`（100 分）｜ 六模块 ｜ 详细内容见 `exam/politics/<模块>/`
> **读法**：§1 分值地图 10 分钟 → §2 六模块骨架 35 分钟 → §3 打法与陷阱 15 分钟。
> **这一科的特点**：**选择题靠理解 + 记忆，分析题靠"踩点"。**
> 一小时的产出不是"背完"，是**建立框架**，让之后刷题时每道题都知道该挂在哪。

## 1 分值地图

| 模块 | 占比 | 分值（100） | 特点 |
|---|---|---|---|
| 马原 | 22% | 22 | **最难**，理解型，分析题必考 |
| 新思想 | 22% | 22 | **分值上升最快**，时政结合紧 |
| 史纲 | 15% | 15 | 时间线 + 因果 |
| 思修与法治 | 15% | 15 | 记忆型，性价比高 |
| 毛中特 | 13% | 13 | 与史纲、新思想有重叠 |
| 时政与当代 | 13% | 13 | **11 月后才齐**，不急 |

**题型**：单选 16 × 1 = 16 分；多选 17 × 2 = 34 分；分析题 5 × 10 = 50 分。

**多选是分水岭**：34 分，错一个就少 2 分（多选题少选得部分分、错选不得分）。
**选择题总分 50 分，分析题总分 50 分**——两边都不能放。

## 2 六模块骨架

### 2.1 马原（22 分，最难）

四块：
```
唯物论（物质与意识、实践） → 辩证法（三大规律 + 五对范畴）
                            → 认识论（实践与认识、真理）
                            → 唯物史观（社会存在与意识、生产力与生产关系）
                            → 政治经济学（商品、剩余价值、资本循环）
                            → 科社（空想 → 科学）
```

**三大规律**（必考）：对立统一（矛盾）、量变质变、否定之否定。
**五对范畴**：原因结果、必然偶然、可能现实、现象本质、形式内容。

**马原分析题打法**：**先找原理，再套材料**。材料里出现"矛盾""发展""实践""认识"就给对应原理，然后"材料中……体现了……"。

### 2.2 新思想（22 分，分值最高）

七章：总论（两个结合、六个必须坚持）→ 中国式现代化 → 经济与高质量发展 → 政治与法治 → 文化与意识形态 → 民生与生态 → 国防外交与党建。

**特点**：与时政强绑定，**每年新增内容必考**。分析题常从这里出。

### 2.3 史纲（15 分）

时间线：
```
1840 鸦片战争 → 1911 辛亥 → 1919 五四 → 1921 建党 → 1927 井冈山
→ 1935 遵义 → 1945 抗战胜利 → 1949 建国 → 1956 社会主义改造完成
→ 1978 改革开放 → 2012 新时代
```

**考法**：**因果 + 意义**。"为什么说 XX 是转折点""XX 的历史意义"。

### 2.4 思修与法治（15 分，性价比最高）

五章：人生观 → 理想信念 → 社会主义核心价值观 → 道德 → 法治。

**特点**：**纯记忆，最容易拿分**。选择题多，分析题也有（道德/法治结合时政）。

### 2.5 毛中特（13 分）

四章：新民主主义革命 → 社会主义改造与建设 → 邓小平理论 → 三个代表与科学发展观。

**与史纲重叠**：史纲讲"发生了什么"，毛中特讲"理论是什么"。

### 2.6 时政与当代（13 分）

按年度建立。**11 月后才齐**，现在不用投入。

## 3 打法与陷阱

### 选择题（50 分）

- **单选**：四个选项里三个明显错，一个"看起来对但不完整"——选最完整的那个。
- **多选**：**宁缺毋滥**。只选**确定对**的，不确定的不选（错选整题 0 分，少选还有分）。
- **排除法**：绝对化表述（"唯一""完全""彻底"）多为错；"根本""决定""本质"多为对。

### 分析题（50 分）

**踩点给分**，不是"写得多就给分"。每道题：
```
第一步：定位原理（这道题考哪个模块的哪个原理）
第二步：写原理（教材原话，尽量准确）
第三步：结合材料（"材料中……体现了……"）
第四步：总结（一句话回到题目问的问题）
```

**每道题写 4-6 个点**，每点 2-3 行。**分点写，标序号**。

### 陷阱

- 马原：**不要用"常识"答哲学题**，要用**教材术语**（"矛盾的主要方面"不能写成"主要问题"）。
- 马原：**物质与意识的关系**不能倒置（物质决定意识，意识反作用）。
- 史纲：**时间顺序不能错**，尤其"哪次会议确立了什么"。
- 毛中特：**不同时期的"主要矛盾"表述不同**，要按时间对。
- 新思想：**表述要与最新文件一致**，不能凭印象改词。
- 多选：**"只要……就……"这类绝对化表述**基本是错的。
- 分析题：**不要空着**，哪怕只写原理也有分。

## 4 一小时怎么用

**如果只有 1 小时，做这三件事**：

1. **20 分钟**：画一遍**马原框架图**（四块 + 三大规律 + 五对范畴），这是最难也最值钱的部分。
2. **20 分钟**：抄**史纲时间线**（上面 11 个节点），每个节点写"发生了什么 + 意义"。
3. **20 分钟**：做 20 道多选（从已学模块里选），**只看错题的解析**，把错的原因归类（记错/理解错/没见过）。

**不要**在 1 小时里背分析题模板——那是 11 月底的事。
