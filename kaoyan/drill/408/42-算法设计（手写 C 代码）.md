## 二、L1 基础：先把模板默写出来

### L1-1 单链表就地逆置（额外空间 O(1)）
**题干**：设单链表结点定义为
```c
typedef struct LNode { int data; struct LNode *next; } LNode, *LinkList;
```
链表带头结点，初始状态为 `head -> 1 -> 2 -> 3 -> 4 -> 5 -> NULL`，其中 `head` 为头指针。要求编写函数 `void Reverse(LinkList head)`，把链表中除头结点外的所有结点就地逆置，即不新建结点、不借助数组，额外空间为 $O(1)$，并说明算法的时间复杂度。函数不得改变头结点的地址，调用后 `head` 仍指向头结点。

**题眼**：看到「就地」「额外空间 $O(1)$」「整表逆置」三个条件同时出现，就要想到用头插法重建链表：把原链表的结点依次摘下，再插到头结点之后。

**卡在哪**：多数人会把「改指针」当成一步，写出 `p->next = pre; pre = p; p = p->next;` 这样三行，以为顺序无所谓。停下来的念头是「反正都是往后挪，先改哪个不是一样」；实际上第一行一执行，`p` 原来的后继就再也找不到了，后两步拿到的 `p->next` 已经是逆置后的旧结点，链表当场断成两截。还有一类错法是把哨兵头结点也当成普通结点一起参与翻转，转完之后 `head` 不再是头，整个链表失去入口。

**分步**：① 先处理退化情形：若 `head == NULL` 或 `head->next == NULL` 则直接返回，不进入循环。② 设置三个工作指针：`pre` 置为空（它将成为逆置后链尾的 `next` 值），`p` 指向首元结点，`q` 备用。③ 进入循环，条件是 `p != NULL`，循环体严格按「先存、再改、后移」三步走：先用 `q` 暂存 `p->next`，再把 `p->next` 赋为 `pre`，最后令 `pre = p`、`p = q`，两步赋值的先后次序不可交换。④ 循环退出时 `p` 已为空，此时把 `head->next` 指向 `pre`，接回哨兵头结点。⑤ 依据循环体每轮恰好处理一个结点、每步为常数时间，得出时间为 $O(n)$、额外空间为 $O(1)$。

**拿分骨架**：①→2 分　②→3 分　③→6 分　④→2 分　⑤→2 分

**结果锚点**：逆置后链表为 `head -> 5 -> 4 -> 3 -> 2 -> 1 -> NULL`；`head` 地址不变；时间复杂度 `O(n)`；额外空间复杂度 `O(1)`。

**变式**：若链表不带头结点、`head` 直接指向首元结点，要求函数用返回值带回新的首元结点指针，函数签名与末尾的接回步骤要怎么改。

### L1-2 顺序表删除值域内的全部元素（双指针）
**题干**：顺序表定义为
```c
#define MAXSIZE 20
typedef struct { int data[MAXSIZE]; int length; } SqList;
```
当前 `length = 8`，从下标 0 到 7 的元素依次为 $3,\ 7,\ 1,\ 9,\ 5,\ 12,\ 8,\ 2$。给定闭区间端点 $s = 4$、$t = 8$。要求编写函数 `int DelRange(SqList *L, int s, int t)`，删除表中所有满足 $s \le x \le t$ 的元素，函数返回删除后的新表长。约束：不得申请与表长同阶的辅助数组，即空间复杂度为 $O(1)$；其余元素之间的相对次序必须保持不变。同时说明算法的时间复杂度。

**题眼**：看到「顺序表 + 删除满足某条件的一批元素 + 要求保持相对次序 + 空间 $O(1)$」，就要想到快慢双指针就地覆盖：用慢指针记写入位置、快指针负责扫描，一次遍历完成压缩。

**卡在哪**：最容易停在「删除就得挪元素」这个念头上，于是对每个待删元素都调用一次「删一个并前移后面全部」的函数，写出来是双重循环还不自知，复杂度滑到 $O(n^2)$——题目没说不许，但一旦在复杂度分析里写 $O(n^2)$ 就丢了分。另一种典型错法是用单层 `while` 边扫边删，删掉 `data[i]` 后把后面的元素整体前移，却让 `i` 照常自增，紧跟在被删元素后面的那个元素因此被跳过、没被检查。

**分步**：① 先做入口合法性判断：若 $s > t$ 则交换二者使区间有效（本题已给 $s \le t$，仍应写出该分支以体现完整性），若 `L->length == 0` 直接返回 0。② 设慢指针 `k = 0` 表示下一个保留元素的写入位置，快指针 `i` 从 0 扫到 `L->length - 1`。③ 循环体只做一个判断：若 `L->data[i]` 落在 $[s, t]$ 之外，就执行 `L->data[k] = L->data[i]` 并让 `k` 自增；落在区间内则跳过、什么也不做。④ 循环结束后把 `L->length` 置为 `k` 并返回 `k`，被覆盖掉的尾部元素不必清零。⑤ 依「两个指针各自单调后移、`i` 只走一遍」得出时间为 $O(n)$，辅助变量只有 `i`、`k` 两个，空间为 $O(1)$。

**拿分骨架**：①→2 分　②→3 分　③→6 分　④→2 分　⑤→2 分

**结果锚点**：`DelRange(&L, 4, 8)` 返回新表长 `5`；`L.length = 5`；删除值为 `7, 5, 8`；保留序列为 `3, 1, 9, 12, 2`（存于 `L.data[0..4]`）；时间复杂度 `O(n)`；辅助空间复杂度 `O(1)`。

**变式**：若改为把落在 $[s, t]$ 内的元素按原次序另存到一个给定的空顺序表中、原表保留其余元素，双指针的写入目标要怎么拆成两条路径。

## 三、L2 提高：真题主干难度

### L2-1 两个等长有序表求中位数（O(n) 时间、O(1) 空间）
**题干**：两个长度均为 $n=6$ 的非递减有序顺序表 $A$、$B$，元素为整数，以数组加长度表示：

| 下标 | 0 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|---|
| $A$ | 11 | 13 | 15 | 17 | 19 | 21 |
| $B$ | 12 | 14 | 16 | 18 | 20 | 22 |

把 $A$、$B$ 归并成一个长度 12 的非递减序列后，规定其中位数为该序列中下标为 6 的元素（下标从 1 计，即第 6 小者）。要求设计算法求此中位数，时间 $O(n)$、辅助空间 $O(1)$；不允许把 $A$、$B$ 归并到新数组，也不允许改动 $A$、$B$。给出 C/C++ 函数，并说明时间、空间复杂度。

**题眼**：看到「两个有序表 + 只要第 $k$ 小 + 辅助空间 $O(1)$」，就要想到双指针归并，只走指针、只记个数、不写入结果表。

**卡在哪**：多数人条件反射写归并排序的 merge，先把两表抄进长度 12 的辅助数组再取第 6 个，空间立刻变成 $O(n)$，空间分丢干净；另一部分人看到「有序」就上二分减治法，在 $A$、$B$ 两端各切一半，可是那套下标折算本是给「长度不等、要 $O(\log)$」的场景用的，本题等长且明写 $O(n)$，硬套减治极易把边界和偏移写错，连截断条件都写不出来。

**分步**：①先判定方法：辅助空间 $O(1)$ 直接排除「归并进数组」，也排除需要在中途保存半段的写法，只留双游标扫描；②设 $i=j=0$、计数 $cnt=0$，每轮比较 $A[i]$ 与 $B[j]$，把较小者当作「虚拟取出」，只把 $cnt$ 加一、对应游标后移；③取出的瞬间判 $cnt$ 是否已到目标序号，到了立即返回，不再继续扫描；④处理一个表先扫完的边界，用越界即视为无穷大的短路判断，让剩下的表继续按序「虚拟取出」；⑤按「每个元素至多比较一次、无额外数组」写出复杂度。

**拿分骨架**：①→3 分　②→5 分　③→4 分　④→3 分

**结果锚点**：n=6；中位数（第6小）=16；时间 O(n)；辅助空间 O(1)。

**变式**：把目标改成合并后第 6 小与第 7 小的平均值，并允许 $A$、$B$ 长度不等（$n$ 与 $m$），要求时间降到 $O(\log\min(n,m))$。

### L2-2 二叉树按层遍历求最大宽度
**题干**：二叉树以二叉链表存储，结点结构为 `lchild | data | rchild`，`data` 为单个大写字母且互不相同。现有二叉树用括号表示法给出，逗号左侧为左子树、右侧为右子树，缺省一侧即为空：

$$T=A\bigl(B(D,E(G,)),\ C(,F(H,I))\bigr)$$

定义某层的「宽度」为该层上实际存在的结点个数，空位置不计入。请设计算法求 $T$ 的最大宽度值以及首次取得最大宽度的层号（根为第 1 层），给出 C/C++ 函数，并说明所用辅助空间与时间复杂度。

**题眼**：看到「按层 + 每层计数 + 取最大」，就要想到队列层序遍历时把「出队前队列的长度」当作本层结点数，整层整层地处理。

**卡在哪**：多数人写队列层序遍历时不设层边界，出队一个就把左右孩子压进去，边压边数，结果把下一层的结点算进本层，宽度必然偏大、层号也跟着错位；也有人想省事，按完全二叉树的编号规则把树塞进顺序数组再逐层统计，可是遇到单支树就要开 $2^{h}$ 大小的数组，空间早已超出范围，而且编号法本身还要先知道树高。真正的岔路口就是：究竟在出队前先把本层规模固定下来，还是边出队边入队边计数。

**分步**：①判断分层手段：不预先存整棵树，采用队列，每轮进入新层时先读出队列当前长度并存为 $size$；②只出队 $size$ 个结点，出队时把非空左右孩子入队，空孩子不入队，避免虚增下一层的 $size$；③本层 $size$ 与当前最大宽度比较，只有严格大于才更新最大值并记下该层号，保证记录的是首次出现的层；④树空时单独返回宽度为 0、层号为 0；⑤复杂度：每个结点入队出队各一次，队列中最多同时存放一层结点。

**拿分骨架**：①→3 分　②→5 分　③→4 分　④→3 分

**结果锚点**：结点数 N=9；层宽序列（根层起）=(1,2,3,3)；最大宽度=3（第3、4层并列最大）；首次取得最大宽度的层号=3；时间 O(N)；辅助空间 O(N)（队列）。

**变式**：把宽度改定义为该层最左结点到最右结点之间的位置数（中间空位也计入），队列元素须额外携带结点在完全二叉树下的编号，用编号之差计算宽度。

### L2-3 判断完全二叉树（不数层数）
**题干**：二叉树以二叉链表存储，`data` 为正整数且互不相同。请设计一个算法判断该二叉树是否为完全二叉树。约束：只允许做一次遍历，不允许先统计结点总数或树高，也不允许把树转存成顺序结构后再逐层比对。给出 C/C++ 函数，返回 1 表示是完全二叉树、0 表示不是，并说明判定依据与复杂度。现有两棵树用括号表示法给出（逗号左侧为左子树、右侧为右子树，缺省一侧为空）：

$$T_1=A\bigl(B(D,E),\ C(F,)\bigr)\qquad T_2=A\bigl(B(D,),\ C(,E)\bigr)$$

要求算法对任意二叉树都成立，并说明 $T_1$、$T_2$ 各自会走哪条分支退出。

**题眼**：看到「完全二叉树 + 不许数层数结点数」，就要想到层序遍历中把空孩子也入队，用「出过空结点之后不许再出非空结点」这条判据。

**卡在哪**：多数人第一反应是求树高 $h$ 与末层结点数逐层核对，题目恰好把这条路堵死；退一步想到「按完全二叉树编号，看最大编号是否等于结点个数」，这又要数结点总数，单支树时编号还会指数增长。真正要选的岔路口是：把空孩子当哨兵一并入队、用一个标志位记录「是否已经见过空」，还是先入队再判空导致标志位与出队顺序错乱。

**分步**：①定判据：层序遍历，空孩子也入队；②出队元素为空时置标志 $flag=1$，之后继续出队，若再出现非空结点即可立即判定不是完全二叉树；③队列排空且期间从未出现「空后又非空」，则判定是完全二叉树；④空树单独处理，直接返回 1；⑤复杂度：每个结点及其空孩子指针各入队至多一次，时间与队列空间按结点数线性计。

**拿分骨架**：①→4 分　②→4 分　③→2 分　④→2 分　⑤→3 分

**结果锚点**：T1 返回 1（完全二叉树），T2 返回 0（非完全二叉树）；T1 退出分支：首次遇空为 C 的右空，其后全空，队列排空后返回 1；T2 退出分支：首次遇空为 B 的右空，其后出队到非空结点 E 时立即返回 0；空树返回 1；时间 O(N)；辅助空间 O(N)（N 为结点数）。

**变式**：把判据换成「判断是否为满二叉树」且同样不许求树高，改为在层序遍历中比较每层实际结点数与 $2^{\text{层号}-1}$ 的关系，需要在队列元素中带层号。

## 四、L3 拔高：条件一变就认不出来

### L3-1 单链表循环右移 k 位（三段逆置）
**题干**：不带头结点的单链表结点定义为

```c
typedef struct LNode { int data; struct LNode *next; } LNode, *LinkList;
```

现有链表 $L: 1\to2\to3\to4\to5\to6\to7$，指针 `head` 指向首结点。要求把链表循环右移 $k=10$ 位（即每个结点后移 10 个位置，超出表尾的从头接回），并返回移位后链表的头指针。限制：额外空间 $O(1)$，只允许写一个辅助函数 `LNode* rev(LNode *p, int len)`，其功能是对以 `p` 为起点、连续的 `len` 个结点做原地逆置并返回逆置后的段首指针，主函数中可多次调用它；允许先遍历一次求表长。给出完整函数（含边界处理）并说明调用顺序。

**题眼**：看到“原地 + 循环移位 + 只给你一个通用逆置子函数”这三个特征凑在一起，才意识到这题并不要求你“找倒数第 k 个结点再切断重接”，而是要求“整体逆置一次、再分段逆置两次”——把位移量转成端点的翻转。

**卡在哪**：多数人会停在“先求表长、再定位第 $n-k$ 个结点、把后半段摘下来挂到前面”。他们以为逆置会把结点顺序彻底搞乱、段与段的接缝对不上，所以不敢整体逆置；就算逆置了，也常常忘记“整体逆置后原来的表尾变成表头”，于是第二段、第三段的起点仍然用旧指针去找，指针指向已断开的结点，从而造成断链。另一个高频错误是拿到 $k$ 后直接当位移量用，没有先对表长取模。

**分步**：① 遍历一遍求出表长 $n$，把 $k$ 对 $n$ 取模，若结果为 0 直接返回原表头，这是“右移 $n$ 的整数倍等于不动”的边界；② 记下原表头与原表尾，先对整表调用一次 `rev`，得到新的头和新尾，此时结点次序整体翻转；③ 对前段（长度 $k$）调用 `rev`，得到前段新头与新尾，再对后段（长度 $n-k$）调用 `rev`，同样拿到两端的指针；④ 把前段尾部与后段头部接上，返回前段新头作为整个链表头，依据是逆置只改指针方向不改结点集合，分段逆置恰好等价于把后 $k$ 个结点搬到前面；⑤ 逐项核验 $k=0$、$k$ 是 $n$ 的倍数、$n=1$、空表这几类输入，确认没有对空指针解引用、没有成环。

**拿分骨架**：①→2 分　②→4 分　③→4 分　④→3 分　⑤→2 分

**结果锚点**：n=7；k'=10 mod 7=3；移位后序列：5→6→7→1→2→3→4；移位后头指针指向结点 5；调用参数序列：rev(head=1, len=7) → rev(p=7, len=3) → rev(p=4, len=4)；连接：结点 7 的 next 指向结点 1，结点 4 的 next=NULL；边界判定：head=NULL 或 n=0 返回 NULL，k=0 或 k%n=0（n>0）返回原 head，n=1 返回原 head。

**变式**：把要求改成“只允许遍历链表一次、不许先求表长就确定位移边界”，或者改成循环左移 $k$ 位，并在题干中明确只给一个“把整段原地逆置”的子函数。

### L3-2 求二叉树中两结点的最近公共祖先（不存父指针、不递归）
**题干**：二叉树以二叉链表存储，结点含 `data`、`lchild`、`rchild` 三个域，**没有** `parent` 域。树中 8 个结点的孩子关系如下，`root` 指向 A：

| 结点 | lchild | rchild |
|---|---|---|
| A | B | C |
| B | D | E |
| C | F | G |
| D | NULL | NULL |
| E | H | NULL |
| F | NULL | NULL |
| G | NULL | NULL |
| H | NULL | NULL |

给定 `p` 指向 H、`q` 指向 G。要求写出函数求 `p` 与 `q` 的最近公共祖先并返回其指针。限制：不得增设 `parent` 域或任何等价的“从孩子回指父亲”的辅助结构，不得使用递归（含任何形式的自我调用），时间复杂度 $O(n)$。允许使用显式栈及其它辅助数组。

**题眼**：看到“不许加父指针 + 不许递归 + 求 LCA”，才意识到关键在于“显式后序遍历栈中、从底到顶正好是一条从根到栈顶结点的路径”，于是把递归回溯本该记住的信息提前复制出来保存，问题就变成了比较两条路径。

**卡在哪**：第一反应是“从 p、q 各自往根走、第一个碰头处即答案”，可题面把 `parent` 域禁掉了，这条路当场断；退而求其次去写层序遍历，以为“记录每个结点由谁入队”就能复原路径，可队列里父结点出队后信息已经丢失，同一层多个结点还会共用一个临时变量，路径记录直接失效。还有一个隐蔽的坑：用普通前序或中序的显式栈，栈中结点并不构成一条完整的根路径。

**分步**：① 先点明所做判断的依据——后序遍历过程中栈内从底到顶恰是根到栈顶结点的完整路径，所以只需在“栈顶恰好是 p”与“栈顶恰好是 q”这两个时刻各复制一份栈内容，不必维护父指针；② 用数组模拟栈，栈元素除结点指针外再带一个“右孩子是否已处理”的标志位（或另设一个记录上次访问结点的指针），据此实现不递归的后序遍历，保证每个结点入栈两次、出栈两次的次序正确；③ 每次循环检查栈顶结点是否为 `p` 或 `q`，是则把当前栈内所有结点按自底向顶的次序整份拷入对应数组并记下长度，依据是此刻栈内容就是该结点的祖先链；④ 两个数组都取到后，从下标 0 起逐位比较，最后一个相同位置上的结点即所求，依据是最近公共祖先正是两条根路径的最长公共前缀的末端；⑤ 复核 `p` 是 `q` 的祖先、`p` 或 `q` 为根、`p` 与 `q` 相同这几种退化情形，确认返回值与数组长度都能正确处理。

**拿分骨架**：①→2 分　②→5 分　③→4 分　④→3 分　⑤→1 分

**结果锚点**：n=8；p=H 的根路径栈（自底向顶）[A,B,E,H]；q=G 的根路径栈（自底向顶）[A,C,G]；最长公共前缀下标 0 的结点为 A；最近公共祖先结点=A，返回 root；最大栈深=4；时间复杂度 O(8)=O(n)；退化判定：p 为根或 q 为根→返回该根，p=q→返回 p，p 是 q 的祖先→返回 p。

**变式**：改成求 `p` 到 `q` 路径上的第 $t$ 个结点，或求两结点间距离（提示可用各自在栈中的深度），或把存储结构换成带 `parent` 的三叉链表并要求全程 $O(1)$ 辅助空间。
