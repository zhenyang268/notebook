# drill/ — 难度阶梯题库（第六层）

> **本层回答一个问题：同一类题，我要练到哪一档才算过关。**
> 其余五层都不回答这个：`note/` 只按考点聚类、`exam/` 只按章讲透、`真题/` 只按年份还原，
> 三者里的每道题都是「同级」的，没有一条从模板到变式的坡。
>
> 设计取舍（为什么是这三档、为什么给锚点不给解答、必做集怎么算出来、被否掉的六个方案）见 **`DESIGN.md`**。
> 本页只讲怎么用。

---

## 一、为什么单独一层

2026-11-03 之前，全库 360 道题全是选择题，`exam/真题/README.md` 自己写着「综合应用题（41–47）尚未收录」。
也就是说 **408 的 70 分、数一的 150 分，在库里没有一道题**。补这个缺不能塞进 `真题/`：
真题是**按年份**组织的，而 41–47 的练法是**按题号**——同一位置每年考同一类，练的是那类的手算流程，不是那一年。

所以本层按 **题号 / 题型线** 组织，每条线内部再按 **L1 → L2 → L3** 排坡。

| 层 | 组织维度 | 回答 |
|---|---|---|
| `note/` | 考点 | 这类题往哪想 |
| `exam/` | 章 | 这一章怎么推 |
| `exam/真题/` | 年份 | 整套做一遍 |
| **`drill/`** | **题号 / 题型线 × 难度** | **这一档我会不会，下一档差在哪** |

## 二、三档是什么（与 `syllabus/tiers.md` 的 T1/T2/T3 不是一回事）

`syllabus/tiers.md` 的 T1/T2/T3 分的是**知识点**——哪些分先拿。
本层的 L1/L2/L3 分的是**题目**——同一根题型线上，坡的哪一段。

| 档 | 题长什么样 | 判据（我算不算过了这一档） | 大致对应 |
|---|---|---|---|
| **L1 基础** | 一步到位：方法不用选，直接套模板 | 不看「分步」也能在 **3 分钟**内写出公式 / 表格 / 定义骨架 | T1 的知识点 |
| **L2 提高** | 两步以上，要在两三个方法里选一个，选错走不下去 | 能说出**为什么选这个方法而不是另一个**，而不只是算完 | T2 |
| **L3 拔高** | 条件被改过：加约束、换顺序、两个模块耦合 | 读完题干能指出**哪个条件被改了**，并说出它把哪一步变成了新的一步 | T3 + 跨章耦合 |

**为什么不能拿 T1/T2/T3 直接当题的难度**：T3 的知识点（比如 B 树分裂）完全可以出成一道 L2 的「按流程走一遍」；
反过来 T1 的知识点（比如哈夫曼）耦合进外部排序的置换-选择，就变成 L3。**难度是题的性质，不是知识点的性质。**

## 四、每道题给什么

固定七个字段，一个都不省：

| 字段 | 写什么 | 为什么需要它 |
|---|---|---|
| `题干` | 完整题面，数据 / 表 / 初始状态全在里面 | 不看别处就能动手 |
| `题眼` | 「看到 X 就想到 Y」 | 题型识别的线，比解法本身更值钱 |
| `卡在哪` | 多数人停在第几步、停下来的那个具体错误念头 | 错题复盘的对象在这一行 |
| `分步` | ①②③… 每步「做什么 + 依据」 | 考场上的实际动作 |
| `拿分骨架` | 分值拆到步上，合计等于该题满分 | 综合题是**步骤分**，知道分在哪才知道哪里不能空 |
| `结果锚点` | **只给可核对的量**：数值 / 序列 / 边集 / 判定结论 | 做完先对这里，对不上再回头读「卡在哪」 |
| `变式` | 改一个条件会变成什么题 | 从「会做这道」到「见过这一类」 |

**给锚点，不给推导。** 本层是原创题，答案不在任何别处，所以必须给可核对的结果，否则做完无法验收
（这就是"限时正确率"落不了地的原因）。但只给结果不给过程：过程去看 `exam/`。
锚点由模型推演、**未经人工复核**——重算一遍就能自己判它对不对，这正是它该起的作用。

## 五、怎么用（顺序不能反）

| 阶段 | 做什么 | 判据 | 没过怎么办 |
|---|---|---|---|
| 1 | 七条 408 线 + 七条数一线的 **L1 全过一遍**（39 题，约 3.5 h） | 3 分钟内出骨架 | 回 `note/` 对应考点，别看 L2 |
| 2 | L2 每线 2 道（28 题，约 7 h） | 每题能说出「为什么用这个方法」 | 回 `exam/` 该章「二、正文」 |
| 3 | L3 每线 1 道（14 题，约 6 h） | 能指出被改的是哪个条件 | 回 `syllabus/tiers.md` 对应科目分层 |
| 4 | 整套回归 | `exam/真题/<年>.md` 限时做 | 错题落回本层对应线的「卡在哪」 |

**必做 81 题 / 约 16 小时**，五周排期写在 `DESIGN.md` §6；其余 38 题是选做题，
时间不够时**先砍选做，绝不砍 L1**。做题记录按 `正确 / 部分 / 错` 记，过关线 L1 ≥90%、L2 ≥70%、L3 ≥40%。

**跳档没用**：L2 卡住十次，八成是 L1 里某个表格压根没默写过（典型：关键路径的 $vl$ 取 min 写成取 max、
失败 ASL 把外部结点层数当比较次数）。回 L1，不要往前冲。

## 六、三条纪律

1. **给锚点不给推导。** 每题必须给「结果锚点」，但不得给完整解答；要过程去 `exam/`。
   锚点是模型推演、未经人工复核，抽检记录在 `PROGRESS.md`。
2. **不出现年份。** 本层全是**原创变式题**，题干与数据由本仓自拟；写「某年真题」就是编造。
   真题原卷只认 `exam/真题/` 里实际存在的那九年。注意：`2000 m` 这类数据不算年份，闸门只拦「20xx 年」。
3. **不写"难度星级""建议用时"** 这类打分。档位用 L1/L2/L3，判据写在 §二，用时写在 `DESIGN.md` §6 的预算表里（只此一处）。

- **41–47 的真题原卷仍未收**：综合题需要原卷手写过程才能还原，公开渠道的回忆版只到选择题。
  本层用原创变式替代，解决的是「有没有坡」；「历年原题」这一角仍缺，缺在 `exam/真题/README.md` 里已标明。
- **数一的题不是真题**：`note/` 里 72 个考点的「真题落点」全写「本年段无对应题目」，本层同理。
- **锚点未经人工复核**：抽检 14 题（每线 1 题）之前，不得当标准答案引用。抽检口径见 `DESIGN.md` §7。
- **做题记录没有落点**：做没做、对没对目前靠脑子记，尚未接 `reviews/`。
- 英语一、政治没有对应文件：这两科的「题」是阅读与主观题，不适用本题号-题型线的组织方式。
