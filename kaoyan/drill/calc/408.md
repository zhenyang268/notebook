## 一、数据结构（14 项）

### 1 三重循环的次数 → 组合数

**动作**：把循环边界翻成「有序元组计数」，不要展开成 Σ。
**概念**：渐进复杂度只看增长阶，与机器快慢无关。
**步骤**：① 三个下标满足 $1\le i\le j\le k\le n$；② 这等价于「从 $n$ 个数里取 3 个、允许重复、按非降序排」；
③ 计数为 $\binom{n+2}{3}=\frac{n(n+1)(n+2)}{6}$。
**算例**：$n=5$ → $\binom{7}{3}=\frac{7\cdot6\cdot5}{6}=$ **35**。
**易混**：时间 vs 空间（空间指**辅助**空间，不含输入本身）；复杂度 vs 实测运行时间；上界 O 与紧界 Θ 不是一回事。

### 2 顺序表插入 / 删除的平均移动次数

**动作**：数「可插入位置数」，再对每个位置数要搬多少元素，等概率取平均。
**概念**：顺序表用「连续存储」换随机访问，代价是插入删除要搬元素。
**步骤**：① 长度为 $n$ 的表有 $n+1$ 个插入位置，插在第 $i$ 个位置要搬 $n-i+1$ 个；
② 平均 $=\frac{1}{n+1}\sum_{i=1}^{n+1}(n-i+1)=\frac{n}{2}$；③ 删除有 $n$ 个位置，删第 $i$ 个搬 $n-i$ 个，平均 $\frac{n-1}{2}$。
**算例**：$n=10$ → 插入 **5** 次、删除 **4.5** 次（$n=10$ 插在第 5 位要搬 6 个，删第 5 位搬 5 个）。
**易混**：逻辑结构 vs 存储结构（线性表是逻辑，顺序/链式是存储）；可插入位置数 n+1 与元素数 n；平均情形 vs 最坏情形。

### 3 KMP 的 next 与 nextval

**动作**：`next[j]` 看**前 $j-1$ 个字符**的最长相等前后缀长度，再 $+1$；`nextval` 与该位置的字符比一次，相等就继承。
**概念**：KMP 失配时主串指针不回退，靠模式串自身的前后缀信息往右滑。
**步骤**：① 从 $j=2$ 起逐个算前缀字符串；② 求它的最长「真前缀 = 真后缀」长度 $L$；③ $\text{next}[j]=L+1$（$\text{next}[1]=0$）；
④ `nextval[j]`：若 $p[j]=p[\text{next}[j]]$ 则 $\text{nextval}[j]=\text{nextval}[\text{next}[j]]$，否则等于 $\text{next}[j]$。
**算例**：模式 `ababaa`（1 起）→ next = **0,1,1,2,3,4**；nextval = **0,1,0,1,0,4**。
**易混**：next 与 nextval（后者在「同字符」时可再滑一步）；三套下标约定（0 起 / 1 起 / next[1]=0）；前后缀看「前 j−1 个字符」而非含当前字符。

### 4 二叉树的两条公式

**动作**：结点数与度的计数关系 + 完全二叉树的编号关系。
**概念**：n0=n2+1 本质是「边数 = 结点数−1」的计数结果，不是定义。
**步骤**：① 设度为 0/1/2 的结点数为 $n_0,n_1,n_2$，则 $n=n_0+n_1+n_2$ 且 $n-1=n_1+2n_2$；
② 两式相减得 $n_0=n_2+1$；③ 完全二叉树按层编号，$n$ 个结点的高度 $=\lfloor\log_2 n\rfloor+1$。
**算例**：$n_2=49$ → $n_0=$ **50**；$n=1000$ → 高度 **10**（$2^9=512<1000\le1024=2^{10}$）。
**易混**：完全二叉树 vs 满二叉树；高度 vs 深度（一个从上数、一个从下数）；叶结点 vs 终端结点（同义）。

### 5 哈夫曼 WPL

**动作**：反复取两个最小权合并；**WPL = 所有合并产生的新结点权之和**，不必画树数路径。
**概念**：哈夫曼树让「权大的离根近」，WPL 是**带权外部路径长度**，权只在叶上。
**步骤**：① 权值升序；② 取最小的两个相加，和作为新结点放回；③ 重复到只剩一个；④ 把每次的和累加即 WPL。
**算例**：$\{1,2,3,4,5\}$ → 合并 $3,6,9,15$ → WPL $=3+6+9+15=$ **33**。
**校验**：按路径算 $3(1+2)+2(3+4+5)=33$，一致。
**易混**：WPL vs 简单权值和；二叉树 vs k 叉树（k 叉要补虚叶）；哈夫曼树形态不唯一，但 WPL 唯一。

### 6 卡特兰数

**动作**：判断「是不是卡特兰」再套公式——$n$ 个结点的二叉树形态数、$n$ 个元素的出栈序列数、$n$ 对括号合法串数，是同一个数。
**概念**：卡特兰数数的是「无标号形态」，与结点里放什么值无关。
**步骤**：① 确认「无标号、只数形态」；② 套 $C_n=\frac{1}{n+1}\binom{2n}{n}$；③ 小数值记一下：$1,1,2,5,14,42,132$。
**算例**：$n=4$ → **14**；$n=5$ → **42**；$n=3$ → **5**。
**易混**：形态数 vs 标号树数（后者再乘 n!）；二叉树形态数、出栈序列数、合法括号串数是同一个数；栈与队列的合法序列数不同。

### 7 折半查找判定树与 ASL

**动作**：按 `mid=(lo+hi)/2` 递归建树，统计**每层结点数**，再算加权平均。
**概念**：折半要求「有序 + 顺序存储」，靠下标直接跳到中点。
**步骤**：① 第一个 `mid` 是根，左半、右半递归；② 数出第 1、2、3… 层的结点数；③ $\text{ASL}=\sum$ 层号 × 该层结点数 ÷ $n$；④ 失败 ASL 统计 $n+1$ 个外部结点。
**算例**：$n=11$ → 各层 $1,2,4,4$ → $\text{ASL}=\frac{1\times1+2\times2+3\times4+4\times4}{11}=\frac{33}{11}=$ **3.0**。
**易混**：成功 ASL（除 n）vs 失败 ASL（除 n+1，且落在外部结点）；判定树 vs 二叉排序树；折半 vs 分块（块间有序即可）。

### 8 散列 ASL（成功 / 失败两套）

**动作**：先按探测序列建表，成功数「每个关键字的比较次数」，失败数「每个散列地址查到空位的比较次数（含判空那一次）」。
**概念**：ASL 由「装填因子 + 冲突处理方法」共同决定，不是由散列函数单独决定。
**步骤**：① 逐个插入，记录每个关键字的探测步数；② 成功 ASL = 步数和 ÷ $n$；③ 失败 ASL = 对 $0\sim m-1$ 每个地址各探一次的和 ÷ $m$。
**算例**：表长 11、$H(k)=k\bmod 11$、线性探测、关键字 $\{22,41,53,46,30,13,1,67\}$ → 表 `22,1,46,13,67,_,_,_,41,53,30`；
探测步数 $1,1,1,1,3,2,1,4$ → 成功 ASL **1.75**；失败各地址步数 $6,5,4,3,2,1,1,1,9,8,7$ → 失败 ASL **4.27**。
**易混**：成功 ASL（除 n）vs 失败 ASL（除表长 m）；装填因子 α vs 冲突次数；开放定址与拉链法的失败查找口径不同。

### 9 排序比较次数与外部排序趟数

**动作**：记一张「最好 / 最坏 / 平均」的表，再用趟数公式。
**概念**：排序算法的性质是「时间 / 空间 / 稳定性」三条，互不推导。
**步骤**：① 直接插入、冒泡、快排最坏都是 $\frac{n(n-1)}{2}$；② 归并排序趟数 $\lceil\log_2 n\rceil$；
③ $m$ 个归并段 $k$ 路归并趟数 $\lceil\log_k m\rceil$；④ 最佳归并树若 $(m-1)\bmod(k-1)\ne0$，补 $(k-1)-((m-1)\bmod(k-1))$ 个虚段。
**算例**：$n=10$ 快排最坏 **45** 次；$m=1000$、$k=5$ → **5 趟**（$5^4=625<1000\le3125=5^5$）；$m=1000$、$k=5$ 时 $999\bmod4=3$ → 补 **1** 个虚段。
**易混**：比较次数 vs 移动次数；稳定性 vs 时间复杂度（快排快但不稳定）；外部排序的「趟数」vs「归并段数」。

### 10 B 树的关键字数量与高度

**动作**：用「每结点关键字数」的上下界，推整棵树的关键字总数与高度。
**概念**：B 树是多路平衡查找树，所有叶结点在同一层，每个结点的关键字数被「阶」卡住上下界。
**步骤**：① $m$ 阶：根至少 1 个关键字，非根至少 $\lceil m/2\rceil-1$ 个，每结点最多 $m-1$ 个；
② 高度 $h$ 的树最少关键字 $=2\lceil m/2\rceil^{h-1}-1$；③ 反过来由 $n$ 求最大高度，取每层最少分支；
④ 查找时的读盘次数 = 树高（根算一层）。
**算例**：$m=5$、$h=3$ → 最少 $2\times3^{2}-1=$ **17** 个关键字；$m=5$、$n=17$ → 最大高度 **3**（高度 4 至少 53 个）。
**易混**：阶 $m$ vs 每结点关键字上限 $m-1$（差 1）；B 树 vs B+ 树（后者数据只在叶、内部只存索引）；「树高」vs「查找长度」（有的教材把根算 0 层）。

### 11 AVL 树的旋转判定

**动作**：先算平衡因子，再看「新结点插在失衡结点的哪一侧的哪一侧」，据此选单旋或双旋。
**概念**：AVL 是「每个结点左右子树高度差不超过 1」的二叉排序树，失衡时只靠局部旋转恢复。
**步骤**：① 从插入点向上找第一个 $|BF|>1$ 的结点；② $BF=$ 左高 − 右高；
③ 新结点在外侧（LL / RR）→ 单旋；在内侧（LR / RL）→ 先子后父两次旋；
④ 旋转后中序序列不变（仍是二叉排序树）。
**算例**：依次插入 $3,2,1,4,5$ → 插 1 时 LL 失衡，对 3 右旋，根变 **2**；插 5 时 RR 失衡，对 3 左旋 → 最终层序 **2,1,4,3,5**，共 **2** 次旋转。
**易混**：旋转次数 vs 旋转方向（一次双旋算两次单旋）；「失衡结点」是高度差超 1 的那个，不是新插入点；LL/RR 是「相对失衡结点」的位置，不是相对整棵树。

### 12 最小生成树的表格法与唯一性

**动作**：Kruskal 按边权升序取边、用并查集判环；Prim 按顶点扩展、每次取最小跨界边。
**概念**：MST 是「连通所有顶点且总权最小」的生成子图；只对连通无向图有定义。
**步骤**：① 边按权升序（同权按任一固定次序）；② 依次取边，两端已连通就丢弃；③ 取够 $n-1$ 条停；
④ 判断唯一性：某一步存在「多条同权且都能取」的边，则 MST 不唯一。
**算例**：6 条边 $(A\!-\!B,4),(A\!-\!C,2),(B\!-\!C,1),(B\!-\!D,5),(C\!-\!D,8),(D\!-\!E,2)$
→ 取 $BC(1)$、$AC(2)$、$DE(2)$、$BD(5)$，共 **4 条边、总权 10**（$AB$ 因成环被弃）。
**易混**：MST vs 最短路径树（前者总权最小、后者到源点距离最小）；边数恒为 $n-1$（不是 $n$）；Kruskal 判环用并查集、Prim 不必判环。

### 13 单源最短路径（Dijkstra 距离表）

**动作**：维护「已定集 / 未定集」，每轮从未定集取距离最小者定下来，再松弛它的出边。
**概念**：Dijkstra 求单源最短路，前提是**边权非负**；负权要用 Bellman-Ford。
**步骤**：① 初始化 $dist[s]=0$，其余 $\infty$；② 每轮取未定集中 $dist$ 最小者 $u$ 加入已定集；
③ 对 $u$ 的每条出边松弛 $dist[v]=\min(dist[v],dist[u]+w)$；④ 重复 $n$ 轮。
**算例**：边 $(A\!-\!B,4),(A\!-\!C,2),(B\!-\!C,1),(B\!-\!D,5),(C\!-\!D,8),(C\!-\!E,10),(D\!-\!E,2)$，
从 $A$ 出发 → 依次确定 $A(0),C(2),B(3),D(8),E(10)$，到 $E$ 的最短距离 **10**（路径 $A\!-\!C\!-\!B\!-\!D\!-\!E$）。
**易混**：Dijkstra vs Floyd（单源 vs 全源）；「已定集」的点距离不再改，这是非负权的保证；BFS 只能处理无权图。

### 14 拓扑排序（字典序最小序列）

**动作**：每轮「取一个入度为 0 的顶点输出，并删掉它的出边」，重复到取完或取不动。
**概念**：拓扑排序把偏序拉成线性序，**只有 DAG 才有拓扑序**；有环时一定取不完。
**步骤**：① 统计各顶点入度；② 入度为 0 的进候选集（要字典序最小就用小根堆）；③ 弹出一个输出，其出边终点入度减 1，减到 0 就入候选集；④ 输出个数 $<n$ 即有环；⑤ 判唯一性：每轮候选集都只有 1 个才唯一。
**算例**：边 $A\!\to\!B,A\!\to\!C,B\!\to\!D,C\!\to\!D,D\!\to\!E,C\!\to\!F,F\!\to\!E$ → 字典序最小序列 **A B C D F E**。
**易混**：拓扑序 vs DFS 逆后序（都合法，但逆后序不一定字典序最小）；「有环」vs「不唯一」是两件事；唯一性的判据是**每轮候选集只有 1 个**，不是边数少。

## 二、计算机组成原理（13 项）

### 15 补码与移码的边界值

**动作**：先定字长，再记「补码比原码多表示一个负数」。
**概念**：补码把减法变成加法，且 0 的表示唯一。
**步骤**：① $n$ 位补码范围 $-2^{n-1}\sim 2^{n-1}-1$；② 负数的补码 = 各位取反再加 1；③ 移码 = 补码符号位取反。
**算例**：8 位 → $-128$ 的补码 **1000 0000**、移码 **0000 0000**；$-1$ 的补码 **1111 1111**；$+127$ 的补码 **0111 1111**。
**易混**：原码 / 反码 / 补码的 0（原码有两个 0）；移码 = 补码符号位取反，别当「加 1」；补码范围比原码多一个负数。

### 16 IEEE 754 单精度位段换算

**动作**：符号 1 + 阶码 8（偏置 127）+ 尾数 23（隐含 1）。
**概念**：IEEE 754 的阶码用**移码（偏置）**，尾数**隐含一个 1**。
**步骤**：① 真值写成 $\pm1.xxx\times2^{e}$；② 阶码字段 $=e+127$；③ 尾数只存小数点后 23 位；④ 拼成 32 位再转十六进制。
**算例**：$-12.5=-1100.1_2=-1.1001\times2^{3}$ → 阶码 $130=1000\,0010$ → **0xC1480000**；$0.1$ → **0x3DCCCCCD**（尾数无限循环，必舍入）。
**易混**：单精度偏置 127 vs 双精度 1023；规格化数（隐含 1）vs 非规格化数（隐含 0）；「指数 e」与「阶码字段」差一个偏置。

### 17 浮点加减四步

**动作**：对阶 → 尾数运算 → 规格化 → 舍入。
**概念**：浮点运算先「对齐小数点」，再按定点算，最后规格化。
**步骤**：① **小阶向大阶看齐**，尾数右移 $\Delta e$ 位、低位丢弃；② 尾数按定点加减；③ 左规（尾数高位无 1）或右规（溢出）；④ 就近舍入到偶。
**算例**：$1.5+(-0.25)$：$1.5=1.1\times2^{0}$，$0.25=1.0\times2^{-2}$，对阶后 $0.01\times2^{0}$ → 和 $1.01\times2^{0}=$ **1.25**。
**易混**：对阶方向（小阶向大阶）；规格化 vs 溢出（前者改尾数形式，后者超出范围）；舍入 vs 截断。

### 18 海明码：校验位数与编码

**动作**：先解 $2^k\ge n+k+1$ 得 $k$，校验位放 $2^0,2^1,2^2,\dots$ 位置，每组偶校验。
**概念**：海明码用多位校验位**交叉覆盖**，能定位并纠正一位错。
**步骤**：① 定 $k$；② 数据从左到右填进非 $2^i$ 的位置；③ 第 $2^i$ 位 = 覆盖它的数据位异或；④ 接收端按同样的组重算，出错位的编号 = 各组校验结果拼起来。
**算例**：4 位数据 `1011` → $2^3=8\ge4+3+1=8$ → $k=3$，7 位码 **0110011**（数据在第 3、5、6、7 位）。
**易混**：海明码（可纠一位）vs CRC（只检错、不定位）；校验位位置 2^i vs 末尾；检错能力 vs 纠错能力（差一位）。

### 19 CRC：模 2 除法

**动作**：数据后补 $\deg G$ 个 0，逐位异或，余数位数恒为 $\deg G$；发送串 = 数据 + 余数。
**概念**：CRC 是**模 2 除法**的余数，用来检错，不负责定位。
**步骤**：① 补 0 个数 = 生成多项式的**最高次幂**；② 每次看当前 4 位（$\deg G+1$ 位），首位为 1 就异或、为 0 只左移；
③ 除完取低 $\deg G$ 位为余数；④ 接收端整串除以 $G$，余数 0 判无错。
**算例**：数据 `101110`、$G=1011$ → 余数 **110**，发送 **101110110**。
**易混**：CRC vs 海明码（功能不同）；模 2 减法 = 异或（不是借位减法）；生成多项式「次数」vs「项数」差 1。

### 20 存储器扩展：片数、地址线、片选

**动作**：先算片数，再算片内地址线，剩下的位做片选。
**概念**：字扩展加地址空间，位扩展加数据位宽，两者可叠加。
**步骤**：① 片数 =（总字数 ÷ 片字数）×（总位数 ÷ 片位数）；② 片内地址线 $=\log_2$ 片字数；
③ 总地址线 $=\log_2$ 总字数；④ 片选线 = 总地址线 − 片内地址线。
**算例**：$1\text{K}\times4$ 位芯片组 $4\text{K}\times8$ 位 → 字数扩 4 倍、位数扩 2 倍 → **8 片**；地址线 **12** 根、片内 **10** 根、片选 **2** 根。
**易混**：字扩展 vs 位扩展；片选信号 vs 片内地址；地址线 vs 数据线（一个选位置、一个传内容）。

### 21 Cache 地址字段划分

**动作**：先算**行数**（数据区 ÷ 块大小），再除以相联度得组数。
**概念**：Cache 按**块**搬运，靠时间/空间局部性换平均速度。
**步骤**：① 行数 $=$ 数据区 $/$ 块大小；② 组数 $=$ 行数 $/$ 相联度；③ 组号 $=\log_2$ 组数；④ 块内 $=\log_2$ 块大小；
⑤ 标记 = 地址位数 − 组号 − 块内。
**算例**：32 位地址、块 64 B、4 路组相联、数据区 32 KB → 行 **512**、组 **128**（7 位）、块内 **6** 位、标记 **19** 位。
**易混**：行（line）vs 组（set）vs 块（block）三个词的关系；标记 vs 组号（同属地址高位，但用途不同）；Cache 总容量 vs 数据区容量。

### 22 平均访问时间 AMAT

**动作**：先定性「并行查」还是「串行查」，再套公式；多级就把上一级的缺失代价换成下一级的 AMAT。
**概念**：缺失代价按**概率加权**，同时启动与串行查的公式不同。
**步骤**：① 串行：$\text{AMAT}=h\,t_c+(1-h)(t_c+t_m)$；② 并行：$\text{AMAT}=t_c+(1-h)t_m$；
③ 多级：把 $(t_c+t_m)$ 换成下一级的 AMAT 后逐层外推。
**算例**：$h=0.95$、$t_c=1$ ns、$t_m=100$ ns → $0.95\times1+0.05\times101=$ **6 ns**。
**易混**：命中率 h vs 缺失率 1−h；并行（同时启动）vs 串行（先查 Cache）两个公式；多级 Cache 是「上一级的缺失代价换成下一级的 AMAT」。

### 23 DRAM 刷新开销

**动作**：刷新按**行**做，行数 × 存取周期 = 一轮刷新的总时间；再与刷新周期比。
**概念**：DRAM 靠电容存信息，必须定期按行刷新，刷新期间不能访问。
**步骤**：① 集中刷新死区 = 行数 × 存取周期；② 死区率 = 死区 ÷ 刷新周期；
③ 异步刷新行间隔 = 刷新周期 ÷ 行数；④ 分散刷新把每次存取周期拉长，无死区。
**算例**：128 行、刷新周期 2 ms、存取周期 0.5 μs → 死区 $128\times0.5=$ **64 μs**，死区率 $64/2000=$ **3.2%**；异步间隔 $2000/128=$ **15.625 μs**。
**易混**：刷新 vs 再生（同一件事的不同叫法）；集中 / 分散 / 异步三种安排；刷新周期 vs 存取周期。

### 24 CPI、MIPS 与执行时间

**动作**：三个量互相换算，先统一单位再代公式。
**概念**：CPI 是「平均每条指令占几个时钟周期」，不是时钟周期本身。
**步骤**：① $T=\text{指令数}\times\text{CPI}\times\text{时钟周期}$；② $\text{MIPS}=\dfrac{\text{主频(MHz)}}{\text{CPI}}$；
③ 加速比 = 旧时间 ÷ 新时间（用同一段程序、同一指令数）。
**算例**：主频 2 GHz、CPI = 2 → MIPS $=2000/2=$ **1000**；$10^6$ 条指令 → $10^6\times2/2\text{GHz}=$ **1 ms**。
**易混**：CPI vs 时钟周期；MIPS vs FLOPS（整数/浮点）；主频高 ≠ 执行快（还看 CPI）。

### 25 流水线：拍数、加速比

**动作**：先画装填/排空，再套 $k+(n-1)$。
**概念**：流水线靠重叠执行提高吞吐，受「最慢段」与「冒险」限制。
**步骤**：① 第一条指令走完 $k$ 段用 $k$ 拍；② 之后每拍完成一条，共 $n-1$ 拍；③ 总拍数 $=k+(n-1)$；
④ 加速比 $=\dfrac{nk}{k+n-1}$，取 $n\to\infty$ 得上限 $k$。
**算例**：$k=5$、$n=100$ → **104 拍**，加速比 $500/104=$ **4.81**。
**易混**：加速比 vs 吞吐率；装填（fill）vs 排空（drain）；结构冒险 / 数据冒险 / 控制冒险三类的成因不同。

### 26 总线带宽

**动作**：带宽 = 每次传送字节数 × 每秒传送次数。
**概念**：带宽 = 一次传送的位数 × 单位时间传送次数。
**步骤**：① 位宽转字节（÷8）；② 求「几次传送/秒」——注意是否每 $m$ 个时钟一次；③ 相乘；
④ 突发传送时一次地址可连传 $n$ 个数据，要把地址周期摊薄。
**算例**：总线宽 64 位（8 B）、100 MHz、每 2 个时钟传一次 → $8\times50\text{M}=$ **400 MB/s**。
**易混**：总线宽度 vs 总线带宽；同步总线 vs 异步总线；突发传送 vs 非突发（前者省地址周期）。

### 27 磁盘平均存取时间

**动作**：寻道 + 平均旋转延迟（半圈）+ 传输时间。
**概念**：磁盘存取时间 = 寻道 + 旋转延迟 + 传输，三段性质不同。
**步骤**：① 平均旋转延迟 $=\dfrac{60}{\text{rpm}}\times\frac12$；② 传输时间 = 数据量 ÷ 传输率；
③ 三者相加；④ 若问「读一个磁道」，传输时间按整道数据算。
**算例**：7200 rpm、4 KB、100 MB/s、寻道 8 ms → 旋转 **4.17 ms** + 传输 **0.041 ms** + 8 ms = **12.21 ms**。
**易混**：存取时间 vs 传输时间；平均旋转延迟（半圈）vs 最大（整圈）；扇区 vs 块（块可含多个扇区）。

## 三、操作系统（7 项）

### 28 调度：周转时间与带权周转

**动作**：画甘特图，逐个算「完成 − 到达」。
**概念**：周转时间 = 完成时刻 − 到达时刻，**包含**服务时间。
**步骤**：① 按算法排出执行顺序（注意到达时刻，CPU 不能提前跑）；② 写每个作业的完成时刻；
③ 周转 = 完成 − 到达；④ 带权 = 周转 ÷ 服务时间；⑤ 求平均。
**算例**：A(0,7)、B(2,4)、C(4,1) → FCFS 顺序 A→B→C，周转 7、9、8 → 平均 **8.0**；SJF 顺序 A→C→B，周转 7、4、10 → 平均 **7.0**。
**易混**：周转 vs 等待 vs 响应时间；抢占式 vs 非抢占式；SJF vs SRTF（后者按剩余时间抢占）。

### 29 页面置换：缺页次数

**动作**：逐次走引用串，维护帧内容；命中不换（FIFO）/要移到最近（LRU）。
**概念**：页置换是「帧数固定 + 缺页时选victim」，与局部性假设绑在一起。
**步骤**：① 维护一个长度 = 帧数的队列；② 未命中则缺页数 +1，满了按算法淘汰；③ LRU 命中后必须把该页移到「最近使用」端；
④ OPT 淘汰「未来最晚被用」的页（可算不可实现）。
**算例**：引用串 `7,0,1,2,0,3,0,4,2,3,0,3,2`、3 帧 → FIFO **10**、LRU **9**、OPT **7**。
**易混**：缺页 vs 置换（置换必缺页，缺页未必置换，有空闲帧时直接装入）；Belady 异常只属 FIFO；LRU vs CLOCK（近似）。

### 30 有效访问时间（TLB + 内存）

**动作**：分「TLB 命中 / 未命中」两条路径，各自把访存次数加全。
**概念**：EAT 是按命中率对「两条访问路径」加权。
**步骤**：① 命中路径 = TLB 查询 + 一次访存取数据；② 未命中路径 = TLB 查询 + 访存读页表 + 访存取数据；
③ 加权平均 $=h\cdot$命中 $+(1-h)\cdot$未命中；④ 若还有缺页，再加缺页处理时间 × 缺页率。
**算例**：$h=0.9$、TLB 10 ns、内存 100 ns → 命中 $110$、未命中 $210$ → EAT $=0.9\times110+0.1\times210=$ **120 ns**。
**易混**：TLB 命中 vs 缺页（两级不同事件）；命中时一次访存 vs 未命中两次访存；EAT vs 平均访存时间（口径可能差一次）。

### 31 多级页表：表项数与地址切分

**动作**：页大小定页内偏移，剩余位按级切分。
**概念**：多级页表用「层级」换空间，只为用到的部分分配页表页。
**步骤**：① 页内偏移 $=\log_2$ 页大小；② 剩余位 ÷ 级数 = 每级位数；③ 每级表项数 $=2^{\text{该级位数}}$；
④ 页表占用空间 = 有效项数 × 页表项大小（多级只为用到的部分分配）。
**算例**：32 位地址、4 KB 页、二级 10+10+12 → 每级 **1024** 项，页内偏移 **12** 位，一个页表项 $2^{12}=4$ KB 刚好一页。
**易混**：页表项 vs 页（一个是表里的一格，一个是一页内存）；多级页表 vs 多张单级页表；页号 vs 页内偏移。

### 32 磁盘调度：移动距离

**动作**：写出磁头位置序列，累加相邻差；**方向不同答案不同**。
**概念**：磁盘调度优化的是**寻道时间**，不改变传输时间。
**步骤**：① 按算法生成访问顺序；② 累加 $|x_{i+1}-x_i|$；③ SCAN/C-SCAN 要算「走到端点」的那段；
④ 题干没给初始方向时，两种方向都算并说明。
**算例**：起点 53、请求 `98,183,37,122,14,124,65,67` → FCFS **640**；SSTF（`53→65→67→37→14→98→122→124→183`）**236**；SCAN 先向大再返回（`53→65→67→98→122→124→183→37→14`）**299**。
**易混**：FCFS / SSTF / SCAN / C-SCAN 四者目标不同；SCAN vs LOOK（是否走到端点）；结果依赖初始方向与端点设定。

### 33 死锁：不发生死锁的最少资源数

**动作**：按「最坏情况各差一个」再加一。
**概念**：死锁要四个条件**同时**成立，破一个即可预防。
**步骤**：① $n$ 个进程每个最多要 $m$ 个；② 最坏情况每个已拿 $m-1$ 个，共 $n(m-1)$；
③ 再多 1 个必能让某个进程拿满并释放 → 最少 $n(m-1)+1$。
**算例**：3 个进程各需 4 个 → $3\times3+1=$ **10** 个。
**易混**：死锁 vs 饥饿 vs 活锁；预防 / 避免 / 检测三种策略；安全序列 ≠ 当前无死锁（安全一定无死锁，反之不然）。

### 34 前驱图的 PV 写法与信号量个数

**动作**：**每条有向边一个信号量**（初值 0），起点末尾 V、终点开头 P。
**概念**：前驱关系是偏序；PV 在这里的作用是「让后驱等到前驱完成」，不负责互斥。
**步骤**：① 画前驱图；② 每条边建一个信号量 $S_{ij}$，初值 0；③ $P_i$ 末尾对每条出边 `V(S_ij)`；④ $P_j$ 开头对每条入边 `P(S_ij)`；⑤ 若还要互斥访问资源，另设 `mutex=1`。
**算例**：$P_1\!\to\!P_2$、$P_1\!\to\!P_3$、$P_2\!\to\!P_4$、$P_3\!\to\!P_4$ → **4 个**信号量，初值全 0；$P_1$ 末尾 V 两次、$P_4$ 开头 P 两次。
**易混**：信号量个数 = **边数**（不是顶点数、不是入度合并数）；「每边一个」与「按入度合并」不等价（后者要求同一进程发 V，多前驱时做不到）；P/V 写反不报错，只是失去同步。

## 四、计算机网络（9 项）

### 35 奈奎斯特与香农

**动作**：无噪声用奈氏，有信噪比用香农，两者取**小**。
**概念**：奈氏管「无噪 + 码元数」，香农管「有噪 + 信噪比」，两者取小。
**步骤**：① $C=2W\log_2V$（$V$ 为码元种类数）；② 信噪比换算 $S/N=10^{\text{dB}/10}$；
③ $C=W\log_2(1+S/N)$；④ 若两式都给，取较小者。
**算例**：$W=3$ kHz、$V=4$ → $2\times3000\times2=$ **12 kbps**；$W=3$ kHz、30 dB → $S/N=1000$ → $3000\times\log_21001\approx$ **29.9 kbps**。
**易混**：带宽 vs 速率（Hz 与 bit/s）；波特率 vs 比特率（差一个每码元比特数）；dB 与 S/N 是换算关系不是同一个量。

### 36 编码效率

**动作**：看「一个比特要几个信号周期/几个码元」。
**概念**：编码是把比特映射成码元，调制是把码元搬到载波上。
**步骤**：① 曼彻斯特：每比特中间必跳变 → 2 个码元 → 效率 50%；② 差分曼彻斯特同样 50%；
③ 4B/5B：4 位数据编成 5 位码 → 效率 80%；④ 波特率 = 比特率 ÷ 效率。
**算例**：10 Mbps 曼彻斯特 → 波特率 **20 MBaud**；100 Mbps 用 4B/5B → 线路速率 **125 Mbps**。
**易混**：编码 vs 调制；曼彻斯特 vs 差分曼彻斯特（后者看「起始有无跳变」）；4B/5B（80%）vs 8B/10B（同样 80%）。

### 37 最小帧长（CSMA/CD）

**动作**：帧长 ≥ 2τ × 速率，$	au$ 为单程传播时延。
**概念**：最小帧长保证「发送方发完之前一定能听到冲突」。
**步骤**：① 求 $	au$ = 距离 ÷ 传播速度（铜缆约 $2\times10^8$ m/s）；② 争用期 = $2\tau$；
③ 最小帧长 = $2\tau\times$ 速率；④ 反过来给帧长与速率可求最大跨距。
**算例**：100 Mbps、$2\tau=5.12\ \mu$s → $100\times10^6\times5.12\times10^{-6}/8=$ **64 B**。
**易混**：冲突域 vs 广播域；CSMA/CD（有线，边发边听）vs CSMA/CA（无线，避免冲突）；争用期 vs 帧间间隔。

### 38 子网划分与主机数

**动作**：需要 $k$ 个子网就借 $\lceil\log_2k\rceil$ 位；主机数 $=2^{\text{主机位}}-2$。
**概念**：子网划分是把主机位借给网络位，掩码与前缀长度是同一件事的两种写法。
**步骤**：① 定借位数；② 新前缀 = 原前缀 + 借位数；③ 每子网主机位 = $32-$ 新前缀；④ 可用主机 = $2^{\text{主机位}}-2$；
⑤ 子网块大小 = $2^{\text{主机位}}$，据此写各子网地址。
**算例**：`/24` 划 6 个网 → 借 3 位 → **/27**，每网 $2^5-2=$ **30** 台可用，块大小 32。
**易混**：子网掩码 vs 前缀长度；子网数与每网主机数是「借位」的两端，一边多一边少；VLSM（变长）vs CIDR（聚合）。

### 39 IP 分片

**动作**：片数据长度是 **8 B 的整数倍**；偏移 = 片数据首字节 ÷ 8。
**概念**：分片是链路 MTU 限制下的再切分，**偏移以 8 字节为单位**。
**步骤**：① 可用数据 = MTU − IP 首部；② 向下取 8 的倍数得每片数据长度；③ 依次切片、记偏移；
④ 除最后一片外 MF = 1；⑤ 末片数据长度可不为 8 的倍数。
**算例**：4000 B 数据报（20 B 首部）、MTU 1500 → 每片数据 1480 → **1480 / 1480 / 1020**，偏移 **0 / 185 / 370**，MF = 1,1,0。
**易混**：IP 分片 vs TCP 分段（层次不同）；片偏移的单位 vs 字节数；MF（还有后续片）vs DF（禁止分片）。

### 40 GBN / SR 的窗口上限

**动作**：序号 $n$ 位时，GBN 发送窗口 ≤ $2^n-1$，SR 发送窗口 ≤ $2^{n-1}$。
**概念**：GBN 回退重传整窗，SR 只重传出错的那一帧。
**步骤**：① 先看是 GBN（接收窗口恒 1）还是 SR；② GBN 要求「窗口 + 1 ≤ 序号空间」；
③ SR 要求「发送 + 接收 ≤ 序号空间」且两者相等；④ 折半得 $2^{n-1}$。
**算例**：$n=3$ → GBN **7**，SR **4**。
**易混**：GBN vs SR 的窗口上限；序号空间 vs 窗口大小；接收窗口 1（GBN）vs 等于发送窗口（SR）。

### 41 TCP 拥塞控制逐轮表

**动作**：慢开始每轮翻倍到 ssthresh，之后每轮 +1；超时则 ssthresh 与 cwnd 都减半（cwnd 从 1 重来）。
**概念**：cwnd 是发送方对「网络还能承受多少」的估计，rwnd 是接收方的缓存余量。
**步骤**：① 列轮次表，写 cwnd；② $\text{cwnd}<\text{ssthresh}$ 时翻倍；③ $\text{cwnd}\ge\text{ssthresh}$ 时 +1；
④ 超时：$\text{ssthresh}=\text{cwnd}/2$，$\text{cwnd}=1$，重回慢开始；⑤ 快重传：ssthresh 减半、cwnd 设为新 ssthresh（拥塞避免），不回到 1。
**算例**：初值 cwnd=1、ssthresh=8 → 各轮 cwnd = **1,2,4,8,9,10,11,12**。
**易混**：流量控制（rwnd）vs 拥塞控制（cwnd）；超时（回慢开始）vs 快重传（回拥塞避免）；ssthresh 是两者的分界，不是上限。

### 42 TCP 序号账本

**动作**：SYN / FIN 各消耗 1 个序号，纯 ACK 不消耗；确认号 = 期望收到的下一个字节序号。
**概念**：TCP 按**字节**编号，SYN 与 FIN 各占一个序号。
**步骤**：① 记初始 seq（ISN）；② 发数据后 seq 前进「数据长度」（SYN/FIN 再 +1）；
③ 收方 ACK = 已连续收到的最后字节 + 1；④ 重传时 seq 回到原值，ACK 不变。
**算例**：seq=1000 发 1000 B → 下一段 seq = **2000**，接收方回 ACK = **2000**；若这段是 SYN（seq=1000），下一段 seq = **1001**。
**易混**：序号 vs 确认号（后者是「期望的下一个」）；报文段 vs 字节（一个段含多个字节的序号）；ISN 的随机化是为了安全，不参与计算。

### 43 RIP 距离向量表的收敛结果

**动作**：收到邻居的向量后，**每项跳数 +1**，与本地比较，更小就更新并把下一跳记为该邻居。
**概念**：RIP 用距离向量，度量是**跳数**（经过的路由器数），与带宽无关；直连网段记 0 跳。
**步骤**：① 初始化只写直连网段（0 跳）；② 收邻居表 → 逐项 +1；③ 比本地小则替换并记下一跳；④ 反复直到不再变化（收敛）；⑤「直连记 0 还是 1」按题干口径。
**算例**：$A\!-\!B\!-\!C$ 依次相连，$n_1$ 直连 A、$n_2$ 直连 B、$n_3$ 直连 C → A 的表：$n_1$ 直连 **0**、$n_2$ 经 B **1**、$n_3$ 经 B **2**。
**易混**：RIP（距离向量、跳数）vs OSPF（链路状态、带宽）；跳数 vs 时延；「下一跳」是邻居地址，不是最终目的地址。
