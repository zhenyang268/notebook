## 语法短文

Adjectives are rarely innocent. Some merely describe what can be measured — a narrow street, a wooden chair, a two-hour delay. Others quietly evaluate: a narrow-minded official, a wooden performance, a tedious delay. The first group is comparatively safe, since any observer standing at the same spot would report the same fact. The second group is dangerous, because it smuggles a judgement into what looks like a description.

Consider how easily "a cheap hotel" slides into "a cheap trick". The word has not changed; the speaker's stance has. Were writers more attentive to this distinction, half the disputes in ordinary conversation would disappear. It is therefore worth asking, of every adjective we use, whether it reports or rules. Description invites correction; evaluation invites resistance. Only those who know which game they are playing can be trusted with an adjective.

**译文**

形容词很少是无辜的。有些只是描摹可被测量的东西——一条狭窄的街道、一把木椅、两小时的延误。另一些则在悄悄评价：一位心胸狭窄的官员、一场僵硬的表演、一次乏味的延误。第一类相对安全，因为任何站在同一地点的观察者都会报告同样的事实。第二类则危险，因为它把一种评判偷运进看似描述的东西里。

想一想「一家便宜的旅馆」滑向「一个廉价的花招」有多么容易。词没有变，说话人的立场变了。倘若写作者对这条界线更警觉一些，日常对话中一半的争执都会消失。因此，对我们所用的每一个形容词，都值得问一句：它是在报告，还是在裁决。描述招来更正，评价招来抵抗。只有那些清楚自己在玩哪种游戏的人，才配得上使用一个形容词。

**语法点**

*any observer standing at the same spot would report the same fact* → since 引导的原因状语从句，内含现在分词短语作后置定语 → 交代第一类形容词之所以安全的原因；「standing at the same spot」相当于 who stands at the same spot，用非谓语压缩定语从句，使长句保持紧凑。

*it smuggles a judgement into what looks like a description* → because 引导的原因状语从句 + what 引导的名词性从句作介词 into 的宾语 → 点明第二类形容词的危险机制；what 从句在此充当介词宾语，既不能换成 that，也不能省略，因为它是整个介词短语的落脚点。

*Were writers more attentive to this distinction, half the disputes in ordinary conversation would disappear.* → 省略 if 的虚拟条件句倒装（与现在事实相反）→ 提出一个反事实的假设，把 Were 提到句首代替 if writers were，语气比常规条件句更书面、更凝练，也与前文冷静的论证口吻一致。

*It is therefore worth asking, of every adjective we use, whether it reports or rules.* → it 作形式主语 + whether 引导的主语从句后置 + be worth doing 结构 → 避免主语过长造成的头重脚轻，把真正的主语 whether it reports or rules 移到句末；「of every adjective we use」是插入的状语，其中 we use 又是省略了关系词的定语从句。

*Only those who know which game they are playing can be trusted with an adjective.* → 定语从句（who know...）+ 宾语从句（which game they are playing）+ 被动语态 → 用定语从句限定「那些人」的范围，用被动把焦点从施动者转到受事者身上，收束全文。注意 Only 修饰主语时不引起倒装，谓语仍是 can be trusted。
