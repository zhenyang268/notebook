# 英语单词书 · 目录与使用说明

> 排序原则不是字母，而是**考场怎么用**：先给作文里必须写出来的，再给阅读只要认得的，最后是熟词僻义与词根词缀兜底。
> 每组末尾配一段语法短文（英中对照 + 5 条语法点），用来复习语法与培养语感，不承担背词任务。

> 当前共 17 组、约 2152 个词条。

## 怎么用

1. **第一遍只认不背**：一组 200 个词，十分钟扫完，划掉已经认识的。
2. **第二遍只背划掉的**：剩下的才是你的生词，通常不到三成。
3. **每背完一组，读一遍该组短文**：读的时候不看译文，再回头看哪句没读懂。
4. **写作前翻 01–04 组**：这四组是作文的骨架词，比背生僻词划算。
