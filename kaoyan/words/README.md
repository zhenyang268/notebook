# words/ — 考研英语一单词书

**结构**：30 个主题组 + 1 张大纲补全表。按考场用法分组，不按字母。

| 部分 | 文件 | 内容 |
|---|---|---|
| 主题组 | `01-*.md` … `30-*.md` | 每组约 150–220 词，**词表**（一行一词，无例句）+ **短文**（120–150 词英文 + 中译 + 5 条语法点） |
| 大纲补全 | `97-大纲补全（按词频）.md` | 主题组没覆盖到的大纲词，按真题词频倒序，带释义与分类 |

## 覆盖口径（重要）

- **大纲总量 5530 词**（《2024 年全国硕士研究生招生考试英语（一）考试大纲词汇表》）。
- 主题组覆盖 **2522** 个大纲词 + 1454 个组内额外词（派生词、超纲词），去重后 **3976** 个。
- 补全表再补 **3008** 个，合计 **5530/5530 = 100% 覆盖**。

> **补全表的释义不是模型写的**：词频、释义、分类取自公开数据集
> [`exam-data/NETEMVocabulary`](https://github.com/exam-data/NETEMVocabulary)
> 的 `netem_reranked_simple.json`（2024 大纲 5530 词，词频按四六级/考研/专四专八约 200 套试卷统计）。
> 所以补全表的释义风格与主题组不同——**主题组是写给人背的，补全表是查漏与查义的**。

**为什么不把 3012 个词也塞进主题组**：模型生成主题组时反复吐同一批高频词，
20 块、3000 词只新增 405 个唯一词（重复率 87%）。所以缺口改用数据源填槽，
主题组保持「按场景读得下去」，缺口交给补全表。

## 铁律

1. **一行一词**：`- \`word\` *n.* 释义`，不加例句、不加音标、不加记忆法。
2. **同一词不重复出现在同一组**；跨组允许（不同场景复现是复习手段，但计数只算唯一词）。
3. **不编造词义**：释义不准宁可不收。
4. 每组必须配短文，短文要用上该组 8–12 个词。
