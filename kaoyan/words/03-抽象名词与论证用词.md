## 语法短文

**短文**

Abstract nouns are often dismissed as vague, yet argument depends on them. A claim about justice or equality cannot be tested unless the writer first supplies a definition, states an assumption, and specifies the evidence that would count for or against it. This does not make argument impersonal; rather, it makes disagreement intelligible. When a conclusion is challenged, the dispute can be traced to a premise, an inference, or a criterion of relevance, and each can then be examined in turn. Only when these elements are made explicit can readers judge whether the argument holds. Writers who avoid abstraction may sound concrete, but they often hide the principle on which their judgment rests. Clear argument therefore requires both abstract terms and visible reasoning: the first names the issue, and the second shows how the conclusion follows. Without that connection, an assertion remains only an assertion, however confident its tone.

**译文**

1. Abstract nouns are often dismissed as vague, yet argument depends on them. → 抽象名词常被视为含糊而遭轻视，但论证恰恰依赖它们。
2. A claim about justice or equality cannot be tested unless the writer first supplies a definition, states an assumption, and specifies the evidence that would count for or against it. → 关于正义或平等的主张无法被检验，除非作者先给出定义、说明假设，并明确哪些证据能支持或反驳它。
3. This does not make argument impersonal; rather, it makes disagreement intelligible. → 这并不会使论证变得没有人情味；相反，它使分歧变得可理解。
4. When a conclusion is challenged, the dispute can be traced to a premise, an inference, or a criterion of relevance, and each can then be examined in turn. → 当结论受到质疑时，争议可以被追溯到某个前提、某项推论或某条相关性标准，而每一项都可以依次接受检查。
5. Only when these elements are made explicit can readers judge whether the argument holds. → 只有当这些要素被明确表达出来，读者才能判断该论证是否成立。
6. Writers who avoid abstraction may sound concrete, but they often hide the principle on which their judgment rests. → 回避抽象概念的作者也许听起来很具体，但他们常常隐藏了自己判断所依据的原则。
7. Clear argument therefore requires both abstract terms and visible reasoning: the first names the issue, and the second shows how the conclusion follows. → 因此，清晰的论证既需要抽象术语，也需要可见的推理：前者命名问题，后者显示结论如何得出。
8. Without that connection, an assertion remains only an assertion, however confident its tone. → 缺少这种联系，一个断言就仍然只是一个断言，无论其语气多么自信。

**语法点**

- *unless the writer first supplies a definition* → 条件状语从句（unless 引导）→ 为“主张可被检验”设定必要条件，使论证边界清楚。
- *the evidence that would count for or against it* → 定语从句（that 引导，修饰 evidence）→ 说明证据不是泛泛材料，而是能支持或反驳主张的判别依据。
- *cannot be tested* → 情态动词 + 被动不定式（be tested）→ 用被动不定式避免指明检验者，同时把“可检验性”作为客观标准；其中 be tested 属非谓语形式。
- *Only when these elements are made explicit can readers judge whether the argument holds* → Only + 状语从句置于句首引起的部分倒装；内含 whether 引导的宾语从句 → 强调“要素明确化”是判断论证成立的前提，并让句子重心落在 can readers judge 上。
- *however confident its tone* → 让步状语从句的省略形式（however + 形容词 + 主语 + be 的省略）→ 强调语气自信不能替代论证联系，收束上文关于“断言”的判断。
