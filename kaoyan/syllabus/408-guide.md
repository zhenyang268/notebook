## 怎么用这份导读

**它是地图，不是题库。** 没有题干与推导；它回答「这一科把我从哪份东西变成哪几份，用什么方式复用，复用失败时症状是什么」。带着它看考点，应能立刻判断「它落在哪块、验的是哪条承诺」。

| 编号、A/B/C 要求、标签、真题落点 | `syllabus/408.md`（KP 真源） | 按章节排，不按块 |
| 考点怎么讲通（定义、例子、坑） | `quick/408-*.md`（速查） | 按章推进，不给块间依赖 |
| 考点具体怎么问 | `note/408/*/`（一考点一文件） | —— |
| **这科在考什么 / 四科关系** | **本文件** | 不给正文、不给分数预测 |

**编号只从 `408.md` 取**（全部编号逐字来自该文件，写后 grep 复核，见文末），**口径参考 `quick/`**。不新增考点与标签、不判「必考/不考」；冲突以 `408.md` 为准。

**四条线是通用骨架**（准入/配额/并发一致性/故障恢复，§3.1 ⑦），但四科不平权：有的四条齐全，有的只有一条薄的。第 3 段如实写「有/没有/为什么」，不凑数。

## 一、数据结构（DS）

### 1. 职责一句

把「**一份按位置排好的数据**」变成「**多份能在给定代价内被找到、增删、排序的数据组织**」。挡的问题：**同样的元素换一种存法，某类操作的价格就换一个量级**——这科不生产数据，只生产「代价表」。

### 2. 块表
| 块 | 一份什么→多份什么 | 使用面（考法）｜判据 |
|---|---|---|
| **A. 地址算术** | 一份连续下标空间 → 多份「第 i 个在哪」的算术 | 1) O(1) 随机访问的根据；2) 插删平均移动量；3) 多维矩阵→一维偏移｜算地址/移动次数；公式错则全错 |
| **B. 链式改写** | 一份指针串起的记录 → 多份可局部重排、不搬家的结构 | 1) 改指针顺序的合法性；2) 边界（空表/单结点/首元）；3) 逆置合并、快慢指针｜手写 C 结构体+指针；看断链与边界 |
| **C. 受限容器** | 一份线性序列 → 多份被禁某些访问的子集 | 1) 单/双端可动；2) 判空判满约定；3) 出栈序列计数｜手算序列（出栈合法性、中缀→后缀、队列下标） |
| **D. 序上的搜索** | 一份有偏序的结点集 → 多份对数级、可手算的路径 | 1) 遍历序列定结构；2) 判定树→ASL；3) 不变量把高度压到 O(log n)｜还原序列、算 ASL（成功/失败两分母）、画旋转 |
| **E. 最优性** | 一份带权图 → 多份按不同目标函数的极值 | 1) 按点扩 vs 按边选；2) 表格法逐轮定标；3) 顶点量 vs 边量｜手算逐行；跳步即错，跳的正是判据 |
| **F. 全序化** | 一份乱序记录集 → 多份按关键字排好的序列 | 1) 一趟后的中间状态；2) 时间/空间/稳定性；3) 外排 I/O 次数｜反查算法（一趟结果问是谁）、算趟数与 I/O、判稳定 |

### 3. 线
**两条，最强：**
- **「代价账」**：每块都在答「这个操作多少钱」——顺序表付移动、链表付指针、树付高度、堆付下沉、散列付冲突、外排付 I/O。横穿 A–F，**是这科唯一的统一语言**：新结构进来先问它把哪项代价换成了哪项。
- **「最坏情形」**：退化是主线——BST 退化成链、快排对基本有序退到 $O(n^2)$、顺序表退化成搬全表。六块各有「前提一破价格就变」的失效点（§7：系统侧的极限取最坏）。

**没有的线**：并发一致性与故障恢复在科内为空——单机单线程不出「两个持有者同改一份状态」。唯一越科接口是「优先级就绪队列用单链表」这类缝合题，属 OS 的调度代价。

### 4. KP 映射表
| 块 | KP 编号 | 考点名 |
|---|---|---|
| A | `408-DS-0201` `408-DS-0202` `408-DS-0303` | 线性表定义与基本操作/顺序表/数组与特殊矩阵 |
| B | `408-DS-0203` `408-DS-0406` | 链表/并查集 |
| C | `408-DS-0301` `408-DS-0302` | 栈/队列 |
| D | `408-DS-0402` `408-DS-0403` `408-DS-0405` `408-DS-0602` `408-DS-0603` `408-DS-0604` | 二叉树/线索二叉树/哈夫曼树与编码/折半查找/BST/AVL |
| D′ | `408-DS-0605` `408-DS-0606` `408-DS-0607` | 红黑树/B 树与 B+ 树/散列表 |
| E | `408-DS-0501` `408-DS-0502` `408-DS-0504` `408-DS-0505` `408-DS-0506` `408-DS-0507` | 图基本概念/存储结构/最小生成树/最短路径/拓扑排序/关键路径 |
| F | `408-DS-0703` `408-DS-0704` `408-DS-0706` `408-DS-0707` `408-DS-0708` | 交换排序/选择排序与堆/基数排序/外部排序/算法比较 |

> 遍历（`408-DS-0503`）横跨 D 与 E：「按结构走一遍」归 D，「算法载体」归 E——唯一刻意的双归属，两处都不复制正文。

### 5. 考试问法 vs 工程问法

**考试**：给小规模实例手算一个数字或一条序列（三元素排序、五顶点 Dijkstra 表格、七次查找的 ASL）。判据是与标准答案逐位相同，故**中间记号须与题干约定一致**（下标从 0 还是 1、ASL 分母是 n 还是 m）。考的正是「在有约定的小世界上走完一步不失手」。

**工程**：给规模、负载形状与一个约束（内存上限、必须稳定、数据在外存），问「选哪个结构、它在什么输入上会塌」。判据是**能否预测退化**：选快排要说清哪种分布把它打成 $O(n^2)$，选哈希要说清装填因子到多少时 ASL 失控。考试问「算得对」，工程问「选得对且知道何时不对」。

## 二、计算机组成原理（CO）

### 1. 职责一句

把「**一份用二进制写的意图**（指令+数据）」变成「**多份在固定节拍内、由有限硬件并行兑现的状态变化**」。挡的问题：**软件假设那些操作免费且原子，硬件必须证明它们在确定延迟内成立**。

### 2. 块表
| 块 | 一份什么→多份什么 | 使用面（考法）｜判据 |
|---|---|---|
| **A. 编码** | 一份位串 → 多份解释（有/无符号、单/双精度、大小端） | 1) 位段划分与范围；2) 特殊值（非规格化、±0、NaN）；3) 溢出判据｜位串↔真值互求；**位段错一位即全错** |
| **B. 运算** | 一份操作数对 → 多份结果+标志 | 1) 标志语义（OF 有符号、CF 无符号）；2) 规格化与舍入；3) 硬件代价（几级门）｜算结果+判标志；口诀对而标志反 = 未通过 |
| **C. 存储层次** | 一份大而慢的地址空间 → 多份小而快的副本 | 1) 地址位段（Tag/Index/Offset）；2) 命中率与平均访存；3) 写回 vs 直写｜算容量/位数/比较器/EAT；**含不含脏位、替换位是死判据** |
| **D. 指令通路** | 一份操作意图 → 多份可被硬件识别的字段切分 | 1) 操作码扩展合法性；2) 有效地址与访存次数；3) 三种「字长」不可混｜问访存次数、问机器码；数少一次即错 |
| **E. 控制** | 一份通路状态 → 多份按节拍到达的控制信号 | 1) 微操作序列；2) 微指令编码与微地址；3) 冒险旁路、加速比｜画时序、数周期、判「该不该停 1 拍」；无需停顿说成停顿即错 |
| **F. 通道** | 一份设备完成事件 → 多份 CPU 与设备的分工 | 1) 带宽计算；2) 同步 vs 异步定时；3) 谁搬数据、谁被中断｜判「数据是否经过 CPU」、算带宽与中断开销 |

### 3. 线
**一强一弱。**
- **强线「一次访问的代价链」**：贯穿 C、D、E——定位一个字节付几次访存、几次比较、几个时钟。TLB 命中是否免掉页表访问、Cache 未命中是否仍计时间、一次间接=2 次访存、流水停一拍整体右移，都是同一道算术。资格在于**这条链软件不可见、由硬件保证**（§7：积木来源 = 硬件原子保证）。
- **弱线「表示的二元性」**：同一位串在 A 读成有/无符号、在 C 读成 Tag+Index+Offset、在 D 读成大/小端。只在 A、C、D 显形，是**局部线**，不拔高成贯穿线。

**没有的线**：准入与配额为空（属 OS）；故障恢复只在 E 露一次（异常/中断、断点与现场），不成横穿。

### 4. KP 映射表
| 块 | KP 编号 | 考点名 |
|---|---|---|
| A | `408-CO-0201` `408-CO-0202` `408-CO-0206` | 数制与定点编码/字符与字符串/浮点数表示 |
| B | `408-CO-0204` `408-CO-0205` `408-CO-0207` | 定点运算与溢出/乘除运算与 ALU/浮点运算 |
| C | `408-CO-0302` `408-CO-0303` `408-CO-0305` `408-CO-0306` | 主存储器/主存与 CPU 连接/Cache/虚拟存储器 |
| D | `408-CO-0401` `408-CO-0402` `408-CO-0403` | 指令格式与数据存放/寻址方式/机器级代码表示 |
| E | `408-CO-0502` `408-CO-0503` `408-CO-0504` `408-CO-0505` `408-CO-0506` | 指令执行过程/数据通路/控制器/异常与中断/指令流水线 |
| F | `408-CO-0601` `408-CO-0602` `408-CO-0704` | 总线概述/总线事务与定时/I/O 方式 |
| 标尺 | `408-CO-0103` | 性能指标（CPI/MIPS/Amdahl，A–F 共用度量） |

> 校验码（`408-CO-0203`）在 A 与 C 间摆：作「位串加冗余」属 A，作「链路/存储出错」属 C。本导读按 A 处理——它只关心位串到校验位的算术，不关心错出在哪一层。

### 5. 考试问法 vs 工程问法

**考试**：给一张表（Cache 参数、流水段数、寻址方式、指令位段），要一个数字或一段微操作序列。判据是**算出的量与题问的量必须同名**：问「标记阵列位数」答 Cache 总容量、问「命中时间」只算传输时间，数值再准也不通过。

**工程**：给一组约束（成本、功耗、延迟目标、命中率曲线），问「层次怎么切、写策略怎么配、这点优化省的是哪一项」。判据是**权衡能否定价**：加一级 Cache 要说清多付面积换回多少平均访问时间，直写改写回要说清脏位与一致性协议的新代价。考试验算术闭合，工程验代价归属。

## 三、操作系统（OS）

### 1. 职责一句

把「**一份物理上唯一且有限的机器**」变成「**多份互不干扰、各自以为独占的抽象**」。挡的问题：**多个执行流同时主张同一份物理资源时，谁先动、动多少、出事后退到哪个确定状态**。

### 2. 块表
| 块 | 一份什么→多份什么 | 使用面（考法）｜判据 |
|---|---|---|
| **A. 准入** | 一份裸硬件 → 多份「被授权后才能碰」的入口 | 1) 用户态非法的指令；2) 系统调用全过程；3) 链接/重定位的可移动性｜判指令合法性、判返回到哪；**返回位置是最高频判据** |
| **B. 执行流** | 一份 CPU → 多份可独立推进、可被打断的执行流 | 1) 状态转化的触发者；2) 切换要换什么；3) 时间指标的分母｜画状态图、算三类时间；**分母取错即全错** |
| **C. 并发一致性** | 一份共享状态 → 多份按序访问的临界区 | 1) 信号量初值；2) PV 顺序；3) 四类死锁手法｜写 PV 序列、跑安全性检查；**PV 顺序颠倒⇒必然死锁** |
| **D. 配额** | 一份物理内存 → 多份独立的逻辑地址空间 | 1) 地址翻译与访存次数；2) EAT 两路径加权；3) 置换与 Belady｜算页表大小、画缺页序列；**漏算查 TLB 时间即错** |
| **E. 持久结构** | 一份裸块设备 → 多份按名访问、按字节读写的持久文件 | 1) 按名到 inode 的路径；2) 混合索引覆盖区间；3) 硬链 vs 软链｜算最大文件长度、问第几次 I/O、判回收；**端点差一整链错** |
| **F. 设备边界** | 一份「命令+数据」→ 多份设备完成的时点通知 | 1) 数据是否经过 CPU；2) 单/双缓冲公式；3) 寻道/旋转/传输三分量｜比四种方式开销、算缓冲时间、手算移动距离；**折返段按题干** |

### 3. 线
**四条全齐，线最密。**
- **准入**：A 是主产区（态、特权指令、系统调用、页表基址这类「能改硬件行为的入口」），另有 E 的按名访问入口。
- **配额**：D（内存份额）、B（时间片份额）、F（缓冲份额）共用同一问题——**不够分的东西按什么规则分、分不到排在哪**。
- **并发一致性**：C 是主产区，投影不止：五态的就绪队列、缓冲池三队列、SPOOLing 输出井队列，都是同一线的投影（§8 反模式 11「线不单独成章」——C 讲**机制**，线讲它**投影到哪**）。
- **故障恢复**：D（缺页→故障类异常→重执行本指令）与 A（中断/异常三分类）是同一件事两端；E 超级块损坏、F 设备出错退到哪个状态，是持久侧投影。

**齐全的代价**：四条线不能各讲一遍，必须指定 owner——**准入归 A、一致性归 C、配额归 D、恢复归 A 的异常分类**，其余块只借不造（§2.4 判据 3）。

### 4. KP 映射表
| 块 | KP 编号 | 考点名 |
|---|---|---|
| A | `408-OS-0101` `408-OS-0103` `408-OS-0104` | 基本概念/运行环境/体系结构 |
| B | `408-OS-0201` `408-OS-0202` | 进程与线程/CPU 调度 |
| C | `408-OS-0203` `408-OS-0204` | 同步与互斥/死锁 |
| D | `408-OS-0301` `408-OS-0302` | 内存管理基础/虚拟内存管理 |
| E | `408-OS-0401` `408-OS-0402` | 文件系统基础/文件系统实现 |
| F | `408-OS-0403` `408-OS-0501` `408-OS-0502` | 磁盘与 SSD/概述与控制方式/设备独立软件 |

> 磁盘恒属外存，但「三分量与调度」本科只有 F 在用，故 `408-OS-0403` 归 F。虚存与 `408-CO-0306` 的双归属判据（转换问 CO、分配置换问 OS）见 `408.md`。

### 5. 考试问法 vs 工程问法

**考试**：给紧凑场景（若干进程、资源、到达序列、页引用串），写出确定的 PV 序列或一张表（周转时间、缺页序列、磁头移动距离）。判据是**序列每一步都成立**：PV 写反一次就死锁、磁头初位自己假设就全错、端点差一就整链错。考的是「在最坏交错下机制不出错」。

**工程**：给一个症状（周期性卡顿、写放大、长尾延迟、内存不回收），问「哪条承诺破了、破它的前提是什么」。判据是**能定位到失效那层**：配额定太紧（工作集大于驻留集）、一致性进太晚（锁粒度过粗）、还是恢复没兜住。考试问「按规则走对不对」，工程问「规则在这台机器上够不够」。

## 四、计算机网络（NET）

### 1. 职责一句

把「**一份不可靠、会丢会重会被篡改的链路**」变成「**多份可命名、可靠、有速率保证的端到端连接**」。挡的问题：**在最坏的点上，靠分层与包头把承诺一层层叠出来**。

### 2. 块表
| 块 | 一份什么→多份什么 | 使用面（考法）｜判据 |
|---|---|---|
| **A. 度量与分层** | 一份物理链路 → 多份可比较的代价刻度 | 1) 时延四分量；2) 各层 PDU 名；3) 时延带宽积｜算发送/传播时延、判功能归属；**两时延混算即错** |
| **B. 物理承载** | 一份比特流 → 多份码元、多份可用频率上限 | 1) 无噪声 vs 有噪声定理；2) 编码规则（曼彻斯特家族）；3) 电路/报文/分组｜算码元速率上限、判「无分组」；**条件混用即错** |
| **C. 帧级可靠** | 一份可能出错的比特流 → 多份可检错、可重传、可共享信道的帧 | 1) 检错 vs 纠错；2) 窗口与序号位数约束；3) 冲突域 vs 广播域｜算 CRC 余数位、反推序号位数、算最小帧长与退避；**窗口与位数方向反即错** |
| **D. 寻址转发** | 一份全局地址空间 → 多份可编址、可聚合、可逐跳转发的网络 | 1) 前缀长度优先于「像不像」；2) 片偏移的 8B 单位；3) 控制面 vs 数据面｜算子网、判最长前缀匹配、判分片改哪些字段；**只改总长度即错** |
| **E. 端到端** | 一份不可靠通路 → 多份有序、不丢不重、按 min(cwnd,rwnd) 节流的字节流 | 1) 序号账本；2) 发送窗口取 min；3) 拥塞两分支；4) 挥手 2MSL｜逐轮算 cwnd 与可发量、判状态与序号；**超时与三重复 ACK 混写是最高频错** |
| **F. 名字与应用** | 一份可读的名字/请求 → 多份可解析、可缓存、可分次传输的会话 | 1) 递归 vs 迭代；2) 推 vs 拉；3) RTT 计数（持续/非持续）｜判查询方向、判端口角色、数 RTT；**少算建连 RTT 即错** |

### 3. 线
**明线 + 短程线。**
- **明线「单位错一位」**：片偏移单位是 8B、分片载荷须 8 的倍数、窗口以帧记而序号以位记、SYN/FIN 各吃 1 个序号、发送时延分母是带宽不是距离。**同一个量在相邻两层用不同单位记账**，正是分层的代价，也是失分最集中处。横贯 A–F。
- **短程线（只覆盖 D、E）「承诺堆积」**：上一层把下层的不保证当保证用——E 假定 D 的转发会到达，D 假定 C 的帧会到达，故可靠、有序、节流须由上层自补。只在 D→E 显形，**不扩写成贯穿线**。

**没有的线**：配额与准入在本配置里没有对应考点。故障恢复只在 E 局部成立（超时重传、TIME_WAIT 兜旧报文），不横穿。

### 5. 考试问法 vs 工程问法

**考试**：给一张拓扑或一条报文，逐跳逐字段推到底：第 3 跳哪些首部变了、这轮窗口能发几个字节、这个域名查经几次。判据是**每条结论都能挂到具体字段或计数器**，凭「应该是这样」不算通过。考的是「每层边界上量纲与字段都不串台」。

**工程**：给一个现象（建连慢、吞吐上不去、偶发重传、某网段不通），问「哪层承诺被哪个前提破了」。判据是**能否把症状钉到一层**：吞吐卡在带宽还是窗口、重传来自误码还是拥塞判定、不通来自前缀匹配还是 NAT 表。考试问「这层算得对不对」，工程问「问题落在哪层」。

四科共用一套分层兑现逻辑：**DS 兑现「价格已知」、CO 兑现「位串含义确定」、OS 兑现「多份抽象各见独占机器」、NET 兑现「不可靠下层之上叠出可靠流」**。统一成一句：**每科都在考「承诺 + 价格 + 破在哪」，只是承诺粒度从「一次操作」拉到「一段连接」。**
