# syllabus/ — 考纲与知识点主键

> **这一层是全库唯一的坐标系。** `note/` 的每个文件、掌握度每一档、`projects/` 的每条引用，
> 都必须能对到这里的一个 KP ID。对不上的内容不许落盘。
>
> 依据：各科考试大纲的**结构**（章节划分、要求层次用语）。大纲每年微调，新版发布后只改本层，
> 下游文件路径不动（KP ID 保持不变），这是把考纲和内容解耦的全部意义。

---

## 一、KP ID 规则

```
<科目>-<子科>-<章><节>[-<序>]
```

| 段 | 取值 | 说明 |
|---|---|---|
| 科目 | `408` / `M1`（数一）/ `E1`（英一）/ `P1`（政治） | 与四科代号一致 |
| 子科 | 见下表 | 408 四个，数学三个，英语六个，政治六个 |
| 章 | 两位数字 | 大纲章号，`01`–`09` |
| 节 | 两位数字 | 章内节号，`01`–`09` |
| 序 | 两位数字，**可省略** | 节内知识点序号；只在节内条目需要单独跟踪时才用 |

| 科目 | 子科代码 |
|---|---|
| 408 | `DS` 数据结构 · `CO` 计算机组成原理 · `OS` 操作系统 · `NET` 计算机网络 |
| M1 数一 | `HS` 高等数学 · `LA` 线性代数 · `PS` 概率论与数理统计 |
| E1 英一 | `VO` 词汇 · `LS` 长难句 · `RC` 阅读理解 · `NT` 新题型 · `TR` 翻译 · `WR` 写作 |
| P1 政治 | `MY` 马原 · `MZ` 毛中特 · `XS` 新思想 · `SG` 史纲 · `SF` 思修与法治 · `SZ` 时政 |

示例：`408-DS-0302` = 数据结构·第 3 章·第 2 节；`M1-HS-0203` = 高数·第 2 章·第 3 节。
**只写到章、不写到节的写法不允许** —— 复习单元必须落到节，`tools/lint.py` 会拦。

---

## 二、三件东西共用这一个主键

| 谁 | 用 KP 干什么 | 位置 |
|---|---|---|
| **内容** | `note/` 一考点一文件；文件名前缀是 KP，不靠记忆对位。主键表「文件」列直接给路径 | `note/<科目>/<子科>/<KP>-<考点>.md` |
| **掌握度** | 一行 = 一个 KP = 一个状态单元，末列 M0–M4。**不排期、不算到期日**（2026-11-04 改） | 本层主键表最后一列（`tools/mastery.py`） |
| **项目** | 工程线要说明"这段对应哪个考点"时，写 `→ 408-DS-0504 最短路径`，**只写 ID 不复制内容** | `projects/*.md` |

**「一个 KP 节 = 一个文件 = 一个复习单元」是全库最重要的不变量。**
它同时解决了三个老问题：文件膨胀（粒度天然有界）、复习无依据（有主键可排期）、
两条线混住（项目只能借 ID，不能占用文件）。

## 三、要求层次（大纲原文用语，不改写）

| 层次 | 大纲用词 | 含义 | 处理 |
|---|---|---|---|
| A | **掌握** | 能计算、能推导、能写代码/画图 | 必须过 ③ 验收，配题型清单 |
| B | **理解** | 能解释机制与动机 | 过 ①②，③ 只做选择题级别 |
| C | **了解** | 知道是什么、属于哪一层 | 一次带过，不深追 |

> **本表只写大纲给的要求，不写"真题考了几次"。** 没有可靠的逐年统计就不要编——
> 频次判断看 `syllabus/408.md` 的「标签」列与附录 B；数一的分值权重见 `tiers.md` §3，并注明依据（分值权重 / 真题印象 / 辅导书标注）。

## 附录 A：标签口径

| 标签 | 含义 | 处理 |
|---|---|---|
| `高频` | 教学材料反复强调、计算量大或年年出现的类型 | 必过 ③，限时练 |

## 附录 B 之前：真题落点怎么读

`syllabus/408.md` 每章的「真题落点」行是 **`tools/landing.py` 从 `exam/真题/` 里的 `→ ``DS-03``` 标注生成的**（2026-11-04 起），
不再手写——原先写「（2021–2024）」而库里有 2016–2024 九年，少报 5 年且每加一年要改 25 处。

- 口径：`共 N 题` = 该章在**已打 KP 标注**的题里出现的次数。360 题中 **346 题已标注、14 题未标**，
  所以是**下限**，不是全量。`python3 tools/landing.py --missing` 列出未标注的题（2026-11-04 起用第二模型补齐了
  计算机网络 72 道，此前 NET 六章落点全空）。
- 落点行与真题库不一致时 `tools/lint.py` 会报错，跑 `python3 tools/landing.py --write` 重生成。
