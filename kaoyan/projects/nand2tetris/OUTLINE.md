# nand2tetris · 从与非门到俄罗斯方块 — 项目大纲

> **对位考点**：`CO-01`（系统概述）、`CO-02`（数据表示）、`CO-04`（指令系统）、
> `CO-05`（CPU / 数据通路）、`CO-06`（总线）
> **性质**：考纲强化项目。**它是 408 组成原理的"纵切面"**——从门到 CPU 到 OS 一条线走完。
> **总时长**：40–60 小时（12 个项目）｜ **详细**：`NOTES.md`

---

## 0 一句话

**用 HDL 从 NAND 门搭出一个能跑程序的 CPU**，然后给它写汇编器、VM、编译器和 OS。

## 1 目标：做完之后必须能回答

1. 一个 **D 触发器**怎么用 NAND 搭出来？为什么它能"记住"？
2. **ALU** 的控制位（`zx/nx/zy/ny/f/no`）分别做什么？
3. **指令周期**（取指-译码-执行）在数据通路上对应哪几条路径？
4. 为什么**汇编器要先做符号表两遍扫描**？

## 2 里程碑（12 个项目）

| 阶段 | 项目 | 内容 | 验收 | 估时 |
|---|---|---|---|---|
| **硬件** | P1 逻辑门 | Not/And/Or/Xor/Mux/DMux | 用 NAND 实现，测试全过 | 3h |
| | P2 算术 | HalfAdder/FullAdder/ALU | ALU 六控制位正确 | 4h |
| | P3 时序 | DFF/Register/RAM | 能存能读 | 3h |
| | P4 机器语言 | 手写汇编（Fill/Mult） | 在 CPU 模拟器上跑通 | 3h |
| | **P5 计算机** | CPU + Memory + 连线 | **能跑 P4 的程序** ← 核心 | 6h |
| **软件** | P6 汇编器 | Hack 汇编 → 机器码 | 与官方 Assembler 输出**逐字节相同** | 4h |
| | P7 VM-1 | 栈运算、内存访问 | 通过 `StackTest` | 4h |
| | P8 VM-2 | 分支、函数调用 | 通过 `FibonacciElement` | 5h |
| | P10 编译器-1 | 词法 + 语法分析（XML） | 输出与官方 XML 一致 | 6h |
| | P11 编译器-2 | 生成 VM 代码 | 能编译 `Pong` | 8h |
| | P12 OS | Math/Memory/String/Output | `Pong` 能玩 | 8h |

**P5 是分水岭**：过了 P5，"组成原理"就从名词变成手感。**P6 之后是软件线，与 408 关系变弱。**

## 3 验收标准

- P1–P3：官方 `.tst`/`.cmp` 全过。
- **P5**：`Computer.hdl` 能跑 `Add.asm`、`Max.asm`、`Rect.asm`，**输出正确**。
- P6：`Assembler` 对 `Pong.asm` 的输出与官方**逐行 diff 为空**。
- P11：编译出的 `Pong` 能在 CPU 模拟器上**真的玩**（键盘响应）。

## 4 时间预算与取舍（重要）

**对 408 最有价值的是 P1–P5（19 小时）**，因为：
- P1–P3 → CO-01/CO-02 的"门电路与时序"
- P4 → CO-04 的"指令格式"
- **P5 → CO-05 的"数据通路与指令周期"**（408 最难的 45 分里的大头）

**P6 之后（软件线）与 408 关系很弱**，是"计算机系统完整图景"的兴趣投资。
**距初试 8 周时：只做 P1–P5。**
