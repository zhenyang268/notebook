# CSAPP · 系统级编程实验 — 项目大纲

> **对位考点**：`408-CO-02`（数据表示与运算）、`408-CO-03`（存储与 Cache）、
> `408-OS-02`（进程与线程）、`408-OS-03`（内存管理）
> **性质**：考纲强化项目。CSAPP 的 lab 与 408 组成/OS **重合度极高**，是"用代码验考纲"的最佳载体。
> **总时长**：按 lab 独立计，**不建议全做**（见 §4 取舍）｜ **详细**：`NOTES.md`

---

## 0 一句话

**挑 3 个 lab 做，就能把 408 组成原理里最难的三块（浮点、Cache、链接/进程）从"背"变成"算过"。**

## 1 目标：做完之后必须能回答

1. IEEE 754 的**非规格化数**、**NaN**、**舍入模式**在代码里怎么表示？（Datalab）
2. Cache 的**标记/组号/块内偏移**怎么从地址里拆？写一个 4 路组相联的模拟器（Cachelab）
3. `fork` + `execve` + 信号，一个 shell 怎么管**前台/后台作业**？（Shlab）
4. `malloc` 的**隐式空闲链表**与**显式空闲链表**差别在哪，为什么后者快？（Malloclab）

## 2 里程碑（按 lab，各自独立）

| 里程碑 | 内容 | 验收（可执行） | 估时 |
|---|---|---|---|
| **M1 Datalab** | 位运算实现 `bitAnd`/`logicalShift`/`floatScale` 等 | `dlc` 无告警 + `btest` 全过；**不能用循环/条件/大常数** | 4h |
| **M2 Cachelab** | 写一个 Cache 模拟器（可配 $s,E,b$） | 对给定 trace，**命中/缺失/驱逐计数**与参考答案一致 | 3h |
| **M3 Shlab** | 一个支持作业控制的 shell | 通过 `tshref` 全部 16 个测试（含 Ctrl-C/Ctrl-Z） | 6h |
| **M4 Malloclab** | 实现 `mm_malloc`/`mm_free`/`mm_realloc` | 利用率 > 80%、吞吐 > 参考值的 60% | 8h |

**M1 + M2 是"组团"的**（对 CO-02/CO-03），**M3 对 OS-02**，M4 最难且对 408 直接帮助最小。

## 3 验收标准

- M1：`./btest` 全绿；`./dlc bits.c` 输出 "Your code contains no errors"。
- M2：给定 `traces/` 下的 trace，`miss/hit/eviction` 三个数**逐项相等**（不是"差不多"）。
- M3：`make test` 16/16；**Ctrl-Z 后 `jobs` 能看到、`fg` 能恢复**。
- M4：`mdriver` 的 `util` 与 `thru` 两项都达标，**且不出现"碎片化导致大块失败"**。

## 4 时间预算与取舍（重要）

**不要全做。** 按"对 408 的边际收益"排序：

| lab | 对 408 的帮助 | 建议 |
|---|---|---|
| **Datalab** | CO-02 补码/浮点，**直接对应** | **必做** |
| **Cachelab** | CO-03 Cache 映射，**直接对应** | **必做** |
| **Shlab** | OS-02 进程/信号，**直接对应** | 时间够就做 |
| Malloclab | OS-03 只考"概念"，不考实现 | **不做**（8 小时换 2 个选择题不值） |
| Bomb/Attack lab | 汇编阅读，对 CO-04 有一点帮助 | 选做 |
| Proxylab | 网络，对 NET 有一点帮助 | 不做（cs144 更值） |

**最小闭环：Datalab + Cachelab，共 7 小时。**
