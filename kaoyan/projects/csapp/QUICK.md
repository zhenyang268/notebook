## 1 这一小时只做一件事

**把"地址 → Cache 组号"从公式变成手感。**

因为 408 的 Cache 题全是这个：
```
给 32 位地址、Cache 有 64 组、每块 64 字节、4 路
问：地址 0x1234 落在哪组？标记是多少？
```
一小时手算 10 个，比读 10 页书管用。

## 2 最小可跑（40 分钟）

### 2.1 先拆位（10 分钟）

```
块内偏移 b = log2(块大小)       64 字节 → b = 6
组号     s = log2(组数)         64 组   → s = 6
标记     t = 32 - s - b                 = 20
```

**画一张表，填三次，直到不用想**：

| 地址 | 二进制（分组） | 标记 t | 组号 s | 偏移 b |
|---|---|---|---|---|
| `0x1234` | `0000 0001 0010 0011 0100` | `0x00004` | `0x0D` | `0x34` |

（手算：`0x1234 = 0b0001_0010_0011_0100`，低 6 位 `110100`=偏移，中 6 位 `001000`=组号 8，其余=标记。）

### 2.2 写 20 行判定（20 分钟）

```c
typedef struct { int valid; unsigned tag; unsigned lru; } Line;
typedef struct { Line sets[64][4]; } Cache;

// 返回 1=命中, 0=缺失（缺失时按 LRU 替换）
int access(Cache* c, unsigned addr) {
    unsigned b = 6, s = 6;
    unsigned set = (addr >> b) & ((1u << s) - 1);
    unsigned tag = addr >> (b + s);
    for (int i = 0; i < 4; i++) {
        if (c->sets[set][i].valid && c->sets[set][i].tag == tag) {
            c->sets[set][i].lru = 0;              // 命中，刷新 LRU
            return 1;
        }
    }
    // 缺失：找空位或替换 LRU 最大的
    int victim = 0;
    for (int i = 1; i < 4; i++)
        if (!c->sets[set][i].valid) { victim = i; break; }
        else if (c->sets[set][i].lru > c->sets[set][victim].lru) victim = i;
    c->sets[set][victim] = (Line){1, tag, 0};
    return 0;
}
```

### 2.3 手算验证（10 分钟）

给一串地址 `0x0, 0x40, 0x80, 0x0`（块 64 字节、组 64）：
```
0x00 → 组0，标记0，缺失
0x40 → 组1，标记0，缺失
0x80 → 组2，标记0，缺失
0x00 → 组0，标记0，命中  ← 因为只有 4 组被用到，没冲突
```
**改一改**：如果 Cache 只有 1 组（全相联），上面 4 次全命中（除首次）。**这就是"组相联度"的体感**。

## 3 三个核心难点

### 3.1 组相联的"组内全相联"

**组间是直接映射（mod），组内是全相联（随便放）**。
所以冲突只发生在**同一组内超过 $E$ 个块**时。**这就是为什么组相联是"命中率与成本的折中"**。

### 3.2 写策略与脏位

- **写直达**：每次写都写回主存，**不需要脏位**，但写流量大。
- **写回**：只写 Cache，标记脏位，**替换时才写回**。需要脏位，但省带宽。

**408 常考"总容量"**：写回法时 `总容量 = 行数 × (标记 + 有效位 + 脏位 + 数据)`。

### 3.3 平均访问时间

```
EAT = 命中率 × 命中时间 + (1 - 命中率) × 缺失代价
缺失代价 = 主存访问时间（可能还要加"写回时间"）
```
**注意**：题目给"命中率 95%、Cache 1ns、主存 100ns"，答案不是 `0.95×1 + 0.05×100`，
而是 `0.95×1 + 0.05×(1+100)`——**缺失时也要先查 Cache**。

## 4 卡住怎么办

| 现象 | 原因 | 修法 |
|---|---|---|
| 组号算错 | 忘了 `& ((1<<s)-1)` 掩码 | 先右移再取低 s 位 |
| 命中率总是 100% | 忽略了"不同地址可能同组" | 手工构造冲突地址 |
| LRU 替换错 | 把"最近最少用"理解成"最早进来" | 每次命中要刷新计数 |
