## 二、正文

### 1. 四个名词：为什么要分这么细

- **数据**：能被输入计算机并被程序处理的符号集合。它是全集。
- **数据元素**：数据的基本单位，通常作为一个整体被处理。一个学生记录是一个数据元素。
- **数据项**：数据元素中不可再分的最小单位。学号、姓名、年龄都是数据项。
- **数据对象**：**性质相同**的数据元素的集合。

关键在最后一词。若把“所有学生记录”记作集合 $S$，则 $S$ 是数据对象；$S$ 中任意一条记录是数据元素；记录里的“学号”是数据项。三者的关系是逐层包含，**不是并列**。

为什么需要这组区分？因为后面所有算法的“操作单位”都由它决定：链表插入时移动的是**结点**（数据元素级），排序时比较的是**关键字**（数据项级）。分不清就会在“一趟排序比较了几次”这类问题上数错对象。

**最小例子**：`int a[10];` 中，`a` 整体是数据对象（元素同型），`a[3]` 是数据元素，而 `a[3]` 这个整数本身只有一个数据项——此时数据元素与数据项重合。这说明“数据项不可再分”是相对而言的，别硬套。

### 2. 逻辑结构与存储结构：一次映射，不是两个标签

**逻辑结构**描述元素之间的邻接关系，与计算机无关，只有四类：集合、线性、树、图。

**存储结构**（物理结构）是逻辑结构在内存中的实现，要落地必须回答两个问题：**数据本身怎么放**，**关系怎么表示**。

于是产生四种基本存储方式，它们的区别全在“关系怎么表示”：

| 存储方式 | 数据存放 | 关系表示 |
|---|---|---|
| 顺序 | 连续单元 | 用**下标相邻**隐式表示 |
| 链式 | 任意单元 | 用**指针**显式表示 |
| 索引 | 数据区 + 索引表 | 用**索引项**指向 |
| 散列 | 按函数算地址 | 用**哈希函数**算 |

推导要点：顺序存储中“逻辑相邻 $\Rightarrow$ 物理相邻”成立，所以能 $O(1)$ 随机存取，但插删要搬元素；链式存储放弃物理相邻，换来 $O(1)$ 插删，代价是失去随机存取。**二者不是好坏之分，是同一逻辑结构的两种代价分配方案。**

**最小例子**：线性表 $(a_1,a_2,a_3)$，顺序存为 `[a1][a2][a3]`，`a2` 的地址是首址 $+1\times L$，一步算出；链式存为 `a1→a2→a3`，找 `a2` 要读一次指针。反过来，在 `a1` 后插入 `x`，顺序表要把 `a2,a3` 全部后移（3 次元素移动），链表只改两个指针（2 次指针赋值）。

**抽象数据类型（ADT）** 是第三层：只写“有哪些操作、操作的语义是什么”，不写怎么实现。ADT = 数据对象 + 数据关系 + 基本操作。它的价值是让“逻辑结构”这个层次可被单独描述——同一 ADT 可以有顺序和链式两种实现，这正是上表存在的理由。

### 3. 算法的五个特性

算法是对特定问题求解步骤的描述，须同时满足：

1. **有穷性**：执行有穷步后终止，且每步在有穷时间内完成。注意“程序”不要求有穷（操作系统是程序但不是算法）。
2. **确定性**：每条指令语义唯一，无二义。
3. **可行性**：每步都能通过已实现的基本运算执行有限次完成。
4. **输入**：有零个或多个输入。
5. **输出**：有**一个或多个**输出——零输出的一定不是算法。

判别题的抓手：只要题干出现“无限循环”“含义不清”“无输出”，对应的就是 1、2、5 中的某一条。

### 4. 时间复杂度：从语句频度到渐进量级

设基本语句的执行次数为 $T(n)$，时间复杂度定义为

$$T(n)=O(f(n)) \iff \exists\, C>0,\ n_0>0,\ \text{使}\ \forall n\ge n_0,\ 0\le T(n)\le C f(n).$$

只保留最高阶项、去掉系数。常用阶从低到高：

$$O(1)<O(\log n)<O(n)<O(n\log n)<O(n^2)<O(n^3)<O(2^n)<O(n!)$$

数频度的三条硬规则：

- **单层循环**：次数 = 循环上界与下界之差相关的表达式，逐次累加。
- **嵌套循环**：内层次数乘以外层次数；若内层上界依赖外层变量，必须写成求和号再算。
- **并列代码**：取最大值，不求和。

**例题 1**（求和号推导，必须会手推）

```c
int i = 1, s = 0;
while (i <= n) { s += i; i = i * 2; }
```

`i` 的取值序列是 $1,2,4,\dots,2^k$。设循环执行 $k+1$ 次后退出，则 $2^k\le n<2^{k+1}$，得 $k=\lfloor\log_2 n\rfloor$，次数为 $\lfloor\log_2 n\rfloor+1$。故 $T(n)=O(\log n)$。

要点：**循环变量做乘除，量级是对数；做加减，量级是线性。** 这是 2022#1 那类题的第一判别式。

**例题 2**（内层依赖外层）

```c
for (i = 1; i <= n; i++)
    for (j = 1; j <= i; j++)
        x++;
```

内层执行 $i$ 次，总次数

$$T(n)=\sum_{i=1}^{n} i=\frac{n(n+1)}{2}=\frac{n^2}{2}+\frac{n}{2}.$$

去低阶、去系数，$T(n)=O(n^2)$。

**例题 3**（条件跳步型）

```c
for (i = 0; i * i < n; i++) x++;
```

循环条件 $i^2<n$ 即 $i<\sqrt{n}$，次数约 $\sqrt{n}$，故 $T(n)=O(\sqrt n)$。

**例题 4**（算法级分析：两算法比较）

求 $1+2+\cdots+n$。

算法 A 用循环累加：`for(i=1;i<=n;i++) s+=i;`，$T_A(n)=O(n)$，空间 $O(1)$。

算法 B 用公式：`s = n*(n+1)/2;`，$T_B(n)=O(1)$，空间 $O(1)$。

结论：$T_B$ 优。这说明**同一问题的不同算法可以有不同量级**，“算法”与“问题”要分开说——不能讲“求和问题的时间复杂度是 $O(n)$”。

### 5. 空间复杂度

空间复杂度统计的是**辅助空间**，不含输入本身。

$$S(n)=O(g(n)).$$

- 原地工作（in-place）：只用常数个额外变量，$S(n)=O(1)$。
- 递归：栈深度乘以每层帧大小。递归求阶乘 $S(n)=O(n)$，时间也是 $O(n)$。

**例题 5**：把 $n$ 个数逆置。用循环加一个临时变量 `t`，$S(n)=O(1)$；若另开一个长度 $n$ 的数组辅助，$S(n)=O(n)$。前者是原地算法。

### 6. 常见量级速判表

| 代码形态 | 量级 |
|---|---|
| 无循环、只做算术/赋值 | $O(1)$ |
| `i*=2` 或 `i/=2` 型循环 | $O(\log n)$ |
| 单层 `for i=1..n` | $O(n)$ |
| 双层且内层到 $n$ | $O(n^2)$ |
| 外层 $n$、内层乘除 | $O(n\log n)$ |
| 内层条件为 `i*i<n` | $O(\sqrt n)$ |
| 递归 $T(n)=2T(n/2)+n$ | $O(n\log n)$ |

最后一行来自主定理套路：每层总代价 $n$，层数 $\log_2 n$。

## 三、真题落点

- **2022#1 选择：下列程序段的时间复杂度是**——考的是“**从语句频度提炼渐进量级**”这一步：先判断循环变量是加减型还是乘除型（决定线性还是对数），再看是否嵌套、内层上界是否依赖外层（决定乘法还是求和），最后去低阶项与系数。落点不在记忆结论，而在第 4 节的求和号推导链条上。

## 四、易错清单

1. 把复杂度写成 $O(2n)$、$O(n^2/2)$ 这类带系数的形式 → 一律去掉常数系数与低阶项，答案只保留最简阶，如 $O(n)$、$O(n^2)$。
2. 循环变量做 `i = i * 2` 时按线性数次数 → 写成 $1,2,4,\dots,2^k$ 的等比序列，解 $2^k\le n$ 得 $k=\log_2 n$，答案为 $O(\log n)$。
3. 内层上界依赖外层变量却直接乘 $n\times n$ → 写成 $\sum_{i=1}^n i$ 求和后再算，得 $n(n+1)/2$，量级仍是 $O(n^2)$ 但过程分不能丢；若内层上界是 $\sqrt i$ 之类，直接相乘会错阶。
4. 把“数据元素”与“数据项”混用 → 判断依据是“是否还可再分”：记录级是数据元素，字段级是数据项；数操作次数时先明确操作的是哪一级。
5. 说“顺序存储比链式存储好” → 改成按操作说：顺序存储随机存取 $O(1)$、插删 $O(n)$；链式存储查找 $O(n)$、已知位置插删 $O(1)$。
6. 认为算法必须有输入 → 输入可以是零个（如生成固定常量表），但输出必须至少一个；零输出的一定不是算法。
7. 求空间复杂度时把输入数组本身算进去 → 只统计辅助空间，输入占用不计；循环加常数个临时变量即 $O(1)$。
8. 说“求 $1..n$ 和的时间复杂度是 $O(n)$” → 算法才有复杂度，问题没有；应说“循环累加算法为 $O(n)$，公式法为 $O(1)$”。
