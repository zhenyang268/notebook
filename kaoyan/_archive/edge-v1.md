## 一、计算机组成原理

### 1.1 数据表示与运算

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **符号扩展**：位数不同的有符号数相加，少的先扩展——正数高位补 0、负数高位补 1 | 直接按位相加会得到相反结果 | `408-CO-0201` |
| **OF 管有符号、CF 管无符号**；减法时 CF 是「借位」 | 两个标志位用途互换是最常见的错 | `408-CO-0204` |
| **IEEE 754 阶码是移码**；单精度 8 位、双精度 11 位 | 记成补码 ⇒ 比较大小与范围全错 | `408-CO-0206` |
| **判溢出只看阶码**，不看尾数 | 尾数溢出可以通过右规吸收 | `408-CO-0207` |
| 非规格化数（E=0）：隐藏位是 **0**，指数取 **1−Bias**（不是 0−Bias） | `8020 0000H` 这类题错一片：正确答案 $(-1)^1\times(0.01)_2\times2^{-126}=-2^{-128}$ | `408-CO-0206` |
| 右规时尾数末位要 **+1 舍入** | 只移位不舍入，末位差 1 | `408-CO-0207` |
| **算术移位不改变符号性**；左移溢出判据是「符号位变了」 | 逻辑移位与算术移位混用 | `408-CO-0204` |
| **操作码扩展的合法性**：短操作码不能是长操作码的**前缀** | 只算总条数不校验前缀，答案对不上 | `408-CO-0401` |
| 强制类型转换**不改二进制位**，只改解读方式 | 以为会重新编码 | `408-CO-0201` |
| 寄存器位数**不一定是 8 的倍数**（状态寄存器、地址寄存器） | 一律按字节对齐算错 | `408-CO-0501` |
| **加法器进位链**：串行进位 / 并行进位（先行进位 CLU）/ 组内并行组间串行 | 大纲「运算电路」要求，考题只给一句「延迟几个门」 | `408-CO-0205` |
| **海明码**：校验位在 $2^0,2^1,2^2,\dots$ 位；需 $2^k \ge n+k+1$ | 直接背「4 位数据 3 位校验」不懂推导 | `408-CO-0203` |
| CRC 的余数位数 = 生成多项式位数 − 1 | 少算一位，商与余数都错 | `408-CO-0203` |

### 1.2 存储系统

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **SRAM 地址/数据引脚不复用；DRAM 复用** ⇒ 算 DRAM 引脚数**必须除以 2** | 真题考过多次，不除就翻倍 | `408-CO-0302` |
| **存取时间 ≠ 存取周期**：周期 = 存取时间 + 恢复时间 | 两个概念互换导致带宽算错 | `408-CO-0301` |
| **MDR ≥ 机器字长；MAR ≥ $\log_2(\text{地址空间}/\text{编址单位})$** | 编址单位可能是字节也可能是字，题干不看就错 | `408-CO-0301` |
| **低位交叉编址**才能并行、提升带宽；高位交叉只是扩容 | 「交叉」两字不分高低 | `408-CO-0302` |
| 多体交叉的**访存冲突**：同一存储周期访问同一体，后到者必须等 | 忽略冲突，把并行带宽算高 | `408-CO-0302` |
| **Cache 行 = 有效位 + 脏位 + 替换控制位 + Tag + 数据** | 见下四条 | `408-CO-0305` |
| 　·**直写没有脏位**；回写才有（1 位） | 给直写算脏位 ⇒ 容量多算 | `408-CO-0305` |
| 　·**直接映射没有替换位**；组相联的替换位 = $\log_2(\text{组内行数})$ | 三种映射的位数乱套 | `408-CO-0305` |
| 　·**「标记阵列位数」≠「Cache 总容量」**（前者不含数据区） | 题问哪个不看，答错量 | `408-CO-0305` |
| **比较器个数**：直接映射 1 个；组相联 = 组内行数；全相联 = 行数 | 这是硬件代价题的标准答案 | `408-CO-0305` |
| **命中与否都要先访问 Cache**，那段时间都要计 | 「未命中就不花 Cache 时间」是错的 | `408-CO-0305` |
| 写策略配对：**写回 + 写分配**；**直写 + 非写分配**（常见组合，不是定律） | 混搭后平均访问时间算错 | `408-CO-0305` |
| 写缓冲器只吸收突发写，**不能消除直写的带宽压力** | 以为加了就没事 | `408-CO-0305` |
| **TLB 命中 ⇒ 页表必命中；页表命中 ⇏ TLB 命中**；**Cache 命中 ⇒ 内存必命中** | 两组包含关系方向容易反 | `408-CO-0306` |
| **TLB 与 Cache 命中互不相关**：TLB 管地址、Cache 管数据 | 以为「TLB 命中就一定会 Cache 命中」 | `408-CO-0306` |
| TLB、Cache 都是 **SRAM**；页表在**主存**（DRAM） | 「TLB 是 DRAM」是经典错 | `408-CO-0306` |
| **进程切换 ⇒ TLB 全部失效**（有效位全清） | 忘了 ASID 之外的基本事实 | `408-CO-0306` |
| **缺页由软件（异常处理程序）处理；Cache 缺失由硬件处理** | 两者机制混为一谈 | `408-CO-0306` |
| **内存块 ≠ 页框**：408 里「内存块」= Cache 行大小，通常远小于一页 | 教材混用，408 分得很清 | `408-CO-0305` |
| **页面不缺页 ≠ Cache 必命中**（同页不同块） | 由「页」推「块」 | `408-CO-0305` |
| **多级页表省内存的关键是「页表页按需分配」**，不是页表项变少 | 说不清「为什么能省」 | `408-CO-0306` |
| 4 KB 页 ⇒ 页内偏移 12 位；页表项 8 B ⇒ 每页 512 项 ⇒ 每级 9 位 | 「偏移位数」与「每页能装多少项」是两件事，混算最多 | `408-CO-0306` |
| **页表项含页框号；段表项不含页框号**（2018 真题问「段表项不含什么」） | 段页式里的字段归属 | `408-OS-0301` |
| 磁盘**格式化容量 ≈ 非格式化容量的 60%–70%** | 两个容量混用 | `408-CO-0304` |
| 磁盘恒角速度 ⇒ **内圈位密度大于外圈** | 直觉以为是外圈密 | `408-CO-0304` |
| Flash / SSD **写入前必须按块擦除** | 以为是字节可写 | `408-CO-0304` |
| **芯片数量 vs 可寻址芯片数量**是两个不同的量；注意按字节/按字寻址 | 真题原题就考这个区分 | `408-CO-0303` |
| 磁带是**顺序存取**、磁盘是**直接存取**；**ROM 也属于随机存取**（RAM ≠ 随机存取） | 「随机存取」这个词被误当成 RAM 专属 | `408-CO-0301` |

### 1.3 指令系统

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **边界对齐**：数据起始地址必须是其类型字节数的整数倍 | 「对齐」只背不算是常见毛病 | `408-CO-0401` |
| **大端：高位在低地址；小端：低位在低地址** | 方向反了，多字节数全错 | `408-CO-0401` |
| **有效地址与访存次数**：一次间接 = 2 次访存（取地址 + 取数） | 只算 1 次 | `408-CO-0402` |
| **相对寻址**：目标 = 已自增的 PC + 偏移（PC 已指向下一条） | 用未自增的 PC 算，差一个指令长度 | `408-CO-0402` |
| 指令字长 ≠ 机器字长 ≠ 存储字长 | 三个「字长」混用 | `408-CO-0401` |

### 1.4 中央处理器

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **单周期 CPU 不能用单总线数据通路**（单总线一次只能传一个数据，而单周期要求多部件并行） | 2016 真题原话，纯概念题 | `408-CO-0503` |
| **数据通路不包括控制部件**（控制部件生成信号，不属于通路） | 2017 真题 | `408-CO-0503` |
| **超标量不缩短单条指令的执行时间**，只提高吞吐率 | 2017 真题；「超标量让指令更快」是错的 | `408-CO-0506` |
| **有数据冒险 ≠ 一定阻塞**：多数可由旁路解决；**Load-Use 冒险旁路救不了**，必须停 1 拍 | 见「冒险」就说阻塞，答案必错 | `408-CO-0506` |
| **异常三分类**：故障（返回**当前指令**重执行，如缺页）、自陷（返回**下一条**，如系统调用/断点）、终止（不返回） | 返回位置是最高频考点（2016） | `408-CO-0505` |
| **外部中断与当前指令无关**，处理后返回下一条 | 与异常混为一谈 | `408-CO-0505` |
| **中断响应时间 ≠ 中断处理时间**；总中断时间 = 两者之和 | 概念题直接考 | `408-CO-0505` |
| 微程序存放在**控制存储器**（不是主存） | 位置记错 | `408-CO-0504` |
| 流水线加速比 $S=\dfrac{n\cdot k}{(k+n-1)}$（n 条指令、k 段） | 忘了分母含填充 | `408-CO-0506` |
| 时空图里**气泡要让后续段整体右移**，数周期最容易漏 | 2012 真题「17 个周期」无数人错 | `408-CO-0506` |

### 1.5 总线与 I/O

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **数据总线传「数据 + 指令 + 命令字 + 状态信息」**；控制总线传读/写/中断确认/总线请求 | 「命令字走控制总线」是错的 | `408-CO-0601` |
| **突发传输节约的是地址与命令的建立时间，每周期数据量不变** | 以为突发能提高瞬时带宽 | `408-CO-0602` |
| 同步总线的**工作频率可能 ≠ 时钟频率**（一周期传两次） | 带宽算成一半 | `408-CO-0601` |
| **「总线忙」信号由获得总线使用权的设备发出** | 细节选择题 | `408-CO-0601` |
| **DMA 的预处理与后处理由 CPU 做，数据传送由 DMA 控制器做** | 「DMA 全程不用 CPU」是错的 | `408-CO-0704` |
| **通道（I/O 处理机）比 DMA 更进一步**：能执行通道程序、管理多台设备 | 冷门概念，考过 | `408-CO-0701` |
| 程序查询 / 中断 / DMA 的 CPU 开销与适用场景对比 | 每年可能 1 题 | `408-CO-0704` |
| **单周期 CPU 一个周期内不同部件可并行**（这是它能不用总线的原因） | 与 1.4 呼应 | `408-CO-0502` |

## 二、操作系统

### 2.1 概述与运行环境

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **程序的链接与装入**：静态链接 / 装入时动态链接 / 运行时动态链接 | 大纲明文，书上一句话，选择题常考 | `408-OS-0103` |
| **运行时内存映像**（低→高）：正文 → 已初始化数据 → 未初始化数据（BSS）→ 堆 ↑ …… ↓ 栈 | 堆栈方向与段顺序容易记反 | `408-OS-0103` |
| **系统调用属于「自陷」**，处理后返回下一条指令 | 与缺页（故障）混淆 | `408-OS-0103` |
| **微内核**把文件系统、驱动放到用户态；宏内核相反 | 「微内核只留最基本功能」要知道留了什么 | `408-OS-0104` |
| 硬实时 vs 软实时（航天 = 硬，多媒体 = 软） | 冷门单选 | `408-OS-0102` |
| **虚拟机的两类 Hypervisor**（裸金属 / 宿主型） | 一句话概念 | `408-OS-0105` |

### 2.2 进程与线程

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **进程切换开销来自**：PCB 保存恢复 + **TLB 失效** + Cache 变冷 | 只答「保存上下文」拿不满 | `408-OS-0201` |
| **用户级线程**切换不进内核、一个阻塞全阻塞；**内核级线程**反之 | 调度差异是选择题常客 | `408-OS-0201` |
| **IPC 三件**：共享内存（最快，需自己同步）、消息传递、管道（半双工、内核缓冲区、只能亲缘进程） | 大纲明文，管道特性常考 | `408-OS-0201` |
| `fork` 返回两次；`exec` 不创建新进程、替换映像 | 基础但不能错 | `408-OS-0201` |
| **孤儿进程**被 init 收养；**僵尸**已终止但 PCB 未回收 | 两者定义互换 | `408-OS-0201` |

### 2.3 调度

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **周转 = 完成 − 到达；带权周转 = 周转 / 运行时间；响应 = 首次运行 − 到达** | 三个指标分母不同 | `408-OS-0202` |
| **RR 时间片过大退化为 FCFS**，过小则切换开销大 | 「时间片越小越好」是错的 | `408-OS-0202` |
| **多级反馈队列**：时间片递增、用完降级、低优先级队列可能被饿死（可用老化解决） | 规则细节多 | `408-OS-0202` |
| **优先级调度 + 单链表就绪队列：插入 $O(n)$、选出 $O(1)$** | 2025 年真题把数据结构与 OS 缝在一起考（据解析，见 §7） | `408-OS-0202` |

### 2.4 同步与互斥

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **信号量初值**：互斥量 = 1；同步量按初始资源数（空缓冲 = n、满缓冲 = 0） | 初值写反，全题崩 | `408-OS-0203` |
| **P/V 顺序不能颠倒**：先 P 资源、再 P 互斥；释放时相反 | 写反必死锁 | `408-OS-0203` |
| **读者-写者**要分清「读优先 / 写优先 / 公平」，三种写法不同 | 只背一种，换条件就错 | `408-OS-0203` |
| **哲学家**三种解法：最多 4 人同时取 / 奇偶不同顺序 / 一次拿两只 | 要能写出 PV 序列 | `408-OS-0203` |
| **管程与条件变量**：`wait` 释放锁并阻塞，`signal` 唤醒一个 | 与信号量语义混用 | `408-OS-0203` |

### 2.5 死锁

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **银行家算法**：$Need = Max - Allocation$；每步先试分配再跑安全性检查 | 漏「试分配 → 回滚」这一步 | `408-OS-0204` |
| **资源分配图可化简 ⇒ 无死锁**；不可化简才有死锁（有环不一定死锁） | 「有环就死锁」只在每类资源 1 个时成立 | `408-OS-0204` |
| 预防（破坏四条件）vs 避免（银行家）vs 检测（化简）vs 解除 | 四者手法混答 | `408-OS-0204` |

### 2.6 内存管理

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **地址翻译全流程**：TLB → 页表（多级）→ Cache → 内存；每一步都要数访存次数 | 「至少几次访存」是固定考法 | `408-OS-0301` |
| **EAT 计算**：命中快表与否两条路径按概率加权 | 漏掉「查 TLB 的时间」 | `408-OS-0302` |
| **缺页中断属于「故障」**，处理后重新执行当前指令 | 与缺页属于哪个异常类别 | `408-OS-0302` |
| **FIFO 有 Belady 异常，LRU/OPT 没有**；**改进 Clock** 用（访问位, 修改位）四类扫描 | 四类扫描顺序记不全 | `408-OS-0302` |
| **工作集**是「最近 Δ 时间内访问过的页集合」；抖动 = 缺页率过高 | 定义记成「驻留集」 | `408-OS-0302` |
| 分页 vs 分段 vs 段页式：**分页对用户透明、分段有逻辑意义** | 对比题 | `408-OS-0301` |
| 页大小的影响：太小 ⇒ 页表大；太大 ⇒ 内碎片与换入换出代价大 | 双向因果要能各说一句 | `408-OS-0301` |

### 2.7 文件管理

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **混合索引最大文件长度 = 直接区 + 一级 + 二级 + 三级，直接区最容易漏** | 据解析 2019 年第 45 题约 35% 考生漏算一级间接 | `408-OS-0402` |
| **块号占几字节由总块数决定**：$4\text{TB}/1\text{KB}=2^{32}$ 块 ⇒ 4 B 刚好够，不是 5 B | 单位进制算错 | `408-OS-0402` |
| **硬链接不能跨文件系统**（inode 号只在本文件系统唯一），软链接可以 | 2021 真题直接考这句 | `408-OS-0402` |
| **inode 不含文件名**，文件名在目录项里 | 字段归属 | `408-OS-0401` |
| FAT 是**链接分配**的变体（把指针集中成表），不是索引分配 | 分类错 | `408-OS-0402` |
| 空闲空间管理：位示图 / 成组链接（UNIX）/ 空闲链表 | 成组链接的「组」细节 | `408-OS-0402` |
| **磁盘调度的初始磁头位置必须看题干给的数**，不许自己假设 | 据解析 2016 年第 42 题，自行假设初始位置导致全错 | `408-OS-0403` |
| SCAN 到端点才折返，LOOK / C-LOOK 到最远请求就折返 | 三者混答 ⇒ 移动距离差很多 | `408-OS-0403` |

### 2.8 I/O 管理

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **缓冲时间计算**：单缓冲的处理时间 = max(C, T) + M；双缓冲 ≈ max(C+M, T) | 公式记混，这是标准计算题 | `408-OS-0502` |
| **SPOOLing 是「虚拟设备」技术**，用磁盘模拟独占设备 | 概念题 | `408-OS-0502` |
| I/O 软件四层：用户层 → 设备独立性软件 → 驱动程序 → 中断处理程序 | 顺序错 | `408-OS-0501` |
| **阻塞 / 非阻塞 / 同步 / 异步 I/O** 四个词的区别 | 大纲新增接口条目 | `408-OS-0501` |

## 三、数据结构

### 3.1 线性表 / 栈 / 队列 / 串

| **有重特征值 ≠ 不可对角化**，要验证 $n-r(\lambda E-A)$ 是否等于代数重数 | 见「重根」就判不可对角化 | `M1-LA-0502` |
| $k$ 重特征值对应的线性无关特征向量个数 $\le k$ | 以为一定等于 $k$ | `M1-LA-0501` |
| **实对称**不同特征值的特征向量正交；**普通矩阵**只是线性无关 | 对普通矩阵也用正交 | `M1-LA-0503` |
| **二次型矩阵必须对称**：给非对称矩阵先取 $\frac{A+A^T}{2}$ | 直接用非对称矩阵求特征值，整题白算 | `M1-LA-0601` |
| **标准形不唯一，规范形唯一**（由正负惯性指数决定） | 说「标准形唯一」 | `M1-LA-0601` |
| 配方法必须是**可逆线性变换**；正交变换法遇重根要**正交化 + 单位化** | 重根忘了施密特 | `M1-LA-0601` |
| 齐次基础解系 $n-r$ 个；非齐次通解 = 特解 + 齐次通解（共 $n-r+1$ 项） | 个数差 1 | `M1-LA-0401` |
| 两个非齐次特解**之差**是齐次解；**之和的一半**是非齐次特解 | 常考小结论 | `M1-LA-0402` |
| 克拉默法则**只对方阵且 $|A|\ne0$** | 乱用 | `M1-LA-0402` |
| 极大无关组**不唯一**，但含向量个数 = 秩 | 说唯一 | `M1-LA-0302` |
| 含零向量必相关；两个向量成比例必相关；向量个数 > 维数必相关 | 判定条件不全 | `M1-LA-0301` |

### 5.3 概率论与数理统计

| 要点 | 为什么丢分 | KP |
|---|---|---|
| **两两独立 ≠ 相互独立**（反例必记） | 只证两两 | `M1-PS-0104` |
| **不相关 ⇏ 独立**；**二维正态是唯一例外**（不相关 ⇔ 独立） | 把「不相关」当「独立」 | `M1-PS-0302` |
| 正态变量的线性组合仍正态，**前提是独立或联合正态** | 无条件使用 | `M1-PS-0202` |
| 求函数分布**先看单调性**，非单调必须用分布函数法 | 直接套密度公式 | `M1-PS-0203` |
| 卷积 $Z=X+Y$：**积分限要按支撑集分段**，代换别丢雅可比 | 上下限画错 | `M1-PS-0303` |
| $\max/\min$：$F_{\max}=F^n$，$F_{\min}=1-(1-F)^n$ | 与密度混用 | `M1-PS-0303` |
| $E(XY)\ne E(X)E(Y)$（除非独立）；$D(X+Y)=DX+DY+2\mathrm{Cov}$ | 无条件拆 | `M1-PS-0401` |
| $D(aX)=a^2DX$；$E(X^2)\ne (EX)^2$ | 平方位置 | `M1-PS-0402` |
| 相关系数分母是 $\sqrt{DX}\sqrt{DY}$（别忘开根号） | 忘根号 | `M1-PS-0402` |
| **期望存在 ≠ 方差存在**（柯西分布是反例） | 认为有期望就有方差 | `M1-PS-0402` |
| 切比雪夫不等式要取 $|X-EX|\ge\varepsilon$ 的绝对值 | 漏绝对值 | `M1-PS-0501` |
| 中心极限定理标准化分母是 $\sqrt{n}\,\sigma$ | 写成 $\sigma$ 或 $\sqrt n$ | `M1-PS-0502` |
| 二项近似正态要**连续性修正**（$\pm0.5$） | 直接用 | `M1-PS-0502` |
| $S^2$ 分母是 $n-1$ 才无偏；$E(S^2)=\sigma^2$ | 分母写 $n$ | `M1-PS-0601` |
| **有效性比较必须建立在无偏前提下** | 直接比方差 | `M1-PS-0702` |
| 最大似然：离散用分布律、连续用密度；**均匀分布要按 $\max X_i$ 取边界，不能求导** | 硬求导得不出 | `M1-PS-0701` |
| **枢轴量的分布不能含未知参数**；方差已知用 $Z$、未知且小样本用 $t$ | 选错统计量 | `M1-PS-0703` |
| **置信水平不是「参数落在区间内的概率」**（参数是常数） | 概念表述错，扣分 | `M1-PS-0703` |
| **拒绝域方向由备择假设决定**；上侧/双侧分位数别混 | 方向反了结论反 | `M1-PS-0801` |
| $\alpha$ 减小 ⇒ $\beta$ 增大；样本量增大两者都减小 | 单向推理 | `M1-PS-0801` |

## 八、怎么用这份清单

1. **第一遍：通读打勾**。每条只问自己一句「我知不知道」，不要求会做。约 2 小时。

   这份清单应该越用越长，直到考试前一周封版。
