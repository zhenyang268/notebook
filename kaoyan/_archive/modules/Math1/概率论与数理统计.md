- **它是高数的客户**：连续型的密度积分、卷积、期望方差全是**一元/二重积分**；最大似然要**求导求极值**；多维正态与相关系数矩阵要**线代的二次型与正定**。
- **数一 vs 数三**：数一考**假设检验**、**区间估计**要求更高、多维连续型的函数分布（卷积、max/min）考得深；数三偏经济应用且**不考假设检验**。别拿数三资料当数一复习。

### 0.2 设计层（②）—— 这门课是被什么逼出来的

- 概率论的起点是**赌博问题**（帕斯卡–费马通信，1654）：分赌注问题逼出期望的概念。
- 古典概型（有限等可能）撑不住连续场景，**几何概型**又被**贝特朗悖论**打脸（"随机取一条弦"的答案随"随机"的定义而变）→ 柯尔莫哥洛夫 1933 年用**测度论公理化**（非负、规范、可列可加）把概率钉死。
- 数理统计是概率的**反问题**：概率是"已知模型求事件概率"，统计是"已知数据反推模型参数"——方向反过来了，这就是估计与检验存在的理由。

## 块1 随机事件与概率 ★核心（2026-10-14 展开）

### 必考点清单

1. 事件的关系与运算（并 / 交 / 差 / 对立、互斥、德摩根律）
2. 概率三公理与推导性质（减法公式、加法公式、对立）
3. 古典概型（有限等可能）：抽球、分房、配对、可重复排列
4. 几何概型（长度 / 面积 / 体积比）：会面问题、截段成三角形
5. **互斥 vs 独立的辨析**（高频陷阱）
6. 概率不等式与范围估计（P(AB) 的上下界）

### 1.1 机制层（①）

**公理（柯尔莫哥洛夫）**：非负性 P(A) ≥ 0；规范性 P(Ω) = 1；**可列可加性**——两两互斥的事件之并，概率等于概率之和。
- 直觉：概率就是给样本空间 Ω 的子集**分配面积**，总面积 1。

**事件运算 ↔ 集合运算 ↔ 逻辑**：并 = 或、交 = 且、对立 = 非、差 A−B = A 发生且 B 不发生。
- **德摩根律**：`∪Aᵢ` 的对立 = `∩Āᵢ`；`∩Aᵢ` 的对立 = `∪Āᵢ`。（"都不发生" = "至少一个发生"的反面）

**四条常用公式**（由公理推出，必须能默写）：
- 对立：P(Ā) = 1 − P(A)
- 减法：P(A − B) = P(A) − P(AB)　（A−B 与 AB 是 A 的一个划分）
- 加法：P(A∪B) = P(A) + P(B) − P(AB)　（AB 被数了两遍）
- 三事件：P(A∪B∪C) = P(A)+P(B)+P(C) − P(AB) − P(BC) − P(CA) + P(ABC)

**互斥 vs 独立**（本块最大陷阱）：

| | 定义 | 性质 |
|---|---|---|
| 互斥 | AB = ∅（集合关系，与概率值无关） | P(A∪B) = P(A)+P(B) |
| 独立 | P(AB) = P(A)P(B)（概率关系） | 独立时 P(A|B) = P(A) |

- **互斥且 P(A), P(B) > 0 ⟹ 必不独立**：因为 P(AB) = 0 ≠ P(A)P(B) > 0。"互斥"说的是不能同时发生，"独立"说的是互不影响——恰恰相反。

**古典概型**：样本点有限且等可能，P(A) = |A| / |Ω|。计数工具：组合（不放回）、可重复排列（有放回 / 分房）、多项式系数（分组）。
- **判别手势**：先问"什么是等可能的基本结果"——分房问题里基本结果是"每个球的落点序列"（N^n 种），不是"各盒球数的分布"。

**几何概型**：P(A) = A 的测度 / Ω 的测度（长度、面积、体积）。
- **前提**：必须是对**几何测度均匀**——否则会掉进贝特朗悖论。真题里的"随机"默认对长度/面积均匀。

### 1.2 设计层（②）

- **为什么要公理化**：古典概型只能处理有限等可能；几何概型里"随机"的含义不唯一（贝特朗悖论给出 1/2、1/3、1/4 三个答案）。公理体系把"概率是什么"变成"概率必须满足什么"，才谈得上推定理。
- **为什么加法公式要减 P(AB)**：容斥原理——交集在两边各被数了一次。三事件公式就是容斥的二阶展开，规律是"奇加偶减"。
- **为什么强调"零概率事件 ≠ 不可能事件"**：连续场景下取到某一点的概率是 0，但它可能发生（几何概型里每个点概率都是 0，可总有一个点被取到）。这条是概念判断题的固定弹药。
- **现实视角与边界**：公理体系本身考研只在**概念判断题**里出现，不要求默写证明；得分动作是套公式与计数。

### 1.3 验收层（③）—— 题型清单

| # | 题型 | 模板要点 | 优先级 |
|---|---|---|---|
| 1 | 用运算表示事件 / 德摩根化简 | "至少一个" = 1 − "全不"；"恰好一个" 分情况加 | ★核心 |
| 2 | 给 P(A)、P(B)、P(A∪B) 或 P(A−B) 推其他 | 先求 P(AB) = P(A)+P(B)−P(A∪B)，再用减法公式 | ★核心 |
| 3 | 独立性验证 | **必须算 P(AB) 与 P(A)P(B) 比数值**，不能凭"看起来无关" | ★核心 |
| 4 | 古典概型计数 | 先定基本结果空间（等可能的是什么）→ 有利数 / 总数 | ★核心 |
| 5 | 几何概型 | 画区域 → 面积比 → 定积分或初等几何算面积 | ★核心 |
| 6 | 概率范围估计 | 0 ≤ P(AB) ≤ min(P(A),P(B))；P(A∪B) ≤ P(A)+P(B) | ☆常规 |

**易错点**：
- 独立性**不验证**就下结论（数值接近但不是相等，照样不独立）。
- 分房问题用错样本空间（把"每盒球数的组合"当基本结果 → 不等可能，全错）。
- 减法公式写成 P(A−B) = P(A) − P(B)（漏掉 AB，只有 B⊂A 时才对）。
- "互斥"和"独立"混为一谈（互斥是更强的"不相容"，与独立几乎对立）。
