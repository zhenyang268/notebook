## 一、三条铁律

### 铁律 0：四层分工（2026-11-04 定；旧的「六层」与「exam 分章讲义」已废）

```
syllabus/  L0 坐标：一个 KP 一行（7 列，末列 = 掌握度）；一章一段真题落点
note/      L1 内容：一个考点一个文件 = 考法 + 思路 + 坑 + 真题原题（唯一允许长内容的地方）
quick/     L2 主线：一科一份叙述（概括版 + 口语版），不重复考纲表
exam/真题/  L3 题库：题干 + 思路 + 坑；题干唯一真源
drill/     L4 拔高：按题号 / 题型线组织的计算题，冲刺满分用
```

**判断新内容该放哪**，只有一条判据：**它回答哪个问题？**

| 内容 | 放哪 |
|---|---|
| 考什么、要哪档、考过哪几年、我到现在哪档 | `syllabus/`（状态写最后一列） |
| 这个考点怎么考、有什么坑、真题长什么样 | `note/`（题干内嵌） |
| 这一科的整体主线、为什么这样设计 | `quick/` |
| 某年某题考什么 | `exam/真题/<年>.md` |
| 满分档的计算题 | `drill/` |

**没有第五个地方。** 讲不通就说明它不该进库（见 `BOUNDARY.md` §5）。
`note/` 与 `drill/` 分工是**组织维度不同**：`note/` 按考点聚类（这类题往哪想），`drill/` 按题号线排坡
（这一档会不会、下一档差在哪）。**难度是题的性质，不是知识点的性质**。

### 铁律 1：两把粒度锁

- **`note/`：一个考点 = 一个文件**（`<KP>-<考点名>.md`），按考法聚类去重。
- **`drill/`：一条题型线 = 一个文件**（`41-…` `47-…` / `01-…` `07-…`）。

旧的「`exam/` 一章一文件」已废除（2026-11-04）：它与 `note/` 是同一件事的两种切法，
并存必然重复；分章讲义已归档到 `_archive/exam-lectures-2026-11-04/`。
**装不下 = 说明考点划得不对**，回 `syllabus/` 调整，别往一个文件里堆。

### 铁律 2：双线物理隔离，单向引用

| | `note/` 考试线（本目录） | `../projects/` 工程线（服务面试） |
|---|---|---|
| 目的 | 拿分 | 兴趣与能力 |
| 内容 | 只有考纲里的东西 | 项目设计、代码、调试、复盘 |
| 能不能提对方 | **不写工程细节**。允许一行 `> 工程锚点：projects/xxx.md` 做指针 | **只写 KP 号 + 考点名**，禁止复制 `note/` 正文 |

- 工程线已全部在仓根 `../projects/`（2026-11-02 并入），**本目录不再有 projects**。
- 项目文档两件套 + 第五节 `## 五、面试怎么讲`，规约见 `../projects/README.md`。

### 铁律 3：状态与内容分离，状态必须有证据

- **掌握度不写进正文**。`note/` 只管「怎么考」；档位只在 `syllabus/` 主键表最后一列（M0–M4），
  用 `python3 tools/mastery.py --set <KP> <档>` 记账。（旧 `reviews/` 的到期调度已删：20 条 `R1 待` 7 天零推进。）
- **M2 以上必须有证据**：哪道题、哪天默写的。给不出 → 最高记 `M1`。
- **进度不写进正文**。正文文件头只留「章 / 档位 / 真题落点」这类**静态身份信息**，
  不写「已归档」「学到哪了」；进度进 `PROGRESS.md`，改动进 `CHANGELOG.md`。
- **事实字段不许手写**：真题年份与题号只能来自 `exam/真题/` 里实际存在的那几年
  （当前 2016–2024，共 360 道选择题），写「本章无对应题目」也比分不清真假强。

## 三、三种文件的骨架

**note 考点（一考点一文件，唯一内容层）**

```markdown
# <KP> <考点名>

> 章：<章号 章名>　｜　档位：掌握　｜　真题落点：N 题：2021 #15、#16；…

## 考法 1：<这类题的特征，一句话>
**思路**：往哪想 + 关键一步
**坑**：最容易错的那一步

## 考法 2：…

---

## 真题原题（共 N 题）

> 题干照录自 `exam/真题/`（考生回忆版）；先做，做完再看下面思路。

### 2021 #16　<标题>
<题干 + 选项>
**思路**：…
**坑**：…
```

> 真题段由 `exam/真题/` 按 KP 内嵌（2026-11-04 起）：**题干只有 `exam/真题/` 一处作者**，
> 这里是副本；改题干先改源头再同步。**不写答案字母**（做了自己算）。
> 本考点 2016–2024 无题时，落点写「本考点 2016–2024 无对应题目」，不硬凑。
> 数一无真题，落点写「真题库未收录数学一，按常见考法组织，不冒充原题」。
> 反查（错题 → KP）看 `exam/真题/题号-KP对照.md`。

> `**思路**` 与 `**坑**` 必须**一一配对**，思路几条坑就几条——脚本按这个数校验。

**quick 一份（一科一份）**

```markdown
# <科目> · 快速学完

## 第一部分 · 考纲依据（扫一眼）
## 第二部分 · 概括版（半小时，一口气读完）
## 第三部分 · 口语版（最难的点讲透）
```

**要求**：
- 缺失部分写「待补充」，**不编造**（尤其真题年份、题号、大纲页码）。
- 公式用 KaTeX：行内 `$…$`、独占行 `$$…$$`；不写 Unicode 上下标。
- 图用 **Mermaid**（`flowchart` / `stateDiagram-v2` / `sequenceDiagram` / `gantt`），不贴图片文件。
- 考场要手画的样子另起一段「考场画法」，见 `TOOLKIT.md`。

## 四、归档流程

1. **定位 KP**：先在 `syllabus/` 里找这一条落在哪一节。找不到 → 不建文件，进 `temp.md` 标 `[待归类]`；
   是否新增 KP 由用户决定（**KP 只能由 `syllabus/` 增加，不能由内容倒推**）。
2. **读目标文件**（`note/<KP>-<考点名>.md`，不存在按 §三 骨架新建）。
3. **追加**到对应 `##` 小节末尾；新知识点另起 `##`。
4. **内嵌真题**：该考点有真题 → 在文末「真题原题」段放**题干副本**（从 `exam/真题/` 照录），头部落点写真实题数；没有就写「本考点 2016–2024 无对应题目」，不编造。
5. **追加 `CHANGELOG.md`** 一条：`- YYYY-MM-DD · 408 / 网络 / 05-05 · 慢开始逐轮表格法`。
6. **记掌握度**（只有做题/默写之后才记）：`python3 tools/mastery.py --set 408-NET-0505 M2`。
7. 跑 `python3 tools/lint.py` 自检（0 错才算完成）。

**只追加，不改写历史**：错的地方不要就地改，另起 `> **修正（YYYY-MM-DD）**：…`，
让错误本身留下（它是复习素材）。唯一例外是路径失效与格式错误。

## 五、归属判定

```
1. 对话在谈考试内容吗？
   是 → 2　　否（在谈项目 / 代码 / 调试）→ ../projects/<项目>/NOTES.md
2. 能对上 syllabus/ 里的哪个 KP？
   能 → note/<该 KP 的文件>.md（文件列已写好路径，直接照抄）
   不能 → temp.md，标题加 [待归类]
3. 一段话跨两个 KP？→ 拆两段各归各的
   （例：滑动窗口的两条约束 → TCP 的进 408-NET-0504，链路层 GBN 的进 408-NET-0303）
4. 一句里既有考点又有工程实现？
   → 考点进 note/，工程那半句只留 `> 工程锚点：projects/...`（指向仓根 projects/）
```

**双归属点（两边互写一行「见」指针，不复制正文）**：

| 主题 | 主文件 | 互见 |
|---|---|---|
| 虚拟存储器 | `408-OS-0301/0302`（策略侧） | `408-CO-0306`（硬件转换侧） |
| 磁盘调度 | `408-OS-0403` | `408-CO-0304`（结构参数） |
