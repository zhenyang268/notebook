## 一、三条铁律

### 铁律 0：五层分工（2026-11-02 定）

```
syllabus/  L0 考纲：一个 KP 一行 + 每章「档位 / 真题落点 / 一课位置」（坐标系，唯一）
quick/     L1 速通：一科一份（共 9 份），三合一 = 考纲表 + 概括版 + 口语版
note/      L2 复合：一个考点一个文件，考点 × 真题，只写思路与坑、不写答案
exam/      L3 详解：一章一个文件，四段（考点与档位 / 正文 / 真题落点 / 易错清单）
words/     L4 词汇：30 主题组（词表 + 短文）+ 大纲补全表 5530 词
```

**判断新内容该放哪**，回到「五步复习流程」这张唯一判据：

| 步 | 做什么 | 文件 |
|---|---|---|
| 1 | 研究考纲：考什么、要求到哪档 | `syllabus/` |
| 2 | 读口语解释：建立直觉 | `quick/` |
| 3 | 看考点与真题的复合版 | `note/` |
| 4 | 刷整套真题（题干 + 思路） | `exam/真题/<年份>.md` |
| 5 | 深挖一章 | `exam/<科>/NN-章名.md` |

`quick/` **不写完整推导、不做题型训练**（那是 `exam/` 的活）；`note/` **不写答案**。

### 铁律 1：两把不同的粒度锁

- **`note/`：一个考点 = 一个文件**（`<KP>-<考点名>.md`）。这是复习的第 3 步，按考法聚类去重。
- **`exam/`：一章 = 一个文件**（`NN-<章名>.md`）。这是第 5 步，章内所有考点合在一起讲。

旧版把 `exam/` 也做成「一个 KP 一个文件」，结果是 24 个碎文件、讲不成一条线，2026-11-02 改为一章一文件。
**装不下 = 说明章划得不对**，回 `syllabus/` 调整章结构，别往一个文件里堆。

### 铁律 2：双线物理隔离，单向引用

| | `exam/` 考试线 | `projects/` 工程线 |
|---|---|---|
| 目的 | 拿分 | 兴趣与能力 |
| 内容 | 只有考纲里的东西 | 项目设计、代码、调试、复盘 |
| 能不能提对方 | **不写工程细节**。允许一行 `> 工程锚点：projects/xxx.md` 做指针 | **只写 KP 号 + 考点名**，禁止复制 `exam/` 正文 |

- `projects/` 每个文件顶部必须有「对位考点（单向引用）」表。
- `tools/lint.py` 检查：`exam/` 正文出现工程仓名（CS144 / CS149 / CSAPP / nand2tetris / 6.824 / jos / craft）
  → **提示级**（不阻断，供清理）；`projects/` 大段复制 `exam/` 正文 → 提示。

### 铁律 3：状态与内容分离

- **复习档位不写进正文**。正文只管知识；档位、到期日、通过与否全部在 `reviews/REVIEWS.md`。
  （旧机制往 cell 末尾追加「复习计划」行：88 个 cell 里 43 个漏填，61 个档位 58 个逾期。）
- **进度不写进正文**。正文文件头只留「章 / 档位 / 真题落点」这类**静态身份信息**，
  不写「已归档」「学到哪了」；进度进 `PROGRESS.md`，改动进 `CHANGELOG.md`。
- **事实字段不许手写**：真题年份与题号只能来自 `exam/真题/` 里实际存在的那几年
  （当前 2021–2024，共 160 道选择题），写「本章无对应题目」也比分不清真假强。

## 三、三种文件的骨架

**exam 章（一章一文件）**

```markdown
# <章号> <章名>

## 一、本章考点与档位
| KP | 名称 | 档位 | 真题落点 |

## 二、正文
概念 → 推导 → 例题（完整计算过程）

## 三、真题落点
只写实测年份题号，或「本年段无对应题目」

## 四、易错清单
「错在哪一步 → 正确做法」，3–8 条
```

**note 考点（一考点一文件）**

```markdown
# <KP> <考点名>

> 章：<章号 章名>　｜　档位：掌握　｜　真题落点：…

## 考法 1：<这类题的特征，一句话>
**思路**：往哪想 + 关键一步
**坑**：最容易错的那一步

## 考法 2：…
```

> `**思路**` 与 `**坑**` 必须**一一配对**，思路几条坑就几条——脚本按这个数校验。

**quick 一份（一科一份）**

```markdown
# <科目> · 快速学完

## 第一部分 · 考纲依据（扫一眼）
## 第二部分 · 概括版（半小时，一口气读完）
## 第三部分 · 口语版（最难的点讲透）
```

**要求**：
- 缺失部分写「待补充」，**不编造**（尤其真题年份、题号、大纲页码）。
- 公式用 KaTeX：行内 `$…$`、独占行 `$$…$$`；不写 Unicode 上下标。
- 图用 **Mermaid**（`flowchart` / `stateDiagram-v2` / `sequenceDiagram` / `gantt`），不贴图片文件。
- 考场要手画的样子另起一段「考场画法」，见 `TOOLKIT.md`。

## 四、归档流程

1. **定位 KP**：先在 `syllabus/` 里找这一条落在哪一节。找不到 → 不建文件，进 `temp.md` 标 `[待归类]`；
   是否新增 KP 由用户决定（**KP 只能由 `syllabus/` 增加，不能由内容倒推**）。
2. **读目标文件**（存在则读；不存在按 §三 骨架新建）。
3. **追加**到对应 `##` 小节末尾；新知识点另起 `##`。
4. **登记 `reviews/REVIEWS.md`**：首次归档 → 加一行，R1 = 明天；已有 → 更新档位。
5. **追加 `CHANGELOG.md`** 一条：`- YYYY-MM-DD · 408 / 网络 / 05-05 · 慢开始逐轮表格法`。
6. **更新 `PROGRESS.md`**：只动自己那一行与「下一站」。
7. 跑 `python3 tools/lint.py` + `python3 HANDOFF/tools/verify.py kaoyan/note` 自检
   （覆盖率不到 100% 不算完成，缺哪几条要逐条列名）。

**只追加，不改写历史**：错的地方不要就地改，另起 `> **修正（YYYY-MM-DD）**：…`，
让错误本身留下（它是复习素材）。唯一例外是路径失效与格式错误。

## 五、归属判定

```
1. 对话在谈考试内容吗？
   是 → 2　　否（在谈项目 / 代码 / 调试）→ projects/<项目>.md
2. 能对上 syllabus/ 里的哪个 KP 节？
   能 → exam/<科目>/<子科>/<该 KP 的文件>.md
   不能 → temp.md，标题加 [待归类]
3. 一段话跨两个 KP？→ 拆两段各归各的
   （例：滑动窗口的两条约束 → TCP 的进 05-04，链路层 GBN 的进 03-03）
4. 一句里既有考点又有工程实现？
   → 考点进 exam/，工程那半句只留 `> 工程锚点：projects/...`
```

**双归属点（两边互写一行「见」指针，不复制正文）**：

| 主题 | 主文件 | 互见 |
|---|---|---|
| 虚拟存储器 | `408-OS-0301/0302`（策略侧） | `408-CO-0306`（硬件转换侧） |
| 磁盘调度 | `408-OS-0403` | `408-CO-0304`（结构参数） |
| 中断与异常 | `408-OS-0103`（OS 视角） | `408-CO-0505`（CPU 视角） |
| I/O 方式 | `408-CO-0704`（硬件） | `408-OS-0501`（软件层次） |
| CRC | `408-NET-0302`（链路用法） | `408-CO-0203`（编码原理） |
| 红黑树 / B+ 树 | `408-DS-0605` / `0606` | `408-DS-0600`（共同动机） |
