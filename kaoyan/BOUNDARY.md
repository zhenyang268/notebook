# BOUNDARY.md — 这个库的职责边界（唯一真源）

> 2026-11-04 定。冲突时以本文件为准；本文件只回答「该不该有」，不回答「怎么学」。
> 范围：**只有 408 与数学一**。英语、政治移出主线（归档在 `_archive/off-scope/`）。

---

## 一、一句话

**这个库负责「定位」和「记账」，不负责「教你」，也不负责「排期」。**

拔高冲刺靠纸质真题与模拟卷，用户自己做；库只提供三件事：
① 考纲与考点在哪（坐标）；② 这个考点怎么考、坑在哪（查漏补缺）；③ 我现在到哪一档（掌握度）。

---

## 二、四层职责（每层只回答一个问题）

| 层 | 只回答 | 输入 | 输出 | 不许做 |
|---|---|---|---|---|
| `syllabus/` | 考什么、要哪档、真题落点、我现在到哪档 | 考纲 | KP 主键表（7 列，末列=掌握度） | 不写讲解、不排期 |
| `note/` | 这个考点怎么考、错在哪 | 真题 + 做题反馈 | 一考点一文件：考法 / 思路 / 坑 / 真题原题（内嵌） | 不给答案字母、不做难度分档 |
| `quick/` | 这一科的主线是什么 | 考纲 | 每科一份叙述（概括版 + 口语版） | 不重复考纲表、不做题型训练 |
| `exam/真题/` | 这道题考什么 | 回忆版原题 | 题干 + 思路 + 坑 + 章标注 | 不收综合题原卷、不再扩年份 |
| `drill/` | 满分那道坎怎么过 | — | 拔高题线（按题号 41–47 / 数一题型线）+ `calc/` 计算必备清单（不分难度） | 不做模板默写（那是 note 的活）；408 不许新增题号线 |
| `_archive/` | 回滚与取证 | — | 归档件 | 不参与任何统计 |

已删除：`reviews/`（到期调度）、`tools/review.py`、`exam/{408,math1,english1,politics}/`（讲义正文）、`words/`。

## 三、文件从哪来、到哪去

```
课本章节（纸质辅导书）
   └─ syllabus/<科>.md 主键表：章 → KP → 文件列（指向 note/）→ 真题落点 → 掌握
        └─ note/<KP>-<考点>.md：考法 + 思路 + 坑 + 真题原题（题干从 exam/真题/ 照录）
             └─ exam/真题/<年>.md：题干 + 思路 + 坑（做完回来看）
                  └─ 做题结果 → 改 syllabus 主键表的「掌握」列（唯一状态）
```

这条链是**双向**的：正向查「这个考点考过哪几年」；反向查「错的是第几题 → 哪几个 KP」——反向靠
`exam/真题/` 每题的 `→ \`章代码\`` 标注 + `tools/landing.py` 生成的落点行。

## 四、掌握度五档（取代 reviews/）

| 档 | 判据 | 证据（必填，写在 CHANGELOG 或由 `--set` 一步记） |
|---|---|---|
| `M0` | 没读过这一条 | — |
| `M1` | 看到题能说出考什么 | 题目题号 |
| `M2` | 不看资料能默出公式 / 模板 / 流程 | 「默写」+ 日期 |
| `M3` | 同类真题**限时**做对 | `2019 #23` |
| `M4` | 综合题按评分点拿满 | `2019 #41` + 步骤分 |

三条硬规矩：

1. **M2 以上必须有证据**，无证据最高记 `M1`。（治「归档 20 个、验收 0 个」）
2. **不写「下次复习日」**。什么时候再碰由做题结果决定，不由日历决定。
3. **只有一种统计**：M0–M4 各多少个 KP。仓库的验收指标是「M3 以上几个」，不是「覆盖率 100%」。

记账：`python3 tools/mastery.py --set 408-CO-0305 M3`；总览：`python3 tools/mastery.py`。

## 五、明确不做

| 不做 | 原因 |
|---|---|
| 排期 / 阶段日历 / 「下一站三选一」 | 用户定节奏；排了也不会执行（旧 `reviews/` 20 条 `R1 待` 7 天零推进） |
| 讲义正文（分章讲解） | 纸质辅导书已有；库里的讲义只能重复，且会诱导继续写 |
| 抄真题题干进 `note/` | 题干只允许一处真源（`exam/真题/`），两处必然漂移 |
| 原创变式题的「模板默写档」 | 属于 `note/` 的考法，不属于拔高 |
| 英语 / 政治 / 单词书 | 用户自述英语自学与在库内学效果相同；政治自主刷题判卷 |
| 自动批改 / 通用判分器 | 改一个数就失效，成本高于收益 |
